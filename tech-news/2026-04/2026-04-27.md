## 本日のニュース TOP 3

### 1. Windows Defender トリプルゼロデイ — BlueHammer・RedSun・UnDefend が実環境で連鎖悪用
4月中旬から下旬にかけて、Windows Defenderを標的とする3件のゼロデイ脆弱性（BlueHammer / RedSun / UnDefend）が相次いで公開され、Huntress Labsがいずれも実環境での悪用を確認した。BlueHammer（CVE-2026-33825、CVSS 7.8）はDefenderのファイル修復ロジックのレースコンディションを突き、無権限ユーザーからSYSTEM昇格を可能にする。4月のPatch Tuesdayでパッチが提供されたBlueHammerとは異なり、RedSunとUnDefendは4月27日時点で未修正のまま実攻撃に利用されている。3脆弱性はチェーン利用されており、UnDefendがDefenderの脅威インテリジェンスを静かに劣化させた状態でRedSunがSYSTEM昇格を行うという、防御回避と権限昇格を組み合わせた巧妙な攻撃シナリオが確認されている。

### 2. 米中AIチップ摩擦に転換点 — ホワイトハウスがNvidiaの対中輸出を条件付き承認、議会は反発
米商務省が2026年前半に打ち出した輸出規制の「再調整」の一環として、ホワイトハウスがNvidiaの高性能チップを一定条件のもと中国向けに輸出する方針を承認したとFinTech Weeklyが報じた。トランプ大統領の訪中に向けた貿易協議を優先する判断とみられ、従来の厳格な規制路線からの転換となる。一方、議会では輸出ライセンスへの議会関与を求める動きが強まっており、行政と立法の綱引きが続く。McKinseyの最新レポートによれば、AI関連貿易は2025年比40%増と、世界平均の6.5%を大幅に上回るペースで成長しており、チップサプライチェーンが地政学的競争の中心軸に据えられている状況に変化はない。

AnthropicがClaude Mythos Previewを約50のパートナー組織に限定公開した。入力$25/出力$125 per million tokensという高額設定ながら、「Claude Opus 4.6からのステップチェンジ」と公式に位置づけられる。Opus 4.6自体はLMSYS Chatbot ArenaでGPT-5.4やGemini 3.1 Proを抑えて首位に立ち、SWE-bench Verifiedで65.3%を記録するなどコーディングエージェント分野での存在感が高まっている。一方、3月末に発生したClaude Codeのソースコードリーク（約51.2万行のTypeScriptコードが誤ってnpmパッケージに同梱）は引き続き開発者コミュニティで話題となっており、Anthropicはオープンウェイト公開ではなく誤包含であったと説明している。

## 新技術・新リリース

### Rust 1.95.0 — `cfg_select!` マクロ安定化とif letガード正式対応
4月16日にリリースされたRust 1.95.0は、人気のサードパーティcrateである`cfg-if`の公式代替となる`cfg_select!`マクロを安定化した。コンパイル時のcfgに基づくパターンマッチ分岐が言語標準機能として利用可能になり、条件付きコンパイル記述のボイラープレートが大幅に削減される。加えて、matchアームでの`if let`ガードが正式サポートされた。PowerPC/PowerPC64向けのインラインアセンブリ安定化と`powerpc64-unknown-linux-musl`のTier 2昇格も含まれており、組み込み・クロスコンパイル用途での活用範囲が広がる。

```rust
// cfg_select! の基本的な使い方（1.95.0より安定化）
cfg_select! {
    target_os = "linux" => {
        fn platform_name() -> &'static str { "linux" }
    }
    target_os = "macos" => {
        fn platform_name() -> &'static str { "macos" }
    }
    _ => {
        fn platform_name() -> &'static str { "other" }
    }
}

// if let ガードの正式サポート
fn process(opt: Option<i32>) {
    match opt {
        Some(x) if let Some(y) = extra_check(x) => {
            println!("matched with y = {y}");
        }
        _ => {}
    }
}
```

## セキュリティ

### Windows Defender Triple Zero-Day — UnDefendとRedSunが4月27日時点で未パッチ
前述のBlueHammer（CVE-2026-33825）はMicrosoftの4月Patch Tuesdayで修正済みだが、RedSunとUnDefendは完全にパッチが適用されたWindows 10・11・Server 2019以降でも動作することが確認されており、依然として未修正のまま実攻撃に利用されている。攻撃チェーンの概要は以下のとおり: UnDefendがDefenderの更新パイプラインを妨害してセキュリティ検知能力を静かに劣化させ（管理コンソールには正常と表示されたまま）、次いでRedSunがDefenderのクラウドタグ付きファイル処理を悪用してシステムパスを上書き、SYSTEM権限を奪取する。未パッチシステムへの対策として、セキュリティ専門家はDefenderのクラウドベース保護を最高レベルに設定し、異常なDefender更新失敗ログの監視を推奨している。

### LMDeploy SSRF（CVE-2026-33626）— 開示後13時間未満で実悪用
LLMの圧縮・デプロイ・サービングを担うオープンソースツールキット「LMDeploy」でServer-Side Request Forgery脆弱性（CVE-2026-33626、CVSS 7.5）が公開され、公開から13時間未満で実環境悪用が確認された。LLMサービングインフラがクラウド内部ネットワークやメタデータエンドポイントへのアクセス経路となり得るため、AIモデルをセルフホストする開発者・組織は即時パッチ適用が求められる。CISAも同脆弱性をKnown Exploited Vulnerabilities（KEV）カタログに追加している。
