## 本日のニュース TOP 3

### 1. DeepSeek V4、Huawei チップ上で動作する初のフロンティア AI モデルに
Reuters が 4月4日に報じたところによると、DeepSeek V4 は Huawei の Ascend 950PR チップ上で稼働する初のフロンティア AI モデルとなる。総パラメータ数は1兆（1T）だが、推論時にアクティベートされるのは約 37B のみで、実質的な推論速度は 37B モデル並みに軽量。テキスト・画像・動画をネイティブに扱うマルチモーダルモデルで、SWE-bench 81% を記録。訓練コストは推定 $5.2M と報告されており、中国の半導体インフラ上で米国フロンティアモデルに匹敵する性能を実現したことが業界に衝撃を与えている。

### 2. Fortinet FortiClient EMS の緊急パッチ — CVSS 9.8 の RCE がゼロデイ悪用中
Fortinet は CVE-2026-35616（CVSS 9.8）に対する緊急パッチを公開した。FortiClientEMS 7.4.5/7.4.6 の API エンドポイントにおける不適切なアクセス制御が原因で、認証不要・ネットワークリクエスト1つでサービスアカウント権限での任意コード実行が可能。watchTowr のハニーポットでは 3月31日から攻撃が観測されており、CISA も連邦機関に即時パッチ適用を指示。セキュリティチームは緊急ホットフィックスの適用後、7.4.7 以上へのアップグレードを計画すべきとされている。

### 3. 「Vibe Coding」が主流メディアに浮上 — Bloomberg が FOMO と生産性を分析
Bloomberg が 4月5日付（事前公開 4月4日）の記事で「Vibe Coding」を特集。Andrej Karpathy が 2025年2月に提唱したこのコンセプトは、開発者がプロンプトで意図を伝え AI がコードを生成するスタイルを指す。Claude Code や OpenAI Codex といったツールが普及し、スウェーデンの Lovable は ARR $400M に到達。一方で Fortune 誌は「vibe coding 時代のボトルネックは信頼」と指摘し、Apple が vibe coding アプリへの取り締まりを強化するなど、品質・セキュリティ面の懸念も同時に浮上している。

### WhatsApp、偽 iOS アプリによるスパイウェア被害で 200 名に警告

WhatsApp がイタリアの監視企業 SIO（子会社 ASIGINT）が作成した偽の WhatsApp iOS アプリについて、約 200 名のユーザーに警告を送付。被害者はサイドローディングで偽アプリをインストールさせられ、データ窃取・音声録音・カメラアクセスの被害を受けた。WhatsApp はユーザーをログアウトさせて正規アプリの再インストールを促すとともに、SIO に対する法的措置を予告。国家関連のスパイウェアがメッセージングアプリを標的にする傾向が強まっている。
