### AI エージェントの「本人確認・権限管理」標準化が加速 — Google AP2、NIST、AI AGENT Act

AI エージェントが外部サービスへ自律的に支払いを実行したり、ユーザーの代理として操作を行うユースケースが急増するなか、セキュリティ・責任の帰属・権限境界の標準化を求める動きが産業界・規制当局の双方で進んでいる。Google が提案する **Agent Payments Protocol（AP2）** は、エージェントが決済を行う際に発行者・受取人・タスク範囲を暗号的に束ねた認証済み「認可レコード」を要求する仕組みだ。NIST はエージェント ID とパーミッション管理に関するコンセプトワークを進めており、米議会では **AI AGENT Act（S.5051）** が提出され、エージェントによるアクションに対して検証可能な認可記録を義務付けることが議論されている。規制と技術の両面から「何をしてよいか」の境界を機械可読な形で明示しようとするこの動きは、マルチエージェント・システムの実運用における最重要課題の一つだ。

```python
# エージェント認可レコードのシンプルな概念モデル（AP2 インスパイア）
from dataclasses import dataclass, field
from typing import List

@dataclass
class AgentAuthorizationRecord:
    issuer: str          # 認可を発行したエンティティ（例: ユーザー ID）
    agent_id: str        # 実行エージェントの識別子
    task_scope: List[str]  # 許可されるアクションのリスト
    max_payment: float   # 1 セッションあたりの支払い上限（USD）
    expires_at: str      # ISO 8601 タイムスタンプ
    signature: str = ""  # 発行者による暗号署名

    def is_action_permitted(self, action: str) -> bool:
        return action in self.task_scope

# 使用例
record = AgentAuthorizationRecord(
    issuer="user-abc123",
    agent_id="shopping-agent-v2",
    task_scope=["search_product", "add_to_cart", "checkout"],
    max_payment=50.0,
    expires_at="2026-08-26T23:59:59Z",
)

print(record.is_action_permitted("delete_account"))  # False
print(record.is_action_permitted("checkout"))         # True
```

### Lazarus が Windows カーネルゼロデイ（CVE-2026-68820）を 5 週間悪用 — 防衛・航空宇宙セクターが標的

```bash
# === 2026-08-26 セキュリティ優先対応チェックリスト ===

# ---- [1] CVE-2026-68820: Windows AFD.sys 権限昇格ゼロデイ (CVSS 7.0) ----
# 影響: Windows 全バージョン（2026-08-11 Patch Tuesday でパッチ済み）
# afd.sys (Windows Ancillary Function Driver for WinSock) の use-after-free
# ローカル認証ユーザーが SYSTEM 権限を取得可能 / ユーザー操作不要
# Lazarus グループが Operation Dream Job の一環として 5 週間悪用
# FudModule ルートキットの新バージョンを展開、防衛・航空宇宙組織を標的
# 対処: Windows Update を即時適用（KB番号は Patch Tuesday 一覧を参照）
$hotfix = Get-HotFix | Where-Object {$_.HotFixID -match "KB5062"}
if (-not $hotfix) { Write-Warning "August Patch Tuesday 未適用 — 即時 Windows Update を実行" }

# ---- [2] CVE-2026-60004: Gitea RCE (CVSS 9.8) ----
# 影響: Gitea 1.27.0 以前
# リポジトリへの通常書き込み権限を持つユーザーが任意シェルコマンドを
# Gitea OS ユーザーとして実行可能
# 対処: Gitea 1.27.1 へ即時アップデート
gitea_ver=$(gitea --version 2>/dev/null | awk '{print $3}')
echo "Gitea バージョン: ${gitea_ver}"
# 1.27.1 未満の場合は即時アップデート必須

# ---- [3] Microsoft Patch Tuesday 8 月 — 421 CVE のうち EoP が 42% ----
# 権限昇格 (EoP): 174 件 (42%) / RCE: 109 件 (26%) / 情報漏洩: 85 件 (20%)
# CVE-2026-68820 以外に緊急 RCE が複数含まれるため Patch Tuesday 全体の適用を推奨
echo "=== 2026-08-26 優先セキュリティ対応 ==="
echo "CVE-2026-68820 : Windows AFD.sys EoP CVSS 7.0 → Lazarus 悪用確認済み・即時 Windows Update"
echo "CVE-2026-60004 : Gitea RCE CVSS 9.8 → v1.27.1 へ即時アップデート"
echo "Patch Tuesday  : 8 月分 421 CVE → 全体適用を推奨（EoP 174 件含む）"
```
