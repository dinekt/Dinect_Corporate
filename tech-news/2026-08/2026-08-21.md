### 1. Microsoft 8月Patch Tuesdayが過去最多421 CVEを修正 — afd.sys ゼロデイ（CVE-2026-68820）がすでに実攻撃に悪用、Lazarus系との類似を指摘

Microsoftが8月の定例セキュリティアップデートで**421件のCVE**を修正した。これは6月の208件を大幅に上回り、単月としては過去最大規模となる（SecurityWeek / CrowdStrike）。中でも最大の注目を集めているのが**CVE-2026-68820**（Windows Ancillary Function Driver for WinSock、afd.sys）だ。カーネルモードドライバ afd.sys のuse-after-free脆弱性であり、低特権の攻撃者がSYSTEM権限への昇格を**ユーザー操作不要**で実行できる。Microsoftは「実際の攻撃で悪用が確認された」と認定しており、セキュリティ研究者の間では2022年以降に悪用されたafd.sys系の脆弱性（CVE-2024-38193など北朝鮮Lazarousグループ起因）との類似パターンが指摘されている。62件のCritical脆弱性には、Windows DNSサーバーのRCE（CVE-2026-62878）、QUIC実装のRCE（CVE-2026-62815）、Exchange ServerのEoP（CVE-2026-62911）なども含まれており、エンタープライズ環境での優先パッチ適用が急務だ。

### 2. EU AI法 Article 50（透明性義務）が8月2日に発効 — チャットボット・合成メディアの「AI明示」義務化、違反には最大3%の売上高ペナルティ

EUの**AI法（EU AI Act）Article 50**による透明性義務が**2026年8月2日**に正式発効した（Cooley / AI Factory Austria）。対象はチャットボット・音声アシスタント・感情認識システム・ディープフェイクツールなど、AIが直接ユーザーと対話するシステム全般だ。義務の核心は4点：①AIシステムとの対話であることの明示、②AI生成コンテンツのラベリング、③感情認識・生体カテゴリ分類の通知、④公益関連のディープフェイク・AI生成テキストの識別。2026年8月2日以前に公開されたコンテンツへの遡及適用は不要だが、生成AIシステムの「マーキング・検出」義務については2026年12月2日まで移行期間が設けられている。違反時のペナルティは**最大1,500万ユーロまたは世界年間売上高の3%**と規定されており、国内市場監視当局が執行を担う。AI Officeは任意のCode of Practice（実践規範）を公開し、コンプライアンスの達成経路を示している。

**出典**: [Cooley: EU AI Act Transparency Obligations Take Effect](https://www.cooley.com/news/insight/2026/2026-08-03-eu-ai-act-transparency-obligations-take-effect-2-august-2026) / [EU AI Act: Article 50 Transparency](https://artificialintelligenceact.eu/transparency-rules-article-50/) / [AI-AT.eu: Article 50](https://ai-at.eu/en/news/article-50-of-the-eu-ai-act-transparency-obligations-become-applicable-on-2-august-2026/)

### 3. 8月のAIモデルラッシュ — 12モデルがリリース、Llama 4の1000万トークンコンテキストとオープンソース標準化が加速、Rustクレートへのサプライチェーン攻撃も発覚

8月2026年は単月で**12の新AIモデル**が7プロバイダーから投入された（LLM Stats / LLM Gateway）。最新はZ.AIのGLM-5.2 Turbo（8月17日リリース）であり、MetaのLlama 4（Scout & Maverick）は**1,000万トークンコンテキスト**という驚異的な窓を実現し、7Bクラスモデルが昨年の70Bを性能で上回る局面も生まれている。音声処理LLMの台頭も注目点で、エンドツーエンドの音声処理・感情検出・自然な声質応答が商用レベルに達しつつある。一方で**Rustエコシステムへのサプライチェーン攻撃**が確認され、メンテナーアカウントが侵害された後、3本の広く使われているRustクレートにタイポスクワット依存関係が混入した。Rust Projectは該当バージョンを削除したが、ビルドパイプラインでの依存関係の固定（`Cargo.lock`の厳格な管理）と定期的な`cargo audit`実行の重要性が改めて示された格好だ。

### Visual Studio Code August 2026 — 統合ブラウザコメント・多言語音声入力・Markdownハイブリッドエディタ

VS Code August 2026アップデートが公開された（Releasebot）。今回の目玉は**統合ブラウザへのインラインコメント機能**で、エージェントに対して表示中のWebページの特定要素を指定して正確なフィードバックを与えられるようになった。フロントエンド開発のエージェントワークフローが大幅に改善される。また**多言語音声入力（Multilingual Dictation）**により、音声でのコード編集・コマンド入力がネイティブでサポートされ、**Markdownハイブリッドエディタ**はMarkdown diffとリッチプレビューを切り替えなしで表示できる。ターミナル改善も行われており、セッション間でのコマンド履歴の一貫性が向上した。

```bash
# VS Code August 2026 の新機能確認
code --version

# 統合ブラウザコメント機能を使うには
# 1. サーバーを起動して Simple Browser で開く
# 2. Ctrl+Shift+P -> "Simple Browser: Show"
# 3. ページ上の要素を右クリックして "Add Comment" を選択
# 4. チャットパネルのエージェントに自動でコンテキスト付きで送信される

# 音声入力でコーディング
# 1. Ctrl+Shift+P -> "Voice: Start Dictation (Editor)"
# 2. 日本語・英語・多言語混在での音声→テキスト変換が可能

# 依存関係セキュリティ監査（Rust プロジェクトの場合）
cargo audit

# Cargo.lock を厳密に固定してサプライチェーン攻撃を防ぐ
# Cargo.toml の [profile.release] セクションに追加
# [profile.release]
# overflow-checks = true

# Node.js / npm プロジェクトの場合
npm audit
npm audit fix
```

### CVE-2026-68820（afd.sys EoP ゼロデイ）・GitLab CVSS 9.4・ミネソタ州水道インフラ攻撃 — 8月の脅威トリアージ

```bash
# === 2026-08-21 セキュリティ優先対応チェックリスト ===

# ---- [1] CVE-2026-68820: Windows afd.sys EoP（ゼロデイ・実攻撃確認済み）----
# 影響: Windows 10/11 全バージョン、Windows Server 2019/2022/2025
# 低特権ユーザー → SYSTEM権限昇格、ユーザー操作不要
# 2022年以降のafd.sys系ゼロデイとの類似（Lazarus系の可能性）

# Windows Update 状態確認（PowerShell 管理者権限）
Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 15

# 更新プログラムの即時適用
Install-Module PSWindowsUpdate -Force -Scope CurrentUser
Get-WindowsUpdate -AcceptAll -Install

# ---- [2] CVE-2026-62878: Windows DNS Server RCE（Critical）----
# DNSサーバーとして運用しているホストは特に優先パッチ適用を

# ---- [3] CVE-2026-19478: GitLab 未認証によるプロジェクト・ユーザーデータ変更（CVSS 9.4）----
# 影響: GitLab CE / EE セルフマネージド全インスタンス
# 未認証攻撃者がパブリックプロジェクトとユーザーデータを変更・削除可能
# 既に悪用の試みが観測されている

# GitLab バージョン確認
gitlab-rake gitlab:env:info 2>/dev/null | grep "GitLab"

# 最新版への更新（Linuxパッケージインストールの場合）
sudo apt-get update && sudo apt-get install gitlab-ee
# または
sudo yum update gitlab-ee

# ---- [4] Rust クレートのサプライチェーン汚染対応 ----
# 汚染された3クレートのバージョンは削除済みだが念のため確認

# プロジェクトの依存関係を監査
cargo audit

# Cargo.lock を Git 管理下に置き、差分を定期確認
git diff Cargo.lock

echo "=== 2026-08-21 優先パッチサマリー ==="
echo "CVE-2026-68820 : afd.sys EoP ゼロデイ（実攻撃確認）- Windows Update 即時適用"
echo "CVE-2026-62878 : Windows DNS Server RCE（Critical）- 同上"
echo "CVE-2026-19478 : GitLab 未認証データ改ざん（CVSS 9.4）- 最新版にアップデート"
echo "Rust クレートサプライチェーン : cargo audit で依存関係を確認"
```

8月のPatch Tuesdayは過去最大規模の421 CVEとなった。特筆すべきは**CVE-2026-68820**（afd.sys use-after-free）がすでに実攻撃に悪用されているゼロデイである点だ。2022〜2025年にかけて北朝鮮Lazarusグループが同系統の脆弱性を使用したという前例があり、今回も国家支援型攻撃者による悪用の可能性がセキュリティ研究者から指摘されている。GitLabのCVE-2026-19478（CVSS 9.4）は未認証でのデータ操作が可能な深刻な欠陥であり、セルフマネージドインスタンスの管理者は今週中のアップデートが必須だ。また、ミネソタ州では30以上の水道施設を標的にした協調型サイバー攻撃が発生し、一部で浄水処理システムへの影響が確認された（eSecurity Planet）。OT/ICS環境へのサイバー攻撃が現実の物理インフラに影響を与え始めている状況は、重要インフラ保護の優先度を一段引き上げる事態だ。
