## 本日のニュース TOP 3

### 1. OpenAI vs Anthropic — IPO 競争の裏で AI・データセンターへの世論が冷える

CNBC が 4 月 15 日に報じた分析によると、米国の一般世論は AI とデータセンター過剰投資への懸念を強めており、少なくとも 1,560 億ドル相当のデータセンター建設プロジェクトが 2025 年にキャンセルまたは延期されたとされる。この逆風の中、OpenAI（年換算収益 $25B）と Anthropic（$19B、エンタープライズ市場シェアは 40% まで拡大）はともに 2026 年中の IPO を準備している。先週末には Sam Altman CEO の自宅を標的にした事件も発生し、AI 業界への社会的な緊張感が高まっていることが示された。Anthropic のエンタープライズシェアが 40% に達した一方で OpenAI は 50% → 27% に低下しており、両社の競争構図は逆転しつつある。

**開発者・ビジネスへの影響**:
- IPO 後の株主圧力により、両社の価格戦略・API ポリシーが変わる可能性がある。長期利用を前提とするなら契約条件を今のうちに確認しておくことが望ましい
- Anthropic のエンタープライズ採用加速は Claude API の機能拡充・SLA 強化につながる可能性があり、商用導入の評価タイミングとして注目に値する

**出典**: [CNBC — The public sours on AI and data centers as Anthropic, OpenAI look to IPO](https://www.cnbc.com/2026/04/15/public-opinion-ai-data-centers-anthropic-openai-ipo.html)

### 2. Nginx-UI "MCPwn" (CVE-2026-33032) CVSS 9.8 — 未認証で Nginx を完全乗っ取り、野外で積極悪用中

Pluto Security が「MCPwn」と命名した CVE-2026-33032 は、nginx-ui の MCP 統合における認証バイパスの脆弱性だ。`/mcp_message` エンドポイントが `/mcp` とは異なり `AuthRequired()` ミドルウェアを適用しておらず、空の IP ホワイトリストが「全許可」として扱われる実装上の欠陥を突くことで、ネットワーク隣接の攻撃者が単一の API リクエストだけで Nginx の設定ファイル作成・変更・削除および再起動を無認証で実行できる。影響バージョンは nginx-ui 2.3.5 以下で、Recorded Future は 2026 年 3 月時点で既に野外での積極的な悪用を確認している。インターネット公開インスタンスは約 2,689 件（主に中国・米国・インドネシア・ドイツ・香港）に上る。

**開発者・運用者への影響**:
- nginx-ui をサーバー上で動かしている場合は最優先で最新バージョンへ更新すること。特にパブリック IP から到達可能なインスタンスは侵害リスクが高い
- MCP エンドポイントを外部公開している WebUI・管理ツール全般に同様のパターン（認証バイパス）が潜在している可能性を考慮し、認証ミドルウェアの適用漏れを監査すること

**出典**: [The Hacker News — Actively Exploited nginx-ui Flaw CVE-2026-33032](https://thehackernews.com/2026/04/critical-nginx-ui-vulnerability-cve.html) / [Security Affairs](https://securityaffairs.com/190841/hacking/cve-2026-33032-severe-nginx-ui-bug-grants-unauthenticated-server-access.html)

### 3. Rust for CPython — 設計フェーズ開始、Python 3.16（2027 年 10 月）での Rust 統合が現実味を帯びる

Python 公式インサイダーブログが 4 月の進捗報告を公開し、Rust for CPython プロジェクトが CI での全プラットフォームビルド成功に続き、いよいよ内部 Rust API の設計フェーズに入ったと発表した。PEP ドラフトの公開目標は 2026 年 6〜7 月、Python 3.16 の beta 1 は 2027 年 5 月、正式リリースは 2027 年 10 月が見込まれている。先週 Linux 7.0 が Rust を正式採用したばかりで、システムソフトウェア全体の Rust シフトが同時進行している。Rust チームとの協議では CPython 固有の API 設計ニーズについて活発な議論が行われており、PEP 議論は「相当な長さになる」と予告されている。

**開発者への影響**:
- PEP 議論に参加したい開発者は discuss.python.org のスレッドを今のうちにブックマーク。CPython 中枢への意見表明機会が開かれている
- Python 3.16 での採用を見据えて Rust の基礎（所有権・ライフタイム・FFI）を学んでおくと、速度敏感なモジュール開発や将来のコントリビュートで優位に立てる

**出典**: [Python Insider — Rust for CPython Progress Update April 2026](https://blog.python.org/2026/04/rust-for-cpython-2026-04/) / [discuss.python.org](https://discuss.python.org/t/rust-for-cpython-progress-update-april-2026/106895)

### OpenAI・Anthropic・Google — Frontier Model Forum 経由で中国のモデルコピーに共同対抗

Bloomberg と The Japan Times が報じたところによると、OpenAI・Anthropic・Google の 3 社が Frontier Model Forum を通じて、中国企業が米国最先端 AI モデルの出力を蒸留・コピーしようとする行為を検知・阻止するための情報共有を開始した。各社単独でのポリシー執行には限界があったが、データプール共有によって「モデル盗用」のパターン検知精度が向上するとされる。AI 競争の地政学的な文脈で、米国 AI エコシステムの知財保護を目的とした業界協調として注目される。

EU では AI Act の禁止条項（予測型警察活動・感情認識）が正式発効済みで、米国はトランプ政権の「軽規制（light touch）」フレームワークを維持しており、中国は「inclusive cooperation」を掲げながら国家データ管理を保持するという三極構造が鮮明になっている。

### nginx-ui バージョン確認と更新手順

MCPwn 対応として nginx-ui のバージョンを確認する手順:

```bash
# バイナリのバージョンを確認
nginx-ui --version 2>/dev/null

# dpkg 経由でインストールされている場合
dpkg -l nginx-ui 2>/dev/null

# GitHub Releases から最新版をダウンロード（ARM64 Linux の例）
LATEST=$(curl -s https://api.github.com/repos/0xJacky/nginx-ui/releases/latest \
  | grep '"tag_name"' | cut -d'"' -f4)
echo "Latest version: $LATEST"
# 2.3.5 以下が表示された場合は即時アップデートを実施すること
```

### CERT-UA: UAC-0247 — ウクライナ政府・医療機関を標的に情報窃取キャンペーン

CERT-UA は、脅威クラスター UAC-0247 が 2026 年 3〜4 月にかけてウクライナ政府機関および地方医療機関を標的に、Chromium 系ブラウザの保存認証情報と WhatsApp メッセージを窃取するマルウェアを展開したと警告した。初期侵入にはスピアフィッシングが使われており、公共・インフラ系組織は添付ファイル・リンクの取り扱いポリシーの再確認が必要だ。

### Zerion 仮想通貨ウォレット侵害 — 内部ホットウォレットから約 $100K 窃取

仮想通貨ウォレットサービス Zerion が、チームメンバーのデバイスが侵害され、社内ホットウォレットから約 10 万ドル相当の資産が窃取されたことを開示した。デバイスレベルの侵害が資金流出に直結するという構図で、多層承認なしにホットウォレット秘密鍵をエンドポイントに保管するリスクを改めて示している。
