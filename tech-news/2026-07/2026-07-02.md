### 1. Claude Fable 5 が19日ぶりに復活、同日 Claude Sonnet 5 が正式リリース — Anthropic が輸出規制解除と新モデル公開を同時発表

2026年7月1日、Anthropicは2つの大型発表を同時に行った。まず、6月12日に米商務省の輸出管理令により全世界でアクセスが停止していた**Claude Fable 5**と**Mythos 5**が、商務省が6月30日に輸出規制を解除したことを受け、7月1日から順次グローバル再公開が開始された。規制のきっかけはAmazon研究者が発見したFable 5のセーフガードを回避するjailbreak手法であり、Amazon CEOのAndy Jassyが連邦当局に報告したことで輸出規制措置が発動した経緯がある。Anthropicは19日間の停止期間中に安全分類器をリトレーニングし、当該手法を99%以上の確率でブロックすることに成功したとして復帰を果たした。Mythos 5については米国政府の審査を経た承認済み機関向けに限定再公開となり、Project Glasswingを通じたアクセス拡大交渉が継続している。同日に発表された**Claude Sonnet 5**（2026年6月30日リリース）は1Mトークンのコンテキストウィンドウと128kトークンの最大出力を備え、アダプティブシンキングがデフォルトで有効化されたエージェント特化型モデルとして設計されている。Free・Proプランのデフォルトモデルに昇格し、導入価格は$2/MTok入力・$10/MTok出力（2026年8月31日まで）。Anthropicは、数ヶ月前は大規模モデルでしか実現できなかった水準の自律性をSonnet 5は発揮できると説明している。

### 3. Cursor IDEにゼロクリックRCE脆弱性「DuneSlide」（CVE-2026-50548/50549、CVSS 9.8）— プロンプトインジェクション経由でサンドボックス脱出、Fortune 500の半数超が影響

Cato AI Labsは2026年6月末、AI搭載コードエディタ**Cursor IDE**に存在する2件のゼロクリックRCE脆弱性「**DuneSlide**」（CVE-2026-50548、CVE-2026-50549、いずれもCVSS 9.8）を公開した。攻撃者はMCP（Model Context Protocol）サーバーや検索結果などの信頼できないソースに悪意あるペイロードを埋め込み、被害者が無害なプロンプトを入力するだけでエージェントがそのペイロードを取り込むゼロクリック型プロンプトインジェクションを実現する。成功すると`cursorsandbox`バイナリが攻撃者の制御するものに置き換えられ、サンドボックス化されたコマンドが非サンドボックスRCEに変質してホストシステムの完全制御が可能となる。Fortune 500企業の半数超が利用するとされるCursorに対してこの攻撃は事前の認証も特別な操作も一切不要だ。両CVEはCursor 3.0（2026年4月2日リリース）でパッチ済みであり、Cato AI Labsは同様の構造的欠陥を複数の他社コーディングエージェントにも発見したとして、MCPやウェブ検索との統合を持つAIエージェント全般が同種のプロンプトインジェクション攻撃に晒されうると警鐘を鳴らしている。

### Claude Sonnet 5 — アダプティブシンキングデフォルト化、新トークナイザー導入、エージェントOSへの本格シフト

Claude Sonnet 5は従来のSonnetシリーズから設計思想を大きく転換し、「エージェントファースト」の実装を前面に打ち出した。技術的変更点として特筆すべきはアダプティブシンキングの挙動変更と新トークナイザーの導入の2点だ。アダプティブシンキングはデフォルトでONとなり、開発者が手動で拡張思考を設定する`extended thinking`パラメータは廃止（設定すると400エラー）。サンプリングパラメータ（temperature、top_p、top_k）の非デフォルト値設定も同様に400エラーを返すよう仕様が変更された。

```python
# Claude Sonnet 5 API利用例（Python SDK）
import anthropic

client = anthropic.Anthropic()

# Sonnet 5はアダプティブシンキングがデフォルトON
# temperature / top_p / top_k の変更は不可（400エラー）
# extended_thinking パラメータも廃止

response = client.messages.create(
    model="claude-sonnet-5-20260630",
    max_tokens=16000,
    messages=[
        {
            "role": "user",
            "content": "このPythonスクリプトをリファクタリングして、型アノテーションとエラーハンドリングを追加してください。"
        }
    ]
)

print(response.content[0].text)
print(f"使用トークン数(入力): {response.usage.input_tokens}")
print(f"使用トークン数(出力): {response.usage.output_tokens}")
```

新トークナイザーは同一テキストに対して従来比約30%多くのトークンを生成するため、既存のコスト計算やコンテキスト上限管理のロジックを見直す必要がある。1Mトークンコンテキストウィンドウは長大なコードベース全体やドキュメント群をそのまま入力できる実用水準となっており、GitHub CopilotのGA提供（2026年6月30日）も同時に開始された。コーディング・推論・ツール利用のすべての軸で大幅な性能向上が報告されており、エージェントワークロードにおける費用対性能の実質的な向上を意味する。
