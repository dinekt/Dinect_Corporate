## 🔍 深掘りキーワード

### **Harness Engineering（ハーネスエンジニアリング）**
Claude Code や Copilot のようなコード生成エージェントの出力を「テスト駆動」で検証する設計パターン。生成されたコードをそのまま本番投入するのではなく、テストスイートで「正しさを証明させた上で」マージする手法です。今年は**エージェント時代のシニア開発者スキルの必須要件**になるでしょう。日本語の丁寧な解説記事も登場しており、個人開発に即座に応用できます。

### **Structured Output（構造化出力）**
LLM API が JSON スキーマを指定して、必ず有効なデータ構造を返すこと。Pydantic + OpenAI / Anthropic API の組み合わせで、エージェント出力を型安全にできます。**バリデーション失敗時に自動リトライする Pydantic AI の機能と組み合わせると、ほぼ 100% の信頼度でコード生成パイプラインを構築**できるようになります。

### **Edge Computing & Vite-based Next.js**
Cloudflare Workers、Deno Deploy、Vercel Edge Functions など、地理的に分散したサーバーレス環境での実行。vinext は webpack 依存を排除し Vite で高速化することで、**エッジ環境での Next.js 実行を現実化**しました。SPA（シングルページアプリケーション）ではなく SSR（サーバーサイドレンダリング）がグローバルに低遅延で実現できるメリットは計り知れません。

### **Web Components + Scoped Registries**
カスタム要素（Custom Elements）が名前空間をサポートし、競合を防止できるようになりました。React / Next.js コンポーネントと Web Components を共存させる際、スコーピング機構がなかったため、第三者ライブラリとの競合が問題でした。この解決により、**Chrome 拡張や複合フレームワーク環境での部品再利用性が向上**します。

### **Salt Typhoon & データ主権リスク**
中国の APT グループが世界中の通信キャリアに侵入している報道から、**個人開発者も国家レベルの脅威を意識するべき時代が来た**ことがわかります。特にクラウド上に個人情報やビジネスロジックを預ける際は、データレジデンシー（データがどこに物理的に保管されるか）を確認し、必要に応じて暗号化・分散が必須です。
