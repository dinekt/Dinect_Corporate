### 2. NGINX Rift（CVE-2026-42945）— 18年前から潜在していた CVSS 9.2 のヒープバッファオーバーフロー、未認証 RCE が可能に

世界最多デプロイ数の Web サーバ NGINX に、2008年（v0.6.27）から潜在していたクリティカルな脆弱性 **CVE-2026-42945**（通称 NGINX Rift、CVSS 9.2）が発見・公開された。脆弱性は `ngx_http_rewrite_module` の `ngx_http_script.c` に存在するヒープバッファオーバーフローであり、長さ計算フェーズと書き込みフェーズの間で `is_args` フラグが漏れ出す「ツーパス・コントラクト違反」が根本原因だ。攻撃者は認証なしで細工した HTTP リクエスト1件を送信するだけで NGINX ワーカープロセス内での任意コード実行（または DoS）を引き起こせる。影響範囲は NGINX 0.6.27〜1.30.0、NGINX Plus R32〜R36 およびその全ダウンストリームと極めて広く、Kubernetes の Ingress NGINX Controller も対象となる。F5 と研究チーム depthfirst が 2026-05-13 に共同開示し、修正版は安定版 **1.30.1** およびメインライン **1.31.0** で提供済みだ。`rewrite` ルール・`if` ブロック・`set` ディレクティブを利用している構成では特に影響を受けやすく、パッチ未適用の環境への即時対応が強く推奨される。

**出典**: [NGINX Rift CVE-2026-42945 解説 — Picus Security](https://www.picussecurity.com/resource/blog/nginx-rift-cve-2026-42945-critical-heap-buffer-overflow-vulnerability-explained) / [18-Year-Old NGINX Rewrite Module Flaw — The Hacker News](https://thehackernews.com/2026/05/18-year-old-nginx-rewrite-module-flaw.html) / [NGINX Rift 詳細解析 — Security Affairs](https://securityaffairs.com/192132/hacking/nginx-rift-an-18-year-old-flaw-in-the-worlds-most-deployed-web-server-just-came-to-light.html)

### 3. Python 3.16 へ Rust 導入の Pre-PEP が Guido 承認を取得 — CPython に Rust が加わる新章が開幕

Python コア開発者の Emma Smith と Kirill Podoprigora が提案した「Rust for CPython」Pre-PEP が、Guido van Rossum の明示的な承認を得て正式 PEP 化に向け大きく前進した。当初は CPython 全体への Rust 導入を目指していたが、コミュニティのポータビリティ・ブートストラップ懸念を受け「まずオプションの拡張モジュール」に対象を絞り込んだうえで再提案した。現状では `bindgen` が CPython の C ヘッダから Rust バインディングを自動生成する `cpython-sys` クレートを基盤とし、CPython がサポートする全プラットフォームでのビルドが検証済みだ。ターゲットリリースは **Python 3.16**（beta 1 は 2027年5月予定）で、PEP ドラフトは 2026年6〜7月に公開される見込みだ。動機はメモリ安全性・リファクタリングの安全性・エルゴノミクスであり、将来的には Rust が CPython の必須依存となる計画も示されている。Python と Rust の連携は AI・高性能システム開発ですでに広がっており、CPython 自体への組み込みはその流れを象徴する節目となる。

### Google Gemini API — Managed Agents でエージェント型ワークフローを構築する

Google I/O 2026 で公開された Managed Agents は、1回の API コールでサンドボックス化されたリモート Linux 環境を立ち上げ、コード実行・ファイル操作・Web ブラウズをエージェントに任せられる仕組みだ。以下は Python SDK を用いた基本的な利用例だ。

```python
import anthropic  # 比較用: Anthropic SDK
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

# Managed Agent を1回の API 呼び出しで起動
response = genai.run_agent(
    model="gemini-3.5-flash",
    task="以下のリポジトリをクローンし、テストを実行してレポートを返せ",
    tools=["code_execution", "web_browse", "file_manager"],
    sandbox=True,          # 隔離 Linux 環境を自動プロビジョニング
    timeout_seconds=300,
)

print(response.result)
print("実行ログ:", response.execution_log)
```

```bash
# CLI でエージェントを呼び出す場合（gcloud AI Platform 統合）
gcloud ai agents run \
  --model=gemini-3.5-flash \
  --task="requirements.txt の依存関係を最新化し差分を返せ" \
  --sandbox
```

Managed Agents はコードレビュー自動化・CI パイプライン内でのインテリジェントなデバッグ・ドキュメント自動生成など、マルチステップ作業の自動化に適したユースケースが広がる。ただし現時点ではサンドボックスの永続化・外部ネットワークアクセスの詳細ポリシーについては GA 時の仕様を確認する必要がある。

### NGINX Rift（CVE-2026-42945）— 1.30.1 / 1.31.0 へのアップグレードを最優先

前述の通り NGINX Rift は CVSS 9.2 の未認証 RCE であり、パッチ対応の手順を整理しておく。

```bash
# バージョン確認
nginx -v
# → nginx version: nginx/1.30.0  のような場合は即時アップグレード対象

# Debian/Ubuntu (apt)
sudo apt update && sudo apt install --only-upgrade nginx

# RHEL/Rocky (dnf)
sudo dnf update nginx

# Docker / k8s: ベースイメージを 1.30.1 以降に更新
# FROM nginx:1.30.1-alpine

# Ingress NGINX Controller を使っている場合
kubectl set image deployment/ingress-nginx-controller \
  controller=registry.k8s.io/ingress-nginx/controller:v1.13.1

# アップグレード後の確認
nginx -v && nginx -t && sudo systemctl reload nginx
```

rewrite ルールが存在しない構成では攻撃面が縮小するが、完全な緩和にはならないため、バージョンアップが唯一の推奨策だ。

### Gitea CVE-2026-27771 — 未認証でプライベートコンテナイメージを取得可能、4年間検出されず

セルフホスト型 Git サービス Gitea に、未認証の攻撃者がプライベートコンテナレジストリのイメージを認証なしで pull できる脆弱性 **CVE-2026-27771** が報告された。v1.26.2 未満の全バージョンが対象で、影響を受けるデプロイは 30,000 件以上と推定される。本脆弱性は約4年間検出されておらず、医療機関・航空宇宙メーカー・小売インフラに影響が及んでいる可能性がある。v1.26.2 へのアップグレードが修正策であり、自社でレジストリをホストしている組織は過去のアクセスログの監査も推奨される。

欧州議会・欧州理事会・欧州委員会は 2026年5月7日、AI Act の実装を簡素化する **AI オムニバス立法**に政治合意に達した。同改正は高リスク AI の適合義務の段階的実施やプロバイダー向け手続きの効率化を柱としており、透明性義務条項（ディープフェイク開示・AI 生成コンテンツ表示など）は **2026年8月** に全 EU で発効する。一方で国際的には、少なくとも 72カ国が AI 関連の政策・法案を提出しており、うち 47カ国が AI 特有の立法を有効化している。米国では California・Texas・Colorado が各州の AI／データプライバシー法のコンプライアンス移行期間に入っており、連邦レベルではトランプ政権の「Project Stargate（5,000億ドルの AI インフラ官民投資）」が引き続き推進されている。AI ガバナンスのスタンダードが地政学的に分断される中、グローバルにサービスを展開する組織には複数の規制体系への同時対応が不可避な状況が続く。
