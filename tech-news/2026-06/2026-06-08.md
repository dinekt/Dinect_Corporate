### 1. Apple WWDC 2026 開幕 — iOS 27・macOS "Golden Gate"・Gemini 搭載 Siri AI が正式発表

日本時間 6 月 9 日未明、Apple の年次開発者会議 **WWDC 2026** の基調講演が Apple Park で幕を開けた。最大のトピックは **Siri の全面刷新**で、Google との年間 10 億ドル契約に基づく**約 1.2 兆パラメータのカスタム Gemini モデル**がクラウド推論に採用された。新しい Siri はデバイス上の個人コンテキストをシステム全体で参照し、画面の内容を理解した上で応答できる深いオンスクリーン認識を持つ。さらに **Apple Intelligence Extensions** システムが導入され、ユーザーは ChatGPT・Google Gemini・Anthropic Claude を AI バックエンドとして任意に選択できるようになった。OS の名称は iOS/iPadOS/macOS/watchOS/visionOS が一斉に **27** に引き上げられ、macOS は **"Golden Gate"** と命名された。Liquid Glass デザインには**不透明度スライダー**と**コーナー半径の縮小**が加わり、昨年来のユーザーフィードバックに応える仕上がりとなっている。なお EU の **デジタル市場法（DMA）** への対応協議が不調に終わり、欧州地域では Siri AI が提供されないことも発表された。iOS 27 Beta 1 は同日午後に開発者向けに公開されている。

### 2. Anthropic が「AI の再帰的自己改善」に警告 — IPO 申請直後に業界全体への一時停止要請

Anthropic は 6 月 5 日、AI の能力が**約 4 カ月ごとに倍増**しており、人間の介入なしに自らを改良する**再帰的自己改善（recursive self-improvement）** が「多くの機関が準備できているより早く訪れる可能性がある」と警告した。同社は大手 AI 研究機関に対して**業界横断的な「ブレーキペダル」機構**の構築を求め、リスクが一定水準に達した際に開発を調整できる仕組みの整備を訴えた。注目されるのはタイミングで、Anthropic は**6 月 1 日に評価額 $965 B（約 140 兆円）での IPO を機密申請**したまさに直後のこの声明となった。投資家向けには AI 主導の生産性向上を訴求しつつ開発の一時停止を求める姿勢に対し、「現状のリードを凍結したいのでは」との見方もアナリストから上がっている。一方でアルジャジーラ・CNN・Fortune が揃って報じたことで、生成 AI の安全性ガバナンスを巡る議論は企業倫理レベルから**国際社会レベル**へと引き上げられた格好だ。

### 3. Cisco Catalyst SD-WAN Manager に 2026 年 7 本目のゼロデイ — CVE-2026-20245、パッチ・ワークアラウンドなしで既存悪用確認

Cisco が 6 月 5 日に公開した **CVE-2026-20245**（CVSS **7.8**・High）は、Cisco Catalyst SD-WAN Manager の CLI に存在する**コマンドインジェクション**脆弱性で、2026 年に入って同製品への**7 本目のゼロデイ**となった。**netadmin 権限**を持つ認証済み攻撃者が細工したファイルをアップロードすることで **root 権限での任意コマンド実行**が可能となる。影響範囲はオンプレミス・Cloud-Pro・Cisco Managed Cloud・FedRAMP 環境を問わず全デプロイメント形態に及ぶ。Mandiant がインシデントレスポンス中に発見・報告したもので、エッジデバイスへの設定変更が不正にプッシュされた事例も確認されている。**パッチもワークアラウンドも存在しない**ため、Cisco は影響調査を進める間の緩和策として、netadmin 権限アカウントの棚卸し・最小権限原則の徹底・ネットワーク分離・証拠保全を推奨している。SD-WAN はエンタープライズのブランチ拠点を広域に束ねる基幹インフラであり、侵害が広域 WAN 全体に波及する可能性がある点で特に深刻だ。

### Apple Intelligence Extensions — iOS 27 で ChatGPT・Gemini・Claude をワンタップ切り替え

WWDC 2026 のもう一つの技術的注目点は **Apple Intelligence Extensions** の登場だ。これまで Apple Intelligence の AI バックエンドは ChatGPT（OpenAI との提携）のみだったが、iOS 27 からは **Google Gemini** と **Anthropic Claude** も公式 Extensions として追加された。ユーザーは設定画面から優先モデルを選択でき、Siri や作文ツール・要約機能がそのモデルに切り替わる。Apple は各モデルプロバイダーとの契約で**ユーザークエリを学習に使用しない**条件を義務付けており、プライバシーポリシー面での一貫性を保っている。開発者向けには Extensions API が公開され、サードパーティアプリからも同じ切り替え機構を呼び出せる設計となっている。

```swift
// Apple Intelligence Extensions API の呼び出し例（教育目的サンプル）
import AppleIntelligence

struct WritingAssistant {
    // ユーザーが設定で選択した Extensions モデルを取得
    let model = AIExtensionsModel.userPreferred

    func rewrite(text: String, intent: WritingIntent) async throws -> String {
        let request = WritingRequest(
            input: text,
            intent: intent,
            contextPolicy: .ephemeral   // クエリはリクエスト後に廃棄
        )
        let response = try await model.process(request)
        return response.output
    }
}

// 使用例
let assistant = WritingAssistant()
let result = try await assistant.rewrite(
    text: "This PR adds a new feature.",
    intent: .makeProfessional
)
```

### Cisco CVE-2026-20245 — SD-WAN Manager CLI コマンドインジェクション、2026 年で 7 本目のゼロデイ

**CVE-2026-20245** は netadmin 権限を前提としつつも、企業ネットワークで広く使われる SD-WAN 基盤を root 権限で完全掌握できる点で影響の深刻度は CVSS スコアを超える。SD-WAN Manager は企業の全拠点ルーターやファイアウォールの設定を中央管理するコントロールプレーンであり、侵害されると**全 WAN ポリシーの書き換え・トラフィック傍受・バックドア設置**が可能になる。注意すべきは「netadmin 権限が前提」という点で、これは高い壁ではない。同一製品への以前のゼロデイ（CVE-2026-20182・CVE-2026-20127 等）を連鎖させれば権限昇格の踏み台として使える構造になっている。

```bash
# --- CVE-2026-20245 緊急対応チェックリスト ---

# 1. 影響バージョンの確認（SD-WAN Manager CLI）
show version
# 最新のパッチ済みバージョンが出るまで全バージョンが影響対象

# 2. netadmin 権限アカウントの棚卸し
show aaa users
# 不要・不審なアカウントは即時無効化

# 3. 不審なファイルアップロードのログ確認
show logging | grep "file upload"
# Mandiant が確認した手口: 細工した設定ファイルを vmanage にアップロード

# 4. エッジデバイスへの不正な設定変更確認
show config-transaction-log
# 心当たりのない設定変更は侵害の可能性

# 5. 侵害が疑われる場合: Cisco PSIRT + Mandiant IR への連絡を優先
#    https://tools.cisco.com/security/center/resources/security_vulnerability_policy.html

# 6. ネットワーク分離: SD-WAN Manager の管理インターフェースを
#    アウトオブバンド管理ネットワークに閉じ込め、インターネット直接到達を遮断
```

**影響範囲と優先度**: 全 Cisco Catalyst SD-WAN Manager デプロイメント（オンプレ・クラウド問わず）。パッチ・ワークアラウンドなしのため、侵害インジケーター調査と権限最小化が当面の唯一の緩和策となる。
