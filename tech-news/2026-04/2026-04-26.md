### 1. DeepSeek V4 Preview — MIT ライセンスでオープンソース公開、100万トークンコンテキストを標準装備

中国の AI スタートアップ DeepSeek が 4 月 24 日、最新モデル「DeepSeek-V4」シリーズのプレビューを MIT ライセンスのもとオープンソース公開した。プロモデル「V4-Pro」は総パラメータ数 1.6T（アクティブ 49B）の Mixture-of-Experts 構成、軽量版「V4-Flash」は 284B（アクティブ 13B）となっており、双方が 100 万トークンのコンテキストウィンドウを既定で備える。100 万トークンを付け足しの機能としてではなく設計の出発点にしたのは業界初と DeepSeek は主張しており、長文ドキュメント処理やマルチターンエージェントワークフローでの優位性が注目される。API 価格は V4-Pro が出力 100 万トークンあたり $3.48、V4-Flash が $0.28 と競合他社の同等クラスと比較して大幅に低く、西側ベンダーへのコスト圧力が再び強まっている。HuggingFace でのウェイト公開により、オンプレミスでのファインチューニング・ローカル推論も即日実施可能となった。なお既存エンドポイント `deepseek-chat` と `deepseek-reasoner` は 2026 年 7 月 24 日に廃止予定となっている。

### 2. Microsoft Defender ゼロデイ 3 件が悪用中 — うち 2 件はまだ未パッチ（BlueHammer）

The Hacker News が 4 月 25 日に報じたところによると、Microsoft Defender に関連するゼロデイが 3 件同時に悪用されており、そのうち 2 件はいまだ修正パッチが提供されていない。CVE-2026-33825 は「BlueHammer」と命名された Defender の特権昇格脆弱性で、4 月 10 日から実環境での悪用が確認されており、CISA は 4 月 22 日に KEV カタログへ追加、連邦機関に対して 5 月 6 日までの修正を義務付けた。今月の Microsoft Patch Tuesday（4 月分）は合計 168 件の脆弱性を修正しており、Windows IKE サービス拡張に影響する CVSS 9.8 のリモートコード実行脆弱性 CVE-2026-33824 も Critical に分類されている。未パッチの 2 件については攻撃手法の詳細が限定公開に留まっているが、Defender のリアルタイム保護機能を無効化できるとする報告もあり、影響範囲の広さから企業のセキュリティチームに緊急の対応が求められている。Patch Tuesday アップデートをまだ適用していない環境では即時の Windows Update を強く推奨する。

### 3. EU「Cloud and AI Development Act（CADA）」が立法プロセス入り — データセンター容量 3 倍・米中ハイパースケーラー依存脱却を目標に

欧州委員会が 2026 年第 1 四半期に提案を予告していた「Cloud and AI Development Act（CADA）」が欧州議会の立法スケジュールに正式に登録され、審議が本格化している。CADA はデータセンター容量の 5〜7 年以内の 3 倍化支援、高性能コンピューティング・AI・量子技術の研究開発促進、重要ユースケース向けの EU 拠点クラウドおよび AI 計算基盤の確保という 3 本柱で構成される。背景には、EU の GDP が米国と同等であるにもかかわらずグローバルデータセンター容量の比率が米国の半分に留まり、EU のクラウド市場の約 65% を米国 3 大ハイパースケーラーが占める現状への危機感がある。同法案はクラウドサービスプロバイダーへの EU 全域での資格要件を設けることで非 EU 企業の参入に事実上の制限を加える条項も含んでおり、米国テック企業からの反発が予想される。AI 関連貿易が 2025 年比約 40% 拡大する一方、地政学的対立による多極化が進む中、デジタル主権の確立を目指す欧州の動きが立法という形で具体化した。

**出典**: [EU Parliament — Cloud and AI Development Act Legislative Train](https://www.europarl.europa.eu/legislative-train/theme-a-new-plan-for-europe-s-sustainable-prosperity-and-competitiveness/file-cloud-and-ai-development-act) / [EU CADA 解説記事](https://julsimon.medium.com/the-eu-cloud-and-ai-development-act-cada-a-last-shot-at-cloud-sovereignty-or-another-expensive-74ccc1a4007c)

### Zig 0.16.0「Juicy Main」— 非同期 I/O インターフェース刷新・インクリメンタルコンパイル大幅改善

Zig プログラミング言語が 4 月 14 日にバージョン 0.16.0「Juicy Main」をリリースした。244 名のコントリビューターによる 1,183 コミット、8 か月分の作業がまとまった大型リリースとなっている。最大の変更点は非同期 I/O の抜本的見直しで、新設の `std.Io` インターフェースが Linux（io_uring）・macOS（GCD）それぞれのバックエンドをサポートする統一 API を提供し、非同期関数と同期関数の「関数の色付け問題」が解消された。また「Juicy Main」の由来でもある `main()` への依存注入機能が追加され、`process.Init` パラメータを受け取ることでアロケータや I/O バックエンドへ即座にアクセスできる。コンパイラ内部では依存グラフを循環グラフから DAG（有向非巡回グラフ）に再設計しており、インクリメンタルビルドで一箇所の変更が大量の再解析を引き起こしていた問題が大幅に改善された。Alpha・KVX・OpenRISC・SuperH など新アーキテクチャの基本サポートも追加されている。

```zig
// Zig 0.16.0: "Juicy Main" — process.Init 依存注入
const std = @import("std");

pub fn main(init: std.process.Init) !void {
    // アロケータ・I/O バックエンドが init 経由で提供される
    const allocator = init.allocator;
    var io = init.io;

    // io_uring (Linux) / GCD (macOS) を抽象化した統一 API
    const file = try io.openFile("data.txt", .{ .mode = .read_only });
    defer file.close();

    const content = try file.readToEndAlloc(allocator, 4096);
    defer allocator.free(content);

    try io.stdout.writeAll(content);
    // 非同期・同期どちらのバックエンドでも同じコード ― 関数の色付けなし
}
```

### Chrome 2026 年 4 件目のゼロデイ CVE-2026-5281 — WebGPU Dawn の use-after-free が悪用中

Google Chrome の WebGPU 実装「Dawn」に use-after-free 脆弱性 CVE-2026-5281 が発見され、実環境での悪用が確認されている。Chrome 146.0.7680.178（Windows/macOS）・177（Linux）未満のバージョンが影響を受け、レンダラープロセスへの侵入に成功した攻撃者が細工した WebGPU 命令を通じて解放済みメモリにアクセスし、任意コードを実行できる。本脆弱性はサンドボックス脱出を含むエクスプロイトチェーンの第 2 段として使われているとみられており、単体では「レンダラー侵害済み」が前提となる。CISA は KEV カタログに追加し連邦機関に修正期限を設けた。Chrome の自動更新が有効な環境では既にパッチが配信済みだが、エンタープライズ環境でのバージョン管理・固定を行っている場合は手動での更新確認が必要。2026 年に入ってから Chrome のゼロデイ悪用は本件で 4 件目となり、ブラウザグラフィクス API 周辺のアタックサーフェス拡大が改めて課題として浮き彫りになっている。

**出典**: [The Hacker News — New Chrome Zero-Day CVE-2026-5281 Under Active Exploitation](https://thehackernews.com/2026/04/new-chrome-zero-day-cve-2026-5281-under.html) / [SOCRadar — CVE-2026-5281 Chrome WebGPU Zero-Day](https://socradar.io/blog/cve-2026-5281-chrome-webgpu-zero-day/)

### Fortinet CVE-2026-35616（CVSS 9.1）— FortiClient EMS の認証前 API バイパスが悪用中

Fortinet が FortiClient Endpoint Management Server（EMS）に影響するゼロデイ CVE-2026-35616（CVSS 9.1）に対してアウトオブバンドパッチを公開した。認証前の API アクセスバイパスにより未認証の攻撃者がエンドポイント管理サーバーで特権昇格を実行できる深刻な問題で、既に実環境での悪用が確認されている。FortiClient EMS を使用してエンドポイントの集中管理を行っている組織は、Fortinet が提供するセキュリティアドバイザリを参照し速やかにパッチを適用されたい。

**出典**: [The Hacker News — Fortinet Patches Actively Exploited CVE-2026-35616 in FortiClient EMS](https://thehackernews.com/2026/04/fortinet-patches-actively-exploited-cve.html)
