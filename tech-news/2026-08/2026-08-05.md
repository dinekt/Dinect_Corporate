### 1. Jeff Dean、Google退社後27年ぶりのスタートアップ「Discovery Loop」を創業 — Google DeepMindも大規模組織改編

GoogleのチーフサイエンティストであるJeff Deanが27年間勤続したGoogleを退社し、**Discovery Loop**をco-foundとして創業した（8月5日付）。共同創業者はBigTable・MapReduce・Word2Vecなど数々の重要論文を共に執筆してきた**Sanjay Ghemawat**、AlphaFoldの中心メンバー**Oriol Vinyals**、そして言語モデル研究の先駆者**Quoc Le**の3名。Discovery Loopは**独立した公益法人（Public Benefit Corporation）**として設立され、当面はAI・機械学習研究・エンジニアリングの「自律的な実験ループの自動化」に集中し、将来的にはハードウェア設計・創薬・クリーンエネルギーへの展開を計画している。資金調達はRadical VenturesとKhosla Venturesが共同リードし、Google自身もスタートアップに出資する形での友好的な分離となった。この発表と同日に、Google DeepMindのCEOであるDemis Hassabisも同職を退いてDeepMindの会長・Alphabet全体のチーフサイエンティストに就任することが発表され、Google AIの組織が大規模に再編された。TensorFlow・Transformerアーキテクチャの礎を築いた人物たちが一斉にGoogleから独立して研究機関ともスタートアップとも異なるPBCを立ち上げたことは、大規模AIラボの優秀な人材をつなぎとめる求心力の限界と、「基礎科学×AI」という新たな投資テーマの台頭を同時に示している。

### 2. npmワーム「Shai-Hulud」がkeyv等800以上のパッケージを汚染 — AIエージェント設定ファイルを隠れ蓑に月間20億DL超の依存を侵害

8月4日、npmエコシステムを直撃するサプライチェーン攻撃「**Shai-Hulud**」が発覚した。攻撃者はキャッシュライブラリ**keyv**と**cacheable**のメンテナ（Jared Wray）のGitHubアカウントを乗っ取り、10種の広く使われるnpmパッケージに悪意あるバージョンを公開。ワームは自律的に拡散し、9:35〜13:18 UTC（わずか4時間弱）の間に**@ornikar・@deliveroo・@qlik・@picsart・@servicetitan**など12の無関係な組織へと感染が広がった。SafeDepの検証では**444パッケージ名・2,234汚染バージョン**、Aikidoは最広義で1,381バージョン以上と報告しており、月間ダウンロード数は合計で**20億回以上**に上ると推計されている。技術的に際立つのは3つの巧妙な回避手法だ。①悪意コードを**AIコーディングエージェントやIDEの設定ファイル**（依存関係スキャナが読まない領域）に埋め込む、②C2通信を**Ethereumスマートコントラクト**経由にして固定ドメインのブロックを無効化する、③防御側がクレデンシャルを**ローテートしようとした瞬間**に攻撃者制御コードをトリガーするトークン失効ウォッチャーを仕込む。ペイロードはnpm・GitHub・AWS・HashiCorp Vaultの認証情報を収集するドロッパーで、`package.json`の`preinstall`スクリプトを通じて`npm install`を実行するだけで発火する設計だった。

### Langflow CVE-2026-9198（CVSS 9.8）がCISA KEVに追加 — AIエージェント基盤の認証不要RCEが実際に悪用中

CISAは8月5日、Langflowのコードインジェクション脆弱性**CVE-2026-9198**（CVSS: **9.8**）を既知悪用脆弱性（KEV）カタログに追加した。Langflowは視覚的なノードベースUIでLangChainコンポーネントを組み合わせてAIエージェントを構築・実行できるオープンソースフレームワーク。この脆弱性では、デフォルトのLangflow展開に対して**認証不要の攻撃者が完全なRCEを実行可能**で、野外での実際の悪用が確認されたため緊急のKEV指定となった。Langflowは多くの組織でAIエージェントの開発・プロトタイピング基盤として使われており、インターネットに露出したインスタンスは直接攻撃対象になる。

```bash
# Langflow バージョン確認
pip show langflow | grep Version

# 最新版への更新（緊急対応）
pip install --upgrade langflow

# Langflow がパブリックにアクセス可能か確認（ファイアウォールルール見直し）
# デフォルトポート: 7860
curl -I http://localhost:7860

# 即時緩和: ネットワークレベルでのアクセス制限
# ローカルホストのみにバインドする場合:
# langflow run --host 127.0.0.1 --port 7860

# 認証を必ず有効化（環境変数）
# LANGFLOW_AUTO_LOGIN=false
# LANGFLOW_SUPERUSER=<your_admin>
# LANGFLOW_SUPERUSER_PASSWORD=<strong_password>

echo "CVE-2026-9198: CVSS 9.8, 認証不要RCE — Langflowを即時更新し外部公開を禁止すること"
```

Langflowのような「AIエージェント実行基盤」がCVSS 9.8の認証不要RCEを抱えることは、AIワークフローのセキュリティが従来のWebアプリ以上に深刻になりうることを示す。AIエージェントは外部API・データベース・クラウドリソースへの広範なアクセス権を持つため、RCEの影響範囲がホスト単体にとどまらず組織全体のクレデンシャルや接続先システムへ広がりやすい。
