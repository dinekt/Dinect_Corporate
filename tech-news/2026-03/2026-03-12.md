## ニュース一覧

### 1. Microsoft Patch Tuesday 3月 — 83件の脆弱性を修正、ゼロデイ2件に要注意
**カテゴリ**: セキュリティ
**影響度**: ★★★★★

Microsoftが3月10日にリリースしたセキュリティ更新プログラムで、83件の脆弱性が修正されました。特に注目すべきは公開済みのゼロデイ2件です。

- **CVE-2026-21262（CVSS 8.8）**: SQL Serverの特権昇格の脆弱性。ログインユーザーがsysadmin権限まで昇格可能で、データベースの読み書き・削除・設定変更が可能に
- **CVE-2026-26127（CVSS 7.5）**: .NETのDoS（サービス拒否）脆弱性
- **CVE-2026-26113 / CVE-2026-26110**: Microsoft Officeのリモートコード実行（RCE）— Critical評価

修正の内訳は特権昇格が56%（46件）、RCEが20%（16件）、情報漏洩が12%（10件）です。

**個人開発者への影響**:
- SQL ServerやAzure SQL Databaseを使っているプロジェクトは即座にパッチ適用を
- .NET系のWebアプリ・APIもDoS対策としてアップデート推奨
- **今すべきこと**: `Windows Update` を手動実行。開発用サーバーのSQL Serverバージョンを確認し、パッチが当たっているか検証する

### 2. Cursorが「Automations」発表 — AIエージェントが常時稼働する新しい開発スタイル
**カテゴリ**: AI / 開発ツール
**影響度**: ★★★★★

Cursorが3月5日に発表した「Automations」は、AIコーディングエージェントを**イベント駆動で自動起動**させる仕組みです。Slackメッセージの受信、GitHub PRのマージ、PagerDutyのインシデント発生、Linearのチケット作成などをトリガーにして、クラウドサンドボックス上でAIエージェントが自動的にコードを書き始めます。

エージェントは過去の実行結果を記憶するメモリツールを持ち、繰り返すほど精度が向上。MCP（Model Context Protocol）にも対応し、カスタムモデルの設定も可能です。

**個人開発者への影響**:
- 「コードを書く」だけでなく「コードを書くAIの設定・監督」が開発者の新しい役割になりつつある
- ただしCursor専用機能であり、VS CodeやJetBrainsからは利用不可。エディタのロックインリスクあり
- Claude Codeのヘッドレスモード + スクリプトで**同様のワークフローは既に構築可能**
- **今すべきこと**: 自分の開発フローで「トリガー → 自動実行」にできる作業を洗い出す。Claude Codeユーザーなら `claude -p` + webhookで代替を検討

### 3. Anthropic、Time誌が「世界で最も破壊的な企業」に選出 — Claude Codeの売上$25億超
**カテゴリ**: AI / ビジネス
**影響度**: ★★★★☆

Time誌がAnthropicを「2026年で最も破壊的な企業」に選出しました。Claude Codeの年間売上は$25億（約3,750億円）を超え、2025年末の$10億から急成長。米国企業のAnthropicツール利用率は20%に達し（1年前は4%）、OpenAIの企業向けシェアは50%→27%に低下しています。

一方で、ペンタゴンのブラックリスト問題が続いており、Anthropicは「自律兵器・大規模監視にClaudeを使わせない」との方針を堅持。MicrosoftがClaude をMicrosoft 365 Copilotに統合するパートナーシップも同時に発表されています。

**個人開発者への影響**:
- Claude依存の事業者にとってAnthropicの成長は安心材料。ただしペンタゴン問題は注視
- Microsoft 365 Copilot経由でClaudeが使えるようになれば、企業向けAIツールの選択肢が大幅に広がる
- **今すべきこと**: 引き続きマルチモデル対応の設計を意識。特定モデルへの過度な依存は避ける

### 4. 日本政府、「ガバメントAI（源内）」で国産LLM 7モデルを選定 — 18万人の実証実験へ
**カテゴリ**: AI / 日本
**影響度**: ★★★★☆

デジタル庁が3月6日、政府のAI利用環境「ガバメントAI（源内）」で試用する国産LLM（大規模言語モデル）として7モデルを選定したと発表しました。NTTの「tsuzumi 2」、KDDI・ELYZAの「Llama-3.1-ELYZA-JP-70B」、ソフトバンクの「Sarashina2 mini」などが含まれ、全府省庁の約18万人の職員が対象の大規模な実証実験です。

**個人開発者への影響**:
- 官公庁がAIを「試す」フェーズに入ったことで、自治体DX案件でのAI活用提案がしやすくなる
- 国産LLMのエコシステムが成長すれば、日本語特化の安価なAPI選択肢が増える可能性
- **今すべきこと**: tsuzumi 2やELYZAモデルのAPI提供状況をウォッチ。自治体・官公庁向けのAIソリューション提案では「国産LLM対応」が差別化ポイントになりうる

### 5. 「SaaSpocalypse」— AIコーディングエージェントがSaaSビジネスモデルを破壊する
**カテゴリ**: ビジネス / SaaS
**影響度**: ★★★★☆

TechCrunchが「SaaSpocalypse（SaaS黙示録）」と題した記事で、AIコーディングエージェントの台頭によりSaaSの「Build vs Buy（作るか買うか）」の判断が「作る」側に急速にシフトしていると報じました。AIエージェントが1人でシステムを構築できる時代に、ユーザー数×月額のSaaS課金モデルが成立しにくくなっています。

**個人開発者への影響**:
- 「簡単に作れるもの」をSaaSとして売るのは今後ますます難しくなる
- **データ・ネットワーク効果・専門知識**など、AIで複製できない価値が必要
- 従量課金やAPIベースの課金モデルへの移行を検討すべき
- **今すべきこと**: 自分のプロダクトが「AIエージェントで2日で作れるもの」でないか自問する。作れるなら差別化戦略の見直しが急務

### 6. Google「AI Mode」が検索を超えた生産性ハブに進化
**カテゴリ**: AI / Web
**影響度**: ★★★★☆

Googleが3月6日にGoogle検索の「AI Mode」を拡張。従来の質問応答に加え、ドキュメント作成、コード生成、ツール構築が検索インターフェース上で直接可能になりました。検索が「調べる場所」から「作業する場所」へ変貌しつつあります。

**個人開発者への影響**:
- SEO（検索エンジン最適化）の概念がさらに変化。検索結果ページに留まるユーザーが増え、サイトへの流入が減少する傾向が加速
- GEO（Generative Engine Optimization: 生成AI検索最適化）の重要性がますます高まる
- **今すべきこと**: 自分のWebサイト・サービスのトラフィックソースを確認。Google検索からの流入比率が高い場合、AI検索での引用されやすさを意識したコンテンツ設計を

### 7. 新モデルリリース: Gemini 3.1 Flash-Lite / GPT-5.3 Instant / Qwen3.5
**カテゴリ**: AI / モデル
**影響度**: ★★★☆☆

3月に入り主要AIプロバイダーから新モデルが続々リリースされています:

- **Gemini 3.1 Flash-Lite**: 大規模ワークロード向けの低コスト・高速モデル。入力$0.25/100万トークン、出力$1.50/100万トークン。Gemini 2.5 Flashより高速なレイテンシ
- **GPT-5.3 Instant**: ChatGPTの会話フロー・回答精度・Web検索結果の改善に特化したアップデート
- **Qwen3.5（Alibaba）**: ノートPCやエッジデバイスで動作するコンパクトモデルながら、大型モデルを上回る性能

**個人開発者への影響**:
- Flash-Liteは大量処理（バッチ分析、データ前処理）のコスト削減に有効
- ローカルLLMの選択肢としてQwen3.5は注目。オフライン動作が求められる場面で活躍
- **今すべきこと**: プロダクトの用途別に最適なモデルを選定。速度重視→Flash-Lite、品質重視→Opus/Sonnet、コスト重視→Qwen3.5の使い分けを検討
