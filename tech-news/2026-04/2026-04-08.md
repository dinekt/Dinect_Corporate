# テックニュースデイリー 2026-04-08

## 本日のニュース TOP 3

### 1. Chrome 2026年4本目のゼロデイ — CVE-2026-5281、WebGPU「Dawn」のUAF脆弱性が実攻撃で悪用
GoogleがChrome 146.0.7680.177/178 の緊急アウトオブバンド更新を公開。Dawn（WebGPUのChromium実装）のUse-After-Free脆弱性（CVE-2026-5281）が実際の攻撃に悪用されていることをGoogleが確認した。Dawnは WebGPU APIとGPUハードウェアを仲介するレイヤーであり、メモリ安全性バグが直接GPU操作に影響する。ChromiumベースのブラウザはEdge・Brave・Opera等すべてが影響対象。CISAは4月1日にKEVカタログへ追加し、連邦機関に4月15日までのパッチ適用を命令。今年に入ってChromeで実悪用が確認された4本目のゼロデイとなり、WebGPUが新たな攻撃対象領域として注目されている。

**開発者への影響**:
- ChromeおよびChromiumベースブラウザを即時146系最新版へ更新すること
- Electron製アプリやPuppeteer/Playwright を使うCI環境も、内包するChromiumバージョンの確認を推奨

### 2. MCPがLinux Foundation傘下「AAIF」に移管 — AIエージェント標準の中立化が完了
AnthropicのModel Context Protocol（MCP）が、Linux Foundation傘下に新設されたAgentic AI Foundation（AAIF）に正式移管。AAIFはAnthropic・Block・OpenAIの3社が共同創設し、MCPのほかBlockのgoose、OpenAIのAGENTS.mdも参加プロジェクトとして加わった。技術的な意思決定権は従来のメンテナチームが保持し続け、Linux Foundationは中立的なインフラと法的フレームワークを提供する役割に徹する。MCPは2026年3月時点で9,700万インストールを突破し、主要AIプロバイダー全社がMCP互換ツールを出荷済み。2026年のロードマップではトランスポートのスケーラビリティ、エージェント間通信、エンタープライズ対応が重点領域とされている。

**開発者への影響**:
- MCPの中立化により、ベンダーロックインを懸念せずエコシステムへ投資できる環境が整った
- AIエージェント構築の標準インターフェイスとしてMCPを採用する機運が業界全体で高まっている

### 3. EU DMA/DSA本格執行 vs トランプ政権 — デジタル規制が「貿易摩擦」に発展の兆し
EUが2026年、Digital Markets Act（DMA）とDigital Services Act（DSA）の本格執行フェーズに突入し、Google・Meta・Apple・Amazonへの制裁が現実化しつつある。トランプ政権はこれを「米国企業への差別的規制」と位置づけ、報復措置を示唆。EU側は権利・リスクベースの規制モデルを主張する一方、米国はイノベーション保護のための任意標準を訴え、両陣営の対立が深まっている。同時に、国連主導の「AIガバナンスに関するグローバル対話」が2026年に初めて本格始動し、ほぼすべての国が参加できる国際フォーラムが設置された。クラウド・半導体・データ・AIを安全保障上の戦略資産として明示的に位置付ける動きも各国で加速している。

**開発者への影響**:
- EU向けプロダクトやSaaSを持つ場合、DMA/DSAのコンプライアンス要件を改めて精査する時期
- データローカライゼーションや脆弱性開示の義務化が複数の管轄で進んでおり、グローバル展開時の設計に影響する

## 新技術・新リリース

### GCC 16 リリース予定（2026年4月）— Algol 68フロントエンド・Intel AVX10サポート追加
GCC（GNU Compiler Collection）16が4月中に正式リリース予定。歴史的プログラミング言語Algol 68の新フロントエンドが追加され、GCCが対応する言語ファミリーが拡大する。さらにIntel AVX10（Advanced Vector Extensions 10）への対応により、最新世代CPUの512ビットベクトル演算が活用可能になる。AVX10は従来のAVX-512を統一化したIntelの新世代ベクトル拡張命令セットで、スーパーコンピューティングや機械学習推論の高速化に使われる。

```bash
# AVX10を有効にしたコンパイル例（GCC 16+）
gcc -O3 -mavx10.1-512 -o my_program my_program.c

# Algol 68 フロントエンドを確認する
gcc --version   # GCC 16.x
gnat --help     # 既存ADA等と同様に言語フロントエンドが追加
```

## セキュリティ

### CVE-2026-5281: Chrome WebGPU/Dawn Use-After-Free（実悪用確認、CISA KEV入り）
- **影響**: Chrome 146.0.7680.177未満（Win/macOS/Linux）、Chromiumベース全ブラウザ
- **リスク**: リモート攻撃者がレンダラープロセス経由で任意コード実行可能
- **対応**: `146.0.7680.177`（Linux）/ `146.0.7680.177/178`（Win/macOS）以上へ更新
- **CISA期限**: 連邦機関への適用期限 **4月15日**。今年4本目の実悪用確認ゼロデイ

### CVE-2026-34040: Docker Engine 認証バイパス（CVSS 8.8）
Docker Engineに高深刻度の認証バイパス脆弱性。認証プラグイン（authorization plugin）を迂回して特権APIエンドポイントへ不正アクセスが可能で、コンテナ化ワークロードを本番運用している環境での即時パッチ適用が急務。

### CVE-2025-55182: Next.js 認証バイパス — 766ホストで大規模クレデンシャル窃取
Next.jsの認証バイパス脆弱性を悪用した大規模なクレデンシャルハーベスティングが観測されており、766のNext.jsホストへの侵害とSSH秘密鍵・AWSシークレット・その他機密情報の窃取が確認されている。Next.jsを本番運用している場合は即時バージョン確認を推奨。
