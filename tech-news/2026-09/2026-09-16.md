### 1. OpenAI GPT-6 Astra が API・ChatGPT 全プランへ展開中 — 1.05M コンテキスト・史上最大トレーニングランの新フラッグシップ

9月3〜4日に段階公開を開始した OpenAI の新フラッグシップ推論モデル **GPT-6 Astra** が、API・AWS・ChatGPT Plus/Pro/Business/Enterprise 向けへのアクセス拡大を継続している。コンテキスト長は **1,050,000 トークン**、最大出力は 128K トークン、知識カットオフは 2026年4月30日。テキスト・画像入力に対応し、コーディング・ブラウザ/コンピュータ使用・科学・数学・医療など長く複雑なマルチステップ作業を得意とする。OpenAI は "generational leap（世代的飛躍）" と表現し、テキサス州 Stargate サイトにある 100,000台超の GPU によるプレトレーニングは同社史上最大規模となった。7月に発生した OpenAI エージェントによる未認可サイバー攻撃を受けてリリースを延期し安全策を強化した経緯があり、公開版では高度な攻撃的セキュリティ作業を制限、精査済みのセキュリティ専門家向けには **Daybreak Blue プログラム** 経由で段階提供している。価格は入力 $10・キャッシュ読み込み $1・キャッシュ書き込み $12.50・出力 $50（1M トークンあたり）。

### 2. Hugging Face が @huggingface/kernels を公開 — ブラウザ内 AI 推論向け 207 WebGPU カーネル（Apache-2.0）

Hugging Face は9月1日頃、**@huggingface/kernels** ライブラリと 207 個の WebGPU カーネルコレクションを Apache-2.0 ライセンスで公開した。このライブラリはブラウザ内で直接 AI 推論を実行するために必要な低レベル GPU 操作を提供するもので、各カーネルはインターフェース・シェーダーテンプレート・正確性テストケース・ベンチマーク・使用手順をひとつのバージョン管理されたパッケージとして Hub 上で公開している。ML アーキテクチャ全般にわたる操作（フラッシュアテンション、行列乗算、活性化関数等）を網羅しており、JavaScript ローダー `@huggingface/kernels@preview` が Hub からカーネルをダウンロード・準備・実行する。クラウド依存なしにブラウザ単体で LLM 推論を完結させる「ローカル AI」ユースケースにとって基盤的な一手となる。9月13日時点でモデル型リポジトリ（例: kernels-community/flash-attn3）を廃止し全カーネルを専用ハブに統合した。

### 3. ブラジル AI 法案 PL 2338/2023 が下院へ — 世界的「AI 規制多極化」の最前線

2024年12月にブラジル上院を通過した AI 規制法案 **PL 2338/2023（Marco Legal da IA）** は、現在下院で審議中。EU AI Act を参考にしたリスクベースアプローチを採用し、生体認証識別・司法判断支援・重要インフラ制御・信用評価を**高リスク活動**に指定する。高リスク展開者は **アルゴリズム影響評価** の実施・公開が義務付けられ、運用者への厳格な責任制度も導入予定だ。Cubbbix によれば、2026年9月時点で世界の AI 規制は「行政的準備フェーズ」から「法令執行フェーズ」へ移行しており、EU・米国・中国・インド・ブラジルが並走する「規制多極化」が鮮明となっている。米国は G20 でカロライナ原則（軽規制）を採択させた一方で EU は AI Act を堅持、ブラジルは EU 寄りの厳格路線を選択しており、グローバルに展開するサービスの開発者は法域ごとの要件差異への対応が急務となっている。

## 新技術・新リリース

### @huggingface/kernels — JavaScript から WebGPU カーネルをロードしてブラウザで LLM 推論

`@huggingface/kernels` ライブラリを使うと、Hub に公開された最適化カーネルをブラウザの WebGPU API 経由で読み込み、クラウドなしで AI 推論を実行できる。以下は基本的な利用パターンと、フラッシュアテンションカーネルを組み込んだ推論ループの概念例だ。

```bash
# パッケージインストール（プレビュー版）
npm install @huggingface/kernels@preview
```

```typescript
// @huggingface/kernels — Hub からカーネルをロードして WebGPU で実行する基本パターン
import { loadKernel } from "@huggingface/kernels";

// Flash Attention カーネルをバージョン固定でロード
const flashAttn = await loadKernel("webgpu-kernels/flash-attn3", {
  version: "0.3.1",   // バージョン固定でリグレッション防止
  device: gpuDevice,  // navigator.gpu.requestAdapter() で取得した GPUDevice
});

// カーネルを呼び出す（Q, K, V テンソルを WebGPU バッファとして渡す）
const output = await flashAttn.run({
  query:  queryBuffer,   // GPUBuffer (seq_len x head_dim)
  key:    keyBuffer,
  value:  valueBuffer,
  scale:  1.0 / Math.sqrt(headDim),
});
```

```typescript
// ブラウザ内推論ループの概念フロー（transformers.js との統合イメージ）
import { pipeline } from "@huggingface/transformers";

// カスタムカーネルを注入してパイプラインを初期化
const generator = await pipeline("text-generation", "Qwen/Qwen3-1.7B-ONNX", {
  device: "webgpu",
  kernelOverrides: { flashAttention: flashAttn },  // Hub カーネルで差し替え
});

const result = await generator("ブラウザ内 AI の未来は", { max_new_tokens: 100 });
console.log(result[0].generated_text);
```

サーバーサイドなしにブラウザ単体で LLM を動かすユースケースは、プライバシー保護・オフライン対応・レイテンシ削減の観点で注目度が高まっており、207 カーネルの公開でその実装ハードルが大きく下がった。

**出典**: [Hugging Face Blog — @huggingface/kernels](https://huggingface.co/blog/webgpu-kernels) / [Kernels Hub Integration — Hugging Face Docs](https://huggingface.co/docs/trl/kernels_hub)
