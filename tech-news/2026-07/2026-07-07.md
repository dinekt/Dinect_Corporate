### 1. 世界初の完全自律型AIエージェントランサムウェア「JADEPUFFER」をSysdigが記録 — LangflowのRCEから暗号化まで人間の介入ゼロ

Sysdigの脅威リサーチチームが、LLM（大規模言語モデル）エージェントによって端から端まで制御された世界初の完全自律型ランサムウェア攻撃「**JADEPUFFER**」を記録・公表した。攻撃者はLangflow の未認証RCE脆弱性 **CVE-2025-3248**（CVSS 9.8）を悪用して侵入し、AIエージェントが偵察・クレデンシャル窃取・横断移動・権限昇格・最終的なデータベース暗号化まで600以上の独立したペイロードを自律的に実行した。**Nacos**サービス構成ファイル1,342件を暗号化した後に原本を削除するという手順で、ある失敗ステップからわずか**31秒**で対処策を自力で導き出した記録も残っている。Sysdigは「ランサムウェアの実行に必要な技術的スキルのハードルが、LLMエージェントを動かすコストまで低下した」と分析しており、LLMジャッキング（他社の盗んだクレデンシャルを使ってLLMを無料で利用する手法）と組み合わせれば攻撃コストはほぼゼロになると警告している。Langflowはすでにパッチ済みだが、CVE-2025-3248はCISA KEVに登録されており未適用環境の即時パッチ適用が求められる。

### 3. Claude Fable 5、本日よりサブスクリプション包含外へ — Usage Credits方式に移行、入力$10・出力$50/Mトークン

7月1日に米国商務省が輸出規制を解除したことで約19日間の停止から復旧した **Claude Fable 5** が、本日（7月7日）をもってほぼすべての有料サブスクリプションプランから除外され、**Usage Credits**（従量課金）方式へ移行した。料金は入力トークン**$10/Mトークン**・出力トークン**$50/Mトークン**（プロンプトキャッシュは90%引き）で、Pro・Max・Team・Enterprise各プランから別途チャージされる形となる。Anthropicは「供給容量が整い次第、サブスクリプション内でのFable利用を再開する」と説明しているが、時期は未定だ。7月1日の復旧後、同社は安全分類器を新たに訓練して当該ジェイルブレイク手法を99%以上ブロックしていることも公表しており、政府との合意条件を満たした形となっている。Anthropicの年間経常収益は$47Bに達しOpenAIの$25〜33Bを上回ったとの報道もあり、Fable 5の普及と収益化の両立が今後の課題となる。

### TypeScript 7.0 RC — Goネイティブコンパイラーでビルド速度10倍、VS Code 1.5M行が78秒→7.5秒へ

6月18日にリリースキャンディデート（RC）が公開された **TypeScript 7.0** は、JavaScriptで書かれた従来コンパイラー（内部コード名 Strada）をGoで書き直した **Project Corsa** の成果であり、型チェック速度が従来比**約10倍**に向上している。VS Codeのコードベース（約150万行）での実測では**78秒 → 7.5秒**という劇的な短縮が確認されており、大規模モノレポでの恩恵が特に大きい。型チェックのロジックはTypeScript 6.0と構造的に同一であるため、既存の型定義は互換性を維持しているが、プログラマティックAPIを利用している場合は 7.1 まで待つことが推奨されている。`tsc` バイナリが標準のままGoネイティブ実装に差し替えられた形で、別途のインストール手順は不要だ。GA（正式リリース）はRCから約1ヵ月後を見込む。

```bash
# TypeScript 7.0 RC のインストール
npm install -D typescript@rc

# 型チェックのみ実行（--noEmit で出力なし、速度確認）
npx tsc --noEmit

# 10x 速度改善の恩恵を最も感じやすいモノレポ構成例
# tsconfig.json で composite + incremental を有効化
# （Go 実装ではプロジェクト参照の並列処理が大幅に改善）
```

```json
// tsconfig.json — プロジェクト参照を活用した推奨設定 (TypeScript 7.0+)
{
  "compilerOptions": {
    "composite": true,
    "incremental": true,
    "strict": true,
    "isolatedModules": true
  },
  "references": [
    { "path": "./packages/core" },
    { "path": "./packages/api" },
    { "path": "./packages/web" }
  ]
}
```

TypeScript 6.0 が2026年3月に「最後のJavaScriptベースリリース」として公開された後、7.0 RCによってGoネイティブ実装が本流となった。TypeScript 7.1 では `--declaration` や language server API の完全対応が予定されている。

**出典**: [Microsoft DevBlog: Announcing TypeScript 7.0 RC](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0-rc/) / [Visual Studio Magazine: TypeScript 7.0 RC](https://visualstudiomagazine.com/articles/2026/06/22/typescript-7-0-rc-moves-microsofts-go-rewrite-into-the-mainline-compiler.aspx) / [InfoWorld: Go-based TypeScript 7.0 reaches RC](https://www.infoworld.com/article/4191918/typescript-7-0-reaches-release-candidate-stage.html) / [TechTimes: TypeScript 7.0 RC Ships](https://www.techtimes.com/articles/318666/20260618/typescript-70-rc-ships-go-compiler-cuts-vs-code-build-time-77-seconds-seven.htm)

## セキュリティ

### DHS HSIN 侵害確認 + SharePoint RCE CVE-2026-45659 — 連邦インフラへの攻撃が連続する1週間

**DHS HSIN 侵害（7/1 公表）**

米国国土安全保障省（DHS）が運営する重要インフラ情報共有ネットワーク **HSIN（Homeland Security Information Network）**が、5月下旬〜6月初旬にかけて不明な脅威アクターに侵害されていたことが7月1日に公式確認された。HSINは連邦・州・地方政府および民間セクターがセキュリティ情報を共有するための機密システムであり、現在米国でFIFAワールドカップが開催中のため、**会場警備計画・機関間調整手順**などが流出した可能性が懸念されている。攻撃者はHSINサーバーに加え、SharePointベースの協働システムにもアクセスしており、分類された（classified）ネットワークへの影響は現時点では確認されていない。DHSは影響システムを直ちに隔離し、フォレンジック調査中としている。

**SharePoint RCE CVE-2026-45659（CISA KEV追加）**

同週、CISA は Microsoft SharePoint Server の **信頼できないデータのデシリアライズ**に起因するリモートコード実行脆弱性 **CVE-2026-45659**（CVSS 8.8）をKnown Exploited Vulnerabilities（KEV）カタログに追加した。連邦機関には7月4日までのパッチ適用が義務付けられており、HSIN侵害との関連も調査中とみられる。

```bash
# SharePoint CVE-2026-45659 対応チェック（Windows Server 環境）

# 1. 適用済み更新プログラムの確認
Get-HotFix | Where-Object { $_.HotFixID -like "KB*" } | Sort-Object InstalledOn -Descending | Select-Object -First 10

# 2. CISA KEV リストとのクロスチェック（PowerShell 例）
# CISA が公開している kev.json をダウンロードして照合
$kevUrl = "https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json"
$kev = Invoke-RestMethod -Uri $kevUrl
$kev.vulnerabilities | Where-Object { $_.cveID -eq "CVE-2026-45659" }

# 3. SharePoint Server のバージョン確認
# SharePoint Management Shell で確認
Add-PSSnapin Microsoft.SharePoint.PowerShell -ErrorAction SilentlyContinue
(Get-SPFarm).BuildVersion

# ---- 追加脆弱性: 同週 KEV に追加された主要 CVE ----
# CVE-2026-48558 (SimpleHelp) CVSS 10.0 — 認証バイパス
# CVE-2026-8451  (Citrix NetScaler) — 公開24時間以内に悪用開始、メモリ漏洩
# CVE-2026-12569 (PTC Windchill / FlexPLM) — 製造系 PLM システムが標的
```

7月7日時点でCVE-2026-45659を含む週間新規脆弱性件数は1,939件に達しており、CISA KEVは優先順位付けの指針となっている。SimpleHelp（CVSS満点10.0）やCitrix NetScaler（公開24時間以内に悪用開始）も同時期にKEV入りしており、パッチ管理の自動化と優先度付けの重要性が改めて浮き彫りになった。
