### 1. Anthropic「Dreaming」— AIエージェントが過去セッションを自律学習、タスク完了率 6 倍の実績

Anthropic が 5 月 6 日に **Claude Managed Agents** 向けの新機能「**Dreaming（ドリーミング）**」をリサーチプレビューとして公開し、業界に大きな反響を呼んでいる。Dreaming はエージェントがアイドル時間中に過去のセッション履歴・メモリストアを走査し、繰り返し発生するエラーパターン・成功ワークフロー・チーム全体で共有された嗜好を抽出・整理する仕組みだ。従来の RAG（Retrieval-Augmented Generation）が「検索して読む」設計なのに対し、Dreaming は「振り返って学ぶ」設計であり、単一セッションでは発見できない横断的なパターンをエージェント自身が吸収できる点が本質的な差異となる。法律系 AI 企業 Harvey での導入事例では、Dreaming 適用後にタスク完了率が約 **6 倍**に向上したと報告されており、エンタープライズ向け AI エージェントの自律改善能力が一段階上のレベルに達しつつある。一方で「AIが人間のように夢を見る」という表現がメディアで独り歩きする側面もあり、実態はスケジュールされたメモリ圧縮・パターン抽出であることを技術者は冷静に認識しておく必要がある。

### 2. Cisco SD-WAN CVE-2026-20182（CVSS 10.0）— CISA KEV 登録・連邦機関は 5/17 まで修正必須

米国 CISA が **Cisco Catalyst SD-WAN Controller** の認証バイパス脆弱性 **CVE-2026-20182**（CVSS 10.0、最高スコア）を **Known Exploited Vulnerabilities（KEV）カタログ**に追加し、連邦民間行政機関（FCEB）に対して **5 月 17 日**までの修正を義務付けた。脆弱性は認証を完全に迂回できるもので、攻撃者は管理者権限で SD-WAN コントローラにアクセスし、接続された拠点ネットワーク全体の設定を改ざんできる。KEV 登録は「野外で悪用が確認された」ことを意味しており、公共インフラや金融機関など SD-WAN で広域ネットワークを管理する組織にとっては特に深刻な脅威だ。Cisco は修正済みバージョンを提供しており、パッチ適用が困難な場合は管理インターフェースをインターネット非公開セグメントに隔離することが推奨される。前日の Microsoft Patch Tuesday・NGINX Rift・Fragnesia に続き、5 月第 2 週は重大脆弱性の集中開示が続いている状況であり、インフラ全体の一括点検が求められる。

5 月 7 日に欧州議会と欧州委員会が **EU AI Act** の簡素化に向けた政治合意に達し、透明性規則は **2026 年 8 月**に正式施行される見通しとなった。AI Act は汎用 AI（GPAI）モデルに開発者への開示義務・著作権コンプライアンス・技術ドキュメント提供を課すもので、EU 域内でサービスを提供するすべての AI ベンダーに影響する。一方で地政学的側面では、米国・中国・欧州が相互依存を減らしながら独自の AI インフラを構築する「AI ソブリン（主権 AI）」戦略が 2026 年の主要テーマとして定着している。中国は DeepSeek の新訓練手法でコスト効率を追求しながらオープンソース AI で世界の AI 基盤に影響を与えようとしており、米国は Nvidia のチップ輸出規制を通じて計算資源のコントロールを維持しようとしている。インドや中東諸国などの中規模国も独自 LLM の構築・外資 AI 企業との交渉力強化を進めており、AI を巡るグローバルな勢力図の再編が加速する局面に差し掛かっている。

### Rust 1.95.0 リリース — if let ガード・cfg_select! マクロ・PowerPC インラインアセンブリ

4 月 16 日に正式リリースされた **Rust 1.95.0** の採用が開発現場で広まっている。今バージョンの主要な言語機能追加は以下の通り。

```rust
// if let ガードが match アームで使えるようになった
// 従来はガード条件にパターンマッチを混在させるのが困難だった
fn classify(value: Option<i32>) -> &'static str {
    match value {
        Some(n) if let Ok(s) = n.try_into::<u8>() => "small positive",
        Some(n) if n < 0 => "negative",
        Some(_) => "large",
        None => "none",
    }
}

// cfg_select! マクロ: 条件コンパイル分岐をより宣言的に書ける
cfg_select! {
    target_os = "linux" => {
        fn platform_name() -> &'static str { "Linux" }
    }
    target_os = "macos" => {
        fn platform_name() -> &'static str { "macOS" }
    }
    _ => {
        fn platform_name() -> &'static str { "Other" }
    }
}
```

加えて PowerPC ターゲットへのインラインアセンブリサポートが追加され、組み込み・エッジデバイス向けの対応プラットフォームが拡大している。`str::contains` の aarch64/neon 向けパフォーマンス改善も含まれており、ARM 系サーバー・スマートフォン環境での文字列処理が高速化される。Rust の「9 年連続最も愛される言語」という地位はそのままに、Linux カーネルへの正式組み込みが進む中でシステムプログラミングでの実用性がさらに高まっている。

### Apple「Extensions」— Apple Intelligence にサードパーティ AI を選択可能にする新機能

Apple が内部的に **「Extensions」** と呼ぶ機能の開発を進めていることが報じられた。これは Apple Intelligence の AI バックエンドとして Google（Gemini）や Anthropic（Claude）などのサードパーティプロバイダーをユーザー自身が選べるようにする仕組みだ。現在は OpenAI の ChatGPT との連携が唯一の選択肢となっているが、Extensions が実現すれば Apple デバイス上の AI 体験が大幅に多様化する。プライバシー保護の観点では、どのモデルを呼び出す場合も Apple のプライベートクラウドコンピュート（PCC）を経由させる設計が維持される見込みで、「端末内処理かプライバシー保護クラウド経由のみ」という Apple のポリシーは崩れないとされている。AI エコシステムが「特定ベンダーのモデルに囲い込まれる時代」から「ユーザーがモデルを選ぶ時代」へ移行しつつある象徴的な動きとして注目される。

## セキュリティ

### Cisco SD-WAN CVE-2026-20182（CVSS 10.0）— 管理インターフェース隔離で緊急対応を

CISA の KEV 登録を受け、SD-WAN 環境では即時の脆弱性対応が必要だ。パッチ適用までのリスク軽減策を以下に示す。

```bash
# Cisco IOS XE: SD-WAN コントローラの管理インターフェースを確認
show sdwan system status
# vManage/vBond/vSmart の稼働バージョンを確認し Cisco アドバイザリの修正済みバージョンと照合

# 管理ポートへのアクセスを内部 IP のみに制限する ACL 例
# (IOS XE CLI)
ip access-list standard MGMT_RESTRICT
 permit 10.0.0.0 0.255.255.255
 deny   any log
!
line vty 0 15
 access-class MGMT_RESTRICT in

# アクセスログで不審な認証バイパス試行を監視
# 認証なしでの管理 API へのアクセスがあれば侵害の可能性
show logging | include AUTHFAIL|unauthorized|CVE-2026-20182
```

修正済みバージョンへのアップグレードが最優先。連邦機関は 5 月 17 日が期限だが、民間企業も同等の緊急度として扱うことが推奨される。

### Microsoft Exchange Server CVE-2026-42897（CVSS 8.1）— XSS 起因のスプーフィング、野外悪用中

Microsoft が **CVE-2026-42897**（CVSS 8.1）を開示した。オンプレミス Exchange Server に存在するクロスサイトスクリプティング（XSS）を悪用したスプーフィング脆弱性で、**すでに野外での悪用が確認**されている。攻撃者は細工したリンクをメールで送付し、受信者のブラウザ上で任意のスクリプトを実行させることで Exchange の認証セッションを乗っ取ることが可能だ。Microsoft Exchange Online（クラウド版）は影響を受けないが、オンプレミス運用組織は早急なパッチ適用が必要。Outlook Web App（OWA）を外部公開している環境では特に危険度が高い。前日の Patch Tuesday では約 130 件の修正が配布されたが、CVE-2026-42897 はそれ以降に確認された追加開示となる。

### Google、AI を悪用した「大規模エクスプロイト計画」を阻止 — ハッカーグループの試みを事前に封じ込め

Google が、あるハッカーグループが AI を利用して大規模な脆弱性エクスプロイト攻撃を自動化しようとした試みをほぼ成功直前で阻止したと発表した。Google のセキュリティチームはこの試みを「**AI を活用したマス・エクスプロイテーション・イベント**」と表現しており、攻撃者側も AI を武器として積極的に活用し始めていることを示す最新事例として注目される。AI が防御側（脆弱性スキャン・異常検知）だけでなく攻撃側（エクスプロイトコード生成・標的自動選別）にも使われる「AI vs AI」のセキュリティ構造が現実のものとなりつつある。具体的な攻撃グループ名・標的範囲の詳細は非公開とされているが、Google は AI ベースの脅威インテリジェンスにより事前封じ込めに成功したとしている。
