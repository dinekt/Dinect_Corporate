### 3. nginx-ui CVE-2026-33032（CVSS 9.8）— MCP エンドポイント認証欠如で 2,600 以上のインスタンスが実環境攻撃を受けている

nginx-ui（Web ブラウザから Nginx を管理できるオープンソースダッシュボード）に CVSS 9.8 のクリティカル脆弱性が公開された。4 月 13 日より実環境での悪用が記録されており、対応が急務だ。

**脆弱性の仕組み:**
nginx-ui の MCP（Model Context Protocol）統合が 2 つのエンドポイントを公開している。

| エンドポイント | IP ホワイトリスト | 認証 |
|---|---|---|
| `/mcp` | ✅ | ✅（AuthRequired） |
| `/mcp_message` | ✅ | ❌（欠如） |

デフォルト設定では IP ホワイトリストが空（= 全許可）のため、ネットワーク上の攻撃者が `/mcp_message` に対して認証なしで全 MCP ツール（Nginx 設定の作成・変更・削除・再起動）を呼び出せる。研究者 Yotam Perkal（Pluto Security）は HTTP リクエスト 2 件でフルテイクオーバーを実証した。

**影響範囲:**
- 影響バージョン: v2.3.3 以下
- 修正バージョン: v2.3.6（即時更新推奨）
- インターネット上で露出している 2,600 以上のインスタンスで実環境悪用を確認（Recorded Future, 4 月 13 日〜）

**出典**: [The Hacker News — nginx-ui CVE-2026-33032](https://thehackernews.com/2026/04/critical-nginx-ui-vulnerability-cve.html) / [Rapid7 ETR](https://www.rapid7.com/blog/post/etr-cve-2026-33032-nginx-ui-missing-mcp-authentication/) / [SecurityAffairs](https://securityaffairs.com/190841/hacking/cve-2026-33032-severe-nginx-ui-bug-grants-unauthenticated-server-access.html)

## 新技術・新リリース

### AI 推論フレームワーク SGLang に CVSS 9.8 の RCE 脆弱性 — 細工した GGUF モデルファイルでサーバを乗っ取れる

LLM サービング推論フレームワーク「SGLang」に、悪意ある GGUF モデルファイルを介したリモートコード実行が可能な脆弱性（CVE-2026-5760、CVSS 9.8）が報告された。AI モデルを運用するすべての開発者・MLOps エンジニアが注意すべき攻撃手法だ。

**攻撃の流れ:**
1. 攻撃者が悪意ある Jinja2 SSTI ペイロードを含む `tokenizer.chat_template` を埋め込んだ GGUF モデルを Hugging Face 等で公開
2. 被害者がモデルをダウンロードし SGLang でロード
3. `/v1/rerank` エンドポイントへのリクエスト時に `jinja2.Environment()` でテンプレートが直接レンダリング
4. 任意の Python コードがサーバ上で実行される

**脆弱なコードパターンと修正:**

```python
# 脆弱（SGLang 旧バージョン）
from jinja2 import Environment
env = Environment()
template = env.from_string(chat_template)  # サンドボックスなしで実行
result = template.render(messages=messages)

# 修正（ImmutableSandboxedEnvironment を使用）
from jinja2.sandbox import ImmutableSandboxedEnvironment
env = ImmutableSandboxedEnvironment()
template = env.from_string(chat_template)  # 危険な呼び出しをブロック
result = template.render(messages=messages)
```

同種の脆弱性は llama_cpp_python（CVE-2024-34359「Llama Drama」, CVSS 9.7）や vLLM（CVE-2025-61620, CVSS 6.5）でも過去に修正されており、Jinja2 を用いるチャットテンプレート処理はサプライチェーンリスクの典型的な攻撃面になっている。**社内で Hugging Face からモデルをダウンロードして SGLang・vLLM でサービングしている環境は即刻バージョンを確認すること。**

**出典**: [The Hacker News — SGLang CVE-2026-5760](https://thehackernews.com/2026/04/sglang-cve-2026-5760-cvss-98-enables.html)

## セキュリティ

### nginx-ui CVE-2026-33032（CVSS 9.8）— 即時 v2.3.6 へ更新を

上記 TOP 3 でも取り上げた通り、nginx-ui の `/mcp_message` エンドポイントを通じた認証バイパスが実環境で悪用中。

```bash
# nginx-ui を Docker で運用している場合
docker pull 0xjtw/nginx-ui:v2.3.6

# docker-compose 利用の場合
# image タグを v2.3.6 に更新後
docker-compose pull && docker-compose up -d

# バイナリ直接インストールの場合
wget https://github.com/0xJTW/nginx-ui/releases/download/v2.3.6/nginx-ui-linux-amd64.tar.gz
tar -xzf nginx-ui-linux-amd64.tar.gz
systemctl restart nginx-ui
```

アップグレードが即時困難な場合の緩和策:

```nginx
# nginx などのリバースプロキシで /mcp_message へのアクセスをブロック
location /mcp_message {
    deny all;
    return 403;
}
```
