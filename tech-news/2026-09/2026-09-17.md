### 2. Go 1.27.1 リリース — ジェネリックメソッド・encoding/json/v2・post-quantum 暗号が正式到来

9 月 1 日に Go 1.27.0、9 月初旬には小規模修正を含む **Go 1.27.1** がリリースされた。今サイクルの目玉は **ジェネリックメソッド**（メソッド自身が独立した型パラメータを宣言可能）、標準ライブラリへの **`encoding/json/v2`**（既存 v1 より最大 2〜3× 高速な JSON エンジン、オプトインで後方互換性維持）、そして **`crypto/mldsa`** の追加だ。`crypto/mldsa` は NIST 標準化が完了した ML-DSA（Module-Lattice-Based Digital Signature）アルゴリズムを実装しており、量子コンピュータに耐性を持つポスト量子署名が Go 標準ライブラリだけで完結するようになった。コンパイラパフォーマンスも向上しており、大規模プロジェクトでのビルド時間短縮が報告されている。Rust 側では 8 月 20 日リリースの **Rust 1.98.0** に続く **1.98.1**（9 月 3 日）が細部修正を適用している。

### 3. Microsoft 9 月 Patch Tuesday — 過去最多 1,169 CVE・114 件 Critical、Office プレビューペイン RCE 22 件を含む緊急対応週

Microsoft は 9 月 Patch Tuesday で外部・Chromium CVE を含む **1,169 件**の脆弱性に対処した。これは Patch Tuesday として過去最多記録を更新する規模で、うち **114 件が Critical** 評価だ。特に注意が必要なのは **Office の Critical パッチ 22 件**で、このうち 12 件は「プレビューペイン・閲覧ペインで開くだけでコード実行が発火する」タイプ — マクロを実行しなくても、ファイルを選択して内容をプレビューする動作だけで RCE が成立する。さらに DNS・DHCP・MSMQ・NFS・SSTP VPN といったコアインフラサービスで **未認証ネットワーク到達可能な RCE** が少なくとも 17 件確認されており、境界ネットワーク上にこれらサービスを公開している組織への影響は重大だ。先週の CISA KEV 追加 15 件（JFrog Artifactory CVSS 9.8・SonicWall SMA1000 CVSS 10.0）と重なる対応週となっており、セキュリティチームには高密度なトリアージが求められている。

## 新技術・新リリース

### Go 1.27 — ジェネリックメソッドと encoding/json/v2 の使い方

Go 1.27 で導入されたジェネリックメソッドと新 JSON ライブラリの基本的な利用例を示す。

```go
// Go 1.27 — ジェネリックメソッド: メソッド自身が型パラメータを持てる
package main

import "fmt"

type Repository[T any] struct {
    items []T
}

// メソッドが独立した型パラメータ K を宣言する（Go 1.27 新機能）
func (r *Repository[T]) Transform[K any](fn func(T) K) []K {
    result := make([]K, len(r.items))
    for i, item := range r.items {
        result[i] = fn(item)
    }
    return result
}

func main() {
    repo := &Repository[int]{items: []int{1, 2, 3}}
    // int → string に変換（型推論が働く）
    strs := repo.Transform(func(n int) string {
        return fmt.Sprintf("item-%d", n)
    })
    fmt.Println(strs) // [item-1 item-2 item-3]
}
```

```go
// Go 1.27 — encoding/json/v2: オプトインで高速な JSON 処理
package main

import (
    "fmt"
    jsonv2 "encoding/json/v2" // v2 は別パッケージとして共存
)

type Event struct {
    Name  string `json:"name"`
    Score int    `json:"score,omitempty"`
}

func main() {
    // Marshal: v1 互換の API、ただし内部エンジンが刷新され 2〜3× 高速
    data, _ := jsonv2.Marshal(Event{Name: "release", Score: 100})
    fmt.Println(string(data)) // {"name":"release","score":100}

    var e Event
    _ = jsonv2.Unmarshal(data, &e)
    fmt.Println(e.Name, e.Score) // release 100
}
```

```go
// Go 1.27 — crypto/mldsa: ポスト量子署名 (ML-DSA / CRYSTALS-Dilithium)
package main

import (
    "crypto/mldsa"
    "fmt"
)

func main() {
    // ML-DSA-65 (NIST Level 3) の鍵ペアを生成
    pub, priv, err := mldsa.GenerateKey(mldsa.Level65, nil)
    if err != nil {
        panic(err)
    }

    msg := []byte("post-quantum signed payload")
    sig, _ := priv.Sign(msg)

    ok := pub.Verify(msg, sig)
    fmt.Println("signature valid:", ok) // true
}
```

ジェネリックメソッドにより、コレクション操作や変換パイプラインをコードの重複なく型安全に記述できるようになった。`encoding/json/v2` は既存コードを変更せずに段階移行が可能な設計となっており、高スループット API サーバーでの恩恵が大きい。`crypto/mldsa` の追加で、ポスト量子暗号への移行が外部ライブラリ依存なしに実装できる環境が整った。

### Microsoft 9 月 Patch Tuesday — 1,169 CVE 過去最多、Office プレビューペイン RCE とインフラ未認証 RCE を最優先で

```text
===== 対応優先度チェックリスト: 2026-09-17 =====

【最優先: Office プレビューペイン RCE (12 件)】
  影響: ファイルをプレビューするだけで任意コード実行 — ユーザー操作不要
  対象: Microsoft Office 全バージョン (Preview Pane / Reading Pane 有効環境)
  対処: 2026-09 更新プログラムを即時適用、適用完了まで Preview Pane 無効化を検討

【最優先: コアインフラ 未認証ネットワーク RCE (17+ 件)】
  影響サービス: DNS, DHCP, MSMQ, NFS, SSTP VPN
  攻撃条件: ネットワーク到達可能な未認証攻撃者 → 任意コード実行
  対処: 境界 FW でサービスポートを制限 + 即時パッチ適用

【今月の全体像】
  総CVE数 : 1,169 件 (Chromium / 外部含む) — Patch Tuesday 過去最多
  Critical : 114 件
  Important: 多数
  既知の悪用: 複数 (CrowdStrike 詳報参照)

【先週からの継続対応 (CISA KEV)】
CVE-2026-82329  JFrog Artifactory  CVSS 9.8  未認証 Admin 奪取 → 即時パッチ
CVE-2026-83548  SonicWall SMA1000  CVSS 10.0 SSRF              → ファームウェア更新
CVE-2026-83549  SonicWall SMA1000  CVSS 7.8  認証後 RCE       → ファームウェア更新
```

9 月の Patch Tuesday は CVE 件数が 1,169 件と記録を更新した。Senserva の分析によれば、このうち **Office の Critical 22 件中 12 件** は添付ファイルを開かずにプレビューするだけで RCE が発火するタイプであり、メール経由の初期侵入経路として悪用される危険が高い。インフラサービス側の未認証 RCE 17 件超は内部ネットワーク横断移動のベクタになり得るため、エッジ公開されていなくても LAN 内での悪用シナリオを想定した優先対応が求められる。Zero Day Initiative は今月を「インフラ脆弱性密度の高い月」と位置づけ、DNS/DHCP サーバーを直接インターネットに公開しているケースを特に危険視している。なお先週 CISA KEV に追加された JFrog Artifactory（CVSS 9.8）と SonicWall SMA1000（CVSS 10.0）への対応も並行して必要であり、2 週連続で高密度なパッチウィークが続いている。
