### 3. GitLab に CVSS 10.0 の致命的パストラバーサル脆弱性 CVE-2026-85706 — 公開24時間以内にインターネット規模のスキャンと悪用が開始

GitLab が9月10日に開示した **CVE-2026-85706（CVSS 10.0）** は、リポジトリコミット API に存在するパストラバーサル脆弱性で、**認証不要の単一 HTTP リクエスト**により任意ファイルの読み取りが可能になる。攻撃者は `/etc/passwd`・SSH 秘密鍵・データベース認証情報・CI/CD 変数・デプロイトークンなどの機密設定データを取得できる。セキュリティ研究者は翌9月11日にはインターネット全体を対象とした自動スキャンと実際の悪用が始まっていることを観測しており、**CISA は同日中に既知悪用脆弱性（KEV）カタログに追加**した。GitLab はパッチ済みバージョン **19.3.2・19.2.6・19.1.8** を提供しており、セルフホスト環境を運営するすべての組織に対して即時アップグレードが推奨されている。同脆弱性と同日、**Check Point VPN の2件（CVE-2026-85102・CVE-2026-85103、各 CVSS 9.8）** についてもオランダの国家サイバーセキュリティセンター（NCSC）が「近日中の悪用が避けられない」と警告を出しており、VPN ゲートウェイを持つ組織でも緊急対応が求められる状況だ。

**出典**: [Security Affairs — GitLab CVE-2026-85706: One HTTP Request, No Authentication, Full File Read - Exploited Within 24 Hours](https://securityaffairs.com/198945/hacking/gitlab-cve-2026-85706-one-http-request-no-authentication-full-file-read-exploited-within-24-hours.html) / [watchTowr — Rapid Reaction: GitLab Path Traversal Vulnerability (CVE-2026-85706)](https://watchtowr.com/resources/rapid-reaction-gitlab-critical-path-traversal-vulnerability-cve-2026-85706/) / [AiCybr Blog — GitLab CVE-2026-85706: CVSS 10 Path Traversal Is in CISA KEV](https://aicybr.com/blog/gitlab-cve-2026-85706-path-traversal-kev)

### OpenAI GPT-Live — 300ms 未満の遅延を実現するネイティブ音声 AI モデル

OpenAI が **GPT-Live** を発表した。従来の音声機能では「テキスト変換 → 推論 → 音声合成」という3段階パイプラインが遅延の原因となっていたが、GPT-Live は**エンドツーエンドのネイティブ音声モデル**として動作し、**300ms 未満のレイテンシ**と感情のニュアンス表現を実現する。

```python
# OpenAI GPT-Live Realtime API 利用例（WebSocket）
import asyncio
import websockets
import json

async def realtime_voice_chat():
    url = "wss://api.openai.com/v1/realtime"
    headers = {
        "Authorization": "Bearer YOUR_API_KEY",
        "OpenAI-Beta": "realtime=v1"
    }

    async with websockets.connect(url, additional_headers=headers) as ws:
        # セッション設定: GPT-Live モデルを指定
        session_config = {
            "type": "session.update",
            "session": {
                "model": "gpt-live-001",   # GPT-Live モデル
                "modalities": ["audio", "text"],
                "voice": "alloy",
                "input_audio_format": "pcm16",
                "output_audio_format": "pcm16",
                "turn_detection": {
                    "type": "server_vad",  # サーバー側音声アクティビティ検出
                    "threshold": 0.5
                }
            }
        }
        await ws.send(json.dumps(session_config))

        # 音声データ送信（PCM16、24kHz）
        audio_event = {
            "type": "input_audio_buffer.append",
            "audio": "<base64_encoded_pcm16_audio>"
        }
        await ws.send(json.dumps(audio_event))

        # レスポンス受信
        async for message in ws:
            event = json.loads(message)
            if event["type"] == "response.audio.delta":
                # 音声ストリームをリアルタイムで処理
                audio_chunk = event["delta"]  # base64 エンコード音声
                # ... 音声再生処理 ...
            elif event["type"] == "response.text.delta":
                print(event["delta"], end="", flush=True)

asyncio.run(realtime_voice_chat())
```

GPT-Live はテキストパイプラインのボトルネックを排除することで、応答品質を落とさずに対話的な音声体験を実現している。音声アシスタント・電話サポート自動化・リアルタイム通訳など幅広い用途が想定される。
