### 2. Drupal CVE-2026-9082（SA-CORE-2026-004）— 認証不要の SQL インジェクション、本日パッチ公開

**Drupal** セキュリティチームが事前予告していた「Highly Critical」コアリリースが本日 17:00–21:00 UTC に公開された。脆弱性は **CVE-2026-9082**（SA-CORE-2026-004）、スコア **20/25** で Drupal の定義上の最高深刻度カテゴリに相当する。データベース抽象化 API の欠陥を突いて攻撃者が特別に細工したリクエストを送信することで、**PostgreSQL バックエンドを使用するサイトで認証なし任意 SQL インジェクションが成立**する。Access Complexity が「None」、Authentication が「None」という条件は、スクリプト化された大規模スキャン攻撃に直ちに悪用される典型的パターンであり、Drupal セキュリティチームは「パッチ公開から数時間〜数日以内にエクスプロイトが開発される」と警告している。政府機関・大学・メディア組織など Drupal 採用サイトは本日中のアップデート適用が最優先だ。影響バージョンは Drupal 8.9.0〜11.3.x の広範囲に及ぶ。

### 3. Grafana Labs GitHub ブリーチ — TanStack npm サプライチェーン攻撃でソースコード全件窃取・身代金要求

Grafana Labs は 5/16 に GitHub 環境の不正アクセスを公表し、その後の調査で攻撃の全容が明らかになった。侵入の起点は **TanStack npm パッケージへのサプライチェーン攻撃**（攻撃グループ TeamPCP、5/11 検出）で、Grafana の CI ワークフロー内で `pull_request_target` トリガーに設定された GitHub Actions が外部コントリビューターに本番シークレットを漏洩する **"Pwn Request" 脆弱性**を突かれた。窃取されたトークンにより攻撃者はプライベートリポジトリごとコードベースをダウンロード。その後、サイバー犯罪グループ **CoinbaseCartel**（ShinyHunters・Scattered Spider・LAPSUS$ の系譜）が身代金を要求したが Grafana は FBI ガイダンスに従い拒否。顧客データや本番システムへの影響はないとしている。同攻撃は OpenAI・Mistral AI も標的にした一連のサプライチェーン攻撃の一環であり、CI/CD パイプラインのシークレット管理と `pull_request_target` の権限設計を見直す契機となった。

### Drupal CVE-2026-9082 — 緊急アップデート手順

本日リリースされた Drupal セキュリティパッチの適用手順と、PostgreSQL 環境での影響確認コマンドを示す。

```bash
# 1. 現在の Drupal バージョンを確認
composer show drupal/core | grep versions

# 2. 影響バージョン確認（8.9.0〜11.3.x が対象）
# 影響を受けるバージョン一覧:
# - 8.9.0 - 10.4.10
# - 10.5.0 - 10.5.10
# - 10.6.0 - 10.6.9
# - 11.0.0 - 11.1.10
# - 11.2.0 - 11.2.12
# - 11.3.0 - 11.3.10

# 3. composer でパッチ適用（最新 patch release へアップデート）
composer update drupal/core --with-dependencies

# 4. データベースアップデート実行
vendor/bin/drush updatedb -y

# 5. キャッシュクリア
vendor/bin/drush cr

# 6. PostgreSQL 環境でのみ: pg_stat_activity で不審なクエリを確認
# psql -U drupal_user -d drupal_db -c \
#   "SELECT pid, now() - pg_stat_activity.query_start AS duration, query
#    FROM pg_stat_activity
#    WHERE (now() - pg_stat_activity.query_start) > interval '5 minutes'
#    ORDER BY duration DESC;"
```

### GitHub Actions — "Pwn Request" 脆弱性の検出と修正

Grafana 侵害の根本原因となった `pull_request_target` の権限昇格パターンを確認・修正する方法。

```yaml
# ❌ 危険なパターン: pull_request_target + checkout でシークレットが漏洩
on:
  pull_request_target:  # フォークPRでも本番シークレットにアクセスできる
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ github.event.pull_request.head.sha }}  # フォークのコードを実行
      - run: npm test  # フォーク側のコードがシークレットを盗める

# ✅ 安全なパターン: フォーク由来のコードをシークレットなし環境で実行
on:
  pull_request:  # シークレットへのアクセスなし（通常はこちらを使う）
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4  # HEADを使用（pull_request_targetと異なる）
      - run: npm test

# pull_request_target が必要な場合は権限を最小化する
on:
  pull_request_target:
jobs:
  labeler:
    permissions:
      pull-requests: write  # 必要最小限の権限のみ付与
      contents: none        # リポジトリコードへのアクセスは明示的に禁止
    steps:
      - uses: actions/labeler@v4  # コードをチェックアウトしない
```

### CVE-2026-42897 — Microsoft Exchange OWA XSS が CISA KEV 追加、野放し悪用中

```bash
# Exchange Server の影響バージョン確認
# 影響: Exchange Server 2016, 2019, Subscription Edition RTM
# Exchange Online は影響なし

# Windows Update / Exchange EM Service による自動緩和の確認
# PowerShell (Exchange Server 上で実行)
Get-ExchangeDiagnosticInfo -Server $env:COMPUTERNAME `
    -Process EdgeTransport `
    -Component ResourceThrottling `
    -Probe 'ActiveMonitoring/HealthMonitor'

# 暫定緩和: Exchange Emergency Mitigation (EM) Service が有効かチェック
Get-WebServicesVirtualDirectory | Select Server, InternalUrl, ExternalUrl
# EM Service が自動緩和を展開済みの場合は "CVE-2026-42897" の緩和エントリが存在する

# OWA のアクセスログで不審な JS 実行形跡を確認（W3C ログ形式）
# Get-Content "C:\inetpub\logs\LogFiles\W3SVC1\*.log" |
#   Select-String "owa.*<script|owa.*javascript:" | Select-Object -Last 50
```

**CVE-2026-42897**（CVSS 8.1）は Exchange OWA に存在する XSS 起因の**スプーフィング脆弱性**で、攻撃者が細工したメールをターゲットに送信し、被害者が OWA でそのメールを開くことで任意の JavaScript がブラウザコンテキストで実行される。Microsoft は 5/14 に開示、CISA は 5/15 に KEV 追加した。EM Service による自動緩和が Exchange 2016/2019/SE に展開済みだが、恒久パッチは別途公開予定。オンプレミス Exchange を運用する組織は、EM Service の有効化と恒久パッチのリリース追跡を最優先としたい。

### Linux 三連チェーン（NGINX Rift + Copy Fail + Dirty Frag）— インターネット直結から root まで一気通貫

Security Boulevard が報告した May 2026 の三つの Linux 脆弱性は、組み合わせることで**「インターネット公開 → RCE → root」を race condition なし・フォレンジック痕跡最小**で実現する kill chain を形成すると指摘されている。

| CVE | 別名 | 種別 | CVSS | 概要 |
|---|---|---|---|---|
| CVE-2026-42945 | NGINX Rift | Heap Buffer Overflow | 9.8 | `ngx_http_rewrite_module` の 2008 年来の欠陥、HTTP 1 リクエストで RCE |
| CVE-2026-31431 | Copy Fail | 権限昇格 | 7.8 | AF_ALG `algif_aead`、低権限ローカルユーザーから root |
| CVE-2026-43284/43500 | Dirty Frag | 権限昇格 | 7.8 | Copy Fail の緩和策をバイパスする 2-bug chain |

**推奨対応**: nginx のパッチ適用（NGINX 1.27.5+ または 1.26.4+）と Linux カーネル 6.18.22/6.19.12/7.0 以降へのアップデートを同時に実施する。Copy Fail の暫定緩和策（algif_aead ブラックリスト）は Dirty Frag チェーンには無効なため、カーネルアップデートが唯一の完全対策となる。

**出典**: [Three CVEs and the May 2026 Exploit Chain Nobody's Taking Seriously — Security Boulevard](https://securityboulevard.com/2026/05/three-cves-and-the-may-2026-exploit-chain-nobodys-taking-seriously/)

### YellowKey CVE-2026-45585 — BitLocker バイパスの緩和策が Microsoft Patch Tuesday に

Microsoft の May 2026 Patch Tuesday（120 件 CVE 対応）に含まれた **CVE-2026-45585**（YellowKey、CVSS 6.8）は、BitLocker の暗号化保護をバイパスできる脆弱性で、物理アクセスを持つ攻撃者が暗号化ドライブから平文データを取得できる。攻撃ベクタは物理アクセスを要するため大規模リモート攻撃には向かないが、盗難・内部脅威シナリオでは重大度が増す。Microsoft はパッチ Tuesday で緩和策をリリースしており、エンタープライズ環境では Windows Update の適用を確認されたい。
