### 2. Cisco Catalyst SD-WAN CVE-2026-20182（CVSS 10.0）— 本日が CISA 連邦機関修正期限、国家級アクター UAT-8616 が管理者権限を奪取

### 3. EU AI Act「デジタル・オムニバス」政治合意 — 高リスク AI のコンプライアンス期限を 2028 年まで延期、透明性義務のガイドラインも始動

欧州議会と理事会は 5 月 7 日、**EU AI Act** の実施を簡素化する「**デジタル・オムニバス（Digital Omnibus）**」立法案について政治合意に達した。最大の変更点は「**ストップ・ザ・クロック（Stop-the-Clock）**」メカニズムの導入で、2026 年に迫っていた高リスク AI システムのコンプライアンス義務を技術標準の策定完了まで **2027〜2028 年まで延期**する内容だ。EU は翌 5 月 8 日、AI 透明性義務のドラフトガイドラインに関するパブリックコンサルテーションも開始した。一方で、禁止 AI プラクティスと AI リテラシー義務は 2025 年 2 月からすでに適用中であり、「全義務が延期されたわけではない」点に注意が必要だ。EU AI Act の完全適用は 2026 年 8 月 2 日のまま変わらず、デジタル・オムニバスの最終交渉によって個別義務の適用範囲と時期が再調整される見込みだ。世界 72 カ国で 1,000 件超の AI 政策が進行する中、欧州のガバナンスフレームワークが他地域の規制設計に与える影響は引き続き大きい。

### Grok 4.3 が OCI Enterprise AI に登場 / Mistral 128B が非同期エージェントモードを公開 — 1M トークン時代の大規模推論

xAI の最新推論モデル **Grok 4.3** が **Oracle Cloud Infrastructure（OCI）Enterprise AI** で利用可能になった。コンテキストウィンドウは **100 万トークン**と業界最大水準で、数学・コーディング・多段階論理推論に強みを持つ。OCI のセキュアなインフラ上でプライベートデプロイが可能になり、金融・医療など規制業界での採用が現実的な選択肢となった。

```python
# OCI Generative AI SDK での Grok 4.3 呼び出し例（1M トークンコンテキストを活用）
import oci

config = oci.config.from_file()
generative_ai_client = oci.generative_ai_inference.GenerativeAiInferenceClient(config)

# コードベース全体を一度に渡してセキュリティ分析する例
response = generative_ai_client.chat(
    chat_details=oci.generative_ai_inference.models.GenericChatDetails(
        model_id="xai.grok-4-3",
        messages=[
            oci.generative_ai_inference.models.UserMessage(
                content=[oci.generative_ai_inference.models.TextContent(
                    text="次のコードベースを解析してセキュリティ上の問題を列挙してください。\n\n"
                         + codebase_text  # 最大 ~750,000 単語相当を渡せる
                )]
            )
        ],
        max_tokens=4096,
        temperature=0.0,
    )
)
print(response.data.chat_response.choices[0].message.content[0].text)
```

同時期に Mistral も **128B フラッグシップモデル**を発表し、非同期クラウドコーディングセッションと Le Chat の「**Work エージェントモード**」を公開した。100B 超パラメータのオープン系モデルが実用域に入る 2026 年、1M トークン規模の文脈長と低コスト推論が AI アーキテクチャの設計前提そのものを塗り替えつつある。

### Apache HTTP/2 CVE-2026-23918（CVSS 8.8）— Double Free で RCE の可能性、Apache 2.4.66 が対象

Apache HTTP Server **2.4.66** の HTTP/2 プロトコル処理に「**ダブルフリー（double free）**」バグが発見され、**CVE-2026-23918**（CVSS 8.8）として開示された。悪用に成功した場合、理論上はリモートコード実行（RCE）が可能であり、The Hacker News は「DoS および潜在的 RCE」と分類している。修正済みバージョンは **Apache 2.4.67**。HTTP/2 を有効化した Apache サーバーを運用する組織は至急アップデートを検討されたい。HTTP/2 の無効化（`Protocols http/1.1`）は一時的な攻撃面の排除策として有効だが、パフォーマンスへの影響を考慮した上で判断すること。

```bash
# バージョン確認
httpd -v       # または
apache2 -v

# HTTP/2 の有効状態を確認
httpd -M | grep http2

# Debian / Ubuntu 系でのアップデート
sudo apt update && sudo apt install apache2
```
