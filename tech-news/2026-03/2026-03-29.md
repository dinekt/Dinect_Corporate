# テックニュース 2026年3月29日

> OpenAI が Sora を終了してロボティクスへ転換、Claude Code v2.1.87 リリース、Mistral が初の TTS モデル公開

## 今日のハイライト

**OpenAI、Sora を終了しロボティクス研究へ転換** -- コスト日産 $15M・売上生涯 $2.1M という採算割れを受け、Sora チームを「世界シミュレーション for ロボティクス」に全面転換。Disney との $1B ライセンス提携も 90 日以内に白紙化。AI ビデオ生成市場の厳しさを数字で示した事例。

**Claude Code v2.1.87 / v2.1.86 リリース** -- 3/29 に v2.1.87（Cowork Dispatch のメッセージ配信バグ修正）、3/28 に v2.1.86（セッション追跡ヘッダー追加・トークン効率改善・VS Code 拡張安定化）が相次いでリリース。

**Mistral、初の TTS モデル「Voxtral TTS」を OSS 公開** -- 4B パラメータの軽量音声合成モデルを Hugging Face でオープンウェイト公開。ElevenLabs Flash v2.5 を自然性で上回ると主張。API 料金 $0.016/1k 文字。

## カテゴリ別ニュース

### AI / LLM

**OpenAI Sora 終了（3/24 発表、3/29 TechCrunch がリセットとして分析）**
- 運用コスト: 推定 $15M/日（ピーク時）
- 生涯売上: $2.1M（アプリ内課金）
- Sora チームはロボティクス向け物理世界シミュレーションへ転換
- Disney との $1B 提携も解消（金銭授受なし）

**Mistral Voxtral TTS（3/26 リリース）**
- モデルサイズ: 4B パラメータ
- 対応言語: 9言語（英/仏/独/西/蘭/葡/伊/ヒンディー/アラビア語）
- ライセンス: CC BY NC 4.0（商用利用は API 経由）
- API: $0.016/1k 文字、Hugging Face: `mistralai/Voxtral-4B-TTS-2603`

**Google TurboQuant（3/25 発表、ICLR 2026 採択）**
- LLM の KV キャッシュを 3bit に量子化しても精度ロスなし
- メモリ使用量 6分の1・H100 GPU 上で最大 8x 高速化
- ファインチューニング不要（事前学習済みモデルにそのまま適用）

### 開発ツール・言語

**Claude Code v2.1.87（3/29）**
- Cowork Dispatch のメッセージ未配信バグを修正

**Claude Code v2.1.86（3/28）**
- `X-Claude-Code-Session-Id` ヘッダーを API リクエストに追加
- Jujutsu / Sapling VCS のメタデータを除外
- 古いセッションの resume 機能を修正
- メモリ使用量削減・トークン効率化

### PDF / ドキュメント AI

**AWS IDP GenAI Accelerator v0.5.0（3月リリース）**
- 単一デプロイで2モードを実行時切り替え可能に統合

**IDP 市場規模（Fortune Business Insights 3月更新）**
- 2026年: $14.16B → 2034年: $91.02B（CAGR 26.2%）
- AI 導入組織: 処理コスト 60〜80% 削減・処理時間 70〜90% 短縮

### セキュリティ

特筆すべき新規インシデントなし（週末のため小康状態）。
