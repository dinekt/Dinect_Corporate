### 1. OpenAI の汎用推論モデルが80年来の Erdős 数学予想を自律反証 — 数学史上初のAI単独証明

OpenAI は 5/20 に、内部汎用推論モデルが 1946 年に Paul Erdős が提唱した「単位距離予想」を自律的に反証したと発表した。同予想は「平面上に n 点を配置したとき、距離がちょうど 1 となるペアの最大数」を問うもので、約80年にわたって正方格子配置が最良に近いと信じられてきた。OpenAI のモデルは Golod-Shafarevich 理論・無限類体塔といった深代数的整数論を用いた反例の無限族を自律発見し、Princeton の Will Sawin が精緻化した結果は n^1.014 という明示的多項式因子で正方格子を上回ることが示された。Fields 賞受賞者 Tim Gowers は「AIが数学においてマイルストーンを達成した」と評価し、数学コミュニティに広く衝撃が走った。モデルは数学専用にファインチューンされておらず、汎用推論能力のみでこれを達成した点が特に注目される。

## 新技術・新リリース

### Gemini API Managed Agents — インフラ不要でエージェントを即起動

Google I/O 2026 で発表された Gemini API の Managed Agents 機能は、リモートサンドボックス付きのエージェントを単一 API 呼び出しで起動する。以下はその基本的な利用例だ。

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_API_KEY")

# Gemini 3.5 Flash を使った Managed Agent の起動
agent = genai.ManagedAgent.create(
    model="gemini-3.5-flash",
    tools=["code_execution", "web_search"],
    sandbox=True,          # リモートサンドボックスを有効化
    credential_masking=True,  # シークレット自動マスキング
)

response = agent.run(
    prompt="最新の Python パッケージ脆弱性を調査し、requirements.txt を更新するPRを作成してください",
    context={"repo": "my-org/my-repo"},
)

print(response.result)
print(f"使用トークン: {response.usage.total_tokens}")
```

従来のエージェント構築ではインフラ設定・セッション管理・セキュリティ分離を自前で実装する必要があったが、Managed Agents はこれを API レイヤーで吸収する。Antigravity CLI と組み合わせることで、複数のサブエージェントを連携させた複雑なワークフローをローカル開発環境から直接オーケストレーションできる。

### Ghost CMS CVE-2026-26980 — CVSS 9.4 の SQL インジェクションが ClickFix 攻撃に悪用中

Ghost CMS の Content API に存在する未認証 SQL インジェクション脆弱性 CVE-2026-26980（CVSS 9.4）が、悪意ある JavaScript を注入して ClickFix 攻撃へ誘導するキャンペーンに使用されていることが確認された。攻撃者はこの脆弱性を利用してデータベースから任意データを読み取り、改ざんしたコンテンツページに「ブラウザを更新するために以下を実行してください」という偽の指示を表示、ユーザーを騙して PowerShell / Bash コマンドを実行させるソーシャルエンジニアリング攻撃へ発展させている。Ghost CMS を利用している場合は最新版への即時アップデートを推奨する。

```bash
# Ghost CMS のバージョン確認・アップデート手順
ghost version               # 現在のバージョン確認
ghost update                # 最新安定版へアップデート
ghost restart               # 適用後の再起動

# CVE-2026-26980 の影響確認 — Content API へのアクセスログを確認
# 不正な SQL パターンを含むリクエストをチェック
grep -E "(UNION|SELECT|DROP|INSERT).*content_api" /var/log/ghost/access.log | tail -50
```
