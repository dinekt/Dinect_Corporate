### 2. Microsoft、史上最大のPatch Tuesday — 622件（うちゼロデイ2件積極悪用中）でAD FS・SharePoint Serverに特権昇格リスク、AI支援コード解析で発見件数が急増

Microsoftは7月のPatch Tuesdayで**過去最多となる622件の脆弱性**を修正した。6月の約200件から3倍以上に急増したこの数字の背景について、Microsoftは「AI支援によるコード解析がより多くの潜在的脆弱性を識別できるようになったため、今後も毎月の修正件数が増加することを見込んでほしい」と説明している。内訳はWindows 416件・Office 82件・Microsoft Edge 46件・開発者ツール 27件・SharePoint Server 17件・Azure 11件など。このうち**積極的な悪用が確認されたゼロデイは2件**（一部報告では3件）あり、最優先の対応が求められる。**CVE-2026-56155**はActive Directory Federation Services（AD FS）の権限昇格脆弱性で、ローカル実行により管理者権限の奪取が可能。**CVE-2026-56164**はSharePoint Serverの認証不要なネットワーク経由の権限昇格で、イントラネット環境での横断侵害に悪用される恐れが高い。さらに今月からMicrosoftはKerberos認証の強制モードへの移行を開始しており、Kerberos非対応のレガシーシステムを抱える企業は接続断のリスクも存在する。622件という記録的な規模はAIを使ったセキュリティリサーチの副産物でもあり、「AIが脆弱性発見を加速する」という新たな現実を象徴するPatch Tuesdayとなった。

### Rust 1.97.1 — v0シンボルマングリングがデフォルト化でバックトレース革新、次世代システム言語の成熟が加速

Rust 1.97（7月9日リリース）のパッチ版**Rust 1.97.1**が7月16日に公開された。最大の変更点は**v0シンボルマングリングのデフォルト有効化**だ。従来の"legacy"マングリング形式はRustの型システムの全情報を符号化できないため、バックトレースで関数名が不完全または難読化された形で表示されることがあった。v0マングリングは型パラメータ・クロージャ・定数ジェネリクスを完全に符号化するため、パニック時・LLDB/GDB上でのデバッグ体験が大幅に改善される。また整数ビット操作ヘルパー（`count_ones`・`leading_zeros`等の関連メソッド拡張）も追加された。次の安定版**Rust 1.98**は2026年8月20日にリリース予定。Go 1.26（2月リリース）が導入した"Green Tea"GCのデフォルト化（GCオーバーヘッド10〜40%削減）と合わせ、2026年はシステム言語の両雄がランタイム品質を本格的に底上げした年として記録されるだろう。

```rust
// Rust 1.97 以降: v0 マングリングでバックトレースの可読性が向上
// コンパイル時に -C symbol-mangling-version=v0 が不要になった（デフォルト）

use std::num::Wrapping;

// ジェネリクス・定数パラメータを含む関数名が
// パニック時のバックトレースに正確に表示される
fn sum_clamped<const MAX: i64>(values: &[i64]) -> i64 {
    values
        .iter()
        .map(|&v| v.min(MAX))
        .fold(0i64, |acc, v| {
            // 1.97 新規: checked_add が None の場合の整数オーバーフロー診断が改善
            acc.checked_add(v).unwrap_or(i64::MAX)
        })
}

fn main() {
    let data = vec![100, 200, 9999, 50, -10];
    println!("{}", sum_clamped::<500>(&data)); // → 840
    // バックトレースには sum_clamped::<500i64> と正確に表示される
}
```
