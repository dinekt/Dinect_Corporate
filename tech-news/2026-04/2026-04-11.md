## 本日のニュース TOP 3

### 1. DeepSeek V4、「数週間以内」リリースへ — Huawei Ascend 950PR で動作・西側輸出規制を迂回

Reuters が 4 月 3 日に報じた情報によれば、中国 AI ラボ DeepSeek の次世代モデル V4 はリリースまで「数週間以内」の段階に達している。注目すべきは、V4 が Huawei の次世代 AI チップ「Ascend 950PR」を主要ハードウェアとして採用している点で、米国の半導体輸出規制（Entity List・EAR）を実質的に迂回する構成となっている。現行の DeepSeek-V3.2 はすでに GPT-5 を複数の推論ベンチマークで上回っており、V4 はさらなるスコア改善が見込まれる。API 価格は西側同等モデル比で約 70% 低水準を維持する見通しで、コスト効率を重視するアプリケーション開発への影響は大きい。V4 リリース後、AI 推論コストと「国産ハードウェア上の性能」をめぐる議論が再燃することは必至だ。

**開発者への影響**:
- DeepSeek API は価格競争力と高い推論性能を両立しており、コスト最適化目的での採用候補として評価価値がある
- 輸出規制を受けた中国ハードウェア上での高性能 AI 動作は、制裁の実効性に疑問を呈するとともに、グローバルな AI ハードウェア競争の新局面を示している

### 2. Anthropic、Claude Code を独立製品として正式展開 — ターミナルネイティブ AI エージェントが GitHub/GitLab/Jira と統合

Anthropic が Claude Code をスタンドアロン製品として本格展開。ターミナルから直接リポジトリのクローン・テストの記述と実行・CI パイプライン修復・プルリクエスト作成まで自律的に行える AI エージェントとして設計されており、GitHub・GitLab・Jira との統合を標準で備える。コード実行はサンドボックス環境で行われ、安全性を確保しながら複雑なタスクをこなせる。モデルバックエンドは Claude Sonnet 4.6 がデフォルトで、複雑なアーキテクチャタスクには Claude Opus 4.6 に切り替えられる。LMSYS Chatbot Arena では Claude Opus 4.6 が GPT-5.4・Gemini 3.1 Pro を上回る人間評価スコアを記録し、SWE-bench Verified でも 65.3% と過去最高スコアを達成している。

**開発者への影響**:
- 「プロンプト → 実行 → PR 作成」のループが一つのツールで完結し、反復的な実装タスクの自動化が現実的になった
- CI 修復の自律実行は、パイプライン管理コストの削減につながる一方、CI 設定の機密情報管理に注意が必要

### 3. Mistral Large 3 リリース — EU データ主権対応・構造化出力と関数呼び出しを大幅改善

Mistral AI がフラッグシップモデル Mistral Large 3 を正式リリース。構造化出力生成・関数呼び出し精度・JSON モードの信頼性が前世代から大幅に向上した。特筆すべきは、La Plateforme を通じた EU データレジデンシーのサポートで、GDPR の厳格なデータローカリゼーション要件を持つ欧州企業が規制準拠しつつ最先端モデルを利用できる環境が整った。欧米のモデルが米国クラウドへの依存を強める中、Mistral の EU ネイティブ戦略は「AI デジタル主権」を重視する企業・政府機関の需要を直接捉えている。

**開発者への影響**:
- 関数呼び出しの精度向上は、ツール利用型エージェントのアーキテクチャ設計において Mistral Large 3 を有力候補に引き上げる
- GDPR データローカリゼーション要件がある欧州向けサービスで、最先端モデルを活用できる選択肢が増えた

## 新技術・新リリース

### GCC 16 リリース直前 — C++20 デフォルト化・Algol 68 フロントエンド・AMD Zen 6 サポート

GNU Compiler Collection の次期メジャー版 GCC 16.1 が 2026 年 4 月リリースを目前に控えている。最大のポイントは、明示的な `-std` フラグ指定なしで C++20 が既定の言語標準になる点で、既存の Makefile をそのまま使いながら C++20 機能が利用できるようになる。歴史的なプログラミング言語 Algol 68 のフロントエンドが新たに追加されたほか、AMD の次世代アーキテクチャ Zen 6 に向けた `-march=znver6` フラグと Intel Nova Lake（AVX10.2/APX 命令セット）のサポートも含まれる。

```bash
# GCC 16 以前: C++20 機能を使うには明示的なフラグが必要
g++ -std=c++20 -O2 main.cpp -o app

# GCC 16 以降: C++20 がデフォルト。フラグ省略でも C++20 が有効
g++ -O2 main.cpp -o app

# AMD Zen 6 最適化コンパイル（GCC 16 新規サポート）
g++ -march=znver6 -O3 main.cpp -o app_zen6
```

この変更により、古いプロジェクトで意図せず C++20 機能が有効になる可能性があることに注意。ビルドシステムで言語標準を明示的に固定していない場合は動作確認を推奨する。

## セキュリティ

### CVE-2026-40175: Axios CVSS 10.0 — プロトタイプ汚染からクラウド完全侵害へ連鎖

4 月 10 日に公開された CVE-2026-40175 は、npm 週間ダウンロード数 1 億超の HTTP クライアントライブラリ **Axios 1.15.0 未満**に影響する CVSS スコア **10.0** の最重大脆弱性。Axios 自体がプロトタイプ汚染の起点ではなく、**サードパーティ依存関係で発生したプロトタイプ汚染を RCE（リモートコード実行）または AWS IMDSv2 バイパスによるクラウド完全侵害へ昇格させる「ガジェットチェーン」** が内在している点が特異。つまり、依存関係のいずれかでプロトタイプ汚染が発生すれば、Axios が踏み台となって被害が最大化する。

**対処方法**:
```bash
# 現在のバージョン確認
npm list axios

# 1.15.0 以上へアップデート（修正版）
npm install axios@latest

# または package.json で最小バージョンを固定
# "axios": ">=1.15.0"
```

影響範囲はフロントエンド・Node.js バックエンドを問わず広範。CI/CD パイプラインや Lambda 関数など Axios を使う全環境で即時アップデートが推奨される。

Ivanti Endpoint Manager Mobile（EPMM）の 2 件の脆弱性が CISA の Known Exploited Vulnerabilities（KEV）カタログに登録されており、**米連邦機関向けの対応期限は 4 月 11 日（本日）**。Ivanti 製品の脆弱性は 2025 〜 2026 年にわたり繰り返し積極的な悪用が確認されており、モバイルデバイス管理（MDM）基盤を持つ組織は優先度高でパッチ適用状況を確認すること。
