## 開発ツール・フレームワーク

- **Claude Code — MCP 安定性の大幅改善**: MCP サーバーが起動時の一時エラーで最大 3 回自動リトライするようになった。MCP_TOOL_TIMEOUT が リモート HTTP/SSE サーバーでも正常に機能するよう修正（従来は設定値無視で 60 秒固定）。`/mcp` コマンドが接続サーバーのツール数を表示するようになった。（出典: [Releasebot](https://releasebot.io/updates/anthropic/claude-code)）

- **Claude Code の週次利用上限が 50% 増加 (〜2026 年 7 月 13 日)**: OpenAI Codex への対抗措置として期間限定で上限緩和中。（出典: [pasqualepillitteri.it](https://pasqualepillitteri.it/en/news/2494/claude-code-weekly-limits-50-percent-anti-codex-anthropic-2026)）

- **TypeScript v6 リリース / v7 (Go コンパイラ) が 2026 年中期予定**: v6 は v7 移行のための整理リリース。v7 では Go ベースのコンパイラによりビルド速度が大幅向上見込み。（出典: [Frontend Masters Blog](https://frontendmasters.com/blog/what-to-know-in-javascript-2026-edition/)）
