### 1. Tesla Cybercab、ステアリングホイールなしでオースティン公道デビュー — NHTSA が即日調査開始

Tesla が9月3日夜、テキサス州オースティンで **Cybercab** の商用ライドサービスを開始した。ステアリングホイール・ブレーキペダル・バックミラーを持たない完全ハンドオフ設計の2人乗り電動車で、約1,000台規模での展開が始まった。しかし翌4日、**NHTSA（米国道路交通安全局）** は監査案件「AQ26002」を開設し、「Tesla がCybercabを認証した際に依拠したプロセスと技術データ」の調査を開始した。NHTSAの規定では、ステアリングホイールやペダルを持たない車両を公道に展開するには事前の免除（exemption）申請が必要だが、Tesla はこの手続きを踏んでいないとみられる。以前 Zoox が同類の規制対応で4年間の運用停止を余儀なくされた前例があり、業界は今後の動向を注視している。

### Rust 1.98.0 — 代数的浮動小数点メソッドで `-ffast-math` 相当の最適化をコントロール付きで実現

8月20日にリリースされた **Rust 1.98.0** の最大の目玉は、`f32` / `f64` に追加された **代数的浮動小数点メソッド（algebraic floating-point methods）** だ。C/C++ の `-ffast-math` フラグに相当するパフォーマンス最適化を、関数単位で選択的に適用できる仕組みで、Rust の「安全性を犠牲にしない」設計哲学を守りつつ数値計算の高速化を可能にする。コンパイラは実数の代数的性質に基づく演算の並べ替えが許可されるため、ループのベクトル化効率が大幅に向上する。

```rust
// Rust 1.98.0: 代数的浮動小数点メソッド (algebraic floating-point)
// 通常の演算は IEEE 754 準拠（結果が変わる可能性があれば使わない）
fn dot_product_strict(a: &[f32], b: &[f32]) -> f32 {
    a.iter().zip(b.iter()).map(|(x, y)| x * y).sum()
}

// algebraic_* メソッド: 演算順序の変更・融合 (FMA) を許容
// => SIMD ベクトル化が効きやすくなり大規模数値計算で高速化
fn dot_product_fast(a: &[f32], b: &[f32]) -> f32 {
    a.iter()
        .zip(b.iter())
        .map(|(x, y)| x.algebraic_mul(*y))   // algebraic_mul: reordering OK
        .fold(0.0_f32, |acc, v| acc.algebraic_add(v))
}

// その他の追加機能:
// - NumBuffer: 整数フォーマット用バッファ（alloc なし対応）
// - substr_range / subslice_range: スライスの範囲を返す
// - String::from_utf16le / from_utf16be: LE/BE を明示した UTF-16 変換
// - Atomic::from_mut: &mut T から Atomic<T> の参照を取得
fn main() {
    // NumBuffer: no_std 環境でも整数を文字列化
    use std::fmt::Write;
    let mut buf = String::new();
    write!(buf, "{}", 42_u32).unwrap();
    println!("{}", buf); // "42"
}
```

数値計算・機械学習推論・ゲームエンジンなど、FP 演算のパフォーマンスがボトルネックになるユースケースで特に恩恵が大きい。「速度が欲しい箇所だけ algebraic_* を使い、精度が重要な箇所は従来の演算子を使う」という粒度の制御が、他言語にはない Rust らしいアプローチだ。

# リスク: PLC との通信断絶 → 生産ライン停止・安全システムへの影響

# リスク: ローカル/ネットワーク経由での権限昇格・悪意あるファームウェアの挿入

今週 CISA が連続公開した ICS アドバイザリで最も注意が必要なのは **ICSA-26-246-05（1756-ENBT DoS）** と **ICSA-26-246-03（ControlFLASH 権限昇格）** だ。1756-ENBT は製造・エネルギー・水道・交通など幅広い分野の ControlLogix システムで使われる通信モジュールであり、DoS 攻撃で PLC との接続が切断された場合、自動化システムの緊急停止や安全機能への影響が生じ得る。ControlFLASH の権限不備はファームウェア更新経路を悪用したサプライチェーン攻撃の足掛かりとなる可能性があり、OT 環境に悪意のあるファームウェアを書き込むシナリオが懸念される。IT/OT 融合が進む現代の工場環境では、IT側のランサムウェア感染が OT ネットワークへ波及するリスクも重なるため、ネットワーク分離・最小権限の徹底が急務だ。
