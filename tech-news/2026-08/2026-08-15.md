### 1. Microsoft Patch Tuesday 8月版——421件のCVEを修正、北朝鮮Lazarusグループ悪用のWinSockゼロデイ（CVE-2026-68820）を含む

Microsoftは2026年8月のPatch Tuesdayで**421件のCVE**を修正した。うち最も注目すべきは**CVE-2026-68820**で、Windows Sockets API の基盤となるカーネルモードドライバ「Ancillary Function Driver for WinSock（afd.sys）」に存在する**use-after-free**の脆弱性だ。CVSSv3スコアは**7.0（重要）**で、ローカル認証済みの攻撃者が細工したアプリケーションを実行することで**競合状態（race condition）を引き起こし、ユーザー操作なしにSYSTEM権限へ昇格**できる。Check Point Researchの分析によれば、この脆弱性は北朝鮮の国家支援型脅威アクター**Lazarusグループ**が「**Operation Dream Job**」キャンペーンで積極的に悪用しており、CISAもKEV（Known Exploited Vulnerabilities）カタログへの追加と即時対応を勧告した。今月のPatch Tuesdayには他にも**3件のゼロデイ**が含まれており、BleepingComputerの集計では約400件のフラウが一括修正された。攻撃対象となるwinsock APIは事実上すべてのWindowsアプリケーションが利用する低レイヤーのコンポーネントであるため、パッチ未適用のシステムは広範な侵害リスクにさらされる。

Modularは2026年8月11日、AI向けプログラミング言語**Mojo**のバージョン**1.0**を「Modular 26.5」アップデートとして正式リリースした。2023年にSwift/LLVMの設計者Chris LattnerとTim Davisが創設したこのプロジェクトは、**Pythonライクな直感的シンタックス**と**Rustレベルのメモリ安全性・パフォーマンス**を組み合わせ、GPU・CPU・ASICなどAI推論で利用される多様なヘテロジニアスハードウェアを単一言語でターゲットできる点が最大の特長だ。1.0では**後方互換性の保証**が加わり、Python風ラムダ構文・無効参照を検出するメモリ安全性診断・Pointerタイプ・標準化されたvar宣言が新たに追加された。このリリースは**QualcommによるModular社の買収**（2026年中期）直後のマイルストーンでもあり、エッジからクラウドまでのAIソフトウェアスタック統一という野心的な戦略の一環として注目を集めている。Mojoコンパイラとツールチェーンの2026年中のオープンソース化も引き続きコミットされており、採用の裾野拡大が期待される。AIワークロードの多様化とオープンソース化の流れの中で、Pythonエコシステムとネイティブパフォーマンスのギャップを埋める言語として評価が高まっている。

## 新技術・新リリース

### Mojo 1.0 詳解：Pythonシンタックス×Rustパフォーマンス×AI専用型システム

Mojo 1.0はAI時代のシステムプログラミング言語として設計されており、Pythonとの相互運用性を保ちながらコンパイル後は**C/C++に匹敵するパフォーマンス**を発揮する。主要な特徴と最小サンプルを示す。

```mojo
# Mojo 1.0 — 基本的な型注釈とパフォーマンス最適化の例
# Python風の構文でメモリ安全なシステムプログラミングが可能

fn add_vectors(a: List[Float32], b: List[Float32]) -> List[Float32]:
    """SIMD最適化された要素ごとの加算（AIテンソル演算を想定）"""
    var result = List[Float32](capacity=len(a))
    for i in range(len(a)):
        result.append(a[i] + b[i])
    return result

# Python互換のシンプルな関数定義（fn の代わりに def も使用可）
def greet(name: String) -> String:
    return "Hello, " + name + "!"

# ラムダ構文（1.0 新機能）
var square = fn(x: Int) -> Int: return x * x
print(square(5))   # 出力: 25

# メモリ安全性診断（無効参照を静的に検出）
fn safe_access(ptr: Pointer[Int]) -> Int:
    # コンパイラが無効参照を検出して警告
    return ptr[]
```

**インストール（Linux/macOS）**:
```bash

curl -ssL https://magic.modular.com/install.sh | bash
magic install mojo

# バージョン確認
mojo --version
# mojo 26.5.0 (2026-08-11)
```

Qualcommによる買収を経て、Mojo 1.0はエッジデバイス向けAI推論の標準ツールチェーンとして位置づけられており、Snapdragon NPU上での直接実行も視野に入れている。Pythonエコシステムとの互換性維持はデータサイエンス分野での採用を加速させる可能性が高く、今後のコンパイラオープンソース化と合わせて注目のリリースとなった。

### 今週の主要脆弱性まとめ：Lazarusのゼロデイ・macOS認証バイパス・GeoServer SQL Injection・Secure Boot 13年来の欠陥

**① CVE-2026-68820 — Windows WinSock EoP（Lazarus Group/Operation Dream Job）**

```text
=== CVE-2026-68820 攻撃フロー概要 ===

[攻撃者（Lazarus Group）]
  |
  | ローカル認証済みアクセスを確保後（フィッシング/ソーシャルエンジニアリング）
  v
[afd.sys（Windows Sockets API カーネルドライバ）]
  細工したアプリケーション実行 → race condition を誘発
  → use-after-free により解放済みメモリにアクセス
  → カーネルレベルのコード実行
  → SYSTEM 権限昇格（完全制御）

=== 影響バージョン ===
  Windows 10 / 11 全バージョン
  Windows Server 2016 / 2019 / 2022 / 2025

=== 緩和策 ===
  1. 2026年8月のPatch Tuesday更新プログラムを即時適用
  2. EDR/XDRでafd.sysへの異常アクセスを監視
  3. CISAのKEVカタログを運用フローに組み込み、期限内修正を徹底
  4. ゼロトラストアーキテクチャによりローカル権限昇格の影響範囲を最小化
```

**② CVE-2026-65400 — Apple macOS Screen Sharing 認証バイパス（CVSS 9.8）**

macOSのScreen Sharingコンポーネントに存在する重大な認証欠陥で、**ネットワーク上の攻撃者が有効な資格情報なしでリモートデスクトップ機能サービスに認証できる**。CVSSスコアは9.8で、既に**暗号通貨マイナー**の展開に悪用された実例が報告されている。macOSのシステム環境設定「共有」からScreen Sharingを無効化するか、Appleの最新アップデートを適用することが推奨される。

**③ GeoServer SQL Injection ゼロデイ（2026-08-12 公開）**

オープンソースの地理空間データサーバー**GeoServer**で新たに開示されたSQLインジェクション脆弱性は、**リモートコード実行（RCE）**に至る可能性がある。2026年8月12日（UTC 10:46）に初めて公開されており、インターネット公開インスタンスに対する悪用試行が早くも確認されている。GeoServerのバージョン管理とネットワーク境界でのアクセス制限が急務だ。

**④ Microsoft Secure Boot — 14年間のうち13年間に存在した欠陥**

研究者がMicrosoftのSecure Bootに「設計時から実質的に13年間トリビアルにバイパス可能な脆弱性」が存在していたことを明らかにした。業界標準として信頼されてきたブートチェーンのセキュリティ前提が根底から揺らいでおり、サプライチェーン攻撃やルートキット対策の見直しを促すインパクトがある。
