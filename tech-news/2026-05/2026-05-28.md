### 2. Rust 1.96.0 本日リリース — cfg での expr メタ変数利用・型推論改善、CVE-2026-5222/5223 修正

Rust チームは **Rust 1.96.0** を本日（2026-05-28）公開した。6週ごとのトレインリリースに則ったアップデートで、言語面の主要変更は `macro_rules!` の `:expr` フラグメントが `cfg` 条件式内で利用可能になった点だ。これにより複雑なマクロパターンで不要なアーキテクチャ特有のコードを記述せずに済むケースが増える。型推論も改善されており、クロージャ・ジェネリクスまわりで明示的な型注釈が不要になる場面が拡大された。また rustdoc は非推奨アノテーションの視覚的描画を改善し、API ドキュメントの可読性が向上した。セキュリティ面では **CVE-2026-5222**（コンパイラの特定条件下での境界外読み取り）および **CVE-2026-5223**（cargo のビルドスクリプト実行における権限逸脱）が修正されている。`rustup update stable` で即時適用可能だ。

**出典**: [Rust 1.96.0 Changelog — releases.rs](https://releases.rs/docs/1.96.0/) / [Rust Release Announcements — blog.rust-lang.org](https://blog.rust-lang.org/releases/)

### 3. PAN-OS CVE-2026-0300（CVSS 9.3）— Palo Alto ファイアウォールへの未認証 root RCE が野放しで悪用中、本日パッチ最終段階

Palo Alto Networks の PAN-OS に存在する **CVE-2026-0300**（CVSS 9.3）は、User-ID™ 認証ポータル（Captive Portal）サービスの `CWE-787: Out-of-bounds Write` に起因する未認証リモートコード実行脆弱性だ。攻撃者は特殊細工したネットワークパケット1件を送信するだけで、PA-Series・VM-Series ファイアウォール上で **root 権限による任意コード実行**が可能になる。CISA はすでに既知悪用脆弱性（KEV）カタログへ追加しており、連邦機関には 5月9日までの対処が義務付けられた。修正パッチは 5月13日から段階的にリリースが開始され、本日（5月28日）の最終分で全該当バージョンへの適用が完了する見込みだ。Prisma Access・Cloud NGFW・Panorama は影響を受けない。パッチ適用前の緩和策として、信頼ゾーンのみへの User-ID ポータルアクセス制限、および非信頼インターフェースでの Response Pages 無効化が推奨されている。

**出典**: [Palo Alto Networks Security Advisory CVE-2026-0300](https://security.paloaltonetworks.com/CVE-2026-0300) / [Wiz Blog: CVE-2026-0300 Exploited in the Wild](https://www.wiz.io/blog/critical-vulnerability-in-pan-os-exploited-in-the-wild-cve-2026-0300) / [The Hacker News: Palo Alto PAN-OS Flaw Under Active Exploitation](https://thehackernews.com/2026/05/palo-alto-pan-os-flaw-under-active.html)

### Claude Opus 4.8 & Rust 1.96.0 — 本日同日リリースの新機能を試す

**Claude Opus 4.8 — Fast Mode と Dynamic Workflows**

```python
import anthropic

client = anthropic.Anthropic()

# 通常モード: claude-opus-4-8（1M コンテキスト対応）
response = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=8192,
    messages=[{"role": "user", "content": "このコードベースのバグを解析して"}]
)
print(response.content[0].text)

# Fast Mode: ~2.5x 高速（$10/$50 per M tokens）
# Effort Control で品質とコストのバランスを調整
response_fast = client.messages.create(
    model="claude-opus-4-8",
    max_tokens=8192,
    metadata={"fast_mode": True},   # Fast Mode 有効化（API プレビュー）
    messages=[{"role": "user", "content": "このメソッドをリファクタリングして"}]
)
```

**Rust 1.96.0 — cfg 内 :expr メタ変数と型推論の改善**

```rust
// Rust 1.96.0: macro_rules! 内の :expr を cfg 条件に渡せるように
macro_rules! trace_if {
    ($enabled:expr, $msg:expr) => {{
        // 1.95.0 以前は :expr フラグメントを cfg 相当の条件に使うと制約があった
        if $enabled {
            eprintln!("[TRACE] {}", $msg);
        }
    }};
}

// 型推論の改善: クロージャ戻り値の型注釈が不要なケースが拡大
fn process(items: &[&str]) -> Vec<i64> {
    // 1.95.0 では |s| -> i64 { ... } と明示が必要なケースがあった
    items.iter().map(|s| s.parse().unwrap_or(0)).collect()
}

fn main() {
    trace_if!(cfg!(debug_assertions), "starting up");
    let result = process(&["42", "bad", "100"]);
    println!("{:?}", result); // [42, 0, 100]
}
```

### PAN-OS CVE-2026-0300 — 緩和手順と確認コマンド

```bash
# 影響バージョンの確認（PA-Series / VM-Series）
show system info | grep sw-version

# User-ID Authentication Portal の有効状態確認
show user user-id-service status

# 緩和策: 非信頼インターフェースでの Response Pages を無効化
# Panorama / Web UI で:
#   Network > Interfaces > [対象IF] > Advanced > Interface Management Profile
#   → Response Pages のチェックを外す（信頼ゾーンのみ有効に）

# パッチ適用後バージョン確認
show system info | grep "sw-version"
# → 10.2.x-h6 / 11.1.x-h4 / 11.2.x-h2 等、修正済みビルドを確認
```

Prisma Access・Cloud NGFW は影響外。オンプレミスの PA-Series・VM-Series を利用している場合は本日提供の最終修正ビルドへの即時アップグレードを優先する。
