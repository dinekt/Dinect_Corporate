### 1. トランプ大統領が AI・サイバーセキュリティ統合大統領令に署名 — フロンティアモデルの政府への事前開示義務化が最大の争点

トランプ大統領は 6 月 2 日、「**Promoting Advanced Artificial Intelligence Innovation and Security（先進 AI イノベーションとセキュリティの推進）**」と題した大統領令に署名した。最大の目玉は、フロンティア AI 開発者が新モデルを信頼パートナーへリリースする前に**最大 30 日間**、政府機関に事前アクセスを提供する「任意枠組み」の制度化だ。同時に財務省・CISA・NSA が共同で運営する **AI サイバーセキュリティクリアリングハウス**の設置が命じられ、重要インフラ（地方病院・コミュニティバンク・公益事業）向けにフロンティアモデルを活用した脆弱性スキャン支援を行う。法的拘束力のある「義務」ではなく「任意」と明記されているものの、連邦調達要件や補助金条件と組み合わせることで事実上の強制力を持ちうるとの指摘が多く出ている。EU AI Act の高リスク規定が 8 月に本格適用を迎える中、米国が「義務回避・イノベーション優先」の路線を選択したことで、大西洋両岸のフロンティア AI ガバナンスの亀裂が一層深まった格好だ。

### 2. EU が「テック主権パッケージ」を公開 — Chips Act 2.0・CADA で米国クラウドへの依存脱却を宣言

欧州委員会は 6 月 3 日、**欧州テック主権パッケージ（Tech Sovereignty Package）**を公表した。3 度の延期を経てようやく公開された本パッケージは、半導体・AI・クラウド・オープンソースの 4 分野で EU の自律性を高める立法・戦略文書の束だ。核心は 2 本の立法提案—**Chips Act 2.0**（先端半導体の供給力強化・設備投資支援）と**Cloud and AI Development Act（CADA）**（データセンター展開の一元化・クラウド主権の 4 段階フレームワーク）—で、特に CADA の最高位認定は EU 内の所有・雇用・法的管轄の独立性を要件とし、米国 Cloud Act の管轄外であることを証明させる仕組みとなっている。CNBC は「誰にもキルスイッチを握らせない」という委員のコメントを引用し、米国 Big Tech への依存を問題視する欧州の姿勢を明確に報じた。米国とのデジタル貿易摩擦が深まる可能性がある一方、EU 域外に拠点を持つクラウドプロバイダーは主権フレームワーク適合のため大規模な組織改変・法人分離を迫られる可能性が高い。

**出典**: [CNBC](https://www.cnbc.com/2026/06/03/europe-tech-sovereignty-us-tech-reliance.html) / [European Commission Press Corner](https://ec.europa.eu/commission/presscorner/detail/en/ip_26_1187) / [The Next Web](https://thenextweb.com/news/eu-tech-sovereignty-cloud-chips-act)

### 3. TypeScript が GitHub の利用言語ランキングで初めて首位に — Python・JavaScript を抜き、AI 時代の「型付き言語優位」が鮮明

GitHub が公式 X アカウントで報告したデータによると、2025 年 8 月に TypeScript が Python および JavaScript を抜いて **GitHub の月間アクティブコントリビューター数 1 位**を初めて獲得し、2026 年もその地位を維持している。2025 年 8 月時点のコントリビューター数は約 **263 万人**で、Python を約 4.2 万人上回った。AI 補助開発（GitHub Copilot 等）が普及した結果、「型情報があれば AI 生成コードが安全になる」という実感が TypeScript 採用を後押ししているとの分析が支配的だ。一方、Python は AI/ML タグのついたリポジトリ数では依然トップを維持しており、「アプリ・API 層は TypeScript、データ・ML 層は Python」という二層スタックが 2026 年の標準アーキテクチャとして定着しつつある。

### Gemini 3.5 Flash GA — フロンティア級知性を 4 倍速・低コストで提供

Google DeepMind の **Gemini 3.5 Flash** が一般提供（GA）を開始した。同クラスの競合モデル比で 4 倍の速度を誇り、入力 100 万トークンあたり **$1.50**、出力 **$9.00** という価格設定は API ユーザーにとって実用域に入る水準だ。長文脈処理・コード生成・マルチモーダル理解の全分野でフロンティア級の指標を維持しながら、インファレンスコストを大幅に圧縮しており、Claude Haiku 4.5・GPT-4o mini と並んで「コスト効率最優先」ユースケースの主要選択肢として急浮上している。

```python
# Gemini 3.5 Flash — Google AI SDK での基本的な呼び出し例
import google.generativeai as genai

genai.configure(api_key="YOUR_API_KEY")

model = genai.GenerativeModel(
    model_name="gemini-3.5-flash",
    generation_config={
        "temperature": 0.7,
        "max_output_tokens": 2048,
    }
)

response = model.generate_content(
    "TypeScript と Python の使い分けを 3 行で説明してください"
)
print(response.text)

# ストリーミング出力（長文生成時のレイテンシ改善に有効）
for chunk in model.generate_content("詳しく説明してください", stream=True):
    print(chunk.text, end="", flush=True)
```

### Cisco SD-WAN に第 7 のゼロデイ（CVE-2026-20245）— パッチ未公開のまま悪用確認、2026 年最多ベンダー脆弱性記録が更新

Cisco は 6 月 5 日、**Cisco Catalyst SD-WAN Manager** に 7 本目のゼロデイ脆弱性（**CVE-2026-20245**・CVSS 7.8）が悪用中であることを公表した。CLI のコマンドインジェクション欠陥で、netadmin 権限を持つ認証済み攻撃者が細工したファイルをアップロードすることで **root 権限でのコマンド実行**が可能となる。パッチはいまだ提供されておらず、ワークアラウンドも公式には存在しない。今脆弱性の悪用には有効な認証情報、または先に修正された **CVE-2026-20182**（CVSS 10.0・認証バイパス）の悪用が前提となるため、5 月の CVE-2026-20182 対応が完了していない環境では「完全な認証なし root」シナリオが成立する。オンプレミス・Cloud-Pro・Cloud（Cisco Managed）・FedRAMP（政府向け）の全デプロイタイプが対象範囲で、今年だけで 7 件の SD-WAN ゼロデイが記録されるという前例のない状況となっている。

```bash
# --- CVE-2026-20245 暫定対策チェックリスト ---

# 1. SD-WAN Manager の管理 API/CLI へのアクセス元を絞り込む
#    （netadmin 権限ユーザーを最小化し、不要なアカウントを無効化）

# 2. PSIRT 勧告に従い SD-WAN Manager のアクセスログを監視
#    異常なファイルアップロード（PUT/POST ≥ 1MB）を検知する例
curl -sk https://<vmanage-ip>/dataservice/log/feature \
  -H "Cookie: $SESSION_COOKIE" \
  | python3 -c "
import sys, json
logs = json.load(sys.stdin)
for entry in logs.get('data', []):
    if 'upload' in str(entry).lower():
        print(entry)
"

# 3. CVE-2026-20182 が未適用の場合は先に適用する（認証バイパス修正）
#    vManage のバージョン確認
ssh admin@<vmanage-ip> "show version"

# 4. Cisco PSIRT の勧告ページを定期ポーリングして patch リリースを監視
#    https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-sdwan-rpa-EHchtZk

# 5. セグメンテーション: vManage を専用管理 VLAN に隔離し
#    ユーザーネットワークからの直接アクセスをファイアウォールで遮断
```

**影響範囲と優先度**: SD-WAN Manager を外部ネットワークから管理している環境、および CVE-2026-20182 の対応が未完了の環境は最優先で対処が必要。Cisco PSIRT の勧告ページを継続監視し、パッチリリース後は即日適用を目指す。netadmin ロールの棚卸しと最小権限化を並行して実施されたい。

**出典**: [Help Net Security: CVE-2026-20245](https://www.helpnetsecurity.com/2026/06/05/cisco-sd-wan-cve-2026-20245-0-day-exploited/) / [The Hacker News](https://thehackernews.com/2026/06/cisco-catalyst-sd-wan-manager-cve-2026.html) / [SecurityWeek](https://www.securityweek.com/cisco-warns-of-7th-sd-wan-zero-day-exploited-in-2026/) / [The Register](https://www.theregister.com/security/2026/06/05/yet-another-cisco-sd-wan-0-day-under-attack-and-no-patch-in-sight/5251855)
