### 1. OpenAI vs 数学界 — ナビエ・ストークス制覇宣言にフィールズ賞受賞者25名が公開書簡、Caltech ハッカソンスポンサー撤退で対立激化

### 2. Microsoft 史上最多 974件 CVE — Patch Tuesday 9月版 / Windows ALPC・Update Stack のゼロデイ2件が積極悪用中

Microsoft は9月第2火曜日（Patch Tuesday）に、史上最多となる**974件の CVE**（脆弱性）を修正するセキュリティ更新プログラムを公開した。修正対象は Windows を中心に Office・SQL Server・Exchange Server・SharePoint・Azure・開発者ツールなど広範に及ぶ。中でも**積極的な悪用が確認されたゼロデイが2件**あり、CISA は連邦文官機関（FCEB）に対して**9月22日**を修正期限として通知した。1件目の **CVE-2026-85880**（CVSS 7.8）は Windows ALPC（Advanced Local Procedure Call）のヒープバッファオーバーフローによる権限昇格で、ALPC 系の脆弱性がゼロデイとして悪用されるのは3年以上ぶりだという。2件目の **CVE-2026-81963**（CVSS 7.8）は Windows Update Stack における「リンク追跡前ファイルアクセス」の不適切処理で、低権限のローカル攻撃者が SYSTEM 権限を取得できる。Update Stack 系のゼロデイ悪用は2022年以来初めてとなる。今回の修正件数（974件）は従来の Patch Tuesday の記録を更新するものであり、Windows の技術的負債が改めて浮き彫りとなった。

### 3. YC CEO Garry Tan「AI ディスティレーションを規制するな」— 米中覇権争いの中でシリコンバレー内の意見対立が鮮明に

NSA・CISA・FBI の共同勧告 AA26-251A（中国系 AI 企業による米国フロンティアモデルの組織的蒸留攻撃を警告）から数日後、Y Combinator CEO の Garry Tan が「ディスティレーションについては何もしない（do nothing）」とコメントし、規制反対を明言した。Tan 氏は規制当局に対し、米国のオープンウェイト AI ラボも同手法を活用してフロンティアモデルから蒸留することで、中国製モデルに対抗できる強力なオープンウェイト AI のエコシステムを米国内に構築すべきと主張する。「広く公開されたデータから訓練された知能へのアクセスは、厳格な利用規約の背後に閉じ込めるものではなく、公共財に近い性格を持つべきだ」とも述べた。この立場は Anthropic CEO Dario Amodei が政府機関に対してディスティレーション規制強化を求めた主張と真っ向から対立する。同日、中国系のヒューマノイドロボット企業も OpenAI に対して「逆ディスティレーション」の主張を行い、構図はさらに複雑化した。AI ディスティレーション問題は今や安全保障・知財・オープンソース哲学の3軸が交錯する論争に発展している。

### Forgejo 16.0.4 リリース — 重大な脆弱性を修正したセルフホスト型 Git プラットフォームの緊急アップデート

セルフホスト型 Git サービス **Forgejo** が9月11日に **16.0.4** をリリースし、重大な脆弱性を修正した。Forgejo は GitHub / GitLab の OSS 代替として注目されているプラットフォームで、欧州・アジアの公共機関やプライバシー重視組織での採用が急拡大している。今回のリリースはセキュリティ修正を主目的とした緊急アップデートであり、セルフホストインスタンスを運用している管理者は早急な適用が推奨される。

```bash
# Forgejo 16.0.4 へのアップグレード手順（Docker を使用している場合）

# 1. 現在のバージョン確認
docker exec -it forgejo /app/gitea/gitea --version

# 2. イメージを最新版に更新
docker pull codeberg.org/forgejo/forgejo:16.0.4

# 3. サービスを再起動（データボリュームは変更なし）
docker-compose down
docker-compose up -d

# 4. アップグレード後の確認
docker exec -it forgejo /app/gitea/gitea --version
# → Forgejo version 16.0.4 built with... が表示されればOK

# 5. ログで異常がないか確認
docker logs forgejo --tail=100 | grep -E "ERROR|FATAL|panic"
```

Forgejo はセルフホスト型の性質上、アップデートが自動適用されない点に注意が必要だ。プロジェクトは Gitea のフォークとして始まり、現在は独自のガバナンスのもとで開発が進められており、Codeberg.org がリファレンス実装として機能している。なお Moonshot AI（Kimi の開発元）が年間収益20億ドルを目標に掲げるなど、AI インフラ全体への投資熱が続いており、オープンソース開発ツール群の整備にも間接的な追い風となっている。

### Microsoft Patch Tuesday 9月版 詳細 & CISA KEV 新規7件 — 974 CVE 大規模修正とゼロデイ2件への緊急対応

```powershell
# ===== Microsoft Patch Tuesday 2026-09 緊急対応チェックリスト =====
# 積極悪用が確認されたゼロデイ（最優先で適用）

# 1. CVE-2026-85880 — Windows ALPC 権限昇格 (CVSS 7.8)
#    影響: Windows 10/11, Server 2019/2022/2025
#    種別: ヒープバッファオーバーフロー → ローカル権限昇格
#    備考: ALPC 系ゼロデイの悪用は3年以上ぶり
#    対処: Windows Update より最新累積更新プログラムを適用

# 2. CVE-2026-81963 — Windows Update Stack 権限昇格 (CVSS 7.8)
#    影響: Windows 10/11, Server 2019/2022/2025
#    種別: リンク追跡前ファイルアクセス不正 → SYSTEM 権限取得
#    備考: Update Stack 系ゼロデイ悪用は2022年以来
#    対処: Windows Update より最新累積更新プログラムを適用

# FCEB（連邦文官機関）のパッチ適用期限: 2026-09-22

# ===== パッチ適用状況確認スクリプト (PowerShell) =====
$hotfixes = Get-HotFix | Where-Object { $_.InstalledOn -ge (Get-Date "2026-09-01") }
$hotfixes | Select-Object HotFixID, InstalledOn, Description | Format-Table -AutoSize
# 2026年9月分のホットフィックスが一覧に含まれているか確認すること

# ===== CISA KEV 2026年9月 新規追加分（主要）=====
# - Adobe Commerce:   CVE-2026-75650
# - N-able N-central: CVE-2026-86218 (CVSS 10.0) ← 9/9 にも追加済み
# - MikroTik RouterOS: 2件（ルーター経由での侵入ルートに注意）
# ※ 計7件が新規追加、詳細は CISA 公式 KEV カタログ参照
```

今月の Patch Tuesday は規模（974件）とゼロデイ2件の同時悪用という2つの意味で異例の事態だ。CVE-2026-85880 の ALPC 系脆弱性は RDP 経由のラダー攻撃に組み合わせやすく、CVE-2026-81963 の Update Stack 系はマルウェアによるパッチ更新妨害や特権奪取に直結する。企業環境では WSUS や Microsoft Intune を介した迅速な展開が求められる。CISA KEV への追加も前日（9月10日）の Cisco FMC・Citrix NetScaler 等に続く形であり、9月は全体として極めて多くの緊急パッチが集中した月となっている。MikroTik RouterOS の脆弱性は SOHO 向けルーターを狙ったものであり、中小規模の組織や在宅勤務環境でも注意が必要だ。
