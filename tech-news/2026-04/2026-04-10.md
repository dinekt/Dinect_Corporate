# AI専門家デイリーレポート 2026-04-10

## 本日のAIニュース TOP 3

**1. Claude Code — Focus View 追加・diff 計算 60% 高速化・max_tokens 300k 拡張**

Anthropic が Claude Code に Focus View（Ctrl+O）を追加。プロンプト・ツールサマリー・最終レスポンスのみを表示するシンプルモードで、長時間セッションでのノイズを削減。大規模ファイル diff の計算速度が 60% 向上。合わせて Message Batches API で max_tokens を 300k に拡張（beta ヘッダ `output-300k-2026-03-24` が必要）。Claude Haiku 3 は 4月19日廃止予定で Haiku 4.5 への移行推奨。

**2. デジタル化・AI導入補助金2026 — IT導入補助金を改称・AI評価ウェイト増・申請受付中**

経済産業省・中小企業庁が IT 導入補助金を「デジタル化・AI導入補助金2026」に改称。令和7年度補正予算で 3.4 兆円確保。AI ツール認定品が採択で優遇、補助率最大 2/3、上限 5 億円（従来比 +0.5 億円）。申請受付は 3月末〜開始済み。


**3. Q1 2026 VC 調達が過去最高 — AI セクターがグローバル投資の 80% を占有**

Q1 2026 の世界 VC 調達は 3,000 億ドルを記録し、うち 2,420 億ドル（80%）が AI セクターへ。OpenAI が Amazon の 500 億ドル投資を含む 1,220 億ドルのラウンドをクローズ（バリュエーション 8,520 億ドル）。Anthropic は 300 億ドル、xAI は 200 億ドルを調達。

## 新技術・新リリース

**Cursor 3（4月2日）**
内部コード名「Glass」で再設計。Agents Window で複数エージェントを並列実行可能、複数リポジトリにまたがるマルチリポワークスペース、内蔵ブラウザでエージェントがローカルサイトと対話、MCP+スキルのプラグインマーケットプレイスを搭載。IDE から「エンジニアリングチームのオーケストレーター」へのポジション転換を明示。

**Hyperscience Hypercell Spring 2026 — IDP が Intelligent Inference へ（4月7日）**
CPU/GPU/特化モデル/フロンティアモデルへのワークロード動的ルーティングで、トランザクションあたりコストを最小化しつつ精度を確保。NVIDIA Blackwell GPU + Nemotron 3、Google Gemini 1.5 Flash/2.5 Pro に対応。VLM フレームワークをオープン・モデル非依存で提供。5月14日にウェビナー開催予定。

**MCP エコシステム — 公開サーバー 10,000+ 突破・Linux Foundation 管理へ移行**
MCP v2.1 が 2026 年中にリリース予定。SDK の月次ダウンロードは 9,700 万件。エンタープライズ課題として監査証跡・SSO 統合認証・ゲートウェイ動作・設定の移植性が浮上。
