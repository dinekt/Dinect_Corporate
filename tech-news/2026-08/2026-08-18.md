### 1. OpenAI「Astra」——10年以上未解決の数学・CS問題を$2,000のコンピュート費用で10問解決

OpenAIはまだ一般公開されていない内部モデル「**Astra**」が、数学・理論計算機科学の分野で**数十年来未解決だった問題を10問解決**したと発表した。解決した問題には高次元球充填問題（Sphere-Packing Density の厳密な下界）、非ソフィック群（Non-Sofic Group）の明示的構成、Connes剛性予想（Connes' Rigidity Conjecture）の反例提示などが含まれる。OpenAIはGitHub上に249ページの論文とLean 4による形式証明（Apache 2.0ライセンス）を公開し、証明の各ステップに"sorry"（未証明の仮定）が一切含まれていないことを確認している。驚くべきはそのコスト——現在のAPI料金換算で**わずか約$2,000（約30万円）**の計算リソースでこの成果を達成した。数学コミュニティでは証明の正当性を巡る検証議論がHacker News・学術SNSで活発化しており、AI支援による数学的発見が実用域に入ったことを示す分水嶺として注目されている。

### 2. GitLab Critical脆弱性 CVE-2026-19478——未認証でパブリックプロジェクトを削除できるGraphQL欠陥

GitLabはCVSS 9.4の**Criticalレーティング**を付与したGraphQL APIの脆弱性（**CVE-2026-19478**）のセキュリティアドバイザリを本日公開した。この欠陥を悪用すると、**認証なしの外部攻撃者がパブリックプロジェクトを削除できる**。セルフホスト型・GitLab.com双方が影響対象となるため、数百万のリポジトリが潜在的なリスクに晒されていた。修正済みバージョンは**GitLab 19.2.4・19.1.6・19.0.8・18.11.11**で、いずれも本日リリース。CVSSスコアの高さ（9.4）とエクスプロイトの容易さから、セルフホスト環境では即日アップデートが推奨される。GitLabはCI/CDパイプラインの要となるプラットフォームであり、プロジェクト削除が成立した場合は開発・デプロイフローへの連鎖的影響も考えられる。攻撃POCが流通する前の迅速なパッチ適用が重要だ。

### 3. EU AI Act 高リスク条項の施行開始から2週間——グローバル企業のコンプライアンス対応が本格化

EU AI Actの高リスクシステムに関する条項が**8月2日に本格施行**されてから約2週間が経過し、グローバルなAI企業のコンプライアンス対応状況が明らかになりつつある。違反した場合の制裁金は**最大3,500万ユーロまたは全世界年間売上の7%**と厳しく、特に医療・教育・採用・金融与信などのハイリスクAI用途を持つ企業は集中的な対応を迫られている。米国は依然として連邦AI法を持たず、Trumpホワイトハウスが推進する自発的基準・州法優先モデルとの対比が鮮明化している。一方、**Anthropicは新しいClaudeモデルにEU要件を満たす機械可読ウォーターマーク**を実装し、8月2日以降にEU向けにリリースされたモデルはすべてこのマーキングをサポートしている。規制の三極構造（EU:権利・リスクベース、米国:イノベーション優先、中国:国家統制型）が定着しつつあり、複数地域で展開するAI事業者のコンプライアンスコスト増大が長期課題として浮上している。

### DARPA「VENOM」プログラム：AI制御F-16が実戦機として自律飛行——軍事AIが試験フェーズから展開フェーズへ

DARPAと米空軍は**VENOM（Visual Engagement and Networked Operations for Maneuverability）**プログラムにおいて、既存のF-16戦闘機を**コアソフトウェアを変更せずにAI自律制御対応**に改修し、搭乗員がパイロットからスーパーバイザーに役割移行する形での実飛行を継続している。7月初旬にエグリン空軍基地で最初の自律飛行が確認され、その後も複数ソーティ（出撃）が実施されている。機体に搭載した専用スイッチでコクピット制御とAIエージェント制御をリアルタイム切り替えできる設計により、安全性を担保しながら空戦AI（Autonomous Air Combat）のリアルワールド評価を進めている。この取り組みはX-62A VISTAの実験プラットフォームでの研究成果を実戦機へ移管する重要なステップで、自律戦闘機の開発ロードマップを大幅に前倒しする可能性がある。

```text
=== DARPA VENOM プログラム概要 ===

対象機体   : F-16 Fighting Falcon（実戦配備機を改修）
改修方式   : コアソフトウェア無変更、自律制御レイヤーを追加
制御切替   : コクピットの物理スイッチで人間↔AIを即時切替
役割変化   : パイロット（操縦者）→ スーパーバイザー（監督者）
前段階研究 : X-62A VISTA実験機での自律空中格闘（ACM）成功
次フェーズ : AIエージェント同士の複数機連携（Multi-agent dogfight）
```

## セキュリティ

### GitLab GraphQL RCE・CISA Ray Framework KEV追加・WinSock Zero-Day締め切り迫る

本日のセキュリティトピックは、GitLabのクリティカル脆弱性（TOP3で紹介）に加え、2件の重大インシデントが加わる。

**① CISA：Ray Framework RCEを「既知悪用脆弱性（KEV）」カタログに追加**

CISAはAI/ML向け分散処理フレームワーク**Anyscale Ray**に存在するブラウザベースRCE脆弱性を、本日付けで**Known Exploited Vulnerabilities（KEV）カタログ**に追加した。Rayはデータパイプラインや機械学習ジョブを分散実行するために広く使われており、ダッシュボードUI（デフォルトポート8265）経由で悪用されると**認証なしでリモートコード実行**が可能になる。AI基盤に使用しているチームは外部からのRay Dashboardへのアクセスを即時ブロックし、公式パッチを適用すること。

```bash
# Ray Dashboard を外部に開放していないか確認
ss -tlnp | grep 8265

# iptables で外部アクセスをブロック（暫定措置）
iptables -A INPUT -p tcp --dport 8265 ! -s 127.0.0.1 -j DROP
```

**② CVE-2026-68820——Windows WinSock Zero-Day、CISA KEV締め切りは8月25日**

Microsoft August Patch Tuesdayで修正されたWinSock（afd.sys）のuse-after-free脆弱性**CVE-2026-68820**は、野外での積極的な悪用が確認されており、CISAはパッチ適用期限を**8月25日（月）**と設定している。エンタープライズ環境では7日以内の適用が法的義務に近い状況だ。BYODデバイス・テスト環境を含む全Windowsシステムへの展開状況を再確認すること。

**③ Forminator WordPress Plugin CVE-2026-15748（CVSS 9.8）**

WPMUDevのWordPressプラグイン「Forminator Forms」に任意コード実行を可能にする脆弱性（CVSS 9.8）が公開された。インストール数が多いプラグインであるため、WordPress運営者は即時更新が推奨される。
