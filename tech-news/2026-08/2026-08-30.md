### 1. OpenAI、SpaceX 傘下となった Cursor へのモデル提供を終了へ — Musk vs. Altman 対立が AI ツール市場を揺さぶる

SpaceX が 8 月 14 日に 600 億ドルで AI コーディングアシスタント Cursor を買収したことを受け、OpenAI は 8 月 29 日に Cursor へのモデルアクセスを 2026 年 11 月 12 日をもって終了すると正式発表した。OpenAI は「Elon Musk 傘下の企業が利用規約を遵守するという確信が持てない」と理由を説明し、マスク氏は X（旧 Twitter）で「どうでもいい。Scam Altman と Greg Stockman は信用できない」と即座に反論した。Cursor 側は「OpenAI は顧客全体の 5 % に過ぎない」と沈静化を図り、Anthropic が Claude モデルの提供を拡大する意向を表明したため、実際のユーザー影響は限定的との見方が強い。この一件は、AI モデルプロバイダーとコーディングツールの関係が利用規約・競合関係・政治的対立という三つの要因で急変しうることを改めて示した。AI コーディング市場では Copilot・Cursor・Windsurf の三つ巴の競争が続いており、今後のモデル調達戦略が各社の競争力を左右する局面に入っている。

### 2. OpenAI の未公開モデル Astra、数学の未解決問題 10 題を Lean 4 で機械検証可能な証明として解決

OpenAI は 8 月初旬、内部未公開モデル Astra が数学・理論計算機科学の分野で 10 年以上未解決だった問題を 10 問解いたと発表し、249 ページの論文と全結果の Lean 4 証明ファイルを GitHub で公開した。最大の成果は「非 sofic 群（non-sofic group）の初の明示的構成」であり、1999 年に Mikhail Gromov が soficity を提唱して以来 27 年間未解決だった群論の核心問題に決着をつけた。従来の AI 生成証明に寄せられてきた「独立検証が困難」という批判に対し、Lean 4 の機械チェック可能な証明書を添付することで透明性を確保した点が数学コミュニティから高く評価されている。全 10 解の探索にかかったトークンコストは API レートで概算約 2,000 ドルと公表されており、高度な知的タスクのコストが急速に下がっていることを示す事例ともなった。なお Astra モデル自体は現時点で非公開であり、公開時期は未定。

### 3. Microsoft 8 月 Patch Tuesday：421 件の CVE と 3 件のゼロデイ — Windows SSTP に未認証 RCE

Microsoft は 8 月 11 日の月例セキュリティ更新で 421 件の脆弱性に対処し、うち 62 件を Critical に分類した。アクティブ悪用が確認されているゼロデイ（CVE-2026-68820：Windows WinSock 権限昇格）を含む 3 件が開示ゼロデイとして対応済みとなっている。特に注目されるのは CVE-2026-62889（Windows SSTP の重大 RCE、CVSS 8.1）で、認証不要・ユーザー操作不要でリモートから任意コード実行が可能であり、VPN ゲートウェイとして多用される SSTP サーバーへの影響が懸念されている。また CVE-2026-62792（Windows TCP/IP RCE）も Critical に分類されており、ネットワーク境界への送信パケット一本で攻撃が成立するため、インターネット公開サーバーは即時パッチ適用が推奨される。SAP・VMware・Microsoft 製品の脆弱性は開示から数日以内に悪用が開始される傾向がさらに顕著になっており、パッチ適用の意思決定窓口が急速に縮小していることが業界レポートで指摘されている。

### VS Code 1.135 リリース — AI エージェントセッション引き継ぎとマルチモデル利用追跡が目玉

Visual Studio Code 1.135 が 8 月リリースとして公開され、AI コーディング体験を大きく変える機能が複数追加された。最大の目玉は「他アプリからの Copilot / Claude エージェントセッション継続」機能で、Claude Code などの外部 CLI で開始したエージェントセッションを VS Code 内で引き継いで操作することが可能になった。また「モデルごとのチャット利用量追跡」機能により、複数 AI プロバイダーのコストを IDE 内で一元管理できる。実験的機能として「Rubber Duck（ゴム製アヒル）」セカンドオピニオン機能も搭載されており、コードレビューや設計相談を AI との対話でインタラクティブに進める体験を提供する。

```json
// .vscode/settings.json — 1.135 での新しいエージェントセッション設定例
{
  "github.copilot.chat.agent.continueSessions": true,
  "github.copilot.chat.modelUsageTracking": true,
  "chat.experimental.rubberduck.enabled": true,
  "chat.models.preferred": [
    "claude-opus-5",
    "gpt-5.6",
    "gemini-3.7-flash"
  ]
}
```

この機能追加はコーディング補助の「マルチ AI モデル化」を IDE レベルで正式サポートする方向性を示している。同月に公開された Qwen3.8-Max（2.4T パラメータの大規模オープンウェイトモデル）や匿名モデル OX Alpha（GPT-5.6 をコーディングベンチマークで上回ったと報告）など、オープン系モデルの急速な能力向上と合わせて、コーディングアシスタントのモデル多様化が加速する見通しだ。

**出典**: [Releasebot — VS Code August 2026](https://releasebot.io/updates/microsoft/visual-studio-code) / [LLM Stats — August 2026 AI Updates](https://llm-stats.com/llm-updates) / [AI Weekly — August 28 2026](https://aiweekly.co/ai-news-today)
