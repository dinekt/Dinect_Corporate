## 開発ツール・フレームワーク

- **Claude Code — Fast Mode が Opus 4.7 に更新**: fast mode のデフォルトモデルが Opus 4.6 から 4.7 へ。Background Session 関連フラグが `claude agents` コマンドで利用可能に。MCP 起動の pre-wait がオーバーラップ処理化され最大 2 秒高速化。（出典: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [Releasebot](https://releasebot.io/updates/anthropic/claude-code)）

- **Next.js セキュリティリリース（緊急）**: 13 件の CVE に対処。
  - 対象バージョン: 15.5.18 / 16.2.6
  - 主な脆弱性: RSC での DoS（CVE-2026-23870）、ミドルウェアバイパス、キャッシュポイズニング、XSS、認証バイパス、SSRF
  - 対応: `npm install next@16.2.6` または `npm install next@15.5.18`
  （出典: [Vercel](https://vercel.com/changelog/next-js-may-2026-security-release)）

- **Python ツールチェーン — uv 0.11.15 リリース（5/18）**: OpenAI による Astral 買収後も OSS 継続。Ruff 0.5.4 も同期リリース。（出典: [PyPI](https://pypi.org/project/uv/), [OpenAI](https://openai.com/index/openai-to-acquire-astral/)）

- **Anthropic — Cache Diagnostics パブリックベータ**: API が `cache_miss_reason` を返すようになり、プロンプトキャッシュのプレフィックスが前ターンとどこで乖離したかを特定可能に。（出典: [Releasebot](https://releasebot.io/updates/anthropic)）
