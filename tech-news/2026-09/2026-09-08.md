### 2. Microsoft Patch Tuesday 9月版 — 過去最大規模の966件修正、ALPC と Windows Update Stack の2ゼロデイが積極悪用中

マイクロソフトは9月9日（日本時間）の **Patch Tuesday** で **966〜974 件の脆弱性**を修正した。これは月例パッチとしての過去最大規模で、2026年7月の従来最高664件を大幅に超えた。うち **113件がCritical** と分類され、修正対象はWindows全般・Office・SQL Server・Exchange・SharePoint・Azure・開発者ツールと広範囲に及ぶ。特に注目されるのは積極悪用が確認されている2件のゼロデイだ。**CVE-2026-85880**（Windows ALPC の EoP）は低権限のローカルコード実行から AppContainer を脱出して SYSTEM 権限を奪取できるヒープバッファオーバーフローで、ALPC コンポーネントのゼロデイは2023年4月以来約3年ぶりとなる。**CVE-2026-81963**（Windows Update Stack の EoP）は不適切なリンク解決によって特権昇格を許す欠陥で、Update Stack での初のゼロデイ指定となった。両者はともにローカルアクセスが前提だが、他の初期侵入手法と組み合わせることで完全制御への昇格が容易になるため、24時間以内の適用が推奨されている。同日 SAP も **9月セキュリティパッチデイ** として19件の新セキュリティノート（CVSS 10.0 および 9.8 含む）を公開しており、企業の月次パッチ担当者にとって特にタスクが集中する週となった。

### 3. Python 3.15.0rc2 リリース — 遅延インポート・frozendict 組み込み型・Tachyon プロファイラで10月 GA へ

Python の次期バージョン **Python 3.15.0rc2** が9月1日に公開され、10月1日の正式リリース（GA）に向けた最終候補段階に入った。今サイクルのハイライトは3点だ。①**遅延インポート（PEP 810 / `lazy` キーワード）**: モジュールを実際に使うまでロードを遅らせることで大規模コードベースの起動時間を **最大70%** 短縮できる。②**組み込み `frozendict`**: イミュータブルな辞書型が標準ライブラリに追加され、ハッシュ可能なマッピングをサードパーティライブラリなしに利用できる。③**Tachyon プロファイラ**: 新しい高頻度サンプリング型プロファイリングパッケージが標準搭載され、本番相当の精度でコードのホットスポットを検出できる。JIT コンパイラの性能もアーキテクチャ依存で **8〜13%** の向上が見込まれる。Python 3.15 は LTS 版ではないが、特に CLI ツールや大規模アプリケーションにとって遅延インポートの恩恵は大きく、フレームワーク側での早期対応が期待される。

## 新技術・新リリース

### Python 3.15 の注目機能 — 遅延インポート・frozendict・Tachyon プロファイラの実装例

Python 3.15 では日常の開発フローを変える3つの機能が揃う。特に `lazy` インポートは CLI ツールや大規模 Web アプリの起動レイテンシを劇的に改善し得る。

```python
# Python 3.15: lazy インポート（PEP 810）
# モジュールは実際に使われるまでロードされない
import lazy numpy as np          # numpy はこの時点ではロードされない
import lazy pandas as pd         # 同上

def process_data(path: str):
    # ここで初めて numpy と pandas がロードされる
    df = pd.read_csv(path)
    return np.mean(df["value"].to_numpy())

# 使わないパスで呼ばれなければロードコストがゼロ → 起動が最大70%高速化


# Python 3.15: 組み込み frozendict
# サードパーティ不要でイミュータブル辞書を作成できる
config = frozendict({"host": "localhost", "port": 5432, "db": "prod"})

# ハッシュ可能なのでセットや辞書のキーに使える
cache = {config: "cached_result"}

# 変更しようとすると TypeError
try:
    config["host"] = "remote"  # TypeError: 'frozendict' object does not support item assignment
except TypeError as e:
    print(e)

# frozendict 同士は値が同じなら等値
a = frozendict(x=1, y=2)
b = frozendict({"x": 1, "y": 2})
assert a == b and hash(a) == hash(b)


# Python 3.15: Tachyon プロファイラ
# 高頻度サンプリングで本番相当のホットスポット検出が可能
import tachyon

def slow_function():
    total = 0
    for i in range(10_000_000):
        total += i ** 2
    return total

with tachyon.profile() as prof:
    result = slow_function()

# フレームごとのサンプル数・CPU時間・推定ウォールタイムを表示
prof.print_stats(top_n=10)
# =>
#   Function              Samples   CPU%   Wall(ms)
#   slow_function             843  84.3%    1024.7
#   ...


# JIT 改善の確認（Python 3.15 以降）
import sys
print(sys.version)  # Python 3.15.0rc2 (...)

# JIT は自動的に有効。明示的に確認するには:
# $ python -X jit_debug=1 script.py
```

`lazy` インポートは既存コードとの互換性を保ちながら段階的に導入できるため、大型プロジェクトでのリファクタリングリスクが低い。`frozendict` は型アノテーション側も `Mapping[str, int]` や新たな `frozendict[str, int]` で表現できるようになり、型安全なイミュータブル設定オブジェクトを簡潔に定義できる。GA は10月1日予定。RC2 の段階で大きな破壊的変更はなく、評価環境での検証を今のうちに開始しておくとよい。

### Microsoft Patch Tuesday 9月版 — 積極悪用ゼロデイ2件の即時パッチ適用手順

```powershell
# === Microsoft Patch Tuesday 2026-09 緊急対応チェックリスト ===
# 積極悪用確認: CVE-2026-85880 (Windows ALPC EoP) / CVE-2026-81963 (Windows Update Stack EoP)
# 推奨対応期限: 24時間以内

# ---- Step 1: 未適用パッチの確認 ----
# PowerShell (管理者権限)
Get-WindowsUpdate -MicrosoftUpdate -AcceptAll -IgnoreReboot |
    Where-Object { $_.KB -ne $null } |
    Select-Object KB, Title, Size, MsrcSeverity |
    Format-Table -AutoSize

# ---- Step 2: ゼロデイ2件のKBを個別確認 ----
# CVE-2026-85880 (ALPC EoP) 対応 KB を検索
$kbList = (New-Object -ComObject Microsoft.Update.Session).CreateUpdateSearcher().Search("IsInstalled=0").Updates |
    Where-Object { $_.Title -match "ALPC" -or $_.KBArticleIDs -contains "XXXXXXX" }
$kbList | Select-Object Title, KBArticleIDs

# ---- Step 3: Windows Update の強制実行 ----
# PSWindowsUpdate モジュールを使用（要インストール）
Install-Module PSWindowsUpdate -Force -SkipPublisherCheck
Import-Module PSWindowsUpdate

# Critical・Important を即時適用（再起動を要求する場合は確認してスケジュール）
Install-WindowsUpdate -MicrosoftUpdate -AcceptAll -AutoReboot -Verbose |
    Where-Object { $_.MsrcSeverity -in @("Critical","Important") }

# ---- Step 4: WSUS / Intune 環境での一括展開確認 ----
# Intune の場合: デバイスコンプライアンスポリシーで
#   "最低OS更新状態" の期限を 2026-09-10 00:00 UTC に設定して強制

# ---- Step 5: ゼロデイ悪用の検出クエリ (Microsoft Sentinel / KQL) ----
# ALPC 権限昇格の痕跡を検出
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID in (4688, 4672)     // プロセス作成 & 特権使用
| where SubjectLogonId != "0x3e4"   // NETWORK SERVICE を除外
| where NewProcessName has "alpc"
    or CommandLine has_any ("SeDebugPrivilege", "SeTcbPrivilege")
| project TimeGenerated, Computer, Account, NewProcessName, CommandLine
| order by TimeGenerated desc

# Windows Update Stack の権限昇格検出
SecurityEvent
| where TimeGenerated > ago(7d)
| where EventID == 4673   // 特権サービス呼び出し
| where PrivilegeList has "SeTakeOwnershipPrivilege"
| where ProcessName has "wuauclt" or ProcessName has "usocoreworker"
| project TimeGenerated, Computer, Account, ProcessName, PrivilegeList

# ---- リスクサマリー ----
# CVE-2026-85880: CVSS TBD | ALPC ヒープBO → SYSTEM | 悪用: 積極的に確認済
# CVE-2026-81963: CVSS TBD | Update Stack リンク追跡不備 → SYSTEM | 悪用: 積極的に確認済
# 両者はローカル起点だが、フィッシング等の初期侵入と組み合わせると完全制御が容易
Write-Host "SAP September Patch Day も同日公開 — NetWeaver/Cloud AP の CVSS 10.0 含む" -ForegroundColor Yellow
```

今月の Patch Tuesday は過去最大規模だが、優先すべきは積極悪用が確認されているゼロデイ2件への即時対応だ。両脆弱性はローカル特権昇格であるため単独では利用できないが、メールフィッシングや Web エクスプロイトによる初期侵入と連鎖させることで攻撃者は追加の障壁なく SYSTEM 権限を得られる。特に ALPC の CVE-2026-85880 はアンチウイルスを含む多くのセキュリティソフト自体が ALPC を使用しており、検出が困難なケースがある点に注意が必要だ。SAP 側も同日に CVSS 10.0 の修正を含むパッチを公開しており、ERP 環境を抱える組織はこちらも並行して対応する必要がある。CIS やセキュリティチームは今週中にパッチ展開とSentinelクエリによる事後検証をセットで完結させることが推奨される。
