### Xiaomi 自社設計 CPU が Apple シリコン並みのシングルスレッド性能を達成 — マルチスレッドでは大幅上回る

Hacker News で話題となったベンチマーク結果によると、Xiaomi が開発中の自社設計 CPU がシングルスレッド性能で Apple の最新コアに匹敵し、マルチスレッド性能では大幅に上回るという。中国勢による高性能 SoC 開発が米国の輸出規制をバイパスして独自技術で進展しており、半導体の「自国開発」競争が新たな段階に入った。ARM ライセンスを活用した設計であるとみられるが、詳細はまだ公式発表されていない。

また Hacker News では「Executable Is a SQLite Database（実行ファイルが SQLite データベース）」という技術記事が高評価を集め、SQLite のユビキタスな普及がプログラムのバイナリ構造にまで影響を与えつつある現状が注目を集めた。

さらに「MS Paint および Photos アプリがローカルで生成した画像にも GUID による不可視透かしを埋め込んでいる」ことを示す調査がトレンド入りし、Windows の生成 AI 出力に対するプロベナンス追跡が静かに実装されていることへの懸念の声が上がった。

```python
# ローカル AI サーバー（例: Ollama）をループバックのみにバインドする起動例
# NVIDIA NemoClaw 脆弱性への当面の対策

# 方法1: 環境変数で Ollama をループバックバインドに制限
import subprocess
import os

env = os.environ.copy()
env["OLLAMA_HOST"] = "127.0.0.1:11434"  # デフォルトは 0.0.0.0:11434

proc = subprocess.Popen(["ollama", "serve"], env=env)

# 方法2: systemd サービス設定（/etc/systemd/system/ollama.service.d/override.conf）
override_conf = """
[Service]
Environment="OLLAMA_HOST=127.0.0.1:11434"
"""

# 外部（ブラウザ含む）からのアクセスを iptables でブロック
# iptables -A INPUT -p tcp --dport 11434 ! -s 127.0.0.1 -j DROP
```
