### 1. NGINX Rift（CVE-2026-42945、CVSS 9.2）— 18 年前から潜む ゼロデイが野良 PoC 公開 3 日後に実際の攻撃へ

nginx の HTTP rewrite モジュール（`ngx_http_rewrite_module`）に存在するヒープバッファオーバーフロー脆弱性 **CVE-2026-42945**（CVSS 9.2）が、2026 年 5 月 16 日より野外で活発に悪用されている。脆弱性は 2008 年に導入されたバージョン **0.6.27 以降のすべての nginx ビルド**（nginx Plus R32〜R36 含む）に潜伏しており、約 18 年間未発見のまま放置されていた。攻撃者は無認証で単一の巧妙な HTTP リクエストを送信するだけで nginx ワーカープロセスをクラッシュさせ（DoS）、条件によっては **リモートコード実行（RCE）** が成立する。PoC が 5 月 13 日に公開されるや否や 3 日後に VulnCheck のカナリアシステムが実攻撃を検出した。技術的な根本原因は、PCRE 未名キャプチャ（`$1`, `$2`）と `?` を含む書き換えルールを組み合わせた際に `ngx_escape_uri` が確保済みバッファを超えて書き込む二パスの契約違反だ。修正版は **nginx 1.30.1 / NGINX Plus R37** として提供済みであり、Kubernetes の Ingress NGINX Controller を含む下流パッケージも順次更新されている。

### 2. Astral「ty」v0.0.40 ベータ公開 — Rust 製 Python 型チェッカーが mypy 比最大 60 倍高速化

`ruff` と `uv` を開発した Astral が、**Rust 製の Python 型チェッカー「ty」** のベータ版（v0.0.40）を 2026 年 5 月 27 日にリリースした。mypy・Pyright・Pylance に代わるツールとして設計された ty は、キャッシュなしの全量チェックで **mypy 比 10〜60 倍の速度**を誇る。特にエディタでのインクリメンタル解析では、PyTorch リポジトリの主要ファイル編集後に診断を **4.7ms** で再計算（Pyright の 386ms、Pyrefly の 2.38s と比較して圧倒的に高速）。ファーストクラスの交差型（intersection types）・高度な型絞り込み・到達不能コード解析など、Python 型仕様の最先端機能を実装しており、多くの偽陽性を排除している。Astral は ty を自社プロジェクトで本番利用しており、意欲的なユーザーへの本番採用を公式に推奨し始めた。安定版（Stable）は来年を予定しており、Pydantic や Django などのサードパーティライブラリへのファーストクラスサポートも工程表に載っている。

### TypeScript 7.0 / Project Corsa — Go 再実装により型チェック 10 倍高速化が正式リリース

Microsoft は 2026 年 1 月 15 日に **TypeScript 7.0**（コード名「Project Corsa」）を安定版としてリリースした。コンパイラとランゲージサーバーを TypeScript/JavaScript から **Go** で完全に再実装したことにより、コマンドライン型チェックで約 **10 倍**、エディタのプロジェクトロードで約 **8 倍**の速度向上を達成した。実世界のベンチマークでは VS Code コードベース（150 万行）が 78 秒 → 7.5 秒、Sentry が 133 秒 → 16 秒に短縮されている。新しいバイナリは `tsgo` という名称で提供される。

```bash
# TypeScript 7.0 (tsgo) のインストール
npm install -g typescript@7

# tsgo でのビルド（従来の tsc の代替）
tsgo --version
# TypeScript 7.0.0 (Go native compiler)

# プロジェクトの型チェック（10x 速度向上）
tsgo --noEmit

# ウォッチモードでのインクリメンタルチェック
tsgo --noEmit --watch
```

```typescript
// TypeScript 7.0 では go 製コンパイラでも既存の型定義はそのまま動作
interface User {
  id: number;
  name: string;
  email: string;
}

// satisfies 演算子や const assertion など TS 5.x 以降の機能も引き続きサポート
const config = {
  endpoint: "https://api.example.com",
  timeout: 5000,
} satisfies Record<string, string | number>;
```

メモリ使用量も **3 分の 1** に削減されており、大規模モノレポや CI 環境でのリソース節約効果が大きい。既存の `tsconfig.json` との互換性は維持されているため、多くのプロジェクトでは `npm install -g typescript@7` とバイナリ切り替えのみで移行できる見込みだ。

**出典**: [InfoWorld: TypeScript Native Port](https://www.infoworld.com/article/4100582/microsoft-steers-native-port-of-typescript-to-early-2026-release.html) / [CodeRoasis: TypeScript 7.0 Beta](https://coderoasis.com/typescript-7-0-beta-go-compiler-project-corsa-10x-faster/) / [Alex Cloudstar: Project Corsa Guide](https://www.alexcloudstar.com/blog/typescript-7-project-corsa-go-compiler-2026/)

### CVE-2026-42945 NGINX Rift — 緊急対応チェックリスト

```bash
# --- NGINX Rift (CVE-2026-42945, CVSS 9.2) ---
# 影響バージョン: nginx 0.6.27 〜 1.30.0 すべて
#              NGINX Plus R32 〜 R36
# 修正バージョン: nginx 1.30.1 / NGINX Plus R37 / Ingress NGINX Controller 1.12.3+

# 現在の nginx バージョン確認
nginx -v
# nginx version: nginx/1.30.0 など

# Debian/Ubuntu: アップグレード
sudo apt update && sudo apt install --only-upgrade nginx

# RHEL/CentOS/Amazon Linux
sudo yum update nginx  # または dnf

# Docker Compose 環境での更新例
# docker-compose.yml の image を nginx:1.30.1 以降に変更
docker pull nginx:1.30.1
docker compose up -d

# 暫定緩和: 外部からの rewrite ルール評価を含む location を制限
# nginx.conf で問題のある rewrite パターンを確認
grep -rn 'rewrite\|if\s*(.*)\|set\s' /etc/nginx/conf.d/ /etc/nginx/sites-enabled/
# PCRE 未名キャプチャ ($1, $2) と ? を組み合わせるルールが対象

# Kubernetes: Ingress NGINX Controller のバージョン確認
kubectl get pods -n ingress-nginx -o jsonpath='{.items[*].spec.containers[*].image}'
```

**悪用トリガー条件**: `rewrite`・`if`・`set` ディレクティブで PCRE 未名キャプチャ（`$1`, `$2`）と置換文字列中の `?` を組み合わせる構成。エクスプロイトは認証不要で、単一の HTTP リクエストのみ必要。CISA KEV カタログへの追加状況は随時確認すること。

### Microsoft Exchange Server CVE-2026-42897 — 細工メールで任意の JavaScript 実行

オンプレミス Microsoft Exchange Server に存在する **CVE-2026-42897**（スプーフィング/XSS）は、攻撃者が細工したメールをユーザーに送信するだけで被害者のブラウザコンテキストで任意の JavaScript コードを実行できる脆弱性だ。2026 年 5 月 Patch Tuesday で修正パッチが提供されており、Exchange Server をオンプレミスで運用している組織は即時適用が推奨される。ECP（Exchange Control Panel）経由の認証情報窃取やセッションハイジャックに悪用される恐れがある。

```powershell
# Exchange Server の更新状況確認
Get-Command ExSetup | ForEach-Object { $_.FileVersionInfo }

# Exchange のセキュリティ更新履歴確認（PowerShell）
Get-ExchangeDiagnosticInfo -Server $env:COMPUTERNAME -Process EdgeTransport -Component ResourceThrottling

# Patch Tuesday 2026-05 (KB5059243) 適用確認
Get-HotFix | Where-Object { $_.HotFixID -eq "KB5059243" }
```
