# テックニュース 2026年3月28日

> Claude Code v2.1.86 バグ修正リリース / Google Gemini 3 Deep Think API公開 / OpenAI が Sora 終了を正式発表

## 今日のハイライト

**Claude Code v2.1.86 リリース — セッション安定性・ファイル操作の信頼性向上** -- 3月28日付で v2.1.86 がリリース。API リクエストに `X-Claude-Code-Session-Id` ヘッダーを付与しプロキシ側でのセッション集約が可能になった。長セッションでのスクロールリセット問題が修正され、`--resume` が古いセッション（v2.1.85 以前）で失敗するバグも解消。プロジェクトルート外ファイル（`~/.claude/CLAUDE.md` 等）への Write/Edit/Read が条件付きスキルや rules 設定時に失敗する問題も修正。VS Code 向けにレート制限警告バナー（使用量 % + リセット時刻）が追加された。

**Google Gemini 3 Deep Think — API を研究者・企業向けに開放** -- Gemini 3 Deep Think が Ultra サブスクライバー向けに提供開始され、Gemini API でも select 研究者・企業にアクセス開放。ARC-AGI-2 で 84.6%、IMO 2025 金メダルレベル、Codeforces Elo 3455 を記録。複数仮説の同時探索によるイテレーティブ推論が特徴で、研究論文の論理エラー検出など高度な技術文書処理に強みを発揮。

**OpenAI が Sora を段階的に終了 — 4月26日アプリ、9月24日 API 停止** -- OpenAI が動画生成サービス Sora を正式終了すると発表。2025年9月リリースから7ヶ月未満での廃止。Disney との10億ドル提携計画も破談。理由はコンピュートコストの再配分で、リソースをコーディング・エンタープライズ製品へ集中させる戦略転換を示している。

## カテゴリ別ニュース

### AI / LLM

- **Gemini 3 Deep Think API 開放**: ARC-AGI-2 で 84.6%、HLE で 48.4%（外部ツールなし）。Vertex AI ドキュメントにも `gemini-3-pro` として掲載。技術文書処理・コード審査に実用的な水準
- **OpenAI Sora 終了**: アプリ停止 2026-04-26 / API 停止 2026-09-24。AI 動画生成市場の競合（Runway、Kling 等）が再評価される局面
- **AMI Labs（Yann LeCun 設立）が $1.03B 調達**: ヨーロッパ史上最大のシード資金調達。JEPA アーキテクチャによる世界モデル構築が目的。Bezos・NVIDIA・Samsung・Temasek が出資
- **ロボティクス AI に週次 $1.2B 超流入**: Mind Robotics ($500M)・Rhoda AI ($450M)・Sunday ($165M)・Oxa ($103M) が同週に資金調達

### セキュリティ

- **MCP エンタープライズ認証整備継続**: SSO 統合・監査ログ・ゲートウェイ挙動の標準化が MCP v1.27 ロードマップで進行中
- **AI エージェントの Agent Red-Teaming が研究トレンド化**: 推論モデルの自己蒸留による推論能力劣化・ビデオエージェントの安全性・ベンチマーク設計の信頼性が主要研究テーマ

### 開発ツール・言語

- **Claude Code v2.1.86 主要変更点**:
  - `X-Claude-Code-Session-Id` ヘッダー追加（プロキシでのセッション集約対応）
  - `.jj`・`.sl` を VCS ディレクトリ除外リストに追加（Jujutsu・Sapling 対応）
  - `--resume` が旧セッションで失敗するバグ修正
  - プロジェクトルート外ファイルへの Read/Write/Edit 修正
  - VS Code: レート制限警告バナー追加
- **Amazon + OpenAI: Bedrock 向け Stateful Runtime Environment**: エージェントのメモリ永続化・状態管理インフラを Bedrock 上で提供

### PDF・ドキュメント AI

- **IDP 市場規模の更新値**: 2026年 $14.16B → 2034年 $91.02B（CAGR 26.2%）へ上方修正
- **2026年の IDP トレンド**: アジェンティック AI（文書データで自律判断）・マルチモーダル処理・RPA プラットフォームへのネイティブ統合
- **コスト削減実績**: AI 駆動 IDP 導入企業は文書処理コストを 60〜80% 削減・処理時間を 70〜90% 短縮

### 中小企業 AI 活用・日本市場

- **日本の中小企業 AI 採用率 16%**: 生成 AI 使用率は 23.5%（ドイツ 38.7%、世界最低水準）。スキル不足が最大障壁
- **経産省 RIETI 研究**: クラウド会計データを用いた中小企業の生成 AI 早期採用パターン分析が公開。サービス業が最高採用率（21%）
- **AI-as-a-Service による中小企業 CAGR が最高**: クラウド型・低価格 AI サービスの普及で中小企業セグメントが最も高い成長率を示す見通し
