### Rust for CPython — Python 3.16 ターゲット確定、Guido 承認でビルドシステムが全プラットフォーム対応に

Python 公式ブログが 4 月のアップデートとして、Rust for CPython プロジェクトが Python 3.15 から **Python 3.16**（リリース予定 2027 年 10 月）へターゲットを変更したことを発表した。すべての CPython サポートプラットフォームで CI 上の Rust ビルドが成功し、make-or-break の技術課題をクリア。Guido van Rossum も PEP に明示的な支持を表明した。初期実装では Rust はオプションの拡張モジュールにのみ使用され、標準 CPython のビルド・実行に Rust コンパイラは不要。`cpython-sys` を橋渡しに `bindgen` が C ヘッダーから Rust バインディングを自動生成し、`Cargo.lock` のベンダリングで依存ライブラリを CPython ソースに同梱する設計。PEP ドラフトは 6〜7 月を予定しており、メモリ安全性の向上と段階的な性能改善が Python ランタイムにもたらされると期待される。

```python
# Python 3.16 以降、CPython の一部モジュールが Rust 実装に切り替わる予定
# ユーザーコードに変更は不要 — インターフェースは完全に互換
import hashlib  # 例: 将来 Rust バックエンドで実装される候補モジュールのひとつ

result = hashlib.sha256(b"hello world").hexdigest()
print(result)  # b94d27b9934d3e08a52e52d7da7dabfac484efe04294e576db3701c6ea90d7ec
# Rust バックエンドでも同じ結果・同じ API — 透過的な置き換えが設計の核心
```

## セキュリティ

### nginx-ui CVE-2026-33032（CVSS 9.8）— MCP エンドポイント認証バイパスで Nginx サーバーを完全乗っ取り

Web ベースの Nginx 設定管理ツール「nginx-ui」に認証バイパス脆弱性 CVE-2026-33032（CVSS 9.8）が発見され、約 2,600 件の公開インスタンスに対する実環境での悪用が確認されている。`/mcp_message` エンドポイントが IP ホワイトリストのみで保護されており、デフォルト設定では「全許可」になるため未認証の攻撃者が任意の nginx 設定ファイルを作成・変更・削除できる。攻撃が成功した場合、nginx の再起動・設定の自動リロード・管理者認証情報の傍受が可能になる。バージョン 2.3.4（2026 年 3 月 15 日リリース）で修正済みだが、最新の 2.3.6 への更新が推奨されている。緊急回避策は `middleware.AuthRequired()` を `/mcp_message` に追加するか、IP ホワイトリストのデフォルトを「全拒否」に変更すること。

**出典**: [The Hacker News — Actively Exploited nginx-ui Flaw CVE-2026-33032](https://thehackernews.com/2026/04/critical-nginx-ui-vulnerability-cve.html) / [Rapid7 — CVE-2026-33032 Analysis](https://www.rapid7.com/blog/post/etr-cve-2026-33032-nginx-ui-missing-mcp-authentication/)

### CISA KEV に SimpleHelp・Samsung MagicINFO・D-Link の新規 4 件を追加

CISA が Known Exploited Vulnerabilities（KEV）カタログに 4 件を新規追加した。SimpleHelp の認可不備（CVE-2024-57726、CVSS 9.9）は低権限テクニシャンが過剰な権限を持つ API キーを作成してサーバー管理者権限に昇格できる問題。同じく SimpleHelp のパストラバーサル（CVE-2024-57728、CVSS 7.2）は細工した ZIP ファイルのアップロードによるファイルシステム任意書き込みと任意コード実行を可能にする。Samsung MagicINFO 9 Server および D-Link DIR-823X シリーズルーターの脆弱性も追加され、連邦機関には期限内の修正が義務付けられた。

**出典**: [The Hacker News — CISA Adds 8 Exploited Flaws to KEV](https://thehackernews.com/2026/04/cisa-adds-8-exploited-flaws-to-kev-sets.html)
