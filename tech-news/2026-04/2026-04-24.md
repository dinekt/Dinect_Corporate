### TypeScript が GitHub contributor 数で初の #1 言語に — Python・JavaScript を抜いて首位

GitHub Octoverse 2026 レポートが TypeScript の躍進を確認した。contributor 数ベースで TypeScript が史上初めて首位に立ち、Python と JavaScript の両方を上回った。前年比 +66% の約 260 万人が TypeScript プロジェクトに貢献している。背景には AI コーディングツールの普及による「型安全なコード生成」への需要増がある。AI コーディングアシスタントは TypeScript の型情報を活用して精度の高いサジェストを提供しやすく、既存の JavaScript コードベースを TypeScript に移行するプロジェクトも急増している。Rust は「最も尊敬されるプログラミング言語」1 位（72%）を維持した。

```typescript
// TypeScript 5.8 — satisfies 演算子による型安全なエージェント設定パターン
type AgentConfig = {
  model: "gpt-5.5" | "claude-sonnet-4" | "deepseek-v4-pro";
  tools: string[];
  maxTokens?: number;
};

const config = {
  model: "deepseek-v4-pro",
  tools: ["code_exec", "web_search"],
  maxTokens: 128_000,
} satisfies AgentConfig;
// satisfies: model は "deepseek-v4-pro" リテラル型に推論されたまま AgentConfig への適合を検証
```

## セキュリティ

### Microsoft April 2026 Patch Tuesday — 160 件超を一括修正、ゼロデイ 2 件含む

Microsoft が 4 月定例パッチ（Patch Tuesday）を公開した。修正件数は 160 件を超え、そのうち 2 件は実環境での悪用が確認されたゼロデイ脆弱性。CrowdStrike の分析によると特権昇格（EoP）とリモートコード実行（RCE）カテゴリに集中している。Windows・Exchange・Azure 関連コンポーネントを広く対象としており、企業環境での早急なパッチ適用が推奨される。

**出典**: [CrowdStrike — April 2026 Patch Tuesday Analysis](https://www.crowdstrike.com/en-us/blog/patch-tuesday-analysis-april-2026/) / [LinkedIn — Microsoft April 2026 Patch Tuesday Fixes 160+ Vulnerabilities](https://www.linkedin.com/pulse/microsoft-april-2026-patch-tuesday-fixes-160-vulnerabilities-kwfwe)

### SGLang CVE-2026-5760（CVSS 9.8）— 悪意ある GGUF モデルファイルで RCE が可能に

LLM 推論フレームワーク「SGLang」に重大な脆弱性 CVE-2026-5760（CVSS 9.8）が発見された。攻撃者が細工した GGUF モデルファイルを読み込ませることでサーバー上でのリモートコード実行が可能になる。GGUF 形式でモデルをデプロイする MLOps 環境・API サーバーが対象となる。モデルファイルの配布・ダウンロードパイプラインに署名検証・ハッシュチェックが実装されていない場合は特に危険。LMDeploy（オープンソース LLM 圧縮・デプロイツール）にも別途 SSRF 脆弱性 CVE-2026-33626（CVSS 7.5）が発見されており、実環境での悪用が確認済みとなっている。AI インフラのサプライチェーンセキュリティが改めて問われる事例となった。

**出典**: [The Hacker News — SGLang CVE-2026-5760](https://thehackernews.com/2026/04/sglang-cve-2026-5760-cvss-98-enables.html)

### CISA KEV に 8 件を緊急追加 — Quest KACE CVSS 10.0・Cisco SD-WAN も対象

米 CISA が「Known Exploited Vulnerabilities（KEV）」カタログに 8 件を新規追加し、連邦機関に 4〜5 月中の修正を義務付けた。最も深刻なのは Quest KACE SMA の認証バイパス脆弱性（CVE-2025-32975、CVSS 10.0）で、未認証の攻撃者が正規ユーザーになりすまして任意の操作が可能になる。Cisco Catalyst SD-WAN Manager には特権 API の誤使用（CVE-2026-20122）が含まれ、vmanage 権限での任意ファイル上書きが可能。SimpleHelp のパストラバーサル脆弱性（任意コード実行）も同時追加された。

**出典**: [The Hacker News — CISA Adds 8 Exploited Flaws to KEV](https://thehackernews.com/2026/04/cisa-adds-8-exploited-flaws-to-kev-sets.html) / [The Cyber Express — CISA KEV Catalog Vulnerabilities](https://thecyberexpress.com/cisa-kev-catalog-vulnerabilities/)
