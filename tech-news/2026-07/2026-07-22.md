## セキュリティ

### CVE-2026-50522: Microsoft SharePoint RCE——マシンキー窃取で「パッチ後も侵害継続」のリスク

7月14日の Microsoft セキュリティ更新で修正された **CVE-2026-50522**（SharePoint の信頼されていないデータのデシリアライゼーション欠陥、CVSS 9.8）が、7月20日に PoC が公開されてから数時間以内に野外で悪用されていることを WatchTowr のハニーポットネットワークが確認した。攻撃者は単一リクエストで **SharePoint のマシンキーを奪取**し、そのキーを使って正規の認証トークンを偽造することで SharePoint サイト・文書へ任意ユーザーとしてアクセスできる。問題はパッチを当てても**奪取済みのマシンキーは有効のまま**である点で、セキュリティ専門家は「パッチ適用後に必ずマシンキーとその他のクレデンシャルをローテーションすること」を強調している。SharePoint Enterprise Server 2016、SharePoint Server 2019、SharePoint Server Subscription Edition が対象。

```text
=== CVE-2026-50522 SharePoint 緊急対応チェックリスト ===

[影響対象]
  SharePoint Enterprise Server 2016
  SharePoint Server 2019
  SharePoint Server Subscription Edition

[攻撃手口]
  単一HTTPリクエスト → デシリアライゼーション脆弱性を突く
  → SharePoint マシンキーを窃取
  → 有効な認証トークンを偽造してユーザー権限で侵害継続

[対応手順]
  1. Microsoft July 2026 セキュリティ更新をすべての SharePoint ファームメンバーに適用
     (ファーム内で適用にバラつきがあると横展開リスクあり)
  2. マシンキーのローテーション（必須！パッチだけでは不完全）
     管理センター → セキュリティ → マシンキー管理
  3. アクセスログで /layouts/ や /_vti_bin/ への異常リクエストを確認
  4. 認証トークン発行ログを精査し不審な偽造トークンの痕跡を調査

[野外悪用状況]
  2026-07-14: Microsoft セキュリティ更新でパッチ公開
  2026-07-20: PoC 公開 → 数時間以内に WatchTowr ハニーポットが悪用を検出
  2026-07-22: 現在も継続して積極的に悪用中
```

また今週の脅威状況を俯瞰すると、**CrowdStrike Global Threat Report** は「全侵害の約79%がマルウェアを使わない」と指摘している。クレデンシャル窃取・DLL サイドロード・Living-off-the-Land（正規ツール悪用）が主流となっており、エンドポイントのマルウェア検知に偏った防御では対応が困難な状況が続いている。さらに **Estée Lauder** が Oracle E-Business Suite の脆弱性を悪用された情報流出により従業員へ通知を行ったことも報じられた。
