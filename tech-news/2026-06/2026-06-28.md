### 1. OpenAI、GPT-5.6（Sol / Terra / Luna）を発表するも米政府要請で「信頼できるパートナー」約20社限定公開 — AIフロンティアモデルの市場アクセス制限が常態化

OpenAIは6月26日、次世代モデル群**GPT-5.6 Sol・Terra・Luna**を発表した。Solはフラッグシップで特にコーディングと生物学分野での性能向上が目立ち、Terraは日常用途向けのバランス型、Lunaは高速・低コストのオプションと位置付けられている。しかし米国政府の要請を受け、OpenAIは**政府が個別に承認した約20の「信頼できるパートナー」企業のみ**にGPT-5.6 Solへのアクセスを限定してのプレビュー公開となった。OpenAIは「幅広いアクセスを信じる」としつつ、リリース前に米当局とモデル能力を共有し、将来のリリースに向けた反復可能な審査プロセスを構築中であることを明かした。これはAnthropicがClaude Fable 5を米輸出規制指令で一時停止した事例（6月12日）に続くもので、フロンティアAIモデルの公開が国家安全保障審査を経るプロセスが事実上の標準となりつつある流れを示している。Twitterなど一部では「AIの武器化懸念への過剰反応」との批判も出ているが、GPT-5.6 Sol・Terra・Lunaは数週間以内に一般提供予定とされている。

### 2. 超党派「大米国AI法（Great American AI Act）」269ページ草案が公表 — 連邦統一規制・州法3年間停止・$500M以上の企業に義務、EU AI Act完全施行まで35日

6月4日、米下院議員のJay Obernolte（共和党・カリフォルニア州）とLori Trahan（民主党・マサチューセッツ州）が超党派で**「大米国AI法（Great American Artificial Intelligence Act of 2026）」の269ページ討議草案**を公開した。草案は「フロンティアAIガバナンス」「労働力」「サイバーセキュリティ」「研究開発・国際協力」の4章構成で、年間収益5億ドル以上かつフロンティアモデルを学習させた企業を**「大規模フロンティア開発者」**と定義し、安全テスト・透明性報告などの法的義務を課す。最も議論を呼ぶのが**州AI法への3年間プリエンプション条項**で、AIモデル開発を「特に規制する」州法が連邦法施行後3年間凍結される内容だ。Colorado AI Act（有効日が6月30日に延期済みかつ執行差止め継続中）やカリフォルニアのSB 53など多数の州法に影響する。EU AI Act完全施行（8月2日）まで残り35日となる中、米国がようやく連邦統一フレームワークの具体論に入った形であり、AI規制の「標準覇権」を巡る米・EU・中の三極争いが立法レベルでも本格化している。

### 3. Microsoft 2026年6月Patch Tuesday、史上最多208 CVEを修正 — Windows Kernel RCE（CVE-2026-45657 CVSS 9.8）とHTTP.sys RCE（CVE-2026-47291 CVSS 9.8）が最優先対応

マイクロソフトが6月のセキュリティ更新プログラム（Patch Tuesday）で**208件のCVE**を修正した。Chromiumなどサードパーティバグを含めると**合計571 CVE・うち38件がCritical**という過去最多規模となった。最注目の脆弱性は2件。**CVE-2026-45657**（Windows Kernel RCE・CVSS 9.8）はカーネルのTCP/IP処理におけるuse-after-freeで、認証なし・ユーザー操作不要でSYSTEM権限によるリモートコード実行が可能であり、Windows 11 23H2/24H2/25H2/26H1およびWindows Server 2022/2025が対象だ。もう1件の**CVE-2026-47291**（HTTP.sys RCE・CVSS 9.8）はHTTP.sys カーネルモードドライバの整数オーバーフローで、IIS・Windows Remote Managementを含む多くのWindowsサービスに影響する。ただし`MaxRequestBytes`レジストリ値をデフォルトのまま使用するシステムは影響を受けない。今月のPatch Tuesdayは3件の公開済みゼロデイも含んでおり、CrowdStrikeは「ITチームの緊急スクランブル」と評している。Exploitation category別では権限昇格（65件・32%）、RCE（55件・27%）、情報開示（29件・13%）の順となった。

```rust
use std::mem::MaybeUninit;

fn read_zero_padded<T: Copy>(bytes: &[u8]) -> Option<T> {
    if bytes.len() < std::mem::size_of::<T>() {
        return None;
    }
    let mut out = MaybeUninit::<T>::zeroed();
    // Safety: T: Copy なので未初期化領域への書き込みが安全
    unsafe {
        std::ptr::copy_nonoverlapping(
            bytes.as_ptr(),
            out.as_mut_ptr() as *mut u8,
            std::mem::size_of::<T>(),
        );
        Some(out.assume_init())
    }
}
```

### CVE-2026-45657 / CVE-2026-47291 即時対応ガイド — Windows Kernel & HTTP.sys の認証不要RCE（CVSS 9.8）

```powershell
# === 2026-06-28 Windows 緊急対応チェックリスト ===

# ---- [1] CVE-2026-45657: Windows Kernel TCP/IP RCE (CVSS 9.8) ----
# 影響: Windows 11 23H2/24H2/25H2/26H1 (x64/ARM64), Server 2022, Server 2025
# 攻撃: use-after-free / ネットワーク経由・認証不要・ユーザー操作不要で SYSTEM 権限 RCE
# 公開 PoC: なし（2026-06-28 時点）、ゼロデイではないが早期パッチ適用を推奨

# Windows Update の状態を確認（PowerShell）
Get-WindowsUpdate -IsInstalled | Where-Object KB -match "KB5060"

# WSUSまたはWindows Update経由でKB強制適用
# Install-WindowsUpdate -KBArticleID "KB5060XXX" -AcceptAll

# ---- [2] CVE-2026-47291: HTTP.sys Integer Overflow RCE (CVSS 9.8) ----
# 影響: IIS, Windows Remote Management, HTTP.sys を使用する全 Windows サービス
# 注意: デフォルト MaxRequestBytes 設定のシステムは影響なし（設定確認が必須）

# MaxRequestBytes レジストリ値を確認
$regPath = "HKLM:\SYSTEM\CurrentControlSet\Services\HTTP\Parameters"
$maxReq = (Get-ItemProperty -Path $regPath -Name "MaxRequestBytes" -ErrorAction SilentlyContinue).MaxRequestBytes
if ($null -eq $maxReq) {
    Write-Host "[OK] MaxRequestBytes は未設定（デフォルト値） — CVE-2026-47291 への直接影響なし"
} else {
    Write-Host "[要確認] MaxRequestBytes = $maxReq — パッチ適用を優先"
}

# IIS の HTTP.sys バージョン確認
Get-Item "C:\Windows\System32\drivers\http.sys" | Select-Object VersionInfo

# ---- [3] 今月の Patch Tuesday 優先度サマリー ----
Write-Host "=== 2026年6月 Patch Tuesday 優先対応 ==="
Write-Host "CVE-2026-45657 : Windows Kernel RCE CVSS 9.8 — 認証不要・SYSTEM権限"
Write-Host "CVE-2026-47291 : HTTP.sys RCE CVSS 9.8 — MaxRequestBytes 非デフォルト環境"
Write-Host "ゼロデイ 3件含む — 合計 208 CVE (Chromium含む 571 CVE)"
Write-Host "月例更新プログラムの早急な適用を推奨"
```

今月のPatch TuesdayはCVE総数208件（サードパーティ含む571件）と過去最多規模となった。とりわけCVE-2026-45657とCVE-2026-47291はともにCVSS 9.8の認証不要RCEであり、インターネット公開サーバーはもちろん内部環境でも最優先でパッチを適用すべきだ。CVE-2026-47291についてはMaxRequestBytesのデフォルト設定維持が緩和条件となるが、IISやWinRMを非標準設定で運用しているケースでは脆弱である。3件のゼロデイが含まれることも踏まえ、CIS Controlsでいう「パッチ管理」の72時間以内適用ポリシーを実行することを強く推奨する。
