# テックニュース 2026年3月27日

> AnthropicがClaude Mythosモデルをリーク誤公開、サイバーセキュリティリスクの懸念が浮上。Claude Code v2.1.85リリース、MCP Rust/Ruby/C# SDKも更新。

## 今日のハイライト

**Anthropic「Claude Mythos」リーク — 次世代モデルの存在が誤公開で露呈** -- CMSの設定ミスにより、約3,000件の未公開アセットが一時公開状態になり、社内名称「Claude Mythos」の詳細が流出。Anthropicは「現在最も高性能なモデル」と説明し、"Capybara"という新ティアの存在も確認された。コーディング・学術推論・サイバーセキュリティの各ベンチマークでOpus 4.6を大幅に上回るとされるが、ソフトウェア脆弱性の発見・悪用を加速する懸念も社内文書で指摘されている。

**Claude Code v2.1.85 リリース — MCP強化・条件付きHookと安定性改善** -- MCP OAuth認証がRFC 9728 Protected Resource Metadata発見標準に準拠。複数MCPサーバーを一つのヘルパースクリプトで管理できる環境変数（`CLAUDE_CODE_MCP_SERVER_NAME` / `CLAUDE_CODE_MCP_SERVER_URL`）が追加。`--resume` 失敗バグ、プロジェクトルート外のファイル操作失敗、Windows設定ファイルの不要書き込み、長セッションでのメモリクラッシュが修正された。

**IDP市場 2026年 $14.16B → 2034年 $91.02B（CAGR 26.2%）— エージェントAI統合が主トレンド** -- AI搭載IDPは手作業比でコスト60〜80%削減・処理時間70〜90%短縮を実現。2026年内に70%の組織が何らかのIDPを導入する見通し。最大トレンドは「反応型→予測型文書自動化」へのシフトと、RPA・ワークフロープラットフォームへのネイティブ統合。

## カテゴリ別ニュース

### AI / LLM

- **Claude Mythosリーク（2026-03-26〜27）**: AnthropicのCMSの設定ミスにより社内開発中の「Claude Mythos」の詳細が露出。Opus 4.6を大幅上回るコーディング・推論性能、新ティア"Capybara"の存在が確認。同時にサイバーセキュリティへの悪用リスクが社内文書で言及されており、規制当局の注目が集まる見込み
- **Gemini 3.1 Flash Liveがデベロッパープレビュー中**: 実世界エージェントアプリケーションが30日以内に登場する見込み
- **Qwen 3.5 Small（3月1日リリース）**: Alibaba製 0.8B・2B・4B・9B の4モデル、テキスト・画像・動画のネイティブマルチモーダル対応。エッジ用途での検討価値あり
- **日本政府 FY2026開始の1兆円国産AI支援スキーム継続**: 公的機関AI利用率25%→80%目標。中小企業AI採用率は16%にとどまりスキル不足が最大障壁

### セキュリティ

- **Cisco DefenseClaw（オープンソース）リリース**: AIエージェントのスキルスキャン・サンドボックス実行フレームワーク。Zero Trust Access for AI agents と無料のAI Defense Explorer Editionも提供開始
- **PyPI供給チェーン攻撃（2026-03-27）**: telnyx パッケージ v4.87.1 / v4.87.2 に.WAVファイル内に認証情報ハーベスト機能が埋め込まれた。`pip install telnyx` 使用者は即時バージョン確認を推奨
- **CISA KEV更新（2026-03-27）**: CVE-2025-53521 F5 BIG-IP リモートコード実行脆弱性が悪用確認リストに追加

### 開発ツール・言語

- **Claude Code v2.1.85（2026-03-27）主な変更点**:
  - MCP OAuth RFC 9728対応 / step-upアクセス昇格の403レスポンス修正
  - `CLAUDE_CODE_MCP_SERVER_NAME` / `CLAUDE_CODE_MCP_SERVER_URL` 環境変数追加
  - ステータスラインに `rate_limits` フィールド追加（5時間・7日間の使用率と`resets_at`）
  - `--bare` モードのMCPツール欠落バグ修正
  - Readツールのトークン消費量を最適化
- **MCP SDK更新（2026-03-27）**: Rust SDK・Ruby SDK・C# SDKが同日更新
- **Google Colab MCP Server**: AIエージェントからColabノートブックを直接操作可能

### PDF / ドキュメントAI

- **IDP市場規模更新**: 2026年$14.16B→2034年$91.02B（CAGR 26.2%）
- **予測型文書自動化**: 過去データから次に来る文書を予測・先回り処理するアーキテクチャへ移行中
- **AWS GenAI IDPアクセラレータ v0.5.0**: Amazon Bedrock Data Automation（標準ケース）と Bedrock Pipeline mode（複雑文書）をランタイムで切り替え可能
