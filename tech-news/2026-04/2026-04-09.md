# テックニュースデイリー 2026-04-09

## 本日のニュース TOP 3

### 1. Meta、Muse Spark をリリース — Alexandr Wang 率いる Meta Superintelligence Labs の第一弾モデル
MetaがAIモデル「Muse Spark」を4月8日に発表・公開。Alexandr Wang氏を1,430億ドルで招き設立した Meta Superintelligence Labs が AI スタックを一から再設計した成果で、Llama 4 の後継に位置づけられる。テキスト・音声・画像をネイティブ入力できるマルチモーダル推論モデルで、ビジュアル思考連鎖・ツール使用・マルチエージェントオーケストレーションに対応する。現状はコーディング能力で OpenAI・Anthropic の最新モデルに差があることを Meta 自身が認めており、今後「Contemplating モード」（複雑な問題向けの深い思考モード）の追加を予定。Muse Spark は meta.ai とMetaアプリ経由で無料公開（米国限定）、将来的なオープンソース化も検討中。

**開発者への影響**:
- Meta AI エコシステムを活用した製品開発者は、Llama 4 から Muse Spark API への移行タイムラインを注視すること
- マルチモーダル・マルチエージェント対応が主要モデルで標準化。モデル選定基準に「ツール使用精度」「エージェント連携品質」を加えるタイミングに来ている

### 2. Anthropic、Claude Mythos Preview + Project Glasswing 発表 — AI 主導の自律的脆弱性発見が現実に
Anthropic が Project Glasswing と未公開の最上位モデル「Claude Mythos Preview」を4月7日に発表。Amazon、Apple、Cisco、CrowdStrike、Google、Microsoft、Nvidia など大手パートナー企業に限定して防御的サイバーセキュリティ用途に提供する。Claude Mythos Preview は主要OS・ブラウザ・重要インフラソフトウェアの数千件のゼロデイ脆弱性を自律的に発見・実証済みで、17年間見落とされてきた FreeBSD の NFS リモートコード実行（未認証で root 取得可能）も自律的に特定した。Anthropic は $100M のモデル使用クレジットを Glasswing に投じる一方、一般公開は行わず、将来的な安全なスケール展開を目標としている。

**開発者への影響**:
- AI が自律的にゼロデイを発見する時代が到来。オープンソースライブラリ・自社プロダクトのセキュリティレビューサイクルの短縮が急務になってきた
- Claude Mythos の攻撃能力が明らかになったことで、「攻撃的 AI の濫用リスク」をめぐる議論が活発化。AI 利用ポリシーの動向を追うことが重要

### 3. 米国 MATCH Act 提案 — ASML 株急落、対中半導体製造装置規制がさらに強化へ
米議会で MATCH Act が提案され、中国向け半導体製造装置の輸出規制のさらなる強化の可能性が浮上。オランダの ASML はこの報道を受けて株価が急落し、影響対象となり得る売上が2026年全体売上のローティーンズ % 相当と試算された。台湾・韓国の先端半導体メーカーへの間接的影響も懸念されており、AI 向け HBM・先端ロジック半導体のサプライチェーン安定性への波及が注目されている。KubeCon Europe や RSAC 2026 でも半導体地政学と AI インフラ安全保障が主要なテーマとして議論された。

**開発者への影響**:
- AI 学習・推論インフラのハードウェア調達計画に不確実性が増している。GPU/TPU の将来的な供給制約を念頭に置いたインフラ設計が求められる

## 新技術・新リリース

### Rust for CPython — ターゲットを Python 3.16 に移行決定
CPython への Rust 導入プロジェクトが Python 3.15 から **Python 3.16** をターゲットに変更すると発表（2026年4月アップデート）。現在はフォーク上の CI で全テスト対象プラットフォームにて Rust 混在ビルドが成功している。Rust は特定の内部コンポーネント（メモリ安全性が重要な部分）に限定して段階的に導入される予定で、CPython の安全性・保守性の向上を目指す。

```toml
# CPython Rust コンポーネント（概念的な Cargo.toml 例）
[package]
name = "cpython-core-rs"
version = "0.1.0"
edition = "2021"

[lib]
crate-type = ["staticlib"]

[dependencies]
# Python C API バインディング
pyo3 = { version = "0.23", features = ["extension-module"] }
```

### Mistral Large 3 — 構造化出力・ファンクションコールを大幅改善、EU データ残留サポート
Mistral AI が Mistral Large 3 をリリース。構造化出力生成の精度とファンクションコールの信頼性を大幅に改善し、La Plateforme 経由での EU 域内データ残留を正式サポート。EU AI Act が2026年3月に完全施行されたタイミングと合わせ、GDPR 準拠 AI API としての差別化を強化している。

### MCP（Model Context Protocol）Linux Foundation 傘下へ — オープンガバナンスに移行
Anthropic 主導で策定されてきた Model Context Protocol が Linux Foundation のオープンガバナンスに移行。2026年3月時点で9,700万インストールに達し、主要 AI プロバイダー全社が MCP 互換ツールを提供する事実上のエージェント構築標準インフラとなっている。Rust（Rolldown/Biome/Turbopack）に続き、AI エコシステムにおける「オープン標準の中立的管理」の流れが加速している。

## セキュリティ

### CVE-2026-35616: Fortinet FortiClient EMS — CVSS 9.1、CISA KEV に追加済み
FortiClient EMS バージョン 7.4.5〜7.4.6 に影響する不適切なアクセス制御の脆弱性。未認証での API 認証バイパスから権限昇格が可能で、3月31日から積極的な悪用が確認されている。CISA の Known Exploited Vulnerabilities (KEV) カタログに追加済み。対象バージョンを利用している組織は緊急パッチ適用を推奨。

### CVE-2026-20093: Cisco IMC — CVSS 9.8、未認証リモート認証バイパス
Cisco Integrated Management Controller（IMC）に重大な認証バイパスの脆弱性。未認証のリモート攻撃者が管理者権限を取得できる。Cisco UCS C-Series / S-Series / E-Series サーバーが対象で、即時アップデートを推奨。

### CVE-2025-59528: Flowise CVSS 10.0 — AI エージェントビルダーへの RCE、1.5万インスタンスが未パッチ
LLM ワークフロー構築ツール Flowise にコードインジェクション脆弱性（CVSS 10.0）。`CustomMCP` ノードがユーザー入力をサニタイズなしで実行し、Node.js の `child_process` や `fs` モジュールへの直接アクセスが可能。Flowise 3.0.5 以前が対象（3.0.6 でパッチ済み）。単一 IP からの積極的な悪用が観測されており、インターネット公開インスタンスは即時アップデートが必要。
