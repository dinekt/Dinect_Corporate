## ニュース一覧

### 1. Trivyサプライチェーン攻撃（第2波）-- 76バージョンタグ乗っ取りでCIシークレット窃取
**カテゴリ**: セキュリティ / DevOps
**影響度**: ★★★★★

2026年3月19日、コンテナセキュリティスキャナ「Trivy」の公式GitHub Actionsリポジトリが再侵害。2月末からの継続的攻撃キャンペーンの第2波。

**攻撃の詳細**:
- `aquasecurity/trivy-action` の76/77バージョンタグを強制上書き（force push）
- `aquasecurity/setup-trivy` の全7タグを悪意あるコミットに置換
- 悪意ある `v0.69.4` リリースも公開
- 攻撃者グループ「TeamPCP」によるクラウドネイティブ特化型ステルス

**マルウェアの動作**:
- ランナープロセスメモリをダンプし、シークレットを抽出
- SSHキーを収集
- AWS・GCP・Azure認証情報をexfiltrate
- Kubernetesサービスアカウントトークンを窃取

**根本原因**: 2月の初期開示後に認証情報ローテーションが非アトミックに行われ、一部のトークンが残存。

**対処**: `aquasecurity/trivy-action` を利用しているCI/CDパイプラインは全シークレットの即時ローテーションが必要。

> 出典: The Hacker News / Wiz Blog / GitHub Advisory / CrowdStrike

### 2. Flash-Moe -- MacBook Pro 48GBで397Bパラメータモデルをローカル推論
**カテゴリ**: AI / エッジ推論
**影響度**: ★★★★★

Qwen3.5-397B-A17B（MoEモデル・総パラメータ397B）をApple Silicon MacBook Pro（48GB RAM）でローカル実行する `flash-moe` が公開された。

**技術的仕組み**:
- Apple 2023年論文「LLM in a Flash」にインスパイアされたSSDストリーミング推論
- MoEアーキテクチャの特性：各トークンで全重みではなくエキスパートのサブセットのみを使用
- エキスパート重みを2bit量子化（209GB）、埋め込みテーブルとルーティング行列は原精度（5.5GB常駐）
- Metal Shaderを手書きしたC/Objective-C実装

**性能**:
- 推論速度: **4.4+ トークン/秒**（実用品質の出力・ツールコール対応）
- RAMは48GBのみ、209GBモデルをSSDからストリーミング

**開発プロセス**:
- Claude CodeにApple論文を読ませ、Andrej Karpathyの「autoresearch」パターンで90回の実験を自動化
- Claude CodeがMLX Objective-CとMetalコードを自律生成

> 出典: GitHub danveloper/flash-moe / Simon Willison / Glen Rhodes

### 3. Cloudflareがarchive.todayを「C&C/ボットネット」と判定 -- DNSブロック発生
**カテゴリ**: セキュリティ / インターネット
**影響度**: ★★★★☆

Cloudflareのセキュリティ強化DNS「1.1.1.2」がarchive.todayをコマンド&コントロール（C&C）インフラとして分類し、名前解決をブロック。Hacker Newsで3月22日に大きく話題に。

**影響範囲**:
- 1.1.1.2（Cloudflareのマルウェアブロックモード）経由でarchive.todayにアクセス不能
- ブラウザ・アプリ・自動化ツール等、Cloudflare DNSに依存するあらゆる環境が影響
- 一時的対処: パブリックDNS（8.8.8.8等）への切り替え

**背景**:
- CloudflareとArchive.todayの間にはEDNSクライアントサブネット問題やプライバシー方針の相違から長年の摩擦
- Internet Archiveへのメディア遮断（3/21報道）と時期が重なり「Webアーカイブへの圧力」として注目された

> 出典: Cloudflare Radar / Hacker News / alltoc.com

### 5. JavaScriptバンドルサイズ肥大化の3つの柱 -- コミュニティが「大掃除」を推進
**カテゴリ**: プログラミング / Web
**影響度**: ★★★☆☆

npm依存ツリーの肥大化問題を分析した技術記事がHacker Newsでトップに。

**肥大化の3要因**:
1. **時代遅れのPonyfill**: ブラウザ標準に取り込まれた機能のPolyfill/Ponyfillがいつまでも残る
2. **過大なユーティリティパッケージ**: 単純な関数に6つの深い依存があるケース
3. **モジュール分割の粒度が細かすぎる依存**: 小さすぎる単位での依存が積み重なる

**対策**:
- `module-replacements` プロジェクト: ネイティブ実装やより軽量な代替で置き換え可能なパッケージの一覧を提供
- コミュニティ主導の「クリーンアップ」運動が加速

> 出典: 43081j.com / Hacker News
