### 1. OpenAI × Broadcom が推論特化ASICチップ「Jalapeño」を発表 — NvidiaのBlackwellと互角・コスト50%削減を標榜

OpenAIとBroadcomは6月24〜25日にかけて、共同設計したLLM推論専用ASICチップ**「Jalapeño」（ハラペーニョ）**を正式に発表した（CNBC、OpenAI公式、Fortune）。開発期間はわずか**9ヶ月**であり、Broadcom CEO Hock Tanは「NvidiaのBlackwellチップやGoogle TPUと同等の速度・効率性を持ち、一般的なAI用GPUと比較して約**50%のコスト削減**を実現する」と述べた。このチップはGPUと異なり特定タスク向けのASICであり柔軟性ではGPUに劣るものの、LLM推論に最適化された構造により高いコスト効率を発揮する。初期展開は**2026年末**を目標としており、両社は「マルチ世代計算プラットフォーム」として複数世代にわたる協業を予定している。OpenAIが独自シリコンへと舵を切ったことは、AI推論コストの構造的圧縮とNvidiaへの依存低減という2つの戦略目標を同時に追うものとして注目されており、Google（TPU）、Amazon（Trainium/Inferentia）、Meta（MTIA）に続くAI大手の自社チップ路線への本格参入を意味する。

### 2. Claude Fable 5・Mythos 5の輸出規制停止が継続中（Day 13）— セキュリティコミュニティが規制範囲に反発

6月13日に米商務省が発令した輸出規制指令により、AnthropicのフラッグシップAIモデル**Claude Fable 5**および**Mythos 5**の全ユーザーへの提供停止が続いており、本日2026年6月25日時点で**13日間**の停止となっている（Fortune、CSA、Cybersecurity Dive）。指令の対象は「米国外に所在する者」だけでなく**米国在住の外国籍者**にも及ぶ広範な内容だったため、Anthropicは自社の非市民社員への提供も含め、全ユーザーへのアクセスをグローバル停止せざるを得なかった。政府は停止の根拠として、Fable 5が基盤とするMythos 5のサイバーセキュリティ能力を解除するジェイルブレイク技術の存在を挙げているが、Anthropic側は「当該ジェイルブレイクは特定状況に限定されたものであり、Fable 5の全保護機構を無効化する汎用的なものではない」と反論している。セキュリティコミュニティは、最先端AIを防御目的に利用できなくなるリスクを強調し、規制の範囲設計と実施プロセスへの批判的な声明を相次いで発表している（Dark Reading、Cybersecurity Dive）。同一期間中に**Gemini 2.5 Pro Deep Think**（Google）がGPQA Diamondで82.4%を達成しFable 5（79.1%）を上回るスコアを公表しており、規制によるAnthropicの競争上の空白を他社が急速に埋めつつある構図も生まれている。

### TIOBE Index 2026年6月版：Rust が史上最高位12位を記録、TypeScript vs JavaScript の交差点が目前

2026年6月版 **TIOBE Index** が公開された（TechRepublic）。主なハイライトは以下のとおり。

- **Python**：依然1位（18.96%）、ただし前月の19.98%から低下傾向。AI/MLエコシステムが唯一の支持基盤として認識され始めている。
- **Rust**：**史上初めて12位**に到達。C/C++リライトの波がOSやブラウザ、データベース、クラウドインフラへと拡大中。企業のRustプロダクション利用率は過去2年で10ポイント超増加し、約半数に達した。
- **TypeScript**：新規書き下ろしコードにおいてJavaScriptを上回る割合となっており、TIOBE上でも「TypeScript > JavaScript」の交差点が目前とされる。

また、**PyO3/maturin**経由でのPython拡張モジュールにRustを採用するプロジェクト数が前年比**22%増**を記録。AIモデル推論のホットパスをRustで高速化しつつPythonのエコシステム資産を活かすハイブリッドアーキテクチャが主流になりつつある。

```toml
# Cargo.toml — PythonからRustを呼び出す基本構成 (PyO3 + maturin)
[package]
name = "fast_tokenizer"
version = "0.1.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]

[dependencies]
pyo3 = { version = "0.21", features = ["extension-module"] }
```

```rust
// src/lib.rs — PyO3でPythonから呼び出せるRust関数を定義
use pyo3::prelude::*;

/// 高速トークナイザー（Rustで実装、Pythonから呼び出し可能）
#[pyfunction]
fn tokenize(text: &str) -> PyResult<Vec<String>> {
    // ASCII単純分割の例（実際は言語別ロジックを追加）
    let tokens: Vec<String> = text
        .split_whitespace()
        .map(|s| s.to_lowercase())
        .collect();
    Ok(tokens)
}

#[pymodule]
fn fast_tokenizer(m: &Bound<'_, PyModule>) -> PyResult<()> {
    m.add_function(wrap_pyfunction!(tokenize, m)?)?;
    Ok(())
}
```

```bash
# ビルド・インストール（maturin必要）
pip install maturin
maturin develop --release

# Python側から使用
python -c "import fast_tokenizer; print(fast_tokenizer.tokenize('Hello World from Rust'))"
# => ['hello', 'world', 'from', 'rust']
```

