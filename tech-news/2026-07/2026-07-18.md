### 1. Microsoft July 2026 Patch Tuesday：史上最大規模622 CVE・3件のゼロデイ — AD FSとSharePointが野生で悪用中

Microsoftが7月の月例セキュリティ更新（Patch Tuesday）をリリースし、**過去最大規模となる622件のCVE**を修正した。うち59件がCritical分類で、そのうち48件がリモートコード実行（RCE）に分類される。特に深刻なのは**現在積極的に悪用されている2件のゼロデイ**で、**CVE-2026-56155**（Active Directory Federation Services における権限昇格）と**CVE-2026-56164**（SharePoint Server における認証バイパスによる権限昇格）はいずれもCISAのKEVカタログに追加され、連邦機関への3週間以内の適用が義務付けられた。さらに**CVE-2026-57092**（Windows VMSwitch、CVSS 9.9）はVM脱出からホストへの侵害を可能にする最高水準の深刻度を持ち、仮想化環境を運用する組織にとっても急対応が求められる。前月6月のPatch Tuesdayが208件で記録更新と報じられてから1か月で3倍超に跳ね上がった件数に、セキュリティコミュニティからは「CVEトリアージの実務が限界に近づきつつある」という懸念の声も出ている。

### 2. Claude Fable 5が7月1日に全面復活 — GPT-5.6が7月9日にGA、最上位AIモデル競争が最終局面へ

6月12日に米政府の輸出規制指令を受けて一時停止されていた**Anthropicの Claude Fable 5**が、7月1日に規制解除を受けて全世界向けに提供を再開した。Fable 5はArtificial Analysis Intelligence Index（複合品質指数）で100/100を記録しており、SWE-Bench Proでは**80.3%**と現時点の最高スコアを保持している。一方、**OpenAIはGPT-5.6（Sol）を7月9日に一般提供（GA）開始**し、TerminalBench 2.1で88.8%とFable 5の83.4%を上回るターミナル操作能力を示した。価格面ではGPT-5.6は$5/$30 per 1Mトークン（入力/出力）に対しFable 5は$10/$50と約2倍の差があり、「ベンチマーク最高かつ高コスト」のFable 5と「性能差わずかながら大幅低コスト」のGPT-5.6 Solという構図でエージェントワークフロー向け採用の判断が分かれている。6月に発表されたGrok 4.5やMiniMax M3なども含め、最上位クラスのLLMが乱立するフェーズに入っており、性能向上より**コストパフォーマンスとエージェントタスク特化能力**が選定軸として台頭してきた。

### Python 3.16 への Rust 組み込みPEP草案が7月提出予定 — JITには「6か月クロック」

CPython への Rust 統合を主導するチームが、**Python 3.16をターゲットとしたPEP草案を2026年7月中に提出する**と発表した（Python 3.16 beta は2027年5月、正式リリースは2027年10月を予定）。CI ビルドはすべてのプラットフォームで通過しており、Python の**ビルドや実行に Rust コンパイラは不要**という設計方針が維持される。また Real Python のJuly 2026 ニュースによれば、Python Steering Council がCPython の**JIT コンパイラ実装に6か月のタイムリミット**を設定しており、期限内に本番品質に達しない場合は方針再検討に入る見通しだ。さらにEuroPython 2026がポーランド・クラクフで7月13〜19日に開催（25周年記念大会）されており、Rustとの連携やJITの進捗が発表の主要テーマとなった。

```python
# CPython Rust 統合後のイメージ（Python 3.16 向けPEP草案より概念抜粋）
# RustはCで書かれた内部実装の一部を置き換える — ユーザーコードへの変更なし
# 例: 文字列処理の内部実装が Rust モジュールに移行するケース

# ユーザー視点では以下のコードは変わらない
text = "Hello, Python 3.16"
result = text.encode("utf-8").decode("utf-8")
print(result)

# ただし内部では Rust 実装が呼ばれ、メモリ安全性が向上する
# Rust コンパイラはインストール不要 — ビルド済みバイナリとして同梱
```

また **Azure SDK June 2026** で Rust ライブラリが GA（v1.0.0）に到達し、7つのコアクレートに semver 保証が付与された。Rust のエコシステムが企業向けSDKレイヤーでも本格採用フェーズに入ったことを示す指標として注目される。

### July 2026 Patch Tuesday 緊急対応ガイド — 622 CVE・3ゼロデイ・VMSwitch CVSS 9.9の影響評価

```powershell
# === July 2026 Patch Tuesday 優先対応チェックリスト ===

# [1] 最優先ゼロデイ（野生で悪用中・CISA KEV登録済み）
# CVE-2026-56155  Active Directory Federation Services  権限昇格
# CVE-2026-56164  SharePoint Server  認証バイパス → 権限昇格
# 対応期限: 連邦機関は3週間以内、民間は速やかな適用を推奨

# [2] Critical CVE の中でも特に影響大
# CVE-2026-57092  Windows VMSwitch  CVSS 9.9  VM脱出→ホスト侵害
# CVE-2026-50518  Windows DHCP Server  CVSS 9.8  ヒープバッファオーバーフロー RCE
# CVE-2026-56159  Windows DHCP Server  CVSS 9.8  同上
# CVE-2026-50661  Windows BitLocker  物理アクセスで暗号化バイパス（公開済みPoCあり）

# [3] パッチ適用状況確認（July Patch Tuesday）
$patches = Get-HotFix | Where-Object { $_.InstalledOn -ge (Get-Date).AddDays(-7) }
Write-Host "=== 直近7日間に適用されたパッチ ==="
$patches | Select-Object HotFixID, InstalledOn | Format-Table -AutoSize

# [4] ADFSサービス稼働確認（CVE-2026-56155対象）
$adfs = Get-Service -Name "adfssrv" -ErrorAction SilentlyContinue
if ($adfs) {
    Write-Host "ADFS Status: $($adfs.Status) — CVE-2026-56155 の影響範囲に入る可能性"
    Write-Host "July Patch Tuesday 適用後に ADFS ログの不審な権限昇格イベントを確認すること"
}

# [5] SharePoint Server バージョン確認（CVE-2026-56164対象）
# SharePoint Server 2019 / SE / 2026 が対象
# IIS管理コンソールまたはSharePoint管理シェルでバージョン確認後にKB適用

# [6] 仮想化環境向け（CVE-2026-57092 VMSwitch）
# Hyper-V ホスト / Azure Stack HCI が最優先
# ゲストVMからホストへの経路を遮断するネットワーク隔離を暫定措置として検討

Write-Host "=== July 2026 最優先CVE サマリー ==="
Write-Host "CVE-2026-56155  AD FS  権限昇格  野生悪用中  CISA KEV"
Write-Host "CVE-2026-56164  SharePoint Server  認証バイパス  野生悪用中  CISA KEV"
Write-Host "CVE-2026-57092  VMSwitch  CVSS 9.9  VM脱出"
Write-Host "CVE-2026-50518  DHCP Server  CVSS 9.8  RCE"
Write-Host "CVE-2026-50661  BitLocker  物理バイパス  PoC公開"
```

今月のPatch Tuesdayはゼロデイ2件が**既に実被害を出しつつある状態でリリースされた**点が最大の懸念点だ。AD FSはシングルサインオン基盤として多くの組織の認証インフラを支えており、CVE-2026-56155を悪用すれば管理者権限を取得されるリスクがある。SharePointのCVE-2026-56164は認証を必要とせず外部からの攻撃が可能な構造のため、インターネット公開SharePoint環境は即時パッチ適用が最優先となる。VMSwitchのCVSS 9.9という数値はほぼ満点に相当し、クラウドプロバイダーやHyper-Vを利用するデータセンター運用者にとっては特に重大なリスクとなる。
