### 1. Code with Claude SF 2026（5月6日）— Anthropic が Claude Code を大幅強化、Vercept 買収も発表

Anthropic がサンフランシスコで開催した開発者イベントで多数のアップデートを発表。主要点:

- Claude Code の5時間レート制限を Pro / Max / Team / Enterprise 全プラン向けに **2倍** に拡張。ピーク時スロットリングも廃止
- SpaceX Colossus データセンターと300+メガワット、22万台超の NVIDIA GPU 契約を締結（「月内に稼働」）
- **Managed Agents** に3機能追加: マルチエージェントオーケストレーション、Outcomes（ルーブリック自己評価、docxで+8.4%・pptxで+10.1%のタスク成功率改善）、**Dreaming**（過去セッションを検査して記憶を自己改善するリサーチプレビュー）
- **Claude Agent SDK** を外部開発者向けに正式公開（旧称: Claude Code SDK。3月に改名）
- **Vercept 買収**（金額非公開）: コンピューターユース・デスクトップリモコン機能の強化が目的
- Code Review / CI auto-fix / Security Reviews の新ツール群を Claude Code に追加

**出典**: [Code with Claude SF 2026 Recap - Blake Crosley](https://blakecrosley.com/blog/code-with-claude-sf-2026-recap) / [Live Blog: Code w/ Claude 2026 - Simon Willison](https://simonwillison.net/2026/May/6/code-w-claude-2026/)

### 2. OpenAI GPT-5.5 Instant — 5月5日リリース、幻覚52.5%削減・応答30%短縮

OpenAI が GPT-5.5 Instant を ChatGPT のデフォルトモデルとして全ユーザーへ展開開始。

- 医療・法律・金融領域の高リスクプロンプトで GPT-5.3 Instant 比で幻覚が **52.5%削減**
- 応答ワード数 **30.2%削減**、行数 **29.2%削減**（より簡潔）
- Plus / Pro ユーザー向けに Gmail・過去会話・アップロードファイルを参照した **パーソナライズ回答** を提供
- API では `chat-latest` エイリアスで利用可能。GPT-5.3 Instant は3か月間は設定で継続利用可能

### 3. AWS MCP Server — 5月6日 GA。IAM ガードレール付きで AWS API 全体をエージェントに開放

AWS が MCP Server を一般提供開始。MCP 経由でエージェントが AWS の全 API を呼び出せる。

- IAM ベースのガードレード + CloudWatch メトリクス + CloudTrail ログで監査証跡を維持
- Python コードのサンドボックス実行機能付き（ローカル FS・シェルアクセスなし）
- MCP Server 自体の追加費用なし（使用した AWS リソースのみ課金）
- Agent Toolkit for AWS の中核コンポーネントとして位置付け

**出典**: [AWS MCP Server GA - AWS](https://aws.amazon.com/about-aws/whats-new/2026/05/aws-mcp-server/)

## 新技術・新リリース

**Claude Code CLI v2.1.126〜v2.1.131 (5月上旬)**

Code with Claude SF 前後にリリースされた一連のパッチ:

```bash
# 新コマンド: プロジェクトの全 Claude Code 状態を削除
claude project purge [path]

# セッション ID を bash サブプロセスに注入（ログ追跡等に利用）
echo $CLAUDE_CODE_SESSION_ID

# フルスクリーンレンダラーを無効化（WSL/Windows ターミナル互換性問題の回避）
export CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1
```

主なバグ修正: Windows での VS Code 拡張機能アクティベーション失敗 / Mantle エンドポイント認証ヘッダー欠落 / MCP 接続問題 / スクロールバグ

**Claude Agent SDK — Python & TypeScript 公式公開**

```bash
pip install claude-agent-sdk
```

```python
from claude_agent_sdk import AgentSession

async def main():
    async with AgentSession(model="claude-sonnet-4-6") as session:
        result = await session.run(
            prompt="リポジトリの依存パッケージを最新化してテストを実行せよ",
            tools=["bash", "file_read", "file_write"]
        )
        print(result.output)
```

Vercel Sandbox から Neon / Supabase / AWS RDS / Nile / Prisma Postgres への接続が可能になった。Postgres の TLS ネゴシエーションシーケンスを検知してファイアウォールルールを自動調整する。

**出典**: [Supabase Blog May 2026 - Supabase](https://supabase.com/blog)

**Hyperscience Spring 2026 Release — Inference Layering**

IDP プラットフォーム Hyperscience が「Inference Layering Optimization」をリリース。エージェント型エンタープライズ需要に対応するため、ワークロードをモデル間で動的ルーティングする機能。
