## 本日のニュース TOP 3

### 1. Meta、「Muse Spark」を正式公開 — Alexandr Wang 率いる Meta Superintelligence Labs 初の自社モデル

Meta が 4 月 8 日、Alexandr Wang 率いる Meta Superintelligence Labs が 9 か月をかけて開発したマルチモーダル推論モデル「Muse Spark」を正式公開した。音声・テキスト・画像の入力に対応しつつも出力はテキストのみという設計で、Llama 4 系の中規模モデルを「1 桁違う低コンピュート」で超える性能を目指している。注目機能の「Contemplating mode」は複数エージェントを並列で推論させる仕組みで、Humanity's Last Exam で 58%、FrontierScience Research で 38% を達成し、Gemini Deep Think や GPT Pro と並ぶ「extreme reasoning」枠への挑戦を明確にした。従来の Llama ファミリーがオープンソースだったのに対し Muse Spark はクローズドソース（将来的に一部 OSS 化の方針）という方針転換も業界の注目を集めており、Meta が 2026 年に 1,150〜1,350 億ドルの AI 関連設備投資を計画していることと合わせ、本格的なフロンティアモデル競争への参入を宣言した格好だ。

**開発者への影響**:
- Contemplating mode の API（将来提供予定）は、複数エージェントによる並列推論チェーンをサービス側で実装する手間を削減できる可能性がある
- オープンソース路線からの転換は、ファインチューニングや自己ホストを前提に Llama を採用していた開発者にとって戦略の見直しを迫ることになる

### 2. Anthropic「Claude Mythos Preview」を限定公開 — 全主要 OS・ブラウザのゼロデイを自律的に発見・悪用

Anthropic は 4 月 7 日、新モデル「Claude Mythos Preview」と防御利用コンソーシアム「Project Glasswing」を発表したが、同モデルの一般提供は行わないことも同時に表明した。内部テストで Mythos は主要なすべての OS およびブラウザにおけるゼロデイ脆弱性を自律的に発見・悪用できることが確認されており、4 つの脆弱性をチェーンした複雑な JIT ヒープスプレーでレンダラーと OS 両方のサンドボックスを脱出するブラウザエクスプロイトを単独で生成した事例も報告されている。FreeBSD では 17 年物の NFS サーバ RCE 脆弱性（CVE-2026-4747）を人間の介在なしに完全悪用し、認証なしで root アクセスを取得。発見した脆弱性の中には 27 年前の OpenBSD のバグも含まれていた。4 月 13 日にはフィナンシャルシステムへの脆弱性露出も報告されており、防御側が AI を活用する前に攻撃側が同等技術を持つ「jagged frontier」の現実がより鮮明になってきた。

**開発者への影響**:
- AI による自律的な脆弱性発見は SAST/DAST ツールチェーンを再構成するレベルの変化を示唆し、AI 強化ペネトレーションテストの早期評価が推奨される
- Project Glasswing の枠組みでは一部企業がアクセスを得ており、クリティカルインフラ事業者はコンソーシアムへの参加要件を確認する価値がある

### 3. AI 規制「デジタル主権」時代へ — 米中欧の三極構造が固まりつつある 2026 年春

RSAC 2026 や Atlantic Council のレポートから、AI 地政学の構図がより鮮明になってきた。EU は権利・リスクベースの規制モデルを堅持し、米国は安全保障上の柔軟性を優先した自主基準路線を維持、中国は「包括的協力」を掲げながら国内データ・AI 管理の国家主導を守る三極分化が加速している。米国の対中 AI 輸出規制が対象外のはずの欧州にも波及し、EU 独自の AI 主権確立への圧力が高まっている。クラウドインフラ・半導体サプライチェーン・規制基準の支配が「デジタル主権」の同義語となりつつあり、国際調達・クロスボーダーデプロイを行うプロジェクトでは法制度リスクの評価が不可欠になっている。

**開発者への影響**:
- EU AI Act の適用範囲・リスク分類に基づいたコンプライアンス設計は、欧州市場を対象とするサービスで実装優先度が高まっている
- 米中どちらの規制域にも跨る API・データフローを持つシステムは、輸出規制のデュアルユース該当性チェックを早めに行うことが望ましい

## 新技術・新リリース

### Rust 1.94 & async closures 安定化 — 2026 年、システムプログラミングの本格移行期へ

2026 年 3 月にリリースされた Rust 1.94.0 では、最も待望されていた機能の一つ「async closures」の安定化が含まれており、async/await 以来最大の人間工学的改善と評される。従来、非同期クロージャを扱うには複雑な型注釈や回避策が必要だったが、安定化により自然なシンタックスで記述できるようになった。

```rust
// Rust 1.94 以前: async closure が不安定なため回避策が必要だった
fn call_with<F, Fut>(f: F) -> impl std::future::Future<Output = ()>
where
    F: Fn() -> Fut,
    Fut: std::future::Future<Output = ()>,
{
    f()
}

// Rust 1.94 以降: async closure が安定化され直接利用可能
async fn process_items(items: Vec<i32>) {
    // async |...| { ... } が安定した構文として利用可能
    let fetch = async |id: i32| -> String {
        // 実際の非同期 I/O をここに記述できる
        format!("item_{}", id)
    };

    for item in items {
        let result = fetch(item).await;
        println!("{}", result);
    }
}
```

Rust Foundation はエンタープライズ向け初の認定プログラムも開始しており、金融・医療・組み込みなど規制産業での Rust 採用を後押しする体制が整いつつある。CPython への Rust 導入（ターゲット: Python 3.16）と合わせ、言語エコシステム全体での Rust の存在感が急速に拡大している。

## セキュリティ

### CVE-2026-34621: Adobe Acrobat Reader ゼロデイ — 2025 年 11 月から悪用、緊急パッチを 4/13 公開

4 月 13 日、Adobe が Acrobat Reader の緊急セキュリティアップデートを公開した。CVE-2026-34621 はプロトタイプ汚染（Prototype Pollution）脆弱性で、攻撃者がアプリケーションの JavaScript オブジェクトとプロパティを追加・変更し、現在のユーザーコンテキストで任意コードを実行できる。2025 年 11 月から野生での悪用が確認されており、リモートトリガーは不可能だが「悪意ある PDF ファイルを開く」というユーザー操作だけで成立する点で、フィッシング・ソーシャルエンジニアリングとの組み合わせが特に危険だ。

```bash
# macOS: Acrobat Reader のバージョン確認
defaults read /Applications/Adobe\ Acrobat\ Reader.app/Contents/Info.plist \
  CFBundleShortVersionString

# 自動アップデートが無効の環境は
# Adobe Acrobat Reader > ヘルプ > アップデートの確認 から手動適用を推奨
# Windows では Adobe Acrobat Reader DC の最新版をダウンロードページから取得
```

### CVE-2026-39987: Marimo Python ノートブック 事前認証 RCE — CVSS 9.3、クレデンシャル窃取に悪用中

Python のインタラクティブノートブック「Marimo」（バージョン 0.20.4 以下の全バージョン）に、事前認証リモートコード実行脆弱性（CVSS 9.3）が確認され、すでにクレデンシャル窃取を目的とした能動的な悪用が始まっている。Marimo は Jupyter の代替として開発者コミュニティで採用が広がっており、チームサーバやクラウド環境で公開している場合は緊急対処が必要だ。

```bash
# 現在のバージョン確認
pip show marimo | grep Version

# 0.20.5 以上へアップデート
pip install "marimo>=0.20.5"

# requirements.txt / pyproject.toml でも最小バージョンを固定
# marimo>=0.20.5
```
