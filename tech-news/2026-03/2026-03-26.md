# AI専門家デイリーレポート 2026-03-26

## 本日のAIニュース TOP 3

### 1. Claude Code v2.1.84 リリース — Windows対応強化とAuto Mode拡大
3月26日付で v2.1.84 がリリース。Windows向けに PowerShell ツールがオプトインプレビューとして追加され、起動速度が約30ms改善。Auto Mode（研究プレビュー）が拡張され、人間の承認ステップを減らして複数工程を自律実行できるようになった。TechCrunch は「速度と安全性のトレードオフを built-in safeguard で解決しようとする業界的転換点」と評している。

**個人開発者への影響**: Auto Mode を繰り返しタスク（テスト実行・ファイル変換処理）に即導入できる。Windows PowerShell 対応は Windows 11 開発環境を直接改善する。

### 2. MCP v1.27 — Server Cards による自動発見・エンタープライズ認証整備
TypeScript SDK v1.27.1 / Python SDK v1.26 に更新。Server Cards（`.well-known` URL でサーバーメタデータを公開する規格）により、AIエージェントが接続前にサーバー機能を発見できるようになった。SSO統合認証・監査ログ・ゲートウェイ挙動の標準化が進行中。

**個人開発者への影響**: MCP サーバーを公開する際に Server Cards を実装しておくと将来のエージェント統合が容易になる。

### 3. Cursor ARR $2B 突破・$50B 評価での新ラウンド交渉
Cursor の ARR が20億ドル（うち60%が企業顧客）を突破し、50億ドル評価での資金調達を交渉中。JetBrains サポート追加で VS Code 依存から脱却。GitHub Copilot は SWE-bench 56%（Cursor 52% を上回る）を記録・Jira 連携も追加。一方で無料代替ツール（Morph LLM, SWE-bench 80.8%, $0）も台頭。

**個人開発者への影響**: コスト最適化の観点で各ツールの役割分担・代替候補を定期的に見直す価値あり。

## 新技術・新リリース

### Claude Code v2.1.84 (2026-03-26)
- PowerShell ツール（Windows）: オプトインプレビュー
- MCP サーバー重複排除（ローカル設定優先）
- 起動 ~30ms 高速化
- Hook 追加: `CwdChanged`、`FileChanged`

```bash
# PowerShell ツールをオプトインで有効化
claude config set enablePowerShellTool true

# --bare フラグ（v2.1.81〜）: Hooks/LSP/プラグインをスキップ
claude --bare "テストを実行して結果だけ返して"

# --channels オプション（v2.1.80〜）: MCP メッセージプッシュ
claude --channels "タスク名"
```
