### 2. Microsoft Exchange Server OWA ゼロデイ CVE-2026-42897 が野放しで悪用中 — 細工メール経由で任意 JS 実行

Microsoft は 5/14 に Exchange Server の Outlook Web Access（OWA）に存在するクロスサイトスクリプティング脆弱性 CVE-2026-42897（CVSS 8.1）を開示し、すでに実環境で積極的に悪用されていることを確認した。攻撃者は特定の条件を満たすユーザーに細工されたメールを送付するだけで、OWA 上のブラウザコンテキストで任意の JavaScript を実行できる。影響を受けるのはオンプレミス版 Exchange Server 2016・2019・Subscription Edition RTM であり、Exchange Online には影響がない。Microsoft は Emergency Mitigation Service（EM Service）経由で自動緩和策を配信済みだが、緩和策適用後は OWA の印刷カレンダー機能・インライン画像表示・OWA ライトモードに既知の不具合が生じる。CISA は 5/15 に同脆弱性を Known Exploited Vulnerabilities カタログへ追加し、連邦機関に 5/29 までの修正適用を義務付けている。

### 3. TypeScript 7.0 Beta 公開 — Go ベースのネイティブコンパイラ「tsgo」でビルド時間が最大10倍短縮

Microsoft は 4/21 に TypeScript 7.0 Beta を公開した。本バージョンは Go 言語で書き直されたネイティブコンパイラ（開発コード Project Corsa、CLI 名 `tsgo`）を採用しており、Node.js の起動オーバーヘッドなしでネイティブバイナリとして動作する。VS Code の 100 万行コードベースでの型チェック時間は従来の 77 秒から 7.5 秒（約10倍）に、Playwright の 35.6 万行コードベースでは 11 秒から 1 秒へと大幅に短縮された。`--incremental`・プロジェクト参照・`--build` モードもすでに移植済みで、機能面でのパリティはほぼ達成されている。TypeScript 6.0 が JavaScript ベース最終版として位置付けられ、7.0 がその後継として段階的に移行していく計画だ。

## 新技術・新リリース

### TypeScript 7.0 Beta (tsgo) — 従来 tsc との速度比較

TypeScript 7.0 の新コンパイラ `tsgo` は Go ネイティブバイナリとして動作し、既存プロジェクトへの段階的導入が可能だ。以下は基本的なインストールと動作確認の例だ。

```bash
# tsgo のインストール（npm / volta / mise どれでも可）
npm install -D @typescript/native-preview

# バージョン確認
npx tsgo --version

# 既存プロジェクトで型チェックを実行（tsc 互換の CLI）
npx tsgo --noEmit

# ビルド時間を tsc と比較する
time npx tsc --noEmit   # 例: 77s
time npx tsgo --noEmit  # 例:  7.5s
```

現時点では Beta のため、一部のプラグイン API や変換系オプション（`--declaration` の一部）は未実装だ。プロダクションビルドでは引き続き `tsc` を、型チェックのみを高速化したいワークフローで `tsgo` を活用するハイブリッド構成が現実的な移行パスとなる。Language Server（tsserver 相当）も開発中であり、将来的には VS Code のインテリセンスも `tsgo` バックエンドへ移行する予定だ。

**出典**: [TypeScript 7.0 Beta — Visual Studio Magazine](https://visualstudiomagazine.com/articles/2026/04/21/typescript-7-0-beta-arrives-on-go-based-foundation-with-10x-speed-claim.aspx) / [tsgo vs tsc — PkgPulse Guides](https://www.pkgpulse.com/guides/tsgo-vs-tsc-typescript-7-go-compiler-2026)
