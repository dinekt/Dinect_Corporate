### 2. Check Point VPN CVE-2026-50751（CVSS 9.3）— Qilinランサムウェアがゼロデイ認証バイパスで5月から侵害継続

Check Point Remote Access VPNに存在する**CVE-2026-50751**（CVSS 9.3、認証バイパス、CWE-287）が、Qilinランサムウェアグループを含む攻撃者に5月7日から積極悪用されていることが確認された。脆弱性の根本原因はレガシー**IKEv1**鍵交換プロセスにおける証明書検証ロジックの欠陥で、攻撃者はIKEv1フェーズ1ハンドシェイク中にカスタムVendor IDペイロードで認証フラグを操作することにより、有効な認証情報なしにVPNセッションを確立できる。悪用の前提条件はRemote Access/Mobile Access Bladeが有効かつレガシーIKEv1パスが許可されていること、かつマシン証明書の強制なしで接続を受け入れる設定であること。6月8日にCheck Pointがパッチをリリースしたが、それ以前の5月初旬から少なくとも数十の組織が侵害されており、6月12日には研究者によりPoC（概念実証コード）が公開されたため未パッチ環境への攻撃リスクがさらに高まっている。同一コードパスには関連脆弱性**CVE-2026-50752**（CVSS 7.4、S2S VPNトンネルへのMitM攻撃）も発見されており、合わせて対応が必要だ。

### Microsoft Build 2026 — MAI自社AIモデル群とWindows Agent Framework APIでエージェントOS時代へ

Microsoft Build 2026で発表された**MAI（Microsoft AI）** モデル群は、GitHub Copilot向けコーディング特化モデルを筆頭に、文字起こし・推論・音声・画像処理の各領域に特化した複数のモデルで構成される。これらはOpenAI依存を補完・代替する形でMicrosoftのAIスタックに統合されており、特にCopilot向けコーディングモデルはエディタ上でのコード補完精度と説明品質の向上を目標とする。合わせて発表された**Windows Agent Framework API**は、OS上で自律的に動作するAIエージェントの実装を標準化するAPIセットであり、ファイル操作・ブラウザ制御・UIオートメーションをエージェントが安全に実行するための権限分離モデルを提供する。

```python
# Windows Agent Framework API — 自律エージェント構築の概念例
# 実際のAPIは Build 2026 Preview SDK に含まれる（概念実装）

import asyncio
from windows_agent_framework import AgentSession, Permission, Task

async def run_coding_agent():
    # エージェントセッションを権限スコープ付きで初期化
    session = AgentSession(
        permissions=[
            Permission.FILE_READ,        # ファイル読み取りのみ許可
            Permission.BROWSER_NAVIGATE, # ブラウザナビゲーション
            # Permission.FILE_WRITE は明示的に付与しない（最小権限原則）
        ],
        sandbox=True  # サンドボックスモードで副作用を隔離
    )

    # タスクを自然言語で指示し、エージェントが計画・実行
    task = Task(
        instruction="プロジェクトのREADMEを読んで、依存関係の一覧を返してください",
        max_steps=10,
        timeout_seconds=60
    )

    result = await session.run(task)
    print(f"エージェント実行結果: {result.output}")
    print(f"実行ステップ数: {result.steps_taken}")
    print(f"使用したツール: {result.tools_used}")

asyncio.run(run_coding_agent())
```

Windows Agent Frameworkの設計思想は「最小権限エージェント」であり、エージェントが要求する権限をユーザーが事前に明示的に付与する。ファイル書き込み・ネットワーク送信などの副作用を伴う権限はデフォルト非付与となっており、悪意あるプロンプトによる意図しない操作（プロンプトインジェクション経由の横断的移動など）を抑止する構造だ。エージェントがOSに直接統合される「エージェントOS」のアーキテクチャ議論が始まりつつある局面を象徴するリリースといえる。
