### 1. 上海人工智能研究院が 744B パラメータ Agentic MoE「Atria Dawn Preview」を静かに公開 — MIT ライセンス・無料・アナウンスなし

9月11日、GitHub 上に突如として **Atria-Dawn-Preview** というリポジトリが出現した。作者は中国の国立研究機関である上海人工智能研究院（InternLM シリーズの開発元）で、ブログ記事も論文もプレスリリースも一切なく公開された。このモデルは **744B パラメータの MoE（Mixture of Experts）** 構成で、トークンあたり約 40B パラメータがアクティブになる設計だ。ベースは Zhipu AI が2026年6月13日に MIT ライセンスで公開したコーディング・ツール利用特化の基盤モデル **GLM-5.2** であり、**Verifiable Experience Pipeline** という手法でツール使用を実行環境に根差した形で追加学習している。9月12日には FP8 チェックポイントも公開され、16の評価ベンチマークで競争力のある結果が報告されており、参加者56名による769タスク記録のうち約3分の1は「AIエージェントなしでは実行不可能」と判定された。MIT ライセンスにより商用利用・ファインチューニング・再配布が自由に行えることも注目点で、オープンウェイトモデルの「アウトオブノーウェア」型投入は、中国勢とオープンソースコミュニティ双方の動向を示すトレンドとして続いている。

### 2. G20 が米国の「カロライナ原則」を全会一致で採択 — AI 軽規制フレームワークが国際スタンダードに

9月2〜3日にノースカロライナ州チャペルヒルで開催された G20 イノベーション閣僚会議で、米国が提案した AI ガバナンスフレームワーク**「カロライナ原則（Carolina Principles）」**が中国を含む全 G20 加盟国の全会一致で採択された。米商務長官 Howard Lutnick と OSTP 局長 Michael Kratsios が発表したこの原則は、「AI をテクノロジー種別で名指しした新規制を避け」「専用 AI 規制機関の新設を控え」「官民連携によるテクノロジー評価を促進」するよう各国に求めるものだ。拘束力のない政治的コミットメントではあるが、2019年の G20 AI 原則と同様に各国の政策形成に一定の方向性を与える。一方 EU は独自の AI Act を維持・強化する方針であり、米欧間の規制アプローチの乖離はむしろ鮮明化している。カロライナ原則の採択は、AI 開発加速を掲げるトランプ政権が国際場裏でも「規制より競争・イノベーション」路線の牽引役を担っていることを示す象徴的な出来事となった。

### 3. Visual Studio 2026 正式リリース — BYOK と Agent Mode で AI 開発を民主化

9月8日、Microsoft が **Visual Studio 2026** を正式リリースした。最大の目玉は **Bring Your Own Key（BYOK）** 機能で、GitHub Copilot だけでなく開発者が組織内で独自に契約した LLM（Microsoft Foundry デプロイや対応プロバイダーのキーを利用）を Visual Studio 内で直接利用できるようになった。BYOK は Community・Professional・Enterprise の全 SKU でプレビュー有効化されている。加えて **Agent Mode（プレビュー）** も搭載され、マルチファイル編集の計画・実行・コマンド実行・ツール出力への反応といった一連のエージェント的ワークフローが IDE 内で完結する。同時期にリリースされた **MSVC Build Tools Preview（v14.52 相当）**もコンパイラフロントエンド・バックエンド・リンカ・標準ライブラリの各層にわたる更新を含む。開発ツールへの AI 統合が「特定モデルへの依存」から「モデルの選択自由」へ移行しつつあることを示す象徴的なリリースとなった。

## 新技術・新リリース

### Visual Studio 2026 BYOK — 任意のモデルを IDE に持ち込む

Visual Studio 2026 の BYOK 機能を使うと、Microsoft Foundry エンドポイントや対応プロバイダーのキーを設定するだけで、Agent Mode を含む AI 機能を組織のモデルポリシーに従って利用できる。以下は Azure OpenAI / Microsoft Foundry 経由で接続する設定例と、Agent Mode がツールを呼び出す際の内部フロー概観だ。

```jsonc
// Visual Studio 2026 — AI モデル設定（.vsconfig または UI 設定から反映）
{
  "aiModel": {
    "provider": "AzureOpenAI",            // "GitHubCopilot" | "AzureOpenAI" | "Custom"
    "endpoint": "https://<your-resource>.openai.azure.com/",
    "deploymentId": "gpt-4o-mini",        // 自組織がデプロイしたモデル名
    "apiVersion": "2025-01-01-preview",
    "byokEnabled": true
  }
}
```

```python
# Agent Mode が内部でツール呼び出しする際の概念フロー（Python 疑似コード）
# Visual Studio の Agent (Preview) はこのようなループで動作する

def agent_loop(task: str, tools: list[Tool]) -> str:
    messages = [{"role": "user", "content": task}]
    while True:
        response = llm.chat(messages=messages, tools=tools)
        if response.finish_reason == "stop":
            return response.content           # タスク完了
        # ツール呼び出しが必要な場合
        for tool_call in response.tool_calls:
            result = tools[tool_call.name].execute(**tool_call.arguments)
            messages.append({
                "role": "tool",
                "tool_call_id": tool_call.id,
                "content": str(result),       # ファイル編集・コマンド結果などを返す
            })
```

BYOK により、プロプライエタリな GitHub Copilot サブスクリプションを持たない開発者・組織でも、自前のモデルエンドポイントを利用して Agent Mode の恩恵を受けられるようになった。オンプレミスやプライベートクラウド要件を持つ組織にとって実用的な選択肢が広がっている。

### CISA KEV に今週 11 件追加 — Cisco メールゲートウェイ RCE (CVSS 9.8)・KGUARD DVR 完全侵害 (CVSS 10.0)・Vite クラウド認証情報窃取

```text
===== 緊急対応チェックリスト: 2026-09-15 =====

【Cisco Secure Email Gateway】
CVE-2026-76461 (CVSS 9.8, RCE) — SQL インジェクションによるOSコマンド実行
  攻撃手法: 認証不要の攻撃者がリモートからroot権限でOSコマンドを実行可能
  影響範囲: Cisco Secure Email Gateway (ESA) の特定バージョン
  対処: Cisco セキュリティアドバイザリに従い即時パッチ適用 / CISA KEV 登録済み

【KGUARD DVR デバイス】

  影響範囲: 脆弱なファームウェア稼働中のKGUARD DVR全機器
  対処: ファームウェアを最新版に更新 / インターネット直接公開の排除 / CISA KEV 登録済み

【Vite 開発サーバー】
CVE-2026-39364 (CVSS 7.5) — クラウド認証情報・設定ファイル窃取
  攻撃手法: Vite devサーバーへのリクエストでクラウドキー・設定ファイルを取得
  影響範囲: Vite 7.1.0 以上 7.3.2/8.0.5 未満
  被害実績: F5 Labs が1ヶ月で約32,000イベントを記録
  対処: Vite 7.3.2 または 8.0.5 以上へアップデート
```

今週の CISA KEV には計 11 件の CVE が新たに追加された。注目されるのは3件だ。**CVE-2026-76461**（Cisco Secure Email Gateway の SQL インジェクション、CVSS 9.8）は認証不要の攻撃者が OS レベルでコマンドを実行できるリモートコード実行（RCE）脆弱性で、既に野生での悪用が確認されている。**CVE-2026-87827**（KGUARD DVR、CVSS 10.0）はスコア最大値の脆弱性で、デバイスが持つすべてのネットワークインターフェース上に無防備なコマンド実行サービスが露出しており、デバイスの完全侵害が可能だ。**CVE-2026-39364**（Vite 開発サーバー）は Vite 7.1.0〜7.3.2/8.0.5 未満に影響し、攻撃者がクラウド認証情報や設定ファイルを窃取できる。F5 Labs は単月で 32,000件を超えるスキャンイベントを記録しており、Vite を本番環境外でも利用するプロジェクトは早急な更新が求められる。前週からの Microsoft Patch Tuesday（974件 CVE）対応作業と重なるタイミングであり、組織のパッチ優先度評価プロセスが試される週となっている。
