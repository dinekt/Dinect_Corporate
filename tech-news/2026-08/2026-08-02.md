### 1. EU AI Act Article 50、本日2026年8月2日正式施行 — チャットボット開示・AI生成コンテンツのマーキングが欧州450万人市場で義務化

欧州連合のAI規制法（EU AI Act）の**Article 50（透明性義務）**が本日2026年8月2日より正式施行となり、EU域内で運営するあらゆるチャットボット・AI生成コンテンツサービス・ディープフェイクツール・感情認識システムが対象になった。人類史上初の包括的かつ法的拘束力を持つAI規制が事実上の発動を迎えた歴史的な日だ。主な義務は3本柱だ。**①チャットボット開示義務**：ユーザーが人間ではなくAIシステムと会話していることを明確に通知しなければならない（AIエージェント・アバターを含む）。**②機械可読マーキング義務**：AIが生成または改変した音声・画像・動画・テキストは機械可読フォーマットで生成AIコンテンツであることをマークしなければならない（既存システムは2026年12月2日まで猶予）。**③ディープフェイク開示義務**：本物に見せかける意図のないパロディ・芸術表現は除外されるが、現実と見分けがつかないレベルの合成コンテンツにはAI生成である旨のラベルが必須だ。施行主体は各EU加盟国の市場監視機関となり、**欧州AI Officeは本日付けで一般目的AI（GPAI）モデルプロバイダーへの完全な罰則執行権限**を取得した。違反時のペナルティは最大**1,500万ユーロまたは全世界年間売上3%**（いずれか大きい方）。なお、採用ツール・信用スコアリング・法執行・重要インフラ向けなどAnnex III高リスクAIシステムへの完全義務化は別途**2027年12月2日**に延期されており、本日のスコープはあくまでArticle 50の透明性義務に限定される。グローバルに展開するAIチャットサービスやコンテンツ生成ツールにとって、EU市場へのサービス提供には今日から準拠が不可欠となった。

### 2. DeepSeek-V4-Flash-0731 正式公開 — 284B MoEで$0.14/1Mトークン、エージェント・コーディング性能を再ポストトレーニングで大幅強化

DeepSeekは日本時間7月31日、**DeepSeek-V4-Flash-0731**をHugging Faceで公開するとともに、公式APIを公開ベータへ移行した。アーキテクチャは合計**284Bパラメータ**を持つMixture-of-Experts（MoE）設計で、**1トークンごとに13Bパラメータのみをアクティブ化**するため推論効率が高い。コンテキストウィンドウは**1,000,000トークン（1Mトークン）**をサポートし、長文ドキュメント解析や大規模コードベースへの対応が可能だ。今回のリリースで最も注目されるのはアーキテクチャを変更せず**再ポストトレーニング（re-post-training）のみ**でエージェント・コーディングのベンチマーク性能を大幅向上させた点で、モデルカードはV4-Flashプレビューを正式に置き換えるリリースであると明記している。API仕様面では、OpenAIの**Responses API形式にネイティブ対応**しており、Codex互換のエージェントワークフローへの組み込みが容易になった。価格は1Mトークンあたり入力**$0.14**（キャッシュミス時）、キャッシュヒット時は**$0.0028**、出力は**$0.28**で、同等性能の競合モデルと比べてコスト効率が高い水準にある。同時接続上限は2,500。DeepSeekはV4-Flashを「エージェント向け軽量高速推論モデル」と位置づけており、長期タスクを自律的に実行するAIエージェントのバックボーンとして活用が想定される。

### AIコーディングエージェントが三極分化 — Claude Code（ターミナル）・Cursor（IDE）・Gemini CLI（無料）が明確に棲み分け

2026年8月時点でAIコーディングエージェント市場はターミナル系・IDE統合系・無料ティア系の3極に明確に分化した。**Claude Code**はAnthropicが提供するターミナルベースのコーディングエージェントで、プロジェクト全体を読み込んでマルチファイルの複雑なタスクを会話形式で処理する。カスタムインストラクションをSKILL.mdとして定義することでチームの開発パターンを学習させられる点が特徴で、MCP（Model Context Protocol）サーバーとの統合により外部ツールへの拡張も容易だ。**Cursor**はVS Codeフォークのエディタ内にAIを全面統合したIDEで、タブ補完・Composer（マルチファイル編集）・エージェントモード・並列バックグラウンドエージェントを備える。IDEの操作を離れずに複雑なリファクタリングや機能実装を完結できる点で従来の開発者体験に近い。**Gemini CLI**はGoogleアカウントによるOAuth認証のみで1分60リクエスト・1日1000リクエストという無料ティアを提供し、1Mトークンのコンテキストウィンドウを無料枠で利用できる。Claude Code・Codex CLI・Cursor・Gemini CLIはいずれもSKILL.mdスキルをポータブルな形式でサポートしており、スキルは複数ツール間で共有可能だ。さらにMCPとACP（Agent Communication Protocol）を介してエージェント間の相互運用性が高まっており、「AIコーディングエージェントを使うかどうか」ではなく「どのエージェントをどのユースケースに使うか」の選択が主要な意思決定となっている。

```bash
# Claude Code の基本的な使い方（ターミナル）
# プロジェクトディレクトリで起動
claude

# 特定のタスクを指定して起動（非インタラクティブ）
claude -p "src/auth.ts の JWT バリデーション処理をリファクタリングして"

# SKILL.md によるカスタムスキルの定義例（プロジェクトルートに配置）
cat > .claude/skills/pr-review.md << 'EOF'
---
name: pr-review
description: Pull request review checklist for this project
---
# PR Review Checklist
1. Security: check for SQL injection, XSS, and auth bypass
2. Tests: ensure coverage for new code paths
3. Docs: update API docs if endpoints changed
EOF

# Gemini CLI — 無料ティアの確認（Google OAuth使用）
gemini --version
# 60 req/min, 1000 req/day on free tier with personal Google account

# Cursor Agent Mode での並列エージェント確認（VS Code コマンドパレット）
# Ctrl+Shift+P → "Cursor: Start Background Agent"
# 複数の独立タスクを並列で処理可能（ファイル競合なしの場合）

# MCP サーバー設定例 (claude_desktop_config.json または .claude/settings.json)
# {
#   "mcpServers": {
#     "github": {
#       "command": "npx",
#       "args": ["-y", "@modelcontextprotocol/server-github"]
#     },
#     "filesystem": {
#       "command": "npx",
#       "args": ["-y", "@modelcontextprotocol/server-filesystem", "/workspace"]
#     }
#   }
# }
echo "AI coding tools: terminal vs IDE vs free-tier — pick by workflow, not hype"
```

AIコーディングエージェントの選択において「最高性能」より「ワークフローへの統合コスト」が重要になってきた。ターミナル中心の開発者にはClaude CodeやGemini CLIが、IDEから離れたくない開発者にはCursorやCopilotが、コストを最小化したいチームにはGemini CLIの無料ティアが適している。SKILL.md・MCP・ACPによるインターオペラビリティの進展により、ツールのロックインリスクが低下しており、段階的な移行や複数ツール併用が現実的な戦略として浮上している。
