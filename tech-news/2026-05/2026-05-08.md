### 1. 「Dirty Frag」Linux カーネル LPE — エンバーゴ破れ PoC 公開、ほぼ全ディストリビューションが即時ルート昇格のリスクに

セキュリティ研究者 Hyunwoo Kim（@v4bel）が発見した Linux カーネルのローカル権限昇格脆弱性チェーン **Dirty Frag**（CVE-2026-43284、CVE-2026-43500）が、5 月 7 日にエンバーゴが破られ、概念実証（PoC）エクスプロイトが公開状態となった。xfrm-ESP ページキャッシュ書き込み欠陥と RxRPC ページキャッシュ書き込み欠陥の 2 つを連鎖させることで、非特権ユーザーがほぼすべての主要 Linux ディストリビューションでルート権限を即時取得できる。Ubuntu / Fedora / Debian / RHEL 系すべてが影響を受けるとされており、Canonical はすでに修正済みカーネルを提供しているほか、CloudLinux も緩和策を公開した。コンテナホスト（EKS・GKE ノードプール含む）においては、コンテナ脱出と横断移動の踏み台になるリスクが特に高いと各社が警告している。

## 新技術・新リリース

### Coder Agents（ベータ）— エンタープライズ向け自己ホスト型 AI エージェントアーキテクチャ

AI 開発インフラプロバイダー **Coder** が、エンタープライズ企業向けに AI 駆動の開発者ワークフローを自社インフラ上で完結させるネイティブエージェントアーキテクチャ **Coder Agents** をベータ公開した。SaaS 型の Copilot や Cursor とは異なり、コードがクラウドプロバイダーに送信されないゼロトラスト設計が特徴。DevSecOps ポリシーや内部セキュリティ要件への準拠が容易なため、金融・防衛・規制業界での採用が見込まれている。

```yaml
# coder-agents.yaml（設定例）
agents:
  - name: code-review-agent
    model: claude-sonnet-4-6
    tools:
      - bash
      - file_read
      - file_write
    constraints:
      network: internal_only      # 外部ネットワークアクセスなし
      secrets_access: vault_only  # シークレットは Vault 経由のみ
    triggers:
      - event: pull_request.opened
        workflow: security_scan_then_review
```

## セキュリティ

### Dirty Frag（CVE-2026-43284・CVE-2026-43500）— 即時対応チェックリスト

エンバーゴが破れ PoC が流通している状況では、通常の「次回メンテナンス窓で適用」は機能しない。以下の手順で優先対応を行う。

```bash
# 1. 実行中カーネルバージョン確認
uname -r

# 2. Ubuntu / Debian 系: 修正済みカーネル確認・適用
apt-get update && apt-get upgrade linux-image-$(uname -r)

# 3. RHEL / Fedora 系
dnf update kernel

# 4. EKS ノードグループのローリング更新
aws eks update-nodegroup-version \
  --cluster-name YOUR_CLUSTER \
  --nodegroup-name YOUR_NODEGROUP \
  --release-version LATEST_PATCHED_AMI

# 5. seccomp プロファイルによる緩和確認
docker inspect <container> | grep -i seccomp
```

**即時対応の優先順位:** コンテナホスト（EKS/GKE/AKS ノード）> 公開 API サーバー > 内部 Linux ホスト

### Palo Alto Networks CVE-2026-0300（CVSS 9.3）— PAN-OS に未認証 RCE

Palo Alto Networks の **PAN-OS** User-ID Authentication Portal サービスにバッファオーバーフロー脆弱性 **CVE-2026-0300**（CVSS 9.3）が発見された。インターネット・非信頼ネットワークから Authentication Portal へのアクセスが有効な場合に、未認証の攻撃者が細工したパケットを送信することでルート権限での任意コード実行が可能。Palo Alto は 4 月 9 日以降に悪用試行を検知したと報告しており、すでに武器化が進んでいる可能性がある。**User-ID Authentication Portal をインターネットに直接公開している環境は最優先でパッチを適用**または一時的に無効化すること。CVSS は信頼ネットワーク限定の場合 8.7 に低下するが、いずれも対応が必要。
