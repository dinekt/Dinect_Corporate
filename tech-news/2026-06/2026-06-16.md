### 1. 米議会、「Great American AI Act」269ページ討議草案を公開 — 3年間の州法プレエンプションとフロンティアAI開発者への拘束義務が柱

超党派の下院議員Jay Obernolte（共和・CA）とLori Trahan（民主・MA）が6月4日、**Great American AI Act（GAAIA）**の討議草案（269ページ）を公開した。草案の最大の特徴は「**3年間の州法プレエンプション**」で、採用済みのコロラド州消費者AI保護法（6月30日施行予定）をはじめ各州のAI構築規制を連邦が上書きする仕組みを設ける。もう一方の柱は**年間売上高5億ドル超の「大手フロンティアAI開発者」への拘束力ある義務化**であり、安全評価・透明性報告・インシデント開示が法的義務となる。また商務省内の**AI標準革新センター（CAIS&I）**を法定化し、2027〜2029会計年度に各年1億ドルを授権する条項も盛り込まれた。草案はあくまで討議ドラフト（stakeholderコメントを経て正式提出される予定）ながら、連邦レベルで包括的AI法制を検討する動きとしては過去最も具体性が高く、EU AI Actと競争するか、あるいは米国独自の「イノベーション優先」アプローチを制度化するかの分岐点となる。コロラド州法は施行直前に同法によって骨抜きになる可能性があるため、各州・業界団体から早くも異論が出ている。

### 2. Microsoft 6月Patch Tuesday：記録的208 CVE・ワーム化可能なWindowsカーネルRCE（CVE-2026-45657 CVSS 9.8）が最優先対応課題

6月10日（第2火曜）にリリースされたMicrosoftの月例セキュリティ更新では、過去最多水準の**208件のCVE**が修正された（うち37件がCritical、Zero-dayは計6件）。中でも最も深刻な**CVE-2026-45657**はWindowsカーネルのTCP/IP処理に起因するuse-after-free型のリモートコード実行脆弱性（CVSS 9.8）であり、**未認証の攻撃者がネットワーク越しに特殊パケットを送信するだけでSYSTEMレベルのコード実行を達成できる**という構造を持つ。Microsoftは「一定のネットワーク構成ではワーム化（自己伝播）が可能」と明記しており、Windows 11 23H2〜26H1（x64・ARM64）とWindows Server 2022/2025（Server Core含む）が影響を受ける。現時点でMicrosoftは「悪用可能性は低い」と評価しているが、複数のセキュリティ研究者はパッチリバースエンジニアリングによるエクスプロイト開発が進行中であるとし、「週単位ではなく日単位でPoC公開がある可能性」と警告している。また同時に修正されたBitLockerバイパス**CVE-2026-45585**（"YellowKey"）は、物理アクセスを持つローカル攻撃者が暗号化ドライブにアクセス可能となるもので、持ち出しリスクのある端末を抱える組織にも即時パッチ適用が求められる。

### TIOBE June 2026 — Python 19%割れ、C++がJavaを逆転、Rustが過去最高の12位に定着

2026年6月のTIOBE Indexで**Python**が初めて**19%を下回り**、2026年を通じた緩やかな下降トレンドが継続している。同時に**C++がJavaを逆転して3位に浮上**しており、AI/MLとシステム領域でのC++需要回復が背景にある。**Rust**は4月から引き続き12位を維持しており、当初の「上昇局面は一時的」という見方を覆す定着を見せている。

```rust
// Rust 1.87.0 (2026-04-16) の std::io::pipe() 新API
// プロセス間通信がunsafeなlibc bindingsなしに実現できるようになった
use std::io::{self, pipe, Read, Write};
use std::process::Command;

fn main() -> io::Result<()> {
    let (mut reader, mut writer) = pipe()?;

    // 子プロセスに書き込み
    writer.write_all(b"Hello from parent\n")?;
    drop(writer); // EOFを送出

    let mut buf = String::new();
    reader.read_to_string(&mut buf)?;
    println!("received: {buf}");
    Ok(())
}
```

また**Visual Studio 2026 June Update**がリリースされ、IDE全体にAIアシスタントが深く統合された。コード補完・リファクタリング提案・テスト自動生成がエディタ標準機能として統合されており、JetBrains IDEとの正面競争が本格化している。TIOBE編集長は「C++の3位返り咲きは低レイヤーとAI推論エンジン両方の需要を反映しており、JavaはSpring/Android以外での新規採用が減少している」とコメントしている。

### CVE-2026-45657 緊急対応ガイド — ワーム化可能Windowsカーネル RCEの影響評価と即時緩和策

```powershell
# === CVE-2026-45657 影響確認・パッチ適用チェックリスト ===

# [1] 影響するWindowsバージョン確認
# - Windows 11 23H2, 24H2, 25H1, 26H1 (x64 / ARM64)
# - Windows Server 2022, Server 2025, Server Core

# 現在のビルドを確認
$os = Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsBuildNumber
Write-Host "OS: $($os.WindowsProductName) | Build: $($os.OsBuildNumber)"

# [2] KB適用状況確認（6月Patch Tuesday = KB5065627 / KB5065628）
$patch = Get-HotFix | Where-Object { $_.HotFixID -match "KB5065627|KB5065628" }
if ($patch) {
    Write-Host "PATCHED: $($patch.HotFixID) installed on $($patch.InstalledOn)"
} else {
    Write-Host "WARNING: June 2026 Patch Tuesday not applied — CVE-2026-45657 EXPOSED"
}

# [3] 暫定緩和策（パッチ即時適用が困難な場合）
# TCP/IP経由の外部からのrawパケットをファイアウォールでフィルタリング
# ※ ワーム化は「一定のネットワーク構成下」でのみ成立 — DMZ上のWindows Serverが最優先
# netsh advfirewall set allprofiles firewallpolicy blockinbound,allowoutbound

# [4] CVE-2026-45585 (BitLocker "YellowKey") も同時確認
# 物理アクセス攻撃ベクタ — 持ち出し端末・共有ワークステーションで特に重要
# BitLockerのTPMバージョン・PRE-BOOT認証設定を見直す

Write-Host "=== June 2026 Patch Tuesday 最優先 CVE ==="
Write-Host "CVE-2026-45657  Windows Kernel TCP/IP RCE  CVSS 9.8  (ワーム化可能)"
Write-Host "CVE-2026-45585  BitLocker bypass 'YellowKey'  ローカル物理攻撃"
Write-Host "CVE-2026-50507  BitLocker bypass  CVSS 6.8   物理アクセス攻撃"
Write-Host "今週中のパッチ適用とインターネット公開のWindowsサーバー優先対応を推奨"
```

CVE-2026-45657はWindowsカーネルのTCP/IP処理内のuse-after-freeに起因しており、**認証不要・ユーザー操作不要でSYSTEM権限のコード実行**が可能だ。「Exploitation Less Likely」というMicrosoftの評価にもかかわらず、複数の研究者がパッチ差分解析でPoC開発中であることを公表しており、ワーム型マルウェアへの転用は時間の問題という見方が強い。今週はこの脆弱性を最優先事項として6月Patch Tuesdayを全管理対象Windowsに適用し、パッチが間に合わない場合はDMZ境界ファイアウォールでの外部からのTCPインバウンドフィルタリングを緊急緩和策として実施することを推奨する。
