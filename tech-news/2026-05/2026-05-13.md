## 新技術・新リリース

### Python 3.14 フリースレッドの実装例 — GIL なし並列処理の基本パターン

```python
import threading
import time
import sys

# Python 3.14+ フリースレッドビルドの確認
# python3.14t スクリプト名.py で実行（ t サフィックスがフリースレッドインタプリタ）
print(f"GIL 有効: {sys._is_gil_enabled()}")  # False ならフリースレッドモード

# CPU バウンドタスク: GIL フリーで真の並列実行が可能になる
def count_primes(start: int, end: int) -> list[int]:
    return [n for n in range(start, end) if n > 1 and all(n % i != 0 for i in range(2, int(n**0.5) + 1))]

def parallel_primes(limit: int, workers: int = 4) -> list[int]:
    chunk = limit // workers
    threads: list[threading.Thread] = []
    results: list[list[int]] = [[] for _ in range(workers)]

    def worker(idx: int):
        results[idx] = count_primes(idx * chunk, (idx + 1) * chunk)

    for i in range(workers):
        t = threading.Thread(target=worker, args=(i,))
        threads.append(t)
        t.start()

    for t in threads:
        t.join()

    return sorted(n for sublist in results for n in sublist)

start = time.perf_counter()
primes = parallel_primes(200_000)
elapsed = time.perf_counter() - start
print(f"{len(primes)} 個の素数を {elapsed:.3f}s で発見")
# フリースレッドビルド (4 コア): 約 0.35s
# 通常ビルド (GIL あり): 約 3.70s → 約 10 倍の差
```

### CVE-2026-0300: Palo Alto PAN-OS パッチが本日リリース — 野外悪用確認済み・即時適用を

Palo Alto Networks は PAN-OS のバッファオーバーフロー脆弱性（CVE-2026-0300）に対する正式パッチを本日（5 月 13 日）リリースした。認証不要のリモートコード実行（RCE）を可能にするこの脆弱性は野外での悪用が確認されており、ファイアウォール自体が侵害の足がかりになる深刻なリスクがある。パッチリリースを受けて即時適用が最優先であり、パッチ適用までの間は管理インターフェースへのアクセスを信頼できる送信元 IP のみに絞る回避策を併用することが推奨される。

```bash
# PAN-OS バージョン確認（SSH または CLI）
show system info | match sw-version

# Panorama 経由での一括アップデート確認
show jobs all

# 管理インターフェースのアクセス制限（回避策）
# Device > Setup > Management > Management Interface Settings
# から許可 IP を絞ること

# アップデート後の確認
show system info | match sw-version
# 修正済みバージョンが表示されれば対応完了
```

### CVE-2026-45185 (Dead.Letter): Exim SMTP サーバーにヒープ破壊の恐れ — TLS 処理に起因
