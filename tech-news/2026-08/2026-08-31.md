### 3. EU AI Act の透明性義務が 8 月 2 日に正式発効 — チャットボット開示・合成コンテンツラベル義務が始動

8 月 2 日、EU AI 規制法（AI Act）の第 50 条（透明性義務）が完全施行に入り、EU 域内で一般向けに展開される AI システムに対しチャットボット開示・合成コンテンツのマーキング・ディープフェイクラベリングが法的義務となった。これは人類史上初の包括的 AI 法規制の実施を意味し、世界の規制動向を大きく牽引するマイルストーンとなった。採用ツール・信用スコアリング・教育・法執行など高リスクカテゴリの完全義務化は 2027 年 12 月へ延期されたが、8 月の施行は多くの欧米テック企業が EU 向け UI に免責表示や AI ラベルを追加する直接的契機となった。一方、国連主導の「AI ガバナンス国際対話」も同月から実質的に稼働しており、EU の法的モデル・米国の自主規制アプローチ・中国の国家管理モデルという 3 つの競合フレームワークの調整が 2026 年秋以降の主要外交テーマとなっている。

### OpenAI GPT-Live リリース — 300ms 未満のネイティブ音声 AI でリアルタイム会話が刷新

OpenAI は ChatGPT Voice の基盤として GPT-Live をリリースした。従来の「音声→テキスト変換→LLM 処理→テキスト→音声」パイプラインを廃し、ネイティブ音声モデルとして端末から直接処理する設計を採用。レイテンシが 300ms 未満に到達し、感情的ニュアンスの表現も向上した。

```python
# OpenAI Realtime API — GPT-Live を使った音声会話の最小実装例
from openai import OpenAI
import base64

client = OpenAI()

# GPT-Live ネイティブ音声セッション（2026年8月時点のAPIイメージ）
response = client.audio.speech.create(
    model="gpt-live-1",          # ネイティブ音声モデル
    voice="alloy",
    input="こんにちは、今日の最新AIニュースをお届けします。",
    response_format="pcm",
    speed=1.0,
)

# 出力はストリーミングPCMデータ
with open("output.pcm", "wb") as f:
    for chunk in response.iter_bytes():
        f.write(chunk)
```

GPT-Live の登場は、AI 音声インターフェースが電話サポート・ヘルスケア問診・語学学習などリアルタイム対話を必要とするユースケースへ本格展開する基盤となる。DeepSeek の大規模資本調達・Anthropic の Claude Sonnet 系モデル拡充と並行してリリースされており、2026 年後半のマルチモーダル AI 競争が音声領域でも加速する見通しだ。
