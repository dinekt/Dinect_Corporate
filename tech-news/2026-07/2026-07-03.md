Anthropicの年換算収益（ARR）が$30Bを突破し、OpenAIの$24〜25Bを上回ったことが明らかになった。Anthropicの収益は2025年1月時点のわずか$1Bから15ヶ月で30倍超に拡大しており、エンタープライズ特化の戦略が功を奏した形だ。2026年5月28日にはシリーズHで$65Bの資金調達をクローズし、ポストマネーバリュエーションは$965BとOpenAIを超えて最高値のプライベートAIスタートアップとなった。こうした財務基盤の強化を背景に、Anthropicは7月3日、研究者向けの新製品**Claude Science**のベータ版をPro/Max/Team/Enterpriseユーザー（macOS・Linux）向けに公開した。Claude Scienceはこれまで個別のソフトウェアに散在していた科学ツールを単一環境に統合したAIワークベンチであり、3Dタンパク質構造の可視化、ゲノムブラウザトラックのレンダリング、化学構造の表示などをネイティブでサポートする。AI2が同時期にリリースした**MolmoMotion**（数秒の動画から自然言語の指示に基づいて物体の3D移動軌跡を予測するオープンVLM）とあわせ、AI×科学研究の領域における新たな競争フロンティアが開幕しつつある。AnthropicがOpenAIに対して収益・バリュエーションの両面で逆転を達成したことは、LLM市場の競争構図が根本的に変化したことを示している。

### 3. Microsoft SharePoint Server RCE 脆弱性（CVE-2026-45659、CVSS 8.8）が CISA KEV に追加 — 連邦機関の修正期限は 7 月 4 日

CISA（米国サイバーセキュリティ・インフラセキュリティ庁）は2026年7月1日、Microsoft SharePoint Serverに存在するリモートコード実行脆弱性**CVE-2026-45659**（CVSS 8.8）を既知悪用脆弱性カタログ（KEV）に追加し、連邦民間行政機関（FCEB）に対して7月4日までのパッチ適用を義務付けた。この脆弱性は信頼されないデータのデシリアライゼーションに起因するRCEであり、サイトメンバー権限（PR:L）以上の認証済み攻撃者がネットワーク経由でSharePointサーバー上の任意コードを実行できる。Microsoftは6月のPatch Tuesdayでこの問題をSharePoint Server Subscription Edition・2019・Enterprise Server 2016向けに修正済みであったが、リリース当初は「悪用可能性は低い（Less Likely）」と評価しており、今回のCISA KEV追加はその評価を覆す実際の悪用を受けたものだ。The Registerが指摘するとおり、ベンダーの事前評価と実際の悪用実績の乖離はCISA KEVが独立した重要性を持つことを改めて示している。攻撃者の帰属や最終目的は現時点では不明だが、SharePointは組織内ファイル共有・ポータルとして広く利用されているため、侵害が成功した場合は横移動（ラテラルムーブメント）や機密文書の漏洩につながるリスクが高い。

### Rust 1.96.1 リリース（2026-06-30）— libssh2 の RCE 級 CVE 3 件とMIRミスコンパイルを修正

Rust チームは2026年6月30日、パッチリリース**Rust 1.96.1**を公開した。Cargo が SSH トランスポートのために内包する libssh2 に存在する3件のCVEを修正するセキュリティ対応が主目的であり、Cargo の HTTP クライアントにおけるリトライ・タイムアウト処理の欠如と、MIR 最適化パスのミスコンパイルも同時に解消している。

```bash
# Rust バージョン確認と更新
rustup update stable

# 更新後の確認
rustc --version
# => rustc 1.96.1 (XXXX) 2026-06-30

cargo --version
# => cargo 1.96.1 (XXXX 2026-06-30)
```

修正された libssh2 の CVE は以下の3件：

- **CVE-2026-55200**（深刻度: 高）: 細工された SSH パケットの `packet_length` フィールドが過大な値を持つ場合にヒープ境界外書き込みが発生し、ヒープを破壊されてリモートコード実行につながる可能性がある。
- **CVE-2025-15661**: `sftp_symlink()` のヒープ越し読み取りによるメモリリークまたはクラッシュ。
- **CVE-2026-55199**: 鍵交換処理中の無限ループによる CPU 枯渇（DoS）。

次のメジャーリリースである **Rust 1.97.0** は現在 nightly チャンネル入りしており、stable リリースは 2026年7月9日頃が予定されている。1.96.0 で安定化されたCopy対応の新Range型（`core::range::Range`、`RangeFrom`、`RangeInclusive`）を使用するコードは 1.96.1 でもそのまま動作するため、今回のアップデートは breaking change なし。SSH リポジトリを扱う CI/CD パイプラインを持つプロジェクトは特に早急な更新が推奨される。

**出典**: [Rust Blog: Announcing Rust 1.96.1](https://blog.rust-lang.org/2026/06/30/Rust-1.96.1/) / [LinuxCompatible: Rust 1.96.1 Released](https://www.linuxcompatible.org/story/rust-1961-released-critical-cargo-security-patches-and-compiler-fix/)

### DirtyClone（CVE-2026-43503、CVSS 8.8）＆ BlueHammer（CVE-2026-33825）— Linux LPE とMicrosoft Defenderがランサムウェアに悪用

```bash
# === 2026-07-03 セキュリティ緊急対応チェックリスト ===

# ---- [1] SharePoint Server CVE-2026-45659 (CVSS 8.8) ----
# Deserialization RCE — 認証済み攻撃者（Siteメンバー権限）がネットワーク経由でRCE
# CISA KEV 追加: 2026-07-01 / 連邦機関修正期限: 2026-07-04
#
# 影響: SharePoint Server Subscription Edition / 2019 / Enterprise Server 2016
# 対処: 2026年5月 Patch Tuesday パッチを即時適用
# https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-45659

# ---- [2] DirtyClone CVE-2026-43503 (CVSS 8.8) ----
# Linux カーネル skbuff フラグメント処理の LPE (Local Privilege Escalation)
# 無権限ローカルユーザーが root に昇格可能 / ページキャッシュ操作のためディスク痕跡なし
# 影響: Linux カーネル v7.1-rc5 未満 / クラウド・Kubernetes・コンテナ環境に高リスク

# カーネルバージョン確認
uname -r
# v7.1-rc5 以上であればパッチ済み

# 一時緩和策（アップデートが即時不可の場合）
# 非特権ユーザー名前空間の無効化
sudo sysctl -w kernel.unprivileged_userns_clone=0

# 脆弱モジュールのブラックリスト登録
echo -e "install rxrpc /bin/false\ninstall esp4 /bin/false\ninstall esp6 /bin/false" \
  | sudo tee /etc/modprobe.d/dirtyclone.conf

# ---- [3] BlueHammer CVE-2026-33825 (Microsoft Defender) ----
# Microsoft Defender の脆弱性がランサムウェア攻撃で積極悪用 (CISA 警告)
# Windows Defender の自動更新 (Windows Update) を即時適用

# Windows Update 状態確認 (PowerShell)
# Get-WindowsUpdateLog | Select-String "Defender"

echo "Priority 1: CVE-2026-45659 (SharePoint RCE, CVSS 8.8) — CISA KEV 追加、野外悪用確認済み"
echo "Priority 2: CVE-2026-43503 DirtyClone (Linux LPE, CVSS 8.8) — PoC 公開済み"
echo "Priority 3: CVE-2026-33825 BlueHammer (Defender) — ランサムウェア悪用確認済み"
```

**DirtyClone（CVE-2026-43503）** は Linux カーネルのネットワークスタック、具体的には skbuff フラグメント処理サブシステム（`__pskb_copy_fclone()` / `skb_shift()`）における `SKBFL_SHARED_FRAG` フラグの伝播ミスに起因する。攻撃者は `/usr/bin/su` などの特権バイナリをメモリにロードしてネットワークパケットにリンクし、自分が制御するループバック IPsec トンネルを通じてカーネルにクローンさせることでページキャッシュを改ざん、root 権限を取得できる。この攻撃はカーネルログや監査ログにトレースを残さないため、フォレンジック的検出が困難であり、マルチテナントクラウドや Kubernetes クラスタへの影響が特に深刻だ。JFrog Security Research が6月25日に PoC を公開しており、パッチ済みバージョン（Linux v7.1-rc5 以上）への更新が最優先となる。**BlueHammer（CVE-2026-33825）** は Microsoft Defender の脆弱性がランサムウェアグループに積極悪用されているとして CISA が警告を発しており、Windows Update による Defender の即時更新が必要だ。
