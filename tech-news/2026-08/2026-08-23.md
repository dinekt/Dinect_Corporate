### 2. 北朝鮮系ハッカーが Rust の crates.io を標的に — arrayref（2.4億DL）に悪意あるコードを注入、UNC1069 と関連

8月20日、Rust パッケージレジストリ **crates.io** において **arrayref**・**append-only-vec**・**internment** の悪意あるバージョンが公開されたことが判明した（Wiz Blog / SecurityWeek / DevOps.com）。arrayref は全 Rust 環境の約75%に存在する**2億4,500万ダウンロード**の超人気クレートだ。攻撃者はメンテナーのアカウント認証情報を侵害したうえで、正規の `proc-macro2` を偽装した悪意あるマクロ `proc-macro1` への依存を混入させ、**コンパイル時にコードが実行される**という高度な手法を用いた。Wiz のセキュリティ研究者は、今回の攻撃インフラが北朝鮮の国家支援グループ **UNC1069** の過去のキャンペーン（Mastra・axios への攻撃など）と重複することを確認した。Rust セキュリティレスポンスチームは**86〜107分以内**に汚染パッケージを削除したが、開発者には `Cargo.lock` の監査が強く推奨されている。実際の悪用を示すエビデンスは現時点では確認されていないものの、クリプトウォレットを標的としていた可能性が指摘されている。

### Microsoft 8月 Patch Tuesday — 415脆弱性に対応、SharePoint RCE・Windows DNS RCE・Entra ID ゼロデイを含む

Microsoft が8月 Patch Tuesday として**415件の脆弱性**を修正した（CrowdStrike / Rapid7 / ZDI）。内訳は深刻度別に分析すると、特権昇格（EoP）が174件（42%）、リモートコード実行（RCE）が109件（26%）、情報漏えいが85件（20%）となっている。また Cisco も9件の重大な脆弱性を修正し、うち6件が**CVSS 10.0**（最大深刻度）と評価されている。

```bash
# === 2026-08-23 Microsoft Patch Tuesday 優先対応チェックリスト ===

# ---- [1] CVE-2026-63520: SharePoint Server RCE (Critical) ----
# リモートの認証済み攻撃者がコードを実行可能
# 影響: SharePoint Server 2019, SharePoint Server Subscription Edition

# SharePoint バージョン確認 (PowerShell)
# (Get-SPFarm).BuildVersion

# 修正済みビルドへのアップグレード — Microsoft Update Catalog 参照
# https://www.catalog.update.microsoft.com/

# ---- [2] CVE-2026-62878: Windows DNS Server RCE (Critical) ----
# 未認証リモートから特権付きでコード実行可能 — ユーザー操作不要
# 影響: Windows Server 2019/2022/2025 DNS Server ロール

# DNS Server 稼働確認
Get-Service -Name "DNS" | Select-Object Name, Status

# 優先度: 公開からの悪用速度が早い RCE 系は 72h 以内のパッチ適用を推奨

# ---- [3] Microsoft Entra ID — ゼロデイ (Max-Severity, Actively Exploited) ----
# すでに攻撃に悪用済み。認証関連の異常サインインを緊急調査
# Microsoft Defender / Entra ID Protection のアラートを確認

az ad signin-log list \
  --filter "createdDateTime ge $(date -u -d '48 hours ago' +%Y-%m-%dT%H:%M:%SZ)" \
  --query "[?riskState=='atRisk'].{user:userPrincipalName,ip:ipAddress,risk:riskState}" \
  -o table

# ---- [4] Cisco: 9 Critical Flaws (6 × CVSS 10.0) ----
# 内部テストで発見。IOS XE / NX-OS 系のバージョンを確認してパッチ適用
# https://tools.cisco.com/security/center/publicationListing.x

# ---- [5] Rust Cargo.lock 監査 (arrayref サプライチェーン攻撃) ----
# 悪意あるバージョン: arrayref (crates.io, 2026-08-20 公開分)
cargo audit
grep "arrayref" Cargo.lock  # バージョン固定を確認

echo "=== 2026-08-23 Patch Tuesday 優先対応サマリー ==="
echo "SharePoint RCE (CVE-2026-63520) : 即時パッチ適用"
echo "Windows DNS RCE (CVE-2026-62878): 即時パッチ適用 (未認証RCE)"
echo "Entra ID ゼロデイ               : 悪用確認済み — 直ちに調査"
echo "Cisco CVSS 10.0 × 6             : ファームウェアアップデート"
echo "Rust arrayref サプライチェーン  : cargo audit + Cargo.lock 確認"
```

Cisco のCVSS 10.0 パッチ6件は内部テストで発見されたため、現時点で積極的な悪用は報告されていないが、公開後に攻撃コードが出回る速度は過去の事例から非常に早い。**Windows DNS Server の未認証RCE**（CVE-2026-62878）はユーザー操作なしで成立するため、インターネット向けに DNS サービスを公開している環境では特に最優先での対応が求められる。

## セキュリティ

### Rust crates.io サプライチェーン攻撃・Microsoft Entra ID ゼロデイ・Cisco CVSS 10.0 — 8月23日 脅威トリアージ

```bash
# === 2026-08-23 セキュリティ脅威トリアージ ===

# ---- Rust / crates.io サプライチェーン攻撃 (UNC1069 / DPRK) ----
# 悪意あるクレート: arrayref, append-only-vec, internment (2026-08-20 公開)
# 攻撃手法: proc-macro1 (proc-macro2 を偽装) によりコンパイル時コード実行
# 対象: Rust 環境の ~75%、クリプトウォレット関連が主要ターゲット

# 1. 現在の依存関係に汚染クレートが含まれていないか確認
cargo audit --deny warnings

# 2. Cargo.lock でバージョンを確認
grep -E "^name = .(arrayref|append-only-vec|internment)." Cargo.lock
grep -E "^version" Cargo.lock | head -5

# 3. ビルド時に外部ネットワーク通信が発生していないか監視
# (CI パイプラインで network=none ビルドを推奨)

# ---- Microsoft Entra ID ゼロデイ (Actively Exploited) ----
# 最大深刻度。Microsoft がすでに悪用を確認
# 対策: MFA 強制 + 異常サインインの即時調査

# Azure CLI で過去48hのリスクのあるサインインを検出
az ad signin-log list \
  --filter "riskState eq 'atRisk' or riskState eq 'confirmedCompromised'" \
  --query "[].{UPN:userPrincipalName,IP:ipAddress,App:appDisplayName}" \
  -o table

# ---- Cisco Critical Patches (6 × CVSS 10.0) ----
# IOS XE / NX-OS 系が対象。内部テスト発見だが公開後の悪用リスクに注意
# https://tools.cisco.com/security/center/publicationListing.x

# ---- Windows DNS Server RCE (CVE-2026-62878) ----
# 未認証リモートから特権コード実行。DNS を外部公開している環境は最優先
# ファイアウォールで UDP/TCP 53 の外部公開範囲を最小化し、即時パッチ適用

# Windows Update 適用状況確認 (PowerShell)
# Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 10

echo "=== 脅威レベルサマリー ==="
echo "Entra ID ゼロデイ (悪用確認済み) : CRITICAL — 即時対応"
echo "Windows DNS RCE CVE-2026-62878   : CRITICAL — 即時パッチ"
echo "SharePoint RCE CVE-2026-63520    : HIGH    — 72h以内パッチ"
echo "Cisco CVSS 10.0 × 6             : HIGH    — ファームウェア更新"
echo "Rust crates.io 汚染 (DPRK)      : HIGH    — cargo audit + 監査"
```

今週の脅威で際立つのは**サプライチェーン攻撃の国家帰属**だ。DPRK（北朝鮮）系の UNC1069 が Rust という比較的新しい言語エコシステムを標的としたことは、攻撃者が安全性の高いとされる言語コミュニティにも侵入していることを意味する。`proc-macro1` のような正規パッケージを模した名称（タイポスクワッティング + 偽装）の手口はすでに npm・PyPI でも頻繁に観測されており、全言語エコシステムで依存関係のハッシュ固定・監査自動化・CI での network=none ビルドが標準対策となりつつある。
