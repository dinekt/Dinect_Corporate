# テックニュースデイリー 2026-04-09

## 本日のニュース TOP 3

### 1. Google Gemini 3.1 発表 — 2Mトークンコンテキスト、GPQA Diamond 94.3%
Google DeepMind が 4月5日に Gemini 3.1 をリリース。フラッグシップの Ultra は 200万トークンのコンテキストウィンドウを搭載し、大学院レベルの科学推論ベンチマーク GPQA Diamond で 94.3% を記録。ネイティブなマルチモーダル推論（テキスト・画像・音声・動画）とサンドボックス付きコード実行ツールが特徴。同時にリリースされた Flash-Lite は応答速度 2.5倍・出力生成速度 45% 向上で、プロダクション向けの高速モデルとして位置づけ。Ultra（推論深度）+ Flash-Lite（速度）の二モデル戦略で、Anthropic や OpenAI の単一フラッグシップ路線と差別化。

### 2. Docker Engine に認可バイパス脆弱性 CVE-2026-34040（CVSS 8.8）
Docker Engine に高深刻度の脆弱性が公開（4月7日）。1MB を超える API リクエストで Docker のミドルウェアがリクエストボディを無声で切り詰めるが、デーモン側は完全なリクエストをそのまま処理する。結果、認可プラグイン（AuthZ）は空のリクエストとして承認し、デーモンは完全なペイロードを実行。CVE-2024-41110 の不完全な修正が原因。Docker Engine 29.3.1 で修正済み。CI/CD パイプラインでDocker を利用している場合は即時アップデートを推奨。

### 3. Chrome ゼロデイ CVE-2026-5281 修正 — 2026年4件目
Google が Chrome の 21件の脆弱性を修正、うち CVE-2026-5281（Dawn の use-after-free）は野生での悪用が確認された 2026年4件目のゼロデイ。侵害されたレンダラープロセスから細工された HTML ページ経由で任意コード実行が可能だった。
