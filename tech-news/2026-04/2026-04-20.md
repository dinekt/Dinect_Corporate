### 1. Anthropic「Claude Mythos」— AIが自律的に数千件のゼロデイ脆弱性を発見、Project Glasswing 始動

Anthropic が開発した最新世代モデル「Claude Mythos Preview」がセキュリティ界に衝撃を与えている。過去数週間で主要OS・主要ブラウザ・その他重要ソフトウェアにわたる数千件のゼロデイ脆弱性を自律的に発見したことが明らかになり、中でも FreeBSD に17年間潜伏していたリモートコード実行脆弱性（CVE-2026-4747）を人間の介入なしに自律特定・実証まで完了させた事実は業界に大きな波紋を呼んでいる。Anthropic はそのサイバー攻撃能力が高すぎるとして一般公開を見送り、Amazon Web Services・Apple・Cisco・CrowdStrike・Google・Microsoft・Nvidia など主要企業50社に限定して「防御目的のみ」のアクセスを提供する「Project Glasswing」を立ち上げた。Foreign Policy は本日4月20日、「Claude Mythos Preview がサイバー計算を変える」と題した特集記事を掲載しており、AIが攻撃者・防御者双方の能力を同時に引き上げる転換点として位置付けている。AIを使ってAIをセキュアにするという逆説的な構図が、セキュリティ業界の慣行そのものを問い直している。

**開発者・運用者への影響**:
- ゼロデイ脆弱性の発見サイクルが「人間研究者が数ヶ月かける作業をAIが数時間で完了」する速度になりつつあり、パッチ提供側・攻撃者側の両方が加速している
- Project Glasswing 参加企業はオープンソースソフトウェアの重要コンポーネントへの事前アクセスが得られるが、参加しない中小規模の組織はパッチ適用のタイムラグに従来以上の注意が必要
- 防御目的限定での配布モデルは今後のデュアルユースAIモデルのガバナンス先例となる可能性が高い

### 2. Stanford AI Index 2026 — SWE-bench が1年で60%→100%近傍、透明性スコアは急落

Stanford HAI が年次発行する「AI Index 2026 Report」が公開され、AIの技術進歩と社会実装の乖離を数字で浮き彫りにした。コーディングベンチマーク SWE-bench Verified はわずか1年で60%から100%近傍まで上昇し、博士レベルの科学問題・競技数学でも人間ベースラインを上回るスコアを記録している。その一方で、同じモデルがアナログ時計を正しく読めるのは50.1%に過ぎないという事実は、ベンチマークが実用精度の代理指標として機能しない現実を示している。採用側の動向では組織採用率88%・大学生のAI使用率80%と急拡大しているが、主要フロンティアモデル開発者の責任AI評価の報告率は低く、Foundation Model Transparency Index の平均スコアは58点→40点に急落した。AI関連事故の記録件数も233件（2024年）→362件（2025年）と55%増加しており、能力向上と安全対策の非対称性が拡大している。米国民間AI投資は2025年に$2859億（中国の23倍）に達したが、米国に移住するAI研究者数は2017年比89%減・直近1年で80%減という深刻な研究者流出も記録された。

**開発者・ビジネスへの影響**:
- SWE-bench ほぼ100%という数字はコード自動化ツールの実用水準が急上昇していることを意味するが、実際のプロダクションコードへの適用はベンチマーク外の複雑性（組織固有のコンテキスト、レガシー依存）を伴う点に注意が必要
- 透明性スコアの急落は、AIプロバイダーの能力評価に加えて安全性・倫理評価の独立検証の重要性が高まっていることを示している
- 研究者流出データは、米国の長期的なAI競争力維持に対する構造的リスクとして政策立案者の間で注目されている

### 3. Apache ActiveMQ CVE-2026-34197（CVSS 8.8）— 13年潜伏のRCE脆弱性が野外で積極悪用中

Apache ActiveMQ に13年間発見されなかったリモートコード実行脆弱性 CVE-2026-34197（CVSS 8.8）が野外で積極悪用されており、CISA は4月16日に KEV（既知悪用脆弱性）カタログへ追加し、連邦機関に4月30日までのパッチ適用を義務付けた。Jolokia 管理API（`/api/jolokia/` エンドポイント）の不正入力検証を悪用し、攻撃者が攻撃者制御の Spring XML 設定ファイルを指定してリモートコードを実行できる。ActiveMQ 6.0.0〜6.1.1 では Jolokia が認証不要で公開されており、完全な未認証RCEが成立する。この脆弱性はセキュリティ研究者 Naveen Sunkavally が Claude AIアシスタントを用いて発見したという経緯もあり、AIが長期間見逃されていた脆弱性の発掘を加速させる現象の一例として注目されている。4月14日をピークに Fortinet FortiGuard Labs が数十件の悪用試みを観測しており、金融・製造・ヘルスケア分野のメッセージングインフラとして広く利用されている ActiveMQ は影響範囲が広い。

**対象バージョンとパッチ:**
| 系列 | 脆弱バージョン | 修正バージョン |
|------|----------------|----------------|
| 5.x | 5.18.0 – 5.18.3 | **5.19.4** |
| 6.x | 6.0.0 – 6.0.2 | **6.2.3** |

**開発者・運用者への影響**:
- 内部メッセージングやCI/CDパイプラインにActiveMQを使用している場合は即時バージョン確認が必要
- Jolokia APIが外部公開されていないか、デフォルト認証情報が残存していないかを優先的に確認すること
- ログ中の `brokerConfig=xbean:http://` パラメータを含むブローカー接続は侵害指標として即時調査対象とする

### Rust Foundation — エンタープライズ向け公式認定プログラムを開始

Rust Foundation が規制産業（金融・医療・航空宇宙等）を対象とした初の公式エンタープライズ認定プログラムを開始した。Rust 1.83 では非同期クロージャー（async closures）が安定化し、async/await 以来最も期待されていた機能がついて生産利用可能になった。Rust TIOBE 上位10位をキープしているが、2025年の急上昇トレンドは落ち着き、Go との棲み分けがより明確になりつつある。

```rust
// Rust 1.83 stable: async closures
use tokio::time::{sleep, Duration};

async fn process_with_retry<F, Fut, T>(f: F, retries: u32) -> Option<T>
where
    F: Fn() -> Fut,
    Fut: std::future::Future<Output = Option<T>>,
{
    for attempt in 0..retries {
        if let Some(result) = f().await {
            return Some(result);
        }
        sleep(Duration::from_millis(100 * 2u64.pow(attempt))).await;
    }
    None
}

#[tokio::main]
async fn main() {
    // async closure が安定化: クロージャ内で await が使えるように
    let result = process_with_retry(async || {
        // 非同期処理をインラインで記述可能
        Some(42u32)
    }, 3).await;
    println!("Result: {:?}", result);
}
```

### AI研究者の米国離れが加速 — 2017年比89%減

Stanford AI Index 2026 が明らかにした最も注目すべきデータの一つが研究者流入数の急減だ。米国への移住AI研究者数は2017年比89%減、直近1年だけで80%減となっており、米国の民間AI投資額が2025年に$2859億（中国の23倍）に達している状況と対照的だ。カリフォルニア州は AI安全開示・内部告発者保護を義務付ける SB 53 を成立させており、規制環境の整備が進む一方でイノベーション環境に対する懸念も高まっている。

McKinsey の「地政学と貿易構造 2026年版」では、AI関連貿易が前年比約40%成長（世界平均6.5%の約6倍）している一方、米中技術デカップリングの加速がクロスボーダーのAIサービス展開に複雑なコンプライアンス要件をもたらしていることを指摘している。インドはMeta・Google・Microsoftからの数十億ドル規模の投資約束を受け、2026年中に主要AI開発国としての地位を確立するとの見方が強まっている。
