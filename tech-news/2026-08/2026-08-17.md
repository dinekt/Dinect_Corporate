### NVIDIA NOOA オープンソース公開——Pythonネイティブなオブジェクト指向エージェントフレームワーク

NVIDIA Labsは**NOOA（NVIDIA Object-Oriented Agents）**をApache 2.0ライセンスでオープンソース公開した。NOOAはPythonネイティブのマルチエージェントフレームワークで、従来の関数ベース型エージェントアーキテクチャではなく**オブジェクト指向モデル**を採用している点が差異化ポイントだ。各エージェントを「エージェントオブジェクト」としてモデリングすることで、状態管理・ライフサイクル・エージェント間通信をより直感的に記述できる。

```python
# NOOA — 基本的なエージェント定義の例（Apache 2.0）
from nooa import Agent, tool, AgentRuntime

class ResearchAgent(Agent):
    """文献調査を担当するエージェント"""

    @tool
    def search_papers(self, query: str) -> list[dict]:
        """学術論文を検索して要約を返す"""
        # 実装はツール定義で差し替え可能
        return []

    @tool
    def summarize(self, text: str, max_tokens: int = 500) -> str:
        """テキストを要約する"""
        return ""

# エージェントを起動してタスクを実行
runtime = AgentRuntime()
agent = ResearchAgent(name="researcher", model="claude-sonnet-5")
result = runtime.run(agent, task="最新のLLM評価手法について調査してください")
print(result.output)
```

**インストール**:
```bash
pip install nooa
# または GitHub から最新版を取得
pip install git+https://github.com/NVIDIA/nooa.git
```

**② CVE-2026-62878 — Windows DNS Server RCE（未認証・スタックバッファオーバーフロー）**

Windows DNSサーバーに存在するスタックベースのバッファオーバーフロー脆弱性で、**リモートの未認証攻撃者がユーザー操作なしに昇格権限でコードを実行できる**。Active Directory環境でDNSサーバー機能を持つドメインコントローラが主な影響対象となるため、エンタープライズ環境への影響範囲が広い。Patch Tuesdayの更新プログラムを即時適用するとともに、外部ネットワークからのDNSポートへの直接アクセスを制限することが推奨される。

**③ Adobe 大規模パッチ（51件、うち33件がCritical）**

Adobeは5本のセキュリティアドバイザリを公開し、合計51件の脆弱性を修正した。対象製品はColdFusion・Adobe Commerce・Lightroom Classic・Content Credentials SDK・Adobe Campaign Classicで、51件のうち**33件がCritical**評価。ColdFusionは過去も標的にされやすい製品として知られており、パブリックアクセス可能なインスタンスは優先的に更新すること。
