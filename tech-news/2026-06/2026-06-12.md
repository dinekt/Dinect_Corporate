### 1. OpenAI、ChatGPT に「Dreaming V3」メモリアーキテクチャを搭載 — Microsoft は独自 AI モデル 7 種を公表、GitHub Copilot は AI Credits 従量課金制へ移行

### 2. Check Point VPN ゼロデイ CVE-2026-50751 が Qilin ランサムウェアに悪用中 — CVSS 9.3、CISA が連邦機関に緊急パッチを命令

Check Point は 6 月 8 日、Remote Access VPN・Mobile Access・Spark Firewall 製品に影響する**認証バイパス脆弱性 CVE-2026-50751**（CVSS 9.3）を公表した。IKEv1 レガシーキー交換プロトコルを使用している構成で証明書検証ロジックに欠陥があり、未認証の攻撃者が有効な認証情報なしに VPN セッションを確立できる。野良悪用は **5 月 7 日**まで遡って確認されており、6 月初旬に活動が急増した。**Qilin ランサムウェアアフィリエイト**との関連が中程度の確信度で帰属されており、被害組織は数十社規模に上る。CISA は同脆弱性を既知悪用脆弱性（KEV）カタログに追加し、**連邦民間行政機関（FCEB）に対して 6 月 11 日までのパッチ適用**を義務付けた（BOD 22-01）。IKEv1 を有効にしたまま運用している Check Point 環境は即時のパッチ適用と IKEv2 への移行が急務だ。

## 新技術・新リリース

### Microsoft June 2026 Patch Tuesday: 198 CVEs・3 ゼロデイ — CVE-2026-49160 は「OpenAI Codex が発見した初の AI 帰属 CVE」として記録

今月の Patch Tuesday は **198〜208 件**（速報によりカウント差あり）の CVE を含む過去最大規模の更新となった。3 件のゼロデイと 37 件のクリティカル脆弱性が対象に含まれる。特筆すべきは **CVE-2026-49160**（CVSS 7.5）で、HTTP.sys の HTTP/2 実装における**非制御リソース消費（CWE-400）**を突く「HTTP/2 Bomb」手法だ。研究者のテスト環境では IIS サーバーの **64 GB RAM を 45 秒で枯渇**させることが確認されており、無認証・ユーザー操作不要・低攻撃複雑度のリモート DoS となる。この脆弱性は **OpenAI の Codex** が発見・報告したものであり、主要な Patch Tuesday サイクルに掲載された**初めての AI 帰属 CVE** として記録されている。もう一方の注目株 **CVE-2026-45657**（CVSS 9.8）は Windows カーネルのワーム伝播可能な RCE で、未認証リモートから SYSTEM 権限コードの実行が可能だ。

```powershell
# CVE-2026-49160 暫定緩和策 — MaxHeadersCount レジストリ設定（PowerShell）
# HTTP/2 Bomb: HTTP.sys の非制御リソース消費を制限する
# Microsoft 公式 Bulletin 記載の手順に準拠（教育目的サンプル）

# --- 1. 現在の HTTP.sys パラメータを確認 ---
$regPath = "HKLM:\SYSTEM\CurrentControlSet\Services\HTTP\Parameters"
$current = Get-ItemProperty -Path $regPath -ErrorAction SilentlyContinue

Write-Host "=== Current HTTP.sys Parameters ==="
Write-Host "MaxHeadersCount : $($current.MaxHeadersCount)"
Write-Host "MaxRequestBytes : $($current.MaxRequestBytes)"

# --- 2. MaxHeadersCount を設定（推奨値: 100）---
# デフォルト MaxRequestBytes を使用している環境はこの設定が必要
$recommendedMaxHeaders = 100

Set-ItemProperty -Path $regPath `
    -Name "MaxHeadersCount" `
    -Value $recommendedMaxHeaders `
    -Type DWord

Write-Host "[+] MaxHeadersCount set to $recommendedMaxHeaders"

# --- 3. 設定を反映するため HTTP サービスを再起動（影響範囲を確認後） ---
# Stop-Service -Name W3SVC -Force  # IIS を使用している場合
# net stop http && net start http
Write-Host "[!] HTTP サービスの再起動を手動で実施してください"
Write-Host "[!] 恒久対応: Windows Update で 6 月累積パッチを適用すること"

# --- 4. 適用済みパッチの確認例 ---
Get-HotFix |
    Where-Object { $_.InstalledOn -ge (Get-Date).AddDays(-7) } |
    Select-Object HotFixID, Description, InstalledOn |
    Sort-Object InstalledOn -Descending
```

Microsoft は 6 月 10〜11 日（現地時間）に月例パッチを配布済みで、**Windows Update による即時適用**が最優先の対応となる。CVE-2026-49160 はレジストリ緩和策でも対処できるが、CVE-2026-45657 はパッチのみが有効なため、外部から直接到達可能な Windows Server 環境での速やかな適用が特に求められる。

## セキュリティ

### Check Point VPN CVE-2026-50751 ＋ Windows Kernel CVE-2026-45657 — 即時対応チェックリスト

今週は重大度の高い脆弱性が複数重なっており、特に **Check Point 環境**と**Windows Server** を運用する組織は即時の対応が必要だ。

```bash
# === Check Point VPN CVE-2026-50751 対応チェックリスト ===

# 1. 影響対象製品を確認
#    Remote Access VPN / Mobile Access / Spark Firewall が対象
#    Check Point サポートページ: https://support.checkpoint.com/results/sk/sk182823

# 2. IKEv1 レガシープロトコルの使用状況確認
#    SmartConsole → Gateway → VPN Clients → Remote Access → IKEv1 の有効可否を確認

# 3. 暫定緩和策（パッチ適用前）
#    - IKEv1 を使用する legacy Remote Access クライアントを無効化
#    - Machine Certificate 認証を必須化
#    - VPN ゲートウェイへのアクセスを信頼済み IP に限定

# 4. パッチ適用
#    Check Point HotFix sk182823 を適用（バージョン別対応を確認）

# 5. 侵害調査: 5/7 以降の不審な VPN セッションをログで確認
#    - SmartLog で IKEv1 セッションを一覧化
#    - Qilin ランサムウェア既知 IoC との照合

echo "[PRIORITY: CRITICAL] CVE-2026-50751 — Check Point VPN patch required immediately"
echo "CISA KEV: Federal agencies deadline was 2026-06-11"

# === Windows Kernel CVE-2026-45657 対応確認（PowerShell）===

# 6 月 Patch Tuesday 適用済みか確認
Get-HotFix |
    Where-Object { $_.InstalledOn -ge (Get-Date).AddDays(-7) } |
    Select-Object HotFixID, Description, InstalledOn |
    Sort-Object InstalledOn -Descending

echo "[PRIORITY: CRITICAL] CVE-2026-45657 CVSS 9.8 — Wormable Kernel RCE, apply Windows Update immediately"
```

**CVE-2026-50751（Check Point VPN）優先度: 緊急** — IKEv1 を使用中の環境はパッチ適用まで外部からの VPN 接続を制限し、5 月 7 日以降の認証ログを精査すること。**CVE-2026-45657（Windows Kernel）優先度: 緊急** — ワーム伝播可能な RCE のため、6 月 Patch Tuesday の月例パッチを最優先で適用すること。
