## ニュース一覧

### 1. DeepSeek V4 -- Engramアーキテクチャ、API入力$0.14/1M
**カテゴリ**: AI / オープンソース
**影響度**: ★★★★★

DeepSeekが3月中旬にV4をリリース。前世代のV3（671B/37Bアクティブ）からアーキテクチャを刷新した「Engram」アーキテクチャを採用。

**技術仕様**:
- 総パラメータ: 1兆（1T）
- アクティブパラメータ: 約320億（32B）/ トークン
- MoE（Mixture of Experts）+ Engramアーキテクチャで推論効率を大幅改善
- コンテキストウィンドウ: 128K（拡張オプションあり）

**API料金（DeepSeek公式）**:
- 入力: $0.14/1Mトークン、出力: $0.28/1Mトークン
- Claude Sonnet 4.6（$3/$15）と比較すると入力で約1/21

**開発者向けオープンウェイト**:
- Hugging Faceでウェイト公開（商用利用可能ライセンス）
- vLLM / llama.cpp での動作報告あり

**個人開発者への影響**:
- APIコストが制約だったユースケース（大量文書処理・バッチ翻訳等）の採算が一変する
- ローカルデプロイも技術的には可能だが1T規模はマルチGPUサーバーが必要
- **今すべきこと**: DeepSeek V4 APIキーを取得してClaude・GPT-5との品質コスト比較を実施。非機密文書の一括処理でのコスト削減を検討

### 2. 日本AI促進法 -- 2025年9月施行、イノベーション優先設計の全容
**カテゴリ**: 規制 / 日本市場
**影響度**: ★★★★☆

2025年5月28日に成立、2025年9月に全面施行された「AI関連技術の研究開発・利活用の促進に関する法律」（AI促進法）の運用状況が2026年3月現在で定着してきた。

**法律の特徴**:
- 「禁止・規制」ではなく「促進・支援」を主目的（EU AI Actとは対照的）
- マルチステークホルダー参加による継続的なアジャイル型更新方式
- 既存法（著作権法・個人情報保護法等）の解釈ガイダンスを併用
- 「世界で最もAIフレンドリーな国」を目標に掲げる

**個人事業主・中小企業への影響**:
- AI活用推進の文脈で補助金・税制優遇が受けやすい環境が整備中
- コンプライアンス負担が軽い（EU AI Actのような厳格な分類・審査なし）
- ただし2024年「AIビジネス事業者ガイドライン」の自主的遵守は求められる

**個人開発者への影響**:
- AIプロダクトを国内企業・官公庁向けに提供する際の法的ハードルが低い
- 政府の「AI活用環境整備」予算を活用したBtoG需要が見込める
- **今すべきこと**: 経産省・デジタル庁のAI活用補助金ページを確認。自社の行政・法人向けプロダクトの補助金申請可能性を調べる

出典: [FPF Japan AI Promotion Act解説](https://fpf.org/blog/understanding-japans-ai-promotion-act-an-innovation-first-blueprint-for-ai-regulation/) / [IAPP Japan AI Governance](https://iapp.org/news/a/japan-passes-innovation-focused-ai-governance-bill) / [gov-online.go.jp](https://www.gov-online.go.jp/hlj/en/november_2025/november_2025-08.html)

### 3. Claude Code -- /loopコマンドとVoice Mode展開
**カテゴリ**: AI / 開発ツール
**影響度**: ★★★★☆

3月16日時点でClaude Codeに追加・展開中の機能として以下が確認されている。

**Voice Mode（音声入力）**:
- スマートフォン版Claude（iOS/Android）でVoice Modeが全ユーザー展開中
- Claude Codeとのワークフロー連携（スマホで音声指示→PCのClaudeに送る形式）は非公式ながら実用的

**エージェント並列処理の強化**:
- `claude -p "タスク"` のサブエージェント呼び出しでの並列実行が安定化
- Git worktreeを使った複数エージェントの同時実行パターンが普及中

**コスト最適化の新パターン**:
- `/effort low` で軽量タスクのトークン消費を削減
- `ANTHROPIC_MODEL=claude-haiku-4-5` 環境変数でサブエージェントのモデルを切り替え可能

**個人開発者への影響**:
- 移動中のスマホ音声でタスク登録→帰宅後にClaudeが実行、というワークフローが現実的に
- **今すべきこと**: 繰り返し実行タスクに `/effort low` を設定してコスト削減。worktreeを使った並列開発を試す

出典: [Releasebot Anthropic Claude Updates](https://releasebot.io/updates/anthropic/claude) / [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

### 4. IDP市場 -- 2026年$141.6億、CAGR 26.2%で拡大中
**カテゴリ**: 市場 / ドキュメント処理
**影響度**: ★★★☆☆

Intelligent Document Processing（IDP）市場の2026年最新予測値が出揃った。

**主要数字**:
- 2026年市場規模: $141.6億（約2.1兆円）
- 2025年から: $105.7億（34%成長）
- 2034年予測: $910億、CAGR 26.2%
- Fortune 250企業の63%が既にIDP導入済み（金融セクターが71%でトップ）
- McKinsey試算: 文書ワークフロー自動化でコスト40%削減、処理時間70%短縮

**技術トレンド**:
- OCR単体からLLM統合IDPへのシフトが加速
- 「Human-in-the-loop（HITL）」機能が標準化（AWS IDP v0.5.0も搭載）
- 非構造化文書の理解精度が大幅向上

**個人開発者への影響**:
- IDP市場はまさに成長期。文書処理系プロダクトを持つ開発者にとってタイミングが良い
- BPOセンター向けに特化したIDPツールの商品化余地が大きい
- **今すべきこと**: IDP市場の競合マップを作成。MVP機能を「HITL付き非構造化文書処理」に絞る

出典: [Fortune Business Insights IDP Market](https://www.fortunebusinessinsights.com/intelligent-document-processing-market-108590) / [Bizdata360 IDP Guide](https://www.bizdata360.com/intelligent-document-processing-idp-ultimate-guide-2025/)
