### 1. OpenAI「Astra」が10年超の未解決数学問題を2,000ドルで解決 — Lean形式機械検証証明をGitHubで公開

OpenAIは8月1日、次世代モデル「**Astra**」の内部版が**群論・高次元幾何・符号理論・量子複雑性・格子暗号・極値組合せ論**にわたる10件の未解決問題を解決したと発表した。いずれも専門家が10年以上にわたり進展を得られなかった問題であり、特に注目されるのは**非ソフィック群（non-sofic groups）の構成**（群論の中心的未解決問題）と**最近傍ベクトル問題（CVP）の新しい限界**（格子暗号の核心）の2件だ。AstraはLean 4定理証明系を使って各解答を機械検証可能な証明（Lean certificate）として形式化し、`openai/ten-proofs`リポジトリで公開した。Leanのカーネルは証明がコンパイルするかどうかのバイナリ判定を与えるため、博士号も査読期間も不要でチェックできる。全解答探索に要したトークンコストはOpenAI自身の見積もりで**約2,000ドル**であり、数学研究の費用対効果に対する議論を引き起こしている。OpenAIは合わせて249ページの論文草稿と各問題の推論ウォークスルーを公開しており、AIによる純粋数学研究の「転換点」として研究コミュニティの注目を集めている。

### 2. VMware vCenter CVE-2026-59309/59310（CVSS 9.8）— 未認証認証バイパスとコード実行の複合脆弱性、Broadcomが緊急パッチ公開

Broadcomは7月29日、VMware vCenterに存在する2件のクリティカル脆弱性に関するセキュリティアドバイザリ**VMSA-2026-0006**を公開した。**CVE-2026-59309**（CVSS 9.8）はVMware Directory Serviceの認証バイパスで、ネットワークアクセスを持つ未認証の攻撃者がvCenter管理プレーンの認証を完全回避して制御を奪取できる。**CVE-2026-59310**（同CVSS 9.8）は、CVE-2026-59309と連鎖させることでリモートコード実行（RCE）に昇格できるバッファオーバーフロー系の欠陥とされる。現時点では野外での悪用証跡・PoECコードの公開は確認されていないものの、7月29日のKEV掲載以降、研究者によるスキャン活動が増加していることが報告されている。修正バージョンはvCenter 9.1.0.0300、9.0.2.0100、8.0 Update 3kであり、Broadcomは**ワークアラウンドなし**と明言しているためパッチ適用が唯一の対処策だ。vCenterは仮想化基盤全体の管理プレーンであるため、一台の侵害が多数のVMホストへの横展開につながるリスクがある。エンタープライズ仮想化環境を運用する組織は今週中の緊急適用を強く推奨する。

### DeepSeek V4 Flash 0731 が正式リリース — $0.14/Mで Terminal-Bench 82.7%、低コストモデル競争が激化

**DeepSeek V4 Flash 0731**がプレビューを終了し、入力$0.14/M・出力$0.28/Mの価格で正式提供を開始した。Terminal-Benchスコア**82.7%**を記録しており、エージェント型タスク（ターミナル操作・コーディング自動化）での実用性能が競合モデルと比較して際立っている。同時期に**Claude Sonnet 5**の導入価格（$2/M）が9月1日付で通常価格（$3/M）に戻ることが告知されており、Anthropicは合わせて同モデルが等価テキスト当たり最大35%多くのトークンを消費するトークナイザー変更を行うことを明らかにした。低コスト・高性能モデルの選択肢が急速に広がる中、コスト最適化を重視するユーザーは複数モデルのベンチマーク比較を定期的に行う重要性が増している。

```python
# DeepSeek V4 Flash / Claude Sonnet 5 コスト試算（2026年8月時点）
# 単位: USD / 100万トークン (入力)

models = {
    "DeepSeek V4 Flash 0731":  {"input": 0.14, "output": 0.28},
    "Claude Sonnet 5 (9/1前)": {"input": 2.00, "output": 10.00},
    "Claude Sonnet 5 (9/1以降)": {"input": 3.00, "output": 15.00},
}

# 1日あたり 1,000万トークン（入力8M + 出力2M）の場合の月次コスト試算
monthly_input_M  = 8 * 30   # 240M tokens/month
monthly_output_M = 2 * 30   # 60M tokens/month

for model, pricing in models.items():
    cost = monthly_input_M * pricing["input"] + monthly_output_M * pricing["output"]
    print(f"{model}: ${cost:,.0f}/月")

# 出力例:
# DeepSeek V4 Flash 0731:    $50/月
# Claude Sonnet 5 (9/1前):   $1,080/月
# Claude Sonnet 5 (9/1以降): $1,620/月
```
