## ニュース一覧

### 1. Claude Code v2.1.76 -- MCP Elicitation対応と/effortコマンド
**カテゴリ**: AI / 開発ツール
**影響度**: ★★★★★

Claude Code v2.1.76（3月14日リリース）で以下の重要機能が追加された。

**MCP Elicitation（構造化入力要求）**: MCPサーバーがタスク実行中にフォームUIやブラウザURLでユーザーからの入力を要求できるようになった。`Elicitation`と`ElicitationResult`フックで応答をインターセプト・オーバーライド可能。複雑なワークフローを中断せずにパラメータ収集ができる。

**その他の主な追加**:
- `/effort` コマンドで思考量をlow/medium/high/xhigh、またはプロンプト内で`ultrathink`と入力して最大推論を一時起動
- `-n / --name` フラグでセッションの表示名をCLI起動時に設定
- `worktree.sparsePaths` 設定で大規模モノレポのsparse-checkout対応
- `PostCompact`フックがコンパクション完了後に発火

**バグ修正**: コンパクション後のdeferred toolsがinput schemaを失う問題、スラッシュコマンドエラー、プラン再承認問題、Windowsでのnpmインストール問題を修正。

**個人開発者への影響**:
- MCPサーバーを使ったカスタムワークフローでユーザー入力が必要な場面に対応できる
- モノレポ環境でのClaude Code利用が実用的になる
- **今すべきこと**: `npm update -g @anthropic-ai/claude-code` でv2.1.76に更新。/effortコマンドを複雑な設計タスクで試す

出典: [Releasebot - Claude Code March 2026](https://releasebot.io/updates/anthropic/claude-code) / [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

### 2. Python 3.14.0a6 -- Pi Dayリリース、フリースレッド本格化
**カテゴリ**: 言語 / 開発
**影響度**: ★★★★☆

3月14日（円周率の日）にPython 3.14.0a6が恒例通りリリース。2026年10月の正式リリースに向けた最新アルファ版。

**主な新機能**:
- **PEP 779 フリースレッド正式サポート**: シングルスレッドのオーバーヘッドが3.13の約40%から一桁%台に削減。マルチスレッドCPUワークロードで最大3.1倍の高速化
- **PEP 750 t-strings（テンプレート文字列）**: f-stringsの構文でカスタム文字列処理が可能。SQLインジェクション対策等に応用可能
- **PEP 649 遅延アノテーション評価**: アノテーションの意味論が改善される
- **compression.zstd モジュール**: Zstandard圧縮アルゴリズムのネイティブ対応（PDF・大容量ファイル処理に有効）
- **PyREPL構文ハイライト**: インタラクティブシェルが視覚的に改善

**個人開発者への影響**:
- I/O重視のデスクトップアプリでcompression.zstdが使えると処理速度向上の余地がある
- フリースレッド化でPythonの並行処理がGILなしで動く時代が本格到来
- **今すべきこと**: `pyenv install 3.14.0a6` でテスト環境構築。zstd圧縮を大容量ファイル処理ツールで検証

出典: [Python.org Release](https://www.python.org/downloads/release/python-3140a6/) / [Real Python News](https://realpython.com/python-news-march-2026/)

### 3. GPT-5.4 -- Computer Use APIで画面操作が可能に
**カテゴリ**: AI / API
**影響度**: ★★★★★

OpenAIがGPT-5.4をリリース（3月14日現在API安定稼働中）。最大の特徴はComputer Use APIとSWE-bench Verified約80%達成。

**主な仕様**:
- コンテキストウィンドウ: 272K（API/Codexでは最大1M）
- 推論努力レベル: none/low/medium/high/xhigh の5段階設定可能

- SWE-bench Verified: 約80%（Claude Opus 4.6と同等水準）
- 料金: Standard $2.50/1M入力、$15.00/1M出力

**個人開発者への影響**:
- BPOや書類処理の自動化をGUI操作レベルで組める可能性（スキャニング業務での応用あり）
- Claude Opus 4.6との比較でコスト設計の検討が必要
- **今すべきこと**: Computer Use APIのドキュメントを確認し、スキャン後の手作業ワークフロー自動化の可能性を検証
