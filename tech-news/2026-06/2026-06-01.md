### 1. Miasma サプライチェーン攻撃 — @redhat-cloud-services npm 32 パッケージが本日改ざん、週 8 万 DL 環境に認証情報窃取ワームが侵入

本日 2026 年 6 月 1 日、npm の `@redhat-cloud-services` スコープ配下の公式パッケージ **32 本・計 96 バージョン**が侵害された。攻撃キャンペーン名は **「Miasma: The Spreading Blight」** で、過去に TeamPCP グループが使用した Mini Shai-Hulud マルウェアファミリーの新亜種と分析されている。攻撃者は Red Hat 社員の GitHub アカウントを侵害し、npm の GitHub Actions Trusted Publishing を悪用して有効なプロベナンス付きの悪意あるバージョンを公開することでコードレビューを迂回した。ペイロードは `preinstall` フック経由で発火し、GitHub Actions のシークレットに加え AWS・GCP・Azure・Kubernetes・HashiCorp Vault・CircleCI のトークンを一括吸い出す多段階クレデンシャルハーベスターとして機能する。対象パッケージの累計週次ダウンロード数は約 **8 万件**にのぼり、2026 年 6 月 1 日以降にインストールした環境はすべて侵害済みとみなして対処することが強く推奨される。

## 新技術・新リリース

### Microsoft Build 2026 — .NET/Python 向け Agent Framework と Project Polaris のエージェント開発スタック

Microsoft は Build 2026 で .NET/Python 向け **Agent Framework** を本番リリースし、マルチエージェント協調・エージェント間通信 API・Azure AI Foundry 統合を標準提供した。以下は Python 向け Agent Framework の最小構成例だ。

```python
# Microsoft Agent Framework (Build 2026) — Python 最小構成例
from azure.ai.agents import AgentClient, AgentOptions
from azure.identity import DefaultAzureCredential

credential = DefaultAzureCredential()
client = AgentClient(
    endpoint="https://<your-foundry-endpoint>.services.ai.azure.com",
    credential=credential,
)

# エージェントの作成（Project Polaris モデルを指定）
agent = client.agents.create(
    AgentOptions(
        model="polaris-reasoning-1",
        name="code-reviewer",
        instructions="You are a senior code reviewer. Identify bugs and suggest improvements.",
    )
)

# スレッド作成 → メッセージ送信 → 実行 → ポーリング
thread = client.threads.create()
client.messages.create(thread_id=thread.id, role="user", content="Review this PR diff: ...")
run = client.runs.create(thread_id=thread.id, agent_id=agent.id)
run = client.runs.poll(thread_id=thread.id, run_id=run.id)

for msg in client.messages.list(thread_id=thread.id):
    if msg.role == "assistant":
        print(msg.content[0].text.value)
```

```bash
# Azure AI Foundry CLI でのエージェントデプロイ
az extension add --name ai-foundry
az ai-foundry agent deploy \
  --name code-reviewer \
  --model polaris-reasoning-1 \
  --resource-group <rg> \
  --workspace <foundry-workspace>
```

Copilot Workspace（GA）では、自然言語のイシュー説明から Issue → Plan → Pull Request の全工程をエージェントが自律実行する。Windows Agent Store は OS レベルのエージェントマーケットプレイスとなり、サードパーティの自律エージェントを Windows 11 に直接インストールできるようになる見込みだ。


### Microsoft Defender CVE-2026-41091 / CVE-2026-45498 — CISA KEV 追加、連邦機関は 6/3 までに修正必須

Microsoft Defender に存在する 2 件の脆弱性が **CISA Known Exploited Vulnerabilities（KEV）** カタログに追加され、連邦行政機関（FCEB）は **2026 年 6 月 3 日**までに修正パッチの適用が義務付けられた。**CVE-2026-41091**（CVSS 7.8）は権限昇格の脆弱性で、悪用に成功した攻撃者は SYSTEM 権限を取得できる。**CVE-2026-45498**（CVSS 4.0）は Defender に対するサービス妨害（DoS）バグで、セキュリティ製品そのものを無効化するリスクがある。Windows Update を介したパッチは既に提供済みであり、エンドポイント管理ソリューション（Intune / WSUS）を使用する組織は優先度を上げて展開することが推奨される。

```powershell
# Windows Update 経由でのパッチ適用状況確認
Get-HotFix | Where-Object { $_.InstalledOn -ge (Get-Date).AddDays(-7) } | Sort-Object InstalledOn -Descending

# Intune 管理環境: デバイスコンプライアンス状態の確認
# Azure Portal > Intune > デバイス > コンプライアンスポリシー で適用状況をフィルタ

# WSUS 環境: 未適用デバイスのレポート生成
Get-WsusUpdate -Classification Security -Status NotInstalled |
  Where-Object { $_.Update.Title -match "Defender" } |
  Select-Object -ExpandProperty Update | Select-Object Title, ArrivalDate
```
