### 2. cPanel & WHM に CVSS 9.8 認証バイパス CVE-2026-41940 — CRLF インジェクション悪用で 150 万インスタンス露出、CISA 修正期限は明日 5 月 3 日

cPanel が 4 月 28 日に開示した **CVE-2026-41940**（CVSS **9.8**）は、Basic 認証パスワード処理中の **CRLF インジェクション**とサーバー側セッションファイルの二重保存（テキスト＋ JSON キャッシュ）における競合状態を組み合わせることで、未認証の攻撃者がリモートから管理者相当のセッションを乗っ取れるという重大な欠陥だ。WatchTowr Labs の解析によれば、悪意ある入力を Basic Auth パスワードフィールドに送信するだけで任意のセッション key-value を信頼済みストアに書き込め、認証チェックを完全にバイパスできる。Shodan クエリでは現時点でも約 **150 万件**の cPanel インスタンスがインターネットに露出しており、Help Net Security は **2 月 23 日**時点でゼロデイとしての標的型悪用が始まっていた可能性を指摘している。CISA はすでに既知悪用脆弱性（KEV）カタログに追加済みで、連邦機関に対し **5 月 3 日（明日）**までの修正を義務付けている。対策は最新バージョン（11.110.0.97・11.118.0.63・11.126.0.54・11.132.0.29 等）へのアップグレード、またはポート 2083・2087・2095・2096 へのインバウンドトラフィック遮断と `cpsrvd` / `cpdavd` サービスの停止。

### Anthropic Claude がクリエイティブツール 9 製品と統合 — Blender・Autodesk・Adobe・Ableton・Splice で AI ネイティブワークフローが本格化

Anthropic が Claude を **Blender・Autodesk・Adobe・Ableton・Splice** を含む 9 つのクリエイティブソフトウェアと接続するコネクター群を公開した。設計・音楽・3D モデリングといった専門的なクリエイティブ領域への Claude 統合は、テキスト生成・コード補完にとどまらない「コンテキストを理解するドメイン特化アシスタント」としての方向性を示している。内部的には MCP（Model Context Protocol）ベースでツールとの通信が実装されており、各アプリケーションが Claude にシーン情報・プロジェクト状態・タイムラインを渡すことで高精度な提案が可能となる。

```python
import anthropic

client = anthropic.Anthropic()

# Blender のシーン情報を Claude に渡してアニメーション改善提案を得る例
scene_context = {
    "objects": ["character_rig", "camera_main", "light_sun"],
    "current_frame": 42,
    "keyframes": [0, 24, 60, 90],
}

message = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=1024,
    system="あなたは 3D アニメーションの専門家です。Blender のシーン情報をもとに改善提案を行います。",
    messages=[
        {
            "role": "user",
            "content": f"以下の Blender シーン情報をもとに、モーションをより自然にするためのキーフレーム配置を提案してください。\n\n{scene_context}",
        }
    ],
)

print(message.content[0].text)
```

クリエイティブ分野への AI アシスタント統合は、生産性向上にとどまらず「コンセプト段階から実装まで一貫してアシストされる」新しいワークフローを生み出しつつある。Ableton・Splice との統合では音楽制作における楽器打ち込みやサンプル選定の提案機能も含まれており、ソフトウェアと AI の境界が曖昧になる時代の到来を示している。

### cPanel CVE-2026-41940 技術詳解 — CRLF ＋セッション競合の 2 段階攻撃で完全管理者権限取得、影響版は即時アップグレードを

CVE-2026-41940 の攻撃チェーンは大きく二段階に分かれる。**第一段階**では HTTP Basic 認証のパスワードフィールドに `\r\n` （キャリッジリターン＋ラインフィード）を含む文字列を送信し、cPanel が内部的にセッションファイルへ書き込む際に任意の key-value ペアを注入する。**第二段階**では cPanel が raw テキストと JSON キャッシュの両形式でセッションデータを管理していることに起因する競合状態を突き、注入済みセッションキーで管理者権限の認証チェックを通過する。特に厄介なのは認証前（**Unauthenticated**）に悪用可能であり、有効なアカウントや資格情報が一切不要な点だ。Cloudflare は 4 月 30 日に緊急 WAF ルールをリリースしており、Cloudflare 配下のサイトには仮の緩和が適用されている。それ以外の環境では cPanel の最新版へのアップグレードが根本的な解決策となる。影響を受けるバージョンの一覧と修正済みバージョンは NVD（CVE-2026-41940 詳細ページ）で確認できる。

### CISA KEV 更新情報 — cPanel CVE-2026-41940（CVSS 9.8）を追加、連邦機関の修正期限は 5 月 3 日

CISA は CVE-2026-41940 を既知悪用脆弱性（KEV）カタログに追加し、連邦民間行政府機関（FCEB）に対して **2026 年 5 月 3 日**までのパッチ適用を義務付けた。民間組織に法的義務はないが、実際に野外悪用が確認されているため、CISA は cPanel を運用するあらゆる組織に対して同等のタイムラインでの対応を強く推奨している。
