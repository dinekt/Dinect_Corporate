## 開発ツール・フレームワーク

- **Claude Code v2.1.145（5/19 リリース）**: 最新版の主な変更点:
  - `claude agents --json` でライブセッション一覧を JSON 出力（tmux-resurrect・ステータスバー・セッションピッカーとのスクリプト連携用）
  - OTEL スパンに `agent_id` / `parent_agent_id` 属性を追加し、バックグラウンドサブエージェントのトレースが親 Agent ツールスパン配下に正しくネスト
  - ステータスラインに GitHub リポジトリ・PR 情報を追加
  - `/plugin` のディスカバリー画面でインストール前にコマンド・エージェント・スキル・フック・MCP/LSP サーバーの詳細を確認可能
  - `claude agents` のターミナルタブタイトルに入力待ちエージェント数を表示
  ```bash
  npm update -g @anthropic-ai/claude-code
  claude --version  # 2.1.145 を確認
  claude agents --json  # セッション一覧 JSON 取得
  ```
  （出典: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [GitHub Releases](https://github.com/anthropics/claude-code/releases)）

- **Anthropic — Claude Design（Anthropic Labs、4/17 GA）**: プロンプトからデザイン・プロトタイプ・スライド・ワンページャーを生成するビジュアル作成ツール。Claude Opus 4.7 ベース。コードベースとデザインファイルを読み込み、チームのデザインシステムを自動適用。Claude Pro / Max / Team / Enterprise で利用可能（リサーチプレビュー）。Figma 株が発表当日 7.28% 下落。（出典: [TechCrunch](https://techcrunch.com/2026/04/17/anthropic-launches-claude-design-a-new-product-for-creating-quick-visuals/), [Anthropic](https://www.anthropic.com/news/claude-design-anthropic-labs)）

- **Code with Claude — 東京イベント（6/10-11）**: 開発者・創業者向けフルデイのワークショップ。Anthropic エンジニアとの 1:1 オフィスアワー、最新機能のライブデモを提供。東京拡張セッションは 6/11。（出典: [claude.com/code-with-claude/tokyo](https://claude.com/code-with-claude/tokyo), [Gend Blog](https://www.gend.co/blog/code-with-claude-live-demos-san-francisco-london-tokyo)）

- **Google Antigravity 2.0（I/O 2026 発表）**: デスクトップアプリ・CLI・SDK・Managed Agents・エンタープライズ展開（Gemini Enterprise Agent Platform）を統合したエージェントファースト開発プラットフォーム。`AGENTS.md` によるエージェント定義のバージョン管理、Android アプリ自動生成機能を含む。（出典: [MarkTechPost](https://www.marktechpost.com/2026/05/19/google-launches-antigravity-2-0-at-i-o-2026-a-standalone-agent-first-platform-with-cli-sdk-managed-execution-and-enterprise-support/)）
