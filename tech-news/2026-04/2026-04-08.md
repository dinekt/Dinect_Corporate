# テックニュースデイリー 2026-04-08

## 本日のニュース TOP 3

### 1. GPUBreach — Nvidia GDDR6搭載GPUでRowhammer攻撃によるフルシステム乗っ取りが実証
ハードウェアレベルの攻撃手法「Rowhammer」をNvidiaのGPUに応用した研究が公開され、大きな波紋を呼んでいる。トロント大学の研究チームはRTX 3060で1,171回のビットフリップ誘発に成功し、4月6日に開示された「GPUBreach」はGDDR6のビットフリップを権限昇格・フルシステム侵害まで繋げることを実証した。テスト対象25種のNvidiaディスクリートGPUのうち、GDDR6搭載カードのほとんどが脆弱であることが確認された（GDDR6XおよびGDDR7搭載のRTX 3090/4090は対象外）。RowhammerはDRAMセルの物理特性を利用するため、ファームウェアでの修正は原理的に不可能であり、緩和策はECCメモリや硬件設計レベルの変更が必要。AI学習インフラに世界中で大量展開されているGDDR6 GPUが対象となるため、データセンター運用者への影響が注目されている。

**開発者への影響**:
- AI学習・推論インフラのGPU構成を把握しておくことが重要に。GDDR6搭載カードが脆弱対象
- ソフトウェアパッチで解消されない点を前提に、アクセス制御・テナント分離の設計方針を見直すタイミング

### 2. EU、Apple に €500M・Meta に €200M の DMA 違反制裁金 — 史上初の本格執行
欧州委員会がDigital Markets Act（DMA）に基づく初の非準拠決定を下し、Appleに5億ユーロ（約860億円）、Metaに2億ユーロ（約340億円）の制裁金を課した。Appleの違反はApp Storeの「アンチステアリング」規則——DMAが明示的に求める、開発者がApp Store外の購入先にユーザーを自由に誘導できる仕組みが未実装だった点。Metaの違反は、パーソナライズ広告の同意モデルにおいて「広告あり無料」か「有料無広告」の二択しか提示しなかったことが、同等の代替手段を求めるDMA要件に反するとされた。両社には60日以内の準拠か追加の定期制裁金が課せられる見通し。制裁金額が理論上の上限（年間全世界売上の10%）を大幅に下回っていることについては、トランプ政権による報復関税への牽制として規模が抑制されたとの見方もある。

**開発者への影響**:
- EU向けアプリ・SaaSを持つプラットフォームは、DMAの「公正なアクセス」・「アンチステアリング禁止」要件を改めて確認する必要がある
- 実際の執行例が出たことで、コンプライアンス対応の優先度が一段上がった

### 3. Yann LeCunがAMI Labsを設立、ヨーロッパ史上最大のシードラウンド1,030億円を調達
MetaのチーフAIサイエンティストでチューリング賞受賞者のYann LeCunが同社を離れ、パリにAMI Labs（Advanced Machine Intelligence）を設立。3月9日、NvidiaやBezos Expeditions、Temasekらから**10.3億ドル（プレマネー評価額35億ドル）**のシードラウンドを調達し、ヨーロッパ史上最大のシードラウンドを記録した。AMIの哲学はLLMパラダイムへの正面からの挑戦——LeCunはLLMが「テキストから学習するが現実から学習しない」という根本的限界を持つと主張し、代わりに**JEPA（Joint Embedding Predictive Architecture）**を中心に据える。JEPAはピクセルやトークン単位の予測ではなく、世界の抽象的な表現を予測することで物理的因果関係を理解できるAI構築を目指す。ロボティクス・医療・製造業への応用を想定しており、LLM中心の現在のAI産業に対する最も大規模な対抗馬として位置付けられる。

**開発者への影響**:
- LLMが「テキスト理解」に特化した手段であるという視点が広まり、タスクに応じた適切なAIアーキテクチャの選択を意識するフェーズに入っている
- JEPAはMeta AI ResearchでオープンソースとしてリリースされているI-JEPA・V-JEPAから発展したもので、研究動向として追う価値がある

## 新技術・新リリース

### Java 26 GA — PEM API、HTTP/3クライアント、遅延定数（10 JEPs）
3月17日にJava 26が正式GA。主要JEP：

- **JEP 524（PEM API）**: 暗号鍵・証明書・CRLをPEM形式でエンコード/デコードする標準API追加。ポスト量子暗号への移行を意識した設計
- **HTTP/3サポート**: 標準HTTPクライアントAPIがHTTP/3サーバーへの接続に対応。コード変更はほぼ不要
- **JEP 516（AOTキャッシュ強化）**: ZGC含む全GCにわたる起動・ウォームアップ時間の短縮
- **プリミティブ型のパターンマッチング（第4プレビュー）**: `instanceof`・`switch` でのプリミティブ対応
- AppletAPIが完全削除（近代ブラウザ・JDKのいずれも非対応のため）

```java
// Java 26: 新しいPEM APIでRSA公開鍵を読み込む例
import java.security.pem.PemDecoder;
import java.security.PublicKey;
import java.nio.file.Files;
import java.nio.file.Path;

String pemContent = Files.readString(Path.of("public_key.pem"));
PublicKey publicKey = (PublicKey) PemDecoder.of().decode(pemContent).getKey();
```

### Rari — RustランタイムのReact Server Componentsフレームワークが注目を集める
Hacker Newsで大きな注目を集める新フレームワーク「Rari」（Runtime Accelerated Rendering Infrastructure）が登場。HTTPサーバー・RSCレンダラー・ルーティングをすべて**Rustで実装**し、V8エンジンを内包する構成。ビルドツールチェーンはRustベースのRolldown-Viteと`tsgo`を採用。50並列接続のベンチマーク上でNext.jsの**約46.5倍のスループット**（74,662 req/s vs 1,605 req/s）を計測。Rustツールチェーンのインストール不要で、npmパッケージ内にビルド済みバイナリが同梱される。

```bash
# Rariプロジェクト作成と起動
npx create-rari-app my-app
cd my-app && npm install
npm run dev
```

### Node.js ネイティブTypeScript実行がデフォルトに + Rolldownがエコシステム標準バンドラーへ
Node.js 23.6/22.18から「Type Stripping」がデフォルト有効になり、`.ts`ファイルを`node`コマンドで直接実行可能に。`ts-node`や`tsc`の別途インストールが不要になった。また Rolldown（Rustベースのバンドラー）が2026年前半にNuxt・SvelteKit・AstroなどViteエコシステム全体のデフォルトバンドラーになる見通し。Biome・Turbopack・Rolldownと、RustベースのツールがJSベースのビルドインフラを系統的に置き換える流れが鮮明になっている。

## セキュリティ

### GPUBreach/GPUHammer: Nvidia GDDR6 Rowhammer攻撃（ハードウェア起因、パッチ不可）
- **影響**: GDDR6搭載のNvidiaディスクリートGPU（Ampere/Turing世代の多くのカード）
- **リスク**: DRAM物理特性を悪用したビットフリップ → 権限昇格 → フルシステム侵害
- **緩和**: ファームウェアでの修正は原理的に不可能。ECC対応ハードウェアへの移行、テナント分離の強化が現実的対策
- **AI文脈**: AI学習クラスタに大量展開されているGDDR6ベースのGPUが対象。クラウドプロバイダー各社がインパクト評価中

### CVE-2026-5281: Chrome WebGPU/Dawn Use-After-Free（実悪用確認、CISA KEV入り）
- **影響**: Chrome 146.0.7680.177未満（Win/macOS/Linux）、Chromiumベース全ブラウザ
- **リスク**: 悪意あるWebページ経由でのリモートコード実行。DawnはWebGPUとGPUハードウェアの仲介レイヤー
- **対応**: Chrome/Edgeを即時最新版（146系）に更新。Electron/Puppeteer環境も要確認
- **CISA期限**: 連邦機関への適用期限 **4月15日**。今年4本目の実悪用確認ゼロデイ

### CVE-2025-59528: Flowise AIエージェントビルダーにCVSS 10.0のRCE — 15,000インスタンスが未パッチ
LLMワークフロー・AIエージェント構築用のオープンソースプラットフォームFlowiseに、CVSS 10.0の深刻なコードインジェクション脆弱性。`CustomMCP`ノードがユーザー入力の`mcpServerConfig` JSONをサニタイズなしで実行し、攻撃者がNode.jsの`child_process`や`fs`モジュールへ直接アクセス可能。Flowise 3.0.5以前が影響対象（3.0.6でパッチ済み、2025年9月リリース）。2026年4月時点で15,000以上のインターネット公開インスタンスが未更新であり、単一のStarlinkIPからの積極的な悪用が観測されている。
