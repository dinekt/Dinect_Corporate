### 1. Anthropic「Project Glasswing」が150組織・15カ国に拡大 — Claude MythosがNATO・ENISA・Okta・Samsung等の重要インフラ防衛に参加

Anthropicが**Project Glasswing**（クリティカルソフトウェアの脆弱性を自動発見・修正するAI安全保障プログラム）の参加組織を当初の50社から**150社以上**に拡大し、対象国も**15カ国超**に広がった。参加組織にはNATO、EU公式サイバーセキュリティ機関ENISA、認証基盤大手Okta、Samsung、SK Hynix、SK Telecomが含まれ、電力・水道・医療・通信インフラにClaude Mythosが本格適用される段階に入った。Claude Mythos Previewはすでに主要OS全般・主要Webブラウザを含む広範なコードベースで数千件の高深刻度脆弱性を発見しており、その能力は「最も優秀な人間のセキュリティ研究者を上回る水準」との評価がAnthropicから示されている。一方でOpenAIも対抗措置として**GPT-5.5-Cyber**（脆弱性発見・修正に特化したモデル）を大規模パートナー向けに展開を開始しており、AI駆動のサイバー防衛市場でAnthropicとOpenAIの直接競合が生じている。重要インフラ防衛にAIが介在することで攻撃面の縮小が期待される一方、同一モデルが攻撃側にも転用できる「双刃のリスク」については研究者の間でも議論が続いている。

### 2. Palo Alto CVE-2026-0257（GlobalProtect認証バイパス）— CISA KEV登録・5月17日から悪用継続、パッチ未適用環境は引き続き危険

Palo Alto Networks PAN-OSの**GlobalProtectポータル／ゲートウェイ**コンポーネントに存在する認証バイパス脆弱性**CVE-2026-0257**（CVSS 7.8）が、5月17日から継続的に悪用されていることをUnit 42（Palo Alto脅威インテリジェンス部門）およびRapid7が確認した。攻撃手法は**認証オーバーライドCookieの不正生成**であり、攻撃者は正規の認証情報なしにVPNセッションを確立し、内部ネットワークへの初期アクセスを得られる。CISAは同脆弱性をKnown Exploited Vulnerabilities（KEV）カタログに追加し、連邦政府機関（FCEB）に6月1日を期限として対処を命じた。Palo Alto Networksは同時期にパッチをリリースしているが、VPN機器の業務影響から更新が遅れる組織も多く、6月15日時点でも悪用観測が継続している。Check Point VPN CVE-2026-50751とほぼ同一時期に並行して悪用が進んでいる状況はVPN機器全般に対する脅威アクターの集中的な標的化を示しており、リモートアクセス製品のパッチ優先度を改めて再評価する必要がある。

### 3. ホワイトハウス、AI革新・安全保障に関する大統領令を発令 — フロンティアモデルの30日前政府提出義務化とAIサイバーセキュリティ情報共有センター設置へ

トランプ政権は6月2日、大統領令「**Promoting Advanced Artificial Intelligence Innovation and Security**」を発令した。主要施策は二軸構成で、（1）政府情報システムのサイバー防衛強化と（2）フロンティアAIモデル開発者向けの自発的ベンチマーク・レビュー枠組みの整備だ。注目されるのは、フロンティアモデル開発者が**一般公開の最大30日前**に政府へモデルへのアクセスを任意提供する仕組みが制度化される点で、政府は安全審査・セキュリティ評価を実施できる。また**AIサイバーセキュリティ情報共有センター（AI Cybersecurity Clearinghouse）**の設置が命じられ、AI産業と重要インフラ運用者が連携してソフトウェア脆弱性を大規模に特定・修正するためのボランタリー協調体制が整備される。EUが法的拘束力のあるAI Actを推進するのに対し、米国は「自発的参加」と「イノベーション優先」を基本哲学とする姿勢を維持しており、EU-USアプローチの乖離はさらに鮮明になっている。実施の具体的詳細は30日指示（サイバー防衛）・60日指示（フロンティアモデル枠組み）のタイムライン上、7月中に明らかになる見通しだ。

### TIOBE June 2026 & Python 3.14 — Rustが過去最高位12位に浮上、Python 3.14フリースレッドが実用段階へ

2026年6月のTIOBE Indexでは**Rust**がついに**過去最高位の12位**を記録した（前月比+2）。TIOBE編集長Paul Jansenは「以前の予測を上方修正する」とコメントしており、メモリ安全性・パフォーマンスの両立を評価する採用が加速していることを示す。**Python**は依然1位を維持しながらも18.96%（5月比-1.02pt）と2026年を通じた緩やかな低下傾向が続いており、AI/ML以外のユースケースでRust・Goへのシフトが進んでいる構図が読み取れる。

開発者への実際のインパクトとして注目されるのが**Python 3.14**（2025年10月リリース）のフリースレッド実行（**PEP 703**）の成熟度向上だ。3.14ではフリースレッドビルドが「公式サポート」ステータス（**PEP 779**）を取得し、シングルスレッドのオーバーヘッドが3.13比で約40%から一桁%台に改善。マルチスレッドCPUワークロードで最大**3.1倍のスループット向上**が計測されている。

```python
# Python 3.14 フリースレッド実行の例
# --enable-free-threading ビルドまたは PYTHON_GIL=0 環境変数で有効
import threading
import time

def cpu_bound(n: int) -> int:
    """CPUバウンドな計算（GIL解放後は真の並列実行）"""
    result = 0
    for i in range(n):
        result += i * i
    return result

def benchmark_free_threaded(workers: int = 4, n: int = 10_000_000):
    threads = [threading.Thread(target=cpu_bound, args=(n,)) for _ in range(workers)]
    start = time.perf_counter()
    for t in threads:
        t.start()
    for t in threads:
        t.join()
    elapsed = time.perf_counter() - start
    print(f"workers={workers}, elapsed={elapsed:.2f}s")

# Python 3.13 (with GIL): workers=4 → ~4.2s（スレッド間でGILを競合）
# Python 3.14 (free-threaded): workers=4 → ~1.4s（真の並列実行）
benchmark_free_threaded()
```

またRust 1.87.0（4月16日リリース、Rust10周年記念イベントUtrechtで発表）では`std::io::pipe()`によるプロセス間パイプAPIの標準化、インラインアセンブリラベル、安全なアーキテクチャ固有命令セット（SIMD intrinsics）が追加されており、システムプログラミングの安全性・表現力がさらに向上している。

### VPN機器の同時多発的標的化 — Palo Alto CVE-2026-0257とCheck Point CVE-2026-50751が並走、リモートアクセス製品全般の緊急点検を

```bash
# === VPN機器 緊急確認チェックリスト（2026年6月版） ===

# ---- [1] Palo Alto PAN-OS CVE-2026-0257 (CVSS 7.8) ----
# GlobalProtect ポータル/ゲートウェイの認証バイパス
# 5月17日から悪用継続・CISA KEV掲載済み

# PAN-OS バージョン確認（CLI）
# show system info | match version

# 影響バージョン: PAN-OS 10.2 / 11.0 / 11.1 / 11.2 の特定リビジョン
# Palo Alto サポートポータルで該当バージョンを確認
# https://security.paloaltonetworks.com/CVE-2026-0257

# 暫定緩和: GlobalProtect認証オーバーライドCookieの有効期限を最小化
# または GlobalProtect を一時無効化して代替手段に切り替え

# ---- [2] Check Point Remote Access VPN CVE-2026-50751 (CVSS 9.3) ----
# IKEv1 認証バイパス・Qilinランサムウェアが悪用・PoC公開済み（2026-06-12）
# Check Point ホットフィックスを優先適用:
# https://support.checkpoint.com/results/sk/sk185033

# ---- [3] 一般的な VPN 機器強化手順 ----
# a) MFA（多要素認証）を全ユーザーに強制
# b) レガシープロトコル（IKEv1、SSL 3.0、TLS 1.0/1.1）を無効化
# c) VPN アクセスログの異常セッション検知ルールを強化
# d) 認証失敗の急増・非通常時間帯の接続を SIEM でアラート

echo "=== 影響製品サマリー ==="
echo "Palo Alto PAN-OS GlobalProtect : CVE-2026-0257 (CVSS 7.8) - KEV掲載"
echo "Check Point Remote Access VPN  : CVE-2026-50751 (CVSS 9.3) - PoC公開"
echo "両脆弱性ともに未認証・ネットワーク越しの悪用が可能"
echo "VPNを外部公開している全組織は今週中の対処完了を推奨"
```

2026年6月時点で、Palo Alto PAN-OS（CVE-2026-0257）とCheck Point VPN（CVE-2026-50751）という2大VPN製品の認証バイパス脆弱性が**同時並行で悪用**されている。どちらもネットワーク経由で認証情報なしに悪用可能であり、特にCheck Point側はQilinランサムウェアグループが組織侵害後の暗号化実行まで使用した実績がある。VPN機器は組織の「入口」に位置するためインパクトが大きく、パッチ適用・MFA強制・レガシープロトコル無効化を今週中に完了することが強く推奨される。
