## ニュース一覧

### 1. 2026年度IT導入補助金 -- AIツール・業務自動化が対象に
**カテゴリ**: 補助金 / 日本市場
**影響度**: ★★★★★

中小企業庁が2026年度のIT導入補助金の対象カテゴリにAIツール・業務自動化ツールを正式追加。AI促進法（2025年9月施行）と連動した施策として位置づけられている。

**補助金の概要**（2026年度版・3月18日時点の情報）:
- **通常枠（A・B類型）**: 補助率1/2、上限150万円。既存業務のIT化・AI化ツール全般
- **デジタル化基盤導入枠**: 補助率3/4、上限350万円。インボイス対応・電子帳票含む
- **セキュリティ対策推進枠**: 補助率1/2、上限100万円
- 申請対象: 中小企業・小規模事業者・個人事業主（法人格不要）

**AIツール導入として申請しやすい用途**:
- 文書のデジタル化・OCR・データ入力自動化（スキャニング業務の自動化）
- チャットボット・問い合わせ対応自動化
- 在庫管理・受発注の自動化
- 会計・請求書処理の自動化

**個人開発者への影響**:
- 自社プロダクトをIT導入補助金の「補助対象ITツール」として認定登録（ITSSP登録）できれば、エンドユーザーが補助金で導入できる
- ScanQAやPDF Lite WorksはOCR・文書処理に該当し、補助対象として申請しやすい
- **今すべきこと**: IT導入支援事業者（ITSSP）としての登録条件を確認。ScanQAをITSSPに登録し「補助金で使えるツール」として訴求するロードマップを作る

出典: [中小企業庁IT導入補助金](https://www.it-hojo.jp/) / [IAPP Japan AI Governance](https://iapp.org/resources/article/global-ai-governance-japan) / [Japan SaaS Market Research Nester](https://www.researchnester.com/reports/japan-software-as-a-service-saas-market/2216)

### 2. Claude Code ultrathink / /effortコマンド活用ガイド -- 上位1%の使い方
**カテゴリ**: AI / 開発ツール
**影響度**: ★★★★★

Claude Code v2.1.76で搭載された `/effort` コマンドと `ultrathink` キーワードが開発者コミュニティで本格活用され始めた。正しく使うと設計タスクの品質が大幅に向上する。

**使い分けの実践ガイド**:

```bash
# 軽量タスク（コメント追加・変数リネーム等）
/effort low
claude -p "このファイルのコメントを日本語化して"

# 標準タスク（バグ修正・機能追加）
/effort medium  # デフォルト

# 複雑な設計タスク（アーキテクチャ設計・リファクタリング）
/effort high
claude -p "このモジュールの責務を整理してリファクタリング案を提案して"

# 最大推論（セキュリティレビュー・重要な設計判断）
/effort xhigh
# または会話の中で
"この設計の問題点をultrathinkで徹底的に洗い出して"
```

**コスト試算（Claude Sonnet 4.6ベース）**:
- `/effort low`: 通常の約0.3倍のトークン消費
- `/effort medium`: 基準（1.0倍）
- `/effort high`: 約2.5倍
- `/effort xhigh` / `ultrathink`: 約5-8倍（最大31,999推論トークン）

**実用パターン（Dinekt向け）**:
```bash
# PDF Lite Worksのアーキテクチャレビュー
claude -p "PDF Lite Worksのv8.0設計をultrathinkで評価して問題点を洗い出して"

# ScanQAのMVP設計
/effort xhigh
"ScanQAのMVPで最小限実装すべき機能を、ユーザーペインポイントから逆算して設計して"
```

**個人開発者への影響**:
- 設計タスクに `ultrathink` を使うとアーキテクチャの見落としが大幅に減る
- コスト増加分は設計ミスによる手戻りコストと比較すると十分元が取れる
- **今すべきこと**: 次の設計タスクで `/effort xhigh` を試す。通常モードとの出力品質を比較してみる

出典: [Releasebot Claude Code Changelog](https://releasebot.io/updates/anthropic/claude-code) / [Claude Code Docs](https://code.claude.com/docs/en/changelog)

### 3. Gemini 3.1 Pro ベンチマーク -- 16指標中13でトップ、マルチモーダル強化
**カテゴリ**: AI / ベンチマーク
**影響度**: ★★★☆☆

Googleが2月19日にリリースしたGemini 3.1 Proの第三者ベンチマーク結果が出揃った（3月中旬時点）。

**主要ベンチマーク**:
- ARC-AGI-2: 77.1%（GPT-5.4: 72.3%、Claude Opus 4.6: 74.2%）
- GPQA Diamond: 94.3%（トップ水準）
- MMMU（マルチモーダル）: 91.2%（全モデル中1位）
- SWE-bench Verified: 79.1%

**特に強い領域**:
- マルチモーダル（画像理解・図表解析）が全モデル中最強水準
- 長文コンテキスト処理（1Mトークン）での一貫性
- 数学・理科推論（GPQA Diamond 94.3%）

**個人開発者への影響**:
- 図面・スキャン画像・帳票の解析にはGemini 3.1 Proがコスパ最強の選択肢
- PDF Lite WorksやScanQAのバックエンドAIとして画像理解タスクに有効
- **今すべきこと**: `gemini-3.1-pro` でスキャン画像の文字・構造認識を試験。精度をClaudeと比較

### 4. 2026年日本のSaaS市場 -- 労働不足がAI自動化需要を加速
**カテゴリ**: 市場 / 日本
**影響度**: ★★★☆☆

日本のSaaS市場が労働力不足を背景に加速成長している。ITツール・AI自動化の需要が構造的に強い。

**最新の数字（2026年）**:
- 日本SaaS市場規模: $138億（2026年推計）、2035年に$381億（CAGR 13.5%）
- AI市場全体: $736億の生産性向上効果を2030年までに創出（予測）
- IT人材不足: 2026年見通しで79万人（DX需要の急増が主因）
- 低コード/ノーコード市場: 2026-2033年でCAGR 14.5%

**個人事業主・小規模開発者への機会**:
- 人材不足で「人を雇うよりAIツールを買う」判断が企業で加速
- 特定業種（スキャニング・BPO・製造・物流）の業務特化ツールへの需要大
- 競合が少ないニッチ業種専用ツールが売れやすい環境

**Dinektにとっての示唆**:
- PDF Lite Works（スキャニング業務特化）はこの「業種特化＋人手不足解消」トレンドにど真ん中
- BPOセンター向けScanQAの訴求ポイントを「1人分の業務をAIが代替」に絞ると刺さりやすい
- **今すべきこと**: ターゲットとなるBPOセンター・スキャニング会社のリストを5社作り、ヒアリング依頼を送る

## まとめ

IT導入補助金2026年度版でAIツールが補助対象になった事実は、ScanQAのGTM（Go-to-Market）戦略に直結する。「補助金で導入できるAI文書処理ツール」としてのポジショニングは、日本の中小企業・BPOセンターへの訴求力が非常に高い。PDF Lite WorksのITSSP登録を最短で検討し、4月のScanQAヒアリングに向けて補助金訴求を組み込むことを推奨する。
