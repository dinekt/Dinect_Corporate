## 新技術・新リリース

### Rust 1.95.0 リリース — `cfg_select!` マクロと if-let ガードが安定版へ

Rust が 6 週間サイクルの定期リリースとして **1.95.0** を安定版チャンネルに投入した。目玉は **`cfg_select!` マクロ**と **`match` 式における if-let ガード**の安定化で、どちらもコンパイル時の条件分岐と型安全なパターンマッチをより簡潔に書けるようにする言語機能拡張だ。

```rust
// cfg_select!: プラットフォーム別コードをネストなしで切り替える
cfg_select! {
    target_os = "linux" => {
        fn platform_name() -> &'static str { "Linux" }
    }
    target_os = "macos" => {
        fn platform_name() -> &'static str { "macOS" }
    }
    _ => {
        fn platform_name() -> &'static str { "Other" }
    }
}

// if-let ガード: match アームに追加条件を簡潔に記述
fn classify(opt: Option<i32>) -> &'static str {
    match opt {
        Some(n) if let Ok(s) = n.try_into::<u8>() if s < 128 => "small positive",
        Some(_) => "other",
        None => "none",
    }
}
```

TIOBE Index 4 月版では Rust は 16 位（1.09%）と年初の 13 位からやや後退しているが、システムプログラミング・WebAssembly・組み込み分野での採用は堅調に拡大している。Linux カーネルへの Rust コード組み込みが本格化したことで、メモリ安全性を重視するセキュリティ観点からの採用事例がさらに増える見込みだ。

## セキュリティ

### Fortinet CVE-2026-35616（CVSS 9.1）— FortiClient EMS でゼロデイ悪用、認証前 API アクセスで特権昇格

Fortinet が **FortiClient EMS**（Enterprise Management Server）の深刻な脆弱性 **CVE-2026-35616**（CVSS 9.1）にパッチを発行した。この脆弱性は認証前の API アクセスバイパスを起点として特権昇格が成立する欠陥で、4 月下旬にゼロデイとして実環境悪用が観測されていた。FortiClient EMS はエンドポイント管理の中枢として企業ネットワーク全体の設定とポリシーを制御するため、侵害された場合の影響範囲は極めて広い。インターネットに露出した EMS インスタンスを持つ組織は即時パッチ適用を最優先とされたい。

### Microsoft ASP.NET Core CVE-2026-40372 — 認証クッキー偽造で SYSTEM 権限昇格、緊急帯外パッチを適用

Microsoft が帯外（Out-of-Band）緊急パッチを公開し、**ASP.NET Core Data Protection 暗号化 API** の脆弱性 **CVE-2026-40372** を修正した。未認証の攻撃者が細工した認証クッキーを送信することで **SYSTEM 権限**を取得できる重大な欠陥で、Web アプリケーションホスティング環境への影響が広範にわたる。通常の月例 Patch Tuesday とは別にリリースされた事実が深刻度の高さを示している。.NET アプリケーションを本番で稼働させているすべての組織において、ASP.NET Core のバージョン確認と更新が急務。

### CISA KEV 更新 — 新規 8 件追加、Fortinet・Adobe・Windows 脆弱性を連邦機関に期限付き修正義務化

CISA が既知悪用脆弱性（KEV）カタログに **8 件を新規追加**し、連邦機関に対して 4〜5 月の期限内修正を義務付けた。今回追加された中には、**Adobe Acrobat Reader CVE-2026-34621**（実環境悪用確認済み）や **cPanel CVE-2026-41940**（30 日以上のゼロデイ悪用）も含まれる。4 月は Patch Tuesday 168 件・Chrome ゼロデイ・Cisco SD-WAN・FortiClient・ASP.NET と主要プラットフォームへの悪用報告が集中しており、パッチ優先度付けの負荷が例月以上に高い時期となっている。
