### 1. AnthropicがClaude Scienceを発表 — 60以上のツールを統合した科学者向けAIワークベンチとドラッグディスカバリー部門を同時設立

Anthropicは6月30日〜7月上旬にかけて**Claude Science**を正式発表した。生物製薬研究者向けに設計されたAIワークベンチで、ゲノミクス・単細胞解析・プロテオミクス・構造生物学・ケモインフォマティクスなど**60以上のキュレーション済みスキル・コネクタ**をあらかじめ設定した汎用コーディネートエージェントを中核に持つ。再現可能な成果物（auditable artifacts）の生成と柔軟な計算リソースアクセスが特徴で、早期顧客にはNovo NordiskとAllen Instituteが名を連ねる。同時に**社内ドラッグディスカバリー部門**の設立も発表し、ライフサイエンス責任者Eric Kauderer-Abrams氏は「従来の製薬企業が採算面から手をつけてこなかった"ネグレクト疾患"の治療薬開発に集中する」と述べた。Claude Science AI for Scienceプログラムでは最大50プロジェクトを支援し、最大3万ドルのクレジットと最大2,000ドルの計算コンピュートを提供（応募締切：7月15日、採択通知：7月31日）。GoogleのAlphaFold、OpenAIのo3-Bioと並び、AI×ライフサイエンスの三つ巴競争が本格化した。Anthropicが収益でOpenAIを逆転したという報道も重なり、ConstitutionalAI安全原則を軸にエンタープライズ信頼を積み上げてきた同社の路線が、研究機関向けにも拡大することを示す転換点となる。

### 2. 国連AIガバナンス国際対話がジュネーブで開催 — EU AI Act批准・G7調整・ホワイトハウス自主規制交渉が重なり国際AIルール形成が加速

7月6〜7日、ジュネーブで**UN Global Dialogue on AI Governance（国連AIガバナンス国際対話）**が開幕した。UNESCOは「壊滅的被害のリスクと、すべての人にとって包括的なAIの恩恵を同時に確保する」緊急性を強調、各国政府・テック企業・学術・市民社会が一堂に会した。国際条約面では、**欧州評議会のAI枠組条約**（G7全加盟国を含む21か国が署名）が2026年5月にEUによって**初批准**を受け、人権・民主主義・法の支配の尊重をAIシステムに求める最初の拘束力ある国際条約として発効に向け前進している。EU AI Actの完全施行期限が2026年8月に迫る中、ホワイトハウスもOpenAI・Google・Anthropicとフロンティアモデルの自主標準（ベンチマーク・テストタイムライン・アクセスルール）に関する交渉を進めており、来週にも声明を発表する見通しだ。また7月にはEUサイバーセキュリティ・AI行動計画が公表され、先進AIモデルが引き起こすサイバーセキュリティリスクへの加盟国横断的対応を調整する。米中のAI覇権争いが続く中、中間国が独自の規制アプローチを模索する「ガバナンスの多極化」が2026年後半の最大の地政学的論点になると各シンクタンクが指摘している。

### 3. Microsoft SharePoint RCE（CVE-2026-45659）がCISA KEVに追加 — Storm-2603グループが認証済みアカウントを悪用してランサムウェア展開

CISAは7月1日、**Microsoft SharePoint Serverのリモートコード実行脆弱性CVE-2026-45659**（CVSS 8.8）を**Known Exploited Vulnerabilities（KEV）カタログ**に追加し、米連邦省庁に7月4日までの緊急パッチ適用を命じた。この脆弱性は非信頼データのデシリアライズに起因するRCEで、**サイトメンバー権限以上の認証ユーザーであれば管理者権限なしにサーバー上でコードを任意実行できる**。Microsoftは5月Patch Tuesdayで修正していたが、セキュリティ情報の公開を5月21日まで失念するという異例の経緯を経た。7月初頭に**Storm-2603グループ**による悪用が複数のセキュリティベンダーによって確認されており、同グループはSharePoint経由で初期アクセスを確保後に正規リモート管理ツールで永続化し、Mimikatzで認証情報を窃取してランサムウェアを展開するという手順で攻撃を行っている。SharePoint Server Subscription Edition / 2019 / Enterprise Server 2016の全バージョンが対象で、インターネット公開またはイントラネット公開のSharePointを運用する組織には、即時パッチ適用と侵害インジケータ（IOC）の確認が求められる。

## 新技術・新リリース

### TypeScript 7.0 RC — コンパイラをGoで書き直し、10倍高速化・VS Code 77秒→7.5秒

Microsoftは6月18日（*InfoWorldによると7月上旬に広く認知*）に**TypeScript 7.0 RC**を公開した。最大の変化は**コンパイラ実装をTypeScript（JavaScript）からGo言語へ完全移植**したことで、ゼロから書き直しではなく既存コードを忠実に移植したため、型チェックロジックはTypeScript 6.0と構造的に等価だ。パース・型チェック・エミットを並列化したことで、**VS Code（150万行のTypeScript）のビルドが77.8秒から7.5秒（約10倍）に短縮**された。npmのtypescriptパッケージから即座にインストール可能で、GA安定版は1か月以内のリリースが予定されている。

```bash
# TypeScript 7.0 RC のインストール
npm install -D typescript@rc

# バージョン確認（7.0.0-rc.x が表示される）
npx tsc --version

# tsconfig の変更点: verbatimModuleSyntax がデフォルト有効
# import type を省略した型インポートはエラーになる
# Before (TS 6.x)
# import { Foo } from "./foo"           // 型か値かが曖昧

# After (TS 7.0 推奨)
# import type { Foo } from "./foo"      // 型インポートを明示

# tsbuildinfo の互換性に注意: 6.x と 7.0 の tsbuildinfo は非互換
# キャッシュを一度クリアしてからビルド
rm -rf .tsbuildinfo tsconfig.tsbuildinfo
npx tsc --build
```

GoベースのコンパイラはNode.js版とは別バイナリとして動作するため、既存のwebpack/vite/esbuildとの統合は今後のエコシステム対応が必要だが、言語機能の互換性は維持されている。`--module nodenext`や`verbatimModuleSyntax`のデフォルト化など設定面の変更が一部あるため、移行ガイドの確認が推奨される。

## セキュリティ

### SharePoint CVE-2026-45659 & SimpleHelp CVE-2026-48558（CVSS 10.0）— 今週最優先の2脆弱性

```powershell
# === SharePoint CVE-2026-45659 影響確認・対応チェックリスト ===

# [1] 影響するSharePointバージョン
# - SharePoint Server Subscription Edition
# - SharePoint Server 2019
# - SharePoint Enterprise Server 2016

# [2] パッチ適用状況確認（May 2026 Patch Tuesday = KB5002648 / KB5002650 等）
$patch = Get-HotFix | Where-Object { $_.HotFixID -match "KB5002648|KB5002650|KB5002641" }
if ($patch) {
    Write-Host "PATCHED: $($patch.HotFixID) applied on $($patch.InstalledOn)"
} else {
    Write-Host "WARNING: SharePoint May 2026 patch not found — CVE-2026-45659 EXPOSED"
}

# [3] Storm-2603 IOC確認（正規RAT経由の横展開の痕跡を確認）
# SharePoint ULS Logで不審なデシリアライズエラーを探す
$logPath = "C:\Program Files\Common Files\Microsoft Shared\Web Server Extensions\16\LOGS"
Get-ChildItem $logPath -Filter "*.log" | Select-String "Deserialization|Serialize" | Select-Object -Last 20

# [4] Mimikatz使用の痕跡チェック（Event ID 4624 / 4648 の異常なログオン）
Get-WinEvent -LogName Security -FilterXPath `
    "*[System[(EventID=4624 or EventID=4648)]]" |
    Where-Object { $_.TimeCreated -gt (Get-Date).AddDays(-7) } |
    Select-Object TimeCreated, Message -First 20

Write-Host "=== 今週最優先 CVE ==="
Write-Host "CVE-2026-45659  SharePoint Server RCE  CVSS 8.8  (CISA KEV・実被害確認)"
Write-Host "CVE-2026-48558  SimpleHelp RCE          CVSS 10.0 (認証完全バイパス)"
Write-Host "SharePointはMay PatchTuesdayのKB適用を最優先、SimpleHelp v5.x系は即時アップデートを"
```

CVE-2026-45659（SharePoint）と並んで今週注目すべきは**SimpleHelp CVE-2026-48558**（CVSS 10.0）だ。リモートサポートソフトウェアSimpleHelpのOIDC認証フローを完全にバイパスする認証不要のRCEで、最大深刻度スコアを記録している。SimpleHelpはMSP（マネージドサービスプロバイダ）が広く使用しており、攻撃者がMSP経由でクライアント企業へ横展開するサプライチェーン型攻撃に悪用される懸念が高い。SharePoint側ではStorm-2603によるランサムウェア展開が既に確認済みであり、「パッチ済みだが公開を忘れていた」というMicrosoftの開示プロセスの不備についても業界から批判の声が上がっている。両脆弱性とも今週中の対応完了を強く推奨する。
