# テックニュース 2026年4月29日

Claude Code が 4 月に 30 以上のバージョンを重ね、MCP 出力上限 50 万文字・ネイティブ CLI バイナリ化・60% 高速化など実用面の底上げが顕著となった。一方、Microsoft が日本に 2026〜2029 年で 100 億ドルの AI インフラ投資を表明し、NEC と Anthropic の提携も加わり、国内 AI 採用の加速が鮮明になっている。

## ニュース一覧

### 1. Claude Code、4月に30以上のバージョンを連続投入 — MCP 50万字上限・ネイティブ CLI・60%高速化
**カテゴリ**: ツール / AI
**影響度**: ★★★★★

Anthropic は 4 月を通じて Claude Code のバージョンを 2.1.69 から 2.1.101 まで 30 以上リリースした。主要アップデートは (1) MCP ツール出力の文字上限を 50 万文字に拡大（大規模ドキュメント処理に対応）、(2) バンドル JavaScript からネイティブ CLI バイナリへ移行（コールドスタートの高速化）、(3) Write ツールに「NO_FLICKER レンダリングエンジン」を導入し書き込み速度を 60% 向上、(4) `/powerup` によるインタラクティブオンボーディング追加、(5) PID 名前空間分離・認証情報スクラブ等のセキュリティ強化の 5 点。パフォーマンスを一等市民として扱う方針転換が見られ、開発者体験の底上げが一気に進んだ。

**個人開発者への影響**:
- MCP 50 万字上限により、PDF 全文や長大なログをツール経由でそのままモデルに渡せるようになり、文書処理パイプラインの実装が大幅に簡略化される
- ネイティブバイナリ化でスクリプトから `claude` コマンドを呼ぶ際の起動レイテンシが減少し、CI/CD 組み込みがより現実的になった
- セキュリティ強化（認証情報スクラブ・PowerShell 権限の厳格化）により、Windows 環境での本番利用に対する懸念点が一部解消された

### 2. Big Tech 離職者が AI スタートアップを創業 — 元 DeepMind の David Silver が 11 億ドル調達
**カテゴリ**: AI / 市場
**影響度**: ★★★☆☆

CNBC の 4 月 28 日の報道によると、Meta・Google・OpenAI などの Big Tech から上位スタッフが相次いで離職し、新たな AI スタートアップを立ち上げている。代表例として、Google DeepMind の AlphaGo 研究者として知られる David Silver が設立した Ineffable Intelligence が、創業数か月で評価額 51 億ドル・調達額 11 億ドルのシードラウンドを完了した。4 月の AI 分野の資金調達は 1,314 件、764 件が AI/ML 関連（全体の約 60%）で、Q1 2026 のベンチャー投資総額は 3,000 億ドルと四半期記録を更新した。

**個人開発者への影響**:
- AI インフラ・エージェントフレームワーク系のスタートアップが多数立ち上がっており、6〜12 か月後に個人開発者が利用できる新ツールの選択肢が増える見込み
- 大手からの人材流出は「既存プロダクトの開発速度低下」リスクを示唆するため、特定ベンダーへの依存度を分散しておく判断が合理的
- 資金調達バブルの状況下では新参ツールの品質・継続性にばらつきが大きいため、「枯れた技術優先」の原則が引き続き有効

### 3. Microsoft、日本に 100 億ドル投資表明 — 2029 年までにエンジニア 100 万人 AI 研修
**カテゴリ**: クラウド / 日本市場
**影響度**: ★★★★☆

Microsoft は 4 月 3 日、2026〜2029 年の 4 年間で日本の AI インフラ・サイバーセキュリティ・人材育成に 100 億ドルを投資すると発表した。Fujitsu・Hitachi・NEC・NTT Data・SoftBank との協業で、2030 年までに日本国内のエンジニア・開発者 100 万人に AI トレーニングを提供する計画。同時期に NEC と Anthropic の戦略的パートナーシップも発表されており、Claude が国内エンタープライズ向けの主要 LLM の一つとして採用される流れが加速している。現状の国内 AI 採用率は「企業全体への展開完了」が全体の 8% にとどまり、多くはパイロット段階にある。

**個人開発者への影響**:
- Microsoft Azure OpenAI Service および Anthropic の API が国内データセンター経由で提供されるルートが今後拡充する見通しで、データレジデンシー要件が厳しい顧客案件への対応がしやすくなる
- 国内大企業の AI 導入予算が本格化するに伴い、中小規模のシステムインテグレーション・PoC 案件の発注増加が期待できる
- エンジニア向け AI 研修の普及により、開発現場での AI ツール活用の前提スキルが底上げされ、AI 補助前提のワークフロー提案が受け入れられやすくなる

### 4. Google Gemini 3.1 Pro Preview と Gemma 4 が相次いでリリース — Flex/Priority 料金ティア導入
**カテゴリ**: AI / クラウド
**影響度**: ★★★☆☆

Google は 4 月に Gemini 3.1 Pro Preview を公開し、カスタムツール優先エンドポイント `gemini-3.1-pro-preview-customtools` を追加した。また Deep Research 向けの `deep-research-max-preview-04-2026` も提供開始。オープンウェイトモデルとして Gemma 4 の 4 バリアント（Apache 2.0）も AI Studio・Gemini API 経由で利用可能になった。料金面では Flex（低コスト優先）と Priority（低レイテンシ優先）の 2 ティアが導入され、ユースケースに応じた最適化が可能になっている。4 月 30 日 PST には旧 `gemini-robotics-er-1.5-preview` が廃止される。

**個人開発者への影響**:
- `gemini-3.1-pro-preview-customtools` は MCP/Function Calling 構成でカスタムツールを優先的に呼び出すため、エージェント構築時の信頼性が向上する
- Flex ティアはバッチ処理・非同期推論に適しており、大量ドキュメント処理を低コストで実行するユースケースでコストを抑えられる
- Gemma 4 の Apache 2.0 ライセンスにより、ローカル推論・商用組み込み時のライセンスリスクがゼロで、`ollama pull gemma4` 相当のコマンド一本で環境構築が完了する

### 5. AI コーディングツール市場が集約 — Claude Opus 4.7 が SWE-bench 87.6% を記録、Copilot 460 万有料ユーザー
**カテゴリ**: ツール / 市場
**影響度**: ★★★☆☆

2026 年 4 月時点のコーディング AI 市場では、GitHub Copilot・Cursor・Claude Code・Devin の 4 強構造が確立した。Claude Opus 4.7 が SWE-bench Verified で 87.6% を達成、GitHub Copilot は独立ベンチマークで SWE-bench 56%（Cursor 52% をリード）。有料ユーザー数では GitHub Copilot が 460 万人超、Cursor の評価額は 500 億ドルに到達したと報じられている。Devin は月額 $500 から $20 へ大幅値下げ済みで、コーディングエージェントの参入障壁が急低下している。

**個人開発者への影響**:
- 「日常編集は Cursor、複雑なリファクタ・コードベース調査は Claude Code」という 2 ツール併用が 2026 年の標準構成として定着しつつある
- Devin の $20 という価格設定は個人開発者でも現実的な選択肢になり、完全自律型エージェントの試験導入コストが下がった
- 複数ツールを使い分ける場合、各サービスの利用量を月次でモニタリングしないとコストが意図せず膨らむため、使用量アラートの設定が必須
