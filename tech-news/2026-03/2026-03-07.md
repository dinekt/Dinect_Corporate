## 3. セキュリティ

### AI コーディングエージェント時代のシークレット管理

日本語記事「『.env見るな』は通じない－AI時代のシークレット管理術」は、個人開発者にとって緊迫した課題です。Claude Code などの **AI エージェント（AIが自動でコードを生成・実行するツール）** が普及する中、`.env` ファイルに記述した API キーや DB パスワードが、プロンプトインジェクション（言い方を変えて指示に従わせる攻撃）によって読み出される危険性があります。

**対策：**
- `process.env` に機密情報を直接参照させず、起動時に検証レイヤーを設ける
- **環境変数マスキング**（本番環境では値を確認しないようツール設定）
- Vercel や Netlify の環境変数管理画面で「preview deployment では非表示」設定を活用
- API キーのスコープ限定（例：Stripe キーは特定の操作のみ許可）

これらは追加コストなしで実装可能で、今後のベストプラクティスになっていくでしょう。

## 4. 深掘りキーワード

### **SaaS スターターキット（SaaS Starter Kit）**
Next.js + TypeScript ベースで認証（JWT, OAuth）、支払い処理（Stripe API との連携）、ユーザー管理、ダッシュボードレイアウトが既に実装されたテンプレート。個人開発での開発時間を 70-80% 削減でき、Gumroad や Github でオープンソース版が公開されています。自分のビジネスロジックに集中できるメリットが大きいです。

### **アクセシビリティ（Accessibility, A11y）**
ウェブサイトやアプリが障害者（視覚、聴覚、運動機能の障害者）でも使用可能な状態を指します。EU の WCAG（ウェブコンテンツアクセシビリティガイドライン）や米国の ADA（障害を持つアメリカ人法）への準拠が法的義務になり始めており、個人開発でも機能が有限な初期段階から対応することが将来のスケーリング時のリファクタリングコスト削減につながります。

### **予測市場（Prediction Market）**
将来のイベント（選挙、経済指標、天候など）の発生確率を金銭で取引できるプラットフォーム。Polymarket（仮想通貨対応）が米国で急拡大していますが、インサイダー情報を持つ者による不正取引の温床になりやすく、各国政府が規制を強化しています。ブロックチェーン領域の個人開発を考える場合、規制リスクを事前評価する必要があります。

### **AI コーディングエージェント（AI Coding Agent）**
Claude Code、GitHub Copilot X など、自然言語の指示でコード生成・デバッグ・テストまで自動実行するツール。個人開発の生産性を大幅に上げる一方、セキュリティホール（機密情報漏洩、不正な依存関係の追加）を引き込むリスクも増加しており、使用ガイドラインの設定が重要です。

### **コールドスタート（Cold Start）**
サーバーレス環境（Vercel Functions など）で、アプリが一定時間使用されていないと、次のリクエスト時に初期化処理が入り、応答時間が数秒遅延する現象。個人開発では許容できることが多いですが、ユーザーが多い場合は有料プランへの移行や 別の IaaS の検討が必要になります。

## 用語集

| 用語 | 定義 |
|------|------|
| **API（Application Programming Interface）** | ソフトウェア間のデータ連携を定める仕様・規約。Stripe APIなら「決済処理」、OpenAI APIなら「言語生成」など機能別に提供される |
| **JWT（JSON Web Token）** | ユーザー認証用のトークン。暗号化された JSON 形式で、ブラウザとサーバー間で状態を保持せずに認証を行える |
| **OAuth** | サードパーティサービス（Google、GitHub など）を使用したログイン方式。ユーザーは複数のパスワード管理を避けられる |
| **Semantic HTML** | `<header>`、`<nav>`、`<article>` など意味的に正しい HTML タグを使用する方法。スクリーンリーダーや SEO に有利 |
| **ARIA 属性（Accessible Rich Internet Applications）** | ウェブアプリのアクセシビリティを向上させるための HTML 属性セット。`role`、`aria-label` など |
| **プロンプトインジェクション** | AI に不適切な指示を隠れた形で埋め込み、本来の制限を回避する攻撃手法 |
| **環境変数マスキング** | 本番環境で機密情報を非表示にする設定。CI/CD パイプラインでのログ出力を保護する |
| **MVP（Minimum Viable Product）** | 最小限の機能で市場検証するプロダクト。大規模開発より早期にユーザーフィードバックを得られる |
| **API Routes** | Next.js でバックエンド機能を同一プロジェクト内に書く仕組み。`pages/api/` 下のファイルが自動的にエンドポイント化される |
