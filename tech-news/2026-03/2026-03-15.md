### 1. NVIDIA Nemotron 3 Super -- 完全オープンな120Bアジェンティックモデル
**カテゴリ**: AI / オープンソース
**影響度**: ★★★★★

3月11日にNVIDIAがNemotron 3 Superを発表、3月13-15日にかけてHugging Face等でウェイトが順次公開された。

**技術仕様**:
- 総パラメータ: 120B、アクティブパラメータ: 12B（MoEアーキテクチャ）
- ハイブリッドMamba-Attention構造で前世代比5倍スループット（4bit精度時）
- コンテキストウィンドウ: 1Mトークン
- 学習データ: 10兆トークン（NVIDIAが公開）

**配布と統合**:
- Hugging Face、OpenRouter、Perplexity、build.nvidia.comで利用可能
- CodeRabbit、Factory、Greptileなどコーディングエージェントが統合を発表
- ウェイト・データセット・レシピがすべてオープン（完全商用利用可）

**個人開発者への影響**:
- RTX 4090（24GB VRAM）レベルのGPUでは量子化版なら推論可能。ローカルLLMとして有力候補
- 1Mコンテキストによりコードベース全体を参照した補完が可能
- **今すべきこと**: `ollama pull nemotron3-super:12b-q4` で量子化版を試す。大規模コードベース解析用途での活用を検討

### 2. PyPI悪意あるパッケージ -- クラウド認証情報を窃取する20パッケージ
**カテゴリ**: セキュリティ
**影響度**: ★★★★★

3月15日、PyPIに「時間ユーティリティ」を装った20個の悪意あるパッケージが発見・削除された。合計14,100件超のダウンロードが確認されており、AWS・Alibaba Cloud・Tencent Cloudの認証情報を窃取するコードが含まれていた。

**攻撃の手口**:
- パッケージ名はよく使われるライブラリに酷似（タイポスクワッティング）
- インストール直後に環境変数・`~/.aws/credentials`・`~/.config`を読み取り外部送信
- CI/CDパイプラインでの自動インストール時に最も危険

**個人開発者への影響**:
- `requirements.txt`やGitHub Actionsで`pip install`を使うすべての開発者が対象
- クラウド請求額の急増・リソースの不正利用につながる
- **今すべきこと**: `pip-audit` または `safety check` でインストール済みパッケージを検査。依存関係は`pip install パッケージ名==バージョン`でピン留め。PyPI Inspectで怪しいパッケージを事前チェック

出典: [Real Python Python News](https://realpython.com/python-news-march-2026/) / [Python Developer News Hackertab](https://hackertab.dev/topics/python)

### 4. React/Next.js 新脆弱性 -- DoS CVE-2026-23864（CVSS 7.5）が公開
**カテゴリ**: セキュリティ / Web開発
**影響度**: ★★★★☆

React Server Components（RSC）に影響するDoS脆弱性CVE-2026-23864（CVSS 7.5）が公開された。Next.js App Routerを使ったアプリケーションが対象。2025年末の致命的RCEに続く第2波となる。

**影響範囲**:
- Next.js App Router（RSC使用）を本番環境で運用しているアプリ全般
- 細工されたリクエストを送信することでサーバーをDoS状態にできる

**対応**:
- Next.js最新版へのアップグレードで修正済み
- パッチ未適用環境は外部公開しているAPIルートのレート制限を即時強化

**個人開発者への影響**:
- Next.js App Routerを使ったSaaSは影響範囲の確認が必要
- **今すべきこと**: `npm outdated` でNext.jsバージョンを確認し `npm install next@latest` でアップデート

出典: [Netlify DoS脆弱性解説](https://www.netlify.com/changelog/2026-01-26-react-nextjs-dos-vulnerability/) / [Cybersecurity Dive](https://www.cybersecuritydive.com/news/critical-vulnerabilities-found-in-react-and-nextjs/807016/)
