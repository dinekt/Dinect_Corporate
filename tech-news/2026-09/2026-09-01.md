### 1. 米国防総省が GenAI.mil を正式公開 — ChatGPT Mil と Grok for Government が300万人超の軍関係者に解放

9月1日、米国防総省（DoD）は企業向けセキュア AI プラットフォーム **GenAI.mil** の全面稼働を正式発表した。OpenAI の ChatGPT Mil・xAI（イーロン・マスク）の Grok for Government・Google Gemini の3モデルが統合されており、軍人および民間職員 300万人以上が利用可能になった。すでに170万人以上がオンボード済みとされ、ChatGPT Mil はインパクトレベル5（機密指定なし・機密区分情報 CUI 対応）の認定を受け、商用モデルと完全に隔離された政府環境内で動作する。利用範囲は調達書類のドラフト・政策文書の要約・内規レポート生成・コンプライアンスチェックリスト作成などの非機密業務に限定されており、処理データは OpenAI の商用モデル学習に使用されない。これは米軍が生成 AI をオペレーション的に内製化した最初の大規模事例であり、AI を国防インフラの公式ツールチェーンとして組み込む世界的なトレンドの先駆けとなる可能性がある。

### 2. Google、Chrome Web Store から MV2 拡張機能を全削除 — uBlock Origin が消滅

8月31日〜9月1日にかけて、Google が Chrome Web Store から残存していた全ての Manifest V2（MV2）拡張機能を削除した。最も大きな影響を受けたのは約4,500万人が利用するオープンソース広告ブロッカー **uBlock Origin** であり、Chrome 用ストアから完全に消滅した。Google はManifest V3（MV3）への移行を数年がかりで進めてきており、Chrome 151（2026年7月28日リリース）で MV2 関連フラグが最終的に削除されたことで完全移行が完了した。既存インストール済みのコピーは動作継続するものの、更新受信・再インストールは不可となった。利用者は Firefox や Brave への乗り換え、または機能を絞った MV3 版「uBlock Origin Lite」への移行を迫られている。MV3 移行は Content Blocking API の制約によりブロッキング精度が低下するとする批判が多く、プライバシー重視ユーザーや開発者コミュニティからはブラウザの「囲い込み」に対する強い反発が続いている。

### 3. ShinyHunters が McKesson から 2億8400万件の患者データ窃取を主張 — 恐喝期限は本日

医薬品流通大手 **McKesson**（年商約2,000億ドル）が8月28日にサイバーインシデントを公式開示した。攻撃グループ ShinyHunters は「Okta SSO アカウントへのヴィッシング攻撃（音声フィッシング）で複数の従業員を欺き、Salesforce と Snowflake 環境にアクセス、8月21〜25日の4日間で約1TB のデータを抜き出した」と BleepingComputer に声明を出している。流出データには患者の PII・PHI（保護医療情報）・処方・請求記録・従業員情報・取引先医師クリニック情報が含まれるとされ、件数は 2億8400万件に上るという。ShinyHunters は 5,500万ドル（約83億円）の身代金を要求しており、**支払い交渉の期限は9月1日**（本日）とされている。McKesson は調査中と述べるにとどまっており、HIPAA 通知義務の観点からも当局が調査を開始する見込みだ。ヴィッシング手口で MFA を突破する攻撃はここ数年で急増しており、Snowflake 環境への不正アクセスは2024年の Ticketmaster・Santander 事件以来また大型事件として浮上する。

### Z.ai GLM-5.3 が FLock API Platform で公開 — コーディングベンチで前世代比 +50%

中国 AI ラボ Z.ai（知乗科技）が **GLM-5.3** および軽量版 **GLM-5.3-Flash** を FLock API Platform 上でリリースした。GLM-5.3 は Z.ai 独自の Code Bench において GLM-5.2 比で **50% のスコア向上** を達成しており、複雑なコーディング・ソフトウェアエンジニアリング・長期エージェントタスクに強みを持つと公式は説明する。同日 Perplexity も Mac 向けに **Hybrid モード**（Gemma 4 / Qwen3.6 / Perplexity 独自モデルをローカル処理）をロールアウトしており、クラウド API 依存を減らしながらプライバシーを確保する設計が注目を集めている。

```python
# Z.ai GLM-5.3 — FLock API Platform 経由の最小呼び出し例（2026-09時点のAPIイメージ）
import requests

endpoint = "https://api.flock.io/v1/chat/completions"
headers = {
    "Authorization": "Bearer <YOUR_FLOCK_API_KEY>",
    "Content-Type": "application/json",
}
payload = {
    "model": "glm-5-3",          # GLM-5.3 モデル指定
    "messages": [
        {"role": "system", "content": "You are a helpful coding assistant."},
        {"role": "user",   "content": "Implement a Python async generator that yields Fibonacci numbers."},
    ],
    "temperature": 0.2,
    "max_tokens": 512,
}
response = requests.post(endpoint, json=payload, headers=headers)
print(response.json()["choices"][0]["message"]["content"])
```

GLM-5.3 の登場は、DeepSeek・Qwen・GLM の各シリーズが「モデルサイズより推論コスト効率」を競う中国 AI エコシステムの成熟を示す一例であり、グローバルな基盤モデル競争において米国勢（OpenAI・Anthropic・Google）への対抗軸が多様化している。
