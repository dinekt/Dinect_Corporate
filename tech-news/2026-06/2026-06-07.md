### 3. Android 6 月セキュリティアップデート — 124 件を修正、Framework ゼロデイ CVE-2025-48595 が標的型攻撃で悪用中

Google が 6 月 2 日に公開した **2026 年 6 月 Android セキュリティアップデート**は、合計 **124 件の脆弱性**を修正する大規模パッチだ。最大の懸念は **CVE-2025-48595**（CVSS **8.4**・HIGH）で、Android Framework の **integer overflow** により、**ユーザーインタラクションなしにローカル権限昇格**が可能となる。対象バージョンは **Android 14・15・16・16-QPR2** と 2024 年以降のほぼ全アクティブバージョンをカバーする。「限定的・標的型の悪用が確認された」という Google の異例のコメントは、スパイウェアや国家支援型攻撃者が既にこの脆弱性を武器化していることを示唆する。CISA は即日 KEV カタログに追加し、連邦政府機関に **6 月 5 日までの修正**を義務付けた。重要度 Critical の脆弱性だけで 18 件が含まれ、Qualcomm・MediaTek 製チップセットのドライバを対象とする追加パッチは 2026-06-05 パッチレベルに収録されている。

### Uber × WeRide が欧州初の商業用ロボタクシーをマドリードで開始

Uber と中国系自動運転スタートアップ **WeRide** が 6 月初旬、スペイン・**マドリード**で**欧州初の商業用ロボタクシーサービス**を立ち上げた。乗客は Uber アプリから通常通り配車を依頼し、WeRide の完全自動運転車両が運行する。初期フェーズでは安全担当者が車内に同乗する段階的なアプローチをとりつつ、規制当局との連携のもとで段階的に無人運転へ移行する計画だ。BYD も同時期に欧州向けヒューマノイドロボット事業への本格参入を発表しており、中国テック企業の欧州進出が自動車・ロボティクス領域で加速している。

```python
# 自律走行車両の配車 API における典型的なリクエスト設計（教育目的サンプル）
import dataclasses
from enum import Enum

class RideStatus(Enum):
    REQUESTED   = "requested"
    DISPATCHED  = "dispatched"
    EN_ROUTE    = "en_route"
    ARRIVED     = "arrived"
    COMPLETED   = "completed"

@dataclasses.dataclass
class AutonomousRideRequest:
    origin_lat:            float
    origin_lng:            float
    dest_lat:              float
    dest_lng:              float
    passenger_count:       int  = 1
    accessibility_needed:  bool = False

def request_ride(req: AutonomousRideRequest) -> dict:
    payload = dataclasses.asdict(req)
    payload["vehicle_mode"] = "autonomous"
    # 実装例: 認証済み HTTP クライアントで配車エンドポイントに POST
    return {
        "status":      RideStatus.REQUESTED.value,
        "eta_minutes": 4,
        **payload,
    }

# 使用例
ride = request_ride(AutonomousRideRequest(
    origin_lat=40.4168, origin_lng=-3.7038,   # マドリード市内
    dest_lat=40.4530,   dest_lng=-3.6883,
))
print(ride)
```

## セキュリティ

### Android CVE-2025-48595 — Framework integer overflow、Android 14〜16 全バージョンで権限昇格が可能

今月の Android セキュリティアップデートで最優先の対応が求められるのが **CVE-2025-48595**（CVSS **8.4**・HIGH）だ。Android Framework コンポーネントの integer overflow により、**ローカルの攻撃者が追加権限なし・ユーザー操作なし**でシステム権限を昇格できる。Android 14・15・16・16-QPR2 が全て対象で、2024 年以降にリリースされたアクティブバージョンはほぼ網羅される。Google の「限定的・標的型の悪用確認」という表現は、スパイウェアや国家支援型脅威アクター（APT）が既に悪用しているケースで使われる文言であり、パッチ未適用の端末は深刻なリスクにさらされる。OEM 各社からのパッチ展開速度には差があるため、エンタープライズ環境では MDM を活用した一元的な適用状況の把握と強制アップデートが有効だ。

```bash
# --- CVE-2025-48595 対策チェックリスト ---

# 1. デバイスの現在のセキュリティパッチレベルを確認
adb shell getprop ro.build.version.security_patch
# 期待値: 2026-06-05 以降（2026-06-01 では Android Framework パッチのみ）

# 2. Android バージョンの確認
adb shell getprop ro.build.version.release
# 14, 15, 16 の場合は全て影響あり -> 即時パッチ適用を優先

# 3. エンタープライズ向け: Android Management API でコンプライアンスポリシーを設定
#    securityPatchTime が 2026-06-05 より新しいことを要件として定義
#    https://developers.google.com/android/management/reference/rest/v1/enterprises.policies

# 4. BYOD 環境では全ユーザーに通知: 設定 > セキュリティ > システムアップデート
#    パッチが利用可能なデバイスへの即時適用を案内する

# 5. Google Play Protect が有効であることを確認
adb shell am broadcast \
  -a com.google.android.gms.security.PROVIDER_INSTALL \
  --include-stopped-packages
```

**影響範囲と優先度**: Android 14 以降を搭載した全デバイス（個人・業務用とも）が対象。CISA が KEV に追加済みであり、連邦機関の期限は 6 月 5 日。民間組織も同等の優先度で対応を進めることが強く推奨される。
