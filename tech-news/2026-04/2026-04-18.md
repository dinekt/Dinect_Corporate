### 1. Anthropic、Claude Code Routines を研究プレビュー公開 — デスクトップアプリも全面刷新

4 月 14 日（米国時間）に発表された内容が週明け各メディアで詳細レポートとして揃い、Claude Code の二大アップデートが開発者コミュニティで広く注目された。

**デスクトップアプリ再設計の主な変更点:**
- マルチセッションサイドバー（複数エージェントを並列管理）
- ドラッグ&ドロップによるペインレイアウト
- 統合ターミナル、インアプリファイルエディタ
- HTML/PDF プレビュー拡張、差分ビューア刷新
- 対応プラットフォーム: macOS / Windows

**Routines（研究プレビュー）の仕様:**
- プロンプト・リポジトリ・コネクタをまとめた「実行設定」を定義
- スケジュール実行、API コールトリガー、GitHub イベント（PR 作成等）トリガーに対応
- Claude のクラウドインフラ上で動作するためローカルマシン不要
- 利用上限: Pro = 5回/日、Max = 15回/日、Team/Enterprise = 25回/日

**開発者への影響**:
- PR 作成時に自動でコードレビューが走るワークフローが設定なしで実現可能になった
- 「スケジュール実行 × リポジトリ連携」はローカル cron や CI ジョブの代替として機能し、小規模チームの運用コストを削減できる
- 並列セッション管理の UI 改善により、複数プロジェクトの同時進行が実用的な操作感に近づいた

**出典**: [Anthropic Blog — Redesigning Claude Code on desktop for parallel agents](https://claude.com/blog/claude-code-desktop-redesign) / [SiliconANGLE — Anthropic's Claude Code gets automated 'routines' and a desktop makeover](https://siliconangle.com/2026/04/14/anthropics-claude-code-gets-automated-routines-desktop-makeover/) / [9to5Mac — Anthropic adds routines to redesigned Claude Code](https://9to5mac.com/2026/04/14/anthropic-adds-repeatable-routines-feature-to-claude-code-heres-how-it-works/)

### 2. DeepSeek R2、リーク情報が出揃う — AIME 92.7%、32B オープンウェイト、西側比 70% 安

DeepSeek の次世代推論モデル R2 の詳細がリーク・事前情報として複数の技術メディアに出揃った。正式リリースはまだ行われていないが、ベンチマーク数値と仕様が概ね判明した状態にある。

**リーク・事前情報で判明している仕様:**
- パラメータ数: 32B（オープンウェイト）
- AIME 2025 スコア: 92.7%（15 問中 約 14 問正答相当）
- MATH-500 スコア: 89.4%（OpenAI o3 と同水準）
- 動作環境: 24 GB コンシューマー GPU 1 枚で推論可
- 価格: 西側フロンティア推論 API 比 約 70% 安

**遅延の背景**: Huawei Ascend チップでのトレーニング試みが難航し、中国当局の要請後に Nvidia ハードウェアに戻したことが主因とされる。

**開発者への影響**:
- 24 GB VRAM で動作する推論モデルがコスト 70% 削減で使える状況になれば、社内デプロイ（プライベート LLM 環境）の選択肢が一気に現実的になる
- 公式リリース後は Ollama や vLLM 経由でのローカル運用が即座に可能になると見込まれる
- Claude Opus / GPT-5.4 と競合するコスト帯に収まるため、API コスト最適化の選択肢が増える

**出典**: [DecodeFuture — DeepSeek R2 Explained: 92.7% AIME, 32B Open-Weight](https://decodethefuture.org/en/deepseek-r2-explained/) / [LM Council — AI Model Benchmarks Apr 2026](https://lmcouncil.ai/benchmarks)

### 3. Vercel Flags が GA — Next.js / SvelteKit に統合されたフィーチャーフラグ基盤

4 月 16 日、Vercel が機能フラグサービス「Vercel Flags」の一般提供（GA）を発表した。従来は LaunchDarkly 等のサードパーティサービスで構築していた機能フラグ管理が、Vercel ダッシュボードに統合された形で提供される。

**主な仕様:**
- Vercel ダッシュボードでフラグ作成・ターゲティングルール・ユーザーセグメント・環境制御が可能
- Flags SDK: Next.js / SvelteKit 向けのフレームワークネイティブ統合（TypeScript 完全サポート）
- 他フレームワーク向け: OpenFeature 標準アダプタ対応
- Runtime Logs でのフラグ評価追跡・Web Analytics との連携

**Next.js 16.2 との組み合わせ:** Flags SDK がキャッシュと低オーバーヘッド設計で評価パフォーマンスを改善。ダイナミックインポートのモジュールをローカル変数にキャッシュする実装で初回以降のオーバーヘッドを最小化。

**開発者への影響**:
- A/B テストやカナリアリリースをプラットフォーム外ツールなしに実施できるようになった
- `npm install @vercel/flags` の追加で既存 Next.js プロジェクトに即統合可能
- LaunchDarkly（月 $16/シート〜）などのコストを Vercel プランに包含できる可能性

**出典**: [Vercel Changelog — Vercel Flags is now generally available](https://vercel.com/changelog/vercel-flags-ga) / [Vercel Docs — Flags](https://vercel.com/docs/flags)

## セキュリティ

### Chrome ゼロデイ CVE-2026-5281 — CISA が 4 月 15 日期限で連邦機関に緊急適用指示

Chrome の WebGPU 実装（Dawn）における use-after-free 脆弱性 CVE-2026-5281 が 4 月初旬にゼロデイとして悪用が確認され、CISA が 4 月 1 日に KEV（既知悪用脆弱性）カタログに追加。連邦機関に対しては 4 月 15 日までの適用を義務付けた。

**対応:**
- Chrome を最新版に更新（Chrome 更新: `chrome://settings/help` から確認）
- 社内展開 Chrome がポリシー管理下の場合、Google Chrome Enterprise リリースノートで対象バージョンを確認

### 108 件の悪意ある Chrome 拡張キャンペーンが発覚

Socket の脅威研究チームが、共通の C2 インフラで連携する 108 件の Chrome 拡張を特定した。5 つの発行者 ID 名義で公開され、合計 約 2 万インストールを記録。主な攻撃手法:
- 54 拡張: OAuth2 経由で Google アカウント情報を窃取
- 1 拡張: 15 秒ごとに Telegram Web セッションを外部送信
- 2 拡張: YouTube のセキュリティヘッダーを除去して広告を注入

**Chrome 拡張開発者への示唆**: `declarativeNetRequest` API の権限設計と Content Security Policy の実装が攻撃ベクタに含まれるため、自社拡張の権限スコープを最小化する設計を改めて確認する価値がある。

**出典**: [Socket Blog — 108 Chrome Extensions Linked to Data Exfiltration and Session Theft](https://socket.dev/blog/108-chrome-ext-linked-to-data-exfil-session-theft-shared-c2) / [Cybernews — Over 100 Chrome extensions flagged for stealing user data](https://cybernews.com/security/chrome-extensions-flagged-for-stealing-user-data/)
