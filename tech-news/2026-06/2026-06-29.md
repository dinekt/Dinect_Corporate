### 2. Colorado AI Act、元施行日の明日(6/30)を前に骨抜き改正・2027年1月まで延期 — 米国AI規制は「イノベーション優先・最小限規制」へ転換

**明日6月30日が元々の施行予定日**だったColorado AI Act（SB 24-205）が、実質的なリセットを迎えた。コロラド州知事Polis氏が5月14日に署名した**SB 189**により施行日は2027年1月1日に延期された上、法律の骨格自体が大幅に縮小された。当初の法律はAIシステムが関与する「高リスク」な意思決定（融資審査・採用・住宅・教育など）に対し、開発者・展開者双方に**包括的なリスク管理プログラムの整備・影響評価の実施・アルゴリズム差別防止義務**を課す、米国州レベルではEUのAI Actに最も近い先駆的な内容だった。しかし改正後は**開示・透明性要件に特化した狭い枠組み**へと縮小されており、差別防止のための注意義務規定・展開者向けリスク管理義務・コロラド州司法長官への報告義務は撤廃されている。この背景には3つの力学がある。①ホワイトハウスが6月2日に発令した大統領令「**Promoting Advanced Artificial Intelligence Innovation and Security**」が州レベルの過剰規制を牽制したこと、②超党派「Great American AI Act」草案（6月4日）が州AI法への**3年間プリエンプション条項**を含むこと、③連邦裁判所による執行差止め（4月27日）が既に施行を事実上停止していたこと。EUのAI Act完全施行（8月2日）まで34日に迫る中、米国は連邦・州レベルで「強規制モデル」から「イノベーション優先・透明性開示ベース」へと明確に軸足を移している。

### 3. CISA KEV: Cisco Unified CM の SSRF→RCE（CVE-2026-20230）— 連邦機関の修正期限が昨日(6/28)到来、民間でも即時対応が必須

CISA（米サイバーインフラセキュリティ庁）は6月25日、**Cisco Unified Communications Manager（Unified CM）および Cisco Unified CM SME のサーバーサイドリクエストフォージェリ（SSRF）脆弱性 CVE-2026-20230** を既知悪用脆弱性（KEV）カタログへ追加した。この脆弱性はWebDialerサービスが有効な環境において、認証不要のリモート攻撃者が細工したHTTPリクエストを送信することで基盤となるOSへの**任意ファイル書き込み**が可能となり、最終的に**root権限への昇格**につながる。セキュリティ企業Defusedが実際の攻撃での悪用を確認しており、Binding Operational Directive（BOD）26-04に基づく連邦機関への修正期限は**6月28日（昨日）**だった。Cisco Unified CM は電話・ビデオ会議・メッセージングを統合するUCシステムのコアプラットフォームであり、大企業・官公庁を中心に世界的に広く展開されている。脆弱性の根本原因は特定HTTPリクエストに対する不適切な入力バリデーションであり、WebDialerサービスの無効化またはCisco提供パッチ（Unified CM 14SU5 / 15SU2 以降）の適用が対処策となる。

**出典**: [CISA: CISA Adds Two Known Exploited Vulnerabilities to Catalog (2026-06-25)](https://www.cisa.gov/news-events/alerts/2026/06/25/cisa-adds-two-known-exploited-vulnerabilities-catalog) / [BleepingComputer: CISA sets urgent deadline to fix Cisco flaw exploited in attacks](https://www.bleepingcomputer.com/news/security/cisa-sets-urgent-deadline-to-fix-cisco-flaw-exploited-in-attacks/) / [Cisco Security Advisory: cisco-sa-cucm-ssrf-cXPnHcW](https://www.cisco.com/c/en/us/support/docs/csa/cisco-sa-cucm-ssrf-cXPnHcW.html) / [Threat-Modeling.com: CVE-2026-20230](https://threat-modeling.com/cve-2026-20230-cisco-unified-communications-manager-ssrf-rce/) / [GBHackers: CISA Adds Actively Exploited Cisco Unified CM Flaws to KEV Catalog](https://gbhackers.com/cisa-adds-actively-exploited-cisco-unified-cm-flaws-to-kev-catalog/amp/)

### Karpathy AutoResearch — AIエージェントが2日間で700実験を自律実行しGPT-2学習を11%高速化、Anthropicが次世代Claude学習に応用へ

元Tesla AI部門・OpenAI共同創業者で5月19日にAnthropicへ参加した**Andrej Karpathy**が、AI自律実験フレームワーク**AutoResearch**（Pythonで実装した630行のオープンソースツール）を公開した。シンプルなエージェントが①MLトレーニングコードを自ら編集し②5分間の実験を実行し③モデルが改善したかを評価し④改善していれば次のコード変更を提案する——この**「Karpathyループ」**を連続実行することで、2日間で700の実験を自律的に消化し、GPT-2規模モデルの訓練時間を**約2時間から1.8時間へ（11%短縮）**することに成功した。さらに注目すべき点として、このプロセスでKarpathy自身が20年間気づかなかった20の改善点をAIエージェントが自発的に発見したという。Anthropicは「Claude を使って次の Claude を構築する」というアプローチの一環として、このAutoResearchループを**Claudeの事前学習パイプライン**に組み込む作業を進めており、フロンティアモデルの研究サイクル自体をAIが短縮するという次のフェーズが具体化しつつある。

```python
# Karpathy AutoResearch のコアループ概念（簡略版）
# 実際のフレームワーク: 630行 Python、実験単位を5分に設定

import subprocess
from pathlib import Path

def run_single_experiment(code: str, exp_id: int, timeout_secs: int = 300) -> float:
    """改変されたトレーニングコードを実行し val_loss を返す"""
    script = Path(f"/tmp/exp_{exp_id}.py")
    script.write_text(code)
    result = subprocess.run(
        ["python", str(script)],
        capture_output=True, text=True, timeout=timeout_secs
    )
    # 最終行から val_loss を抽出（実装ではより精緻なパース）
    last_line = result.stdout.strip().split("\n")[-1]
    return float(last_line.split("val_loss=")[-1])

def automl_loop(base_code: str, llm_propose, max_experiments: int = 700):
    """
    LLMがコードを提案 → 実験 → 評価 → 次の提案、を繰り返す。
    700回の反復で GPT-2 の訓練コストを11%削減（2日間での実行）。
    """
    best = {"loss": float("inf"), "code": base_code}
    history: list[dict] = []

    for i in range(max_experiments):
        # 直近10件の実験履歴をLLMに渡してコード改善案を生成
        candidate_code = llm_propose(best["code"], history[-10:])
        try:
            val_loss = run_single_experiment(candidate_code, i)
        except subprocess.TimeoutExpired:
            continue  # タイムアウトは破棄して次の実験へ

        history.append({"exp_id": i, "val_loss": val_loss})
        if val_loss < best["loss"]:
            best = {"loss": val_loss, "code": candidate_code}
            print(f"[Exp {i:03d}] ✓ improved: val_loss={val_loss:.4f}")

    return best

# 700実験 / 2日 → GPT-2 training: 2.0h → 1.8h (−11%)
# 人間研究者が20年で見逃した改善点を20個自動発見
```

このアプローチが示す本質的な意味は、**AIが自分自身の訓練手法を改善する「メタ学習ループ」**の実用化だ。研究コストの削減という観点を超え、AIの性能改善速度そのものをAIが加速するという構造的な変化が始まっている。
