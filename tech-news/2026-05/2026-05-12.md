### TypeScript が GitHub PR 量でついに JavaScript を逆転 — 事実上の主言語交代が完了

GitHub Octoverse の最新データによると、新規プルリクエストの作成量において **TypeScript が JavaScript を追い越した**。この傾向は 2024 年頃から続いており、2026 年に入って逆転が確定した形だ。React・Next.js・NestJS・Bun など主要フレームワークがデフォルトで TypeScript を採用し、型安全性と IDE 補完の恩恵が広く認識されたことが背景にある。新規プロジェクトでは JavaScript を選ぶ理由がほぼなくなりつつある一方、既存の大規模 JavaScript コードベースの TypeScript 移行コストは依然として課題だ。

```typescript
// TypeScript 5.x: satisfies 演算子 + const アサーションの組み合わせ
// 型推論の精度を保ちながら型チェックを強制できる
const config = {
  endpoint: "https://api.example.com",
  retries: 3,
  timeout: 5000,
} satisfies Record<string, string | number>;

// テンプレートリテラル型による URL パス型安全性
type ApiPath = `/api/${string}`;
const userPath: ApiPath = "/api/users"; // OK
// const badPath: ApiPath = "/users";   // Error: string is not assignable to `/api/${string}`

// using キーワード（Explicit Resource Management）
async function withConnection() {
  await using conn = await getDbConnection();
  return conn.query("SELECT 1");
  // スコープを抜けると conn.dispose() が自動呼び出し
}
```

## セキュリティ

### CVE-2026-23918: Apache HTTP/2 二重解放でDoS・RCE の恐れ（CVSS 8.8）

Apache HTTP Server 2.4.66 以前に存在する **HTTP/2 の二重解放（double-free）脆弱性**（CVE-2026-23918）が The Hacker News で詳細報告された。CVSS スコアは 8.8（High）で、悪用に成功すると DoS に加えてリモートコード実行（RCE）に至る可能性がある。修正版は 2.4.67 で提供済みであり、公開 Web サーバーを運用している場合は即時アップデートが推奨される。

```bash
# Apache バージョン確認とアップデート手順
apachectl -v
# Server version: Apache/2.4.66 → 要アップデート

# Debian / Ubuntu
sudo apt update && sudo apt install apache2

# RHEL / CentOS Stream / Fedora
sudo dnf update httpd

# アップデート後の確認
apachectl -v
# Server version: Apache/2.4.67 以降であれば対応済み

# HTTP/2 が有効かどうか確認（有効な場合は特に優先度高）
grep -r "Protocols" /etc/apache2/ /etc/httpd/ 2>/dev/null | grep h2
```

**出典**: [Critical Apache HTTP/2 Flaw (CVE-2026-23918) Enables DoS and Potential RCE — The Hacker News](https://thehackernews.com/2026/05/critical-apache-http2-flaw-cve-2026.html)

### CVE-2026-0300: Palo Alto Networks PAN-OS バッファオーバーフロー — 未認証 RCE で野外悪用を確認

Palo Alto Networks の PAN-OS に存在するバッファオーバーフロー脆弱性（CVE-2026-0300）が実際の攻撃に利用されていることが確認された。認証なしでのリモートコード実行が可能であり、境界防御の核心部分であるファイアウォール自体が侵害の足がかりになるという皮肉な状況だ。PAN-OS を運用している環境では Palo Alto Networks のセキュリティアドバイザリを確認し、ベンダー提供パッチの適用または一時的な回避策（管理インターフェースへのアクセス制限）を早急に実施すること。

### Copy Fail (CVE-2026-31431) CISA 期限まで残り 3 日 — 連邦機関・クラウド環境は 5/15 まで

Linux カーネルの Copy Fail 脆弱性（CVE-2026-31431、CVSS 7.8）は CISA の KEV カタログ入りしており、米国連邦文民機関の適用期限は **5 月 15 日（木）**と 3 日後に迫っている。この脆弱性は 2017 年以降のカーネルが対象で、コンテナブレイクアウトやマルチテナント環境での横断移動リスクが特に高い。前日報告の Dirty Frag（CVE-2026-43284/43500）と合わせ、Linux 基盤を持つ本番・クラウド環境は今週末までのカーネル更新が不可避となっている。
