### 1. Z.AI が GLM-5.3-Flash を MIT ライセンスで公開 — 初の GLM-5 系ネイティブマルチモーダルモデル

中国の Zhipu AI（Z.AI）は 2026 年 8 月 26 日、最新オープンウェイトモデル「GLM-5.3-Flash」を MIT ライセンスで公開した。同モデルは GLM-5 シリーズとして初めてネイティブマルチモーダルに対応しており、総パラメータ数 320B の MoE（Mixture of Experts）構成で、推論時に 18B が有効化される。コンテキストウィンドウは約 131 万トークン（1,310,720）と業界最大クラスであり、コーディング・エージェント・長文処理に特化して設計されている。前モデル GLM-5.2 と比較してコストは 10 分の 1（入力 $0.15/MTok、出力 $0.50/MTok）を実現しており、9 月 9 日まで 50% オフのプロモーション価格も提供されている。オープンウェイトかつ MIT ライセンスという組み合わせは、商用・オンプレミス利用の障壁を大幅に引き下げ、コモディティ化が進む LLM 市場においてコスト効率を重視する開発者・企業の選択肢として注目を集めている。

### 2. Go 1.27 正式リリース — ジェネリックメソッドと JSON v2 でエコシステムが大幅刷新

Google は 2026 年 8 月 19 日、Go 言語の最新安定版 **Go 1.27** を正式リリースした。最大の目玉はコンクリート型へのジェネリックメソッド対応であり、型パラメータをメソッドレベルで宣言できるようになった（インターフェースメソッドは対象外）。これにより、パッケージスコープの汎用関数を型の名前空間に収める設計が可能となり、API の表現力が向上する。また、`encoding/json/v2` として JSON エンジンが全面刷新され、`crypto/mldsa` による ML-DSA ポスト量子暗号サポート、ネイティブ UUID 生成（`uuid` パッケージ）が標準ライブラリに追加された。ランタイム面では小オブジェクトのメモリアロケーションが大幅高速化され、ゴルーチンリークのプロファイリング機能も追加されている。10 件のセキュリティ修正も含まれており、HTTP・TLS・DNS パースなど多岐にわたるハンドリングがより安全になった。

### Go 1.27 ジェネリックメソッド詳解 — 実装パターンの変化

Go 1.27 で導入されたジェネリックメソッドにより、型の名前空間に型パラメータを持つメソッドを定義できるようになった。以下は新旧の実装比較例。

```go
// Go 1.26 以前: パッケージスコープのジェネリック関数
func Map[T, U any](s []T, f func(T) U) []U {
    result := make([]U, len(s))
    for i, v := range s {
        result[i] = f(v)
    }
    return result
}

// Go 1.27 以降: コンクリート型のジェネリックメソッド
type Slice[T any] []T

// メソッド自身に型パラメータ U を宣言できる
func (s Slice[T]) Map[U any](f func(T) U) []U {
    result := make([]U, len(s))
    for i, v := range s {
        result[i] = f(v)
    }
    return result
}

// encoding/json/v2 の新 API (標準ライブラリ刷新)
import "encoding/json/v2"

type Config struct {
    Host    string `json:"host"`
    Port    int    `json:"port,omitempty"`
    Debug   bool   `json:"debug"`
}

func main() {
    cfg := Config{Host: "localhost", Port: 8080}

    // v2 の Marshal はエラーを明示的に返す設計に変更
    data, err := json.Marshal(cfg)
    if err != nil {
        panic(err)
    }

    // ML-DSA ポスト量子署名 (crypto/mldsa)
    // NIST FIPS 204 準拠のポスト量子暗号署名アルゴリズム
    import "crypto/mldsa"
    pk, sk, _ := mldsa.GenerateKey(nil)
    sig, _ := sk.Sign(nil, []byte("message"), nil)
    ok := mldsa.Verify(pk, []byte("message"), sig)
    _ = ok // true
}
```

VS Code 1.135 も同期間にリリースされ、Agents ウィンドウの整理、他アプリからの Copilot / Claude エージェントセッション引継ぎ、実験的な「Rubber Duck 二次意見」機能、モデル別チャット使用量トラッキングが追加されている。
