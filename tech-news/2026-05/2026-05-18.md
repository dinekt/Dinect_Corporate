### 1. NGINX Rift（CVE-2026-42945）— 18 年潜伏したヒープバッファオーバーフローが野放し悪用フェーズに突入

5 月 13 日に PoC が公開されてから 3 日後の **5 月 16 日**、VulnCheck のカナリアシステムが CVE-2026-42945 の実環境での悪用を検知した。NGINX の `ngx_http_rewrite_module` に存在するこのヒープバッファオーバーフローは NGINX 0.6.27（2008 年リリース）以来 18 年にわたりコードベースに潜伏していたもので、影響範囲は **NGINX Open Source 1.0.0〜1.30.0 および NGINX Plus R32〜R36** と極めて広い。細工した HTTP リクエストを送りつけるだけで未認証リモートからワーカープロセスをクラッシュさせる DoS が成立し、ASLR を無効化できる条件が揃えば任意コード実行（RCE）にも至る。修正済みバージョンは **Open Source 1.30.1 / 1.31.0** および **Plus R32 P6 / R36 P4** で、即時パッチ適用が最優先事項となっている。NGINX Ingress Controller・Gateway Fabric・App Protect WAF・F5 WAF も影響を受けるため、クラウドネイティブ環境でのリバースプロキシ全体を確認すること。

### Claude Opus 4.7 — 高解像度画像対応・新トークナイザー・xhigh 推論努力レベルを導入

4 月 16 日にリリースされた **Claude Opus 4.7** は、現行 Claude シリーズで最も高い汎用推論性能を持つモデルとして GA になった。主な新機能は 3 点：(1) **高解像度画像対応**（最大 2576px / 3.75 MP、旧 1568px から約 3.3 倍に拡大）でドキュメント解析・図面読み取り精度が大幅改善、(2) **新トークナイザー**の採用でコードや多言語テキストのトークン効率が向上、(3) `high` と `max` の間に追加された **xhigh 努力レベル**により、推論の深さとレイテンシのトレードオフを細かくチューニングできる。Anthropic は同モデルで「これまで人の監督が必要だった最難関コーディングタスクを安心して委任できる水準」と説明している。価格は Opus 4.6 と同一（入力 $5/M・出力 $25/M トークン）で、Amazon Bedrock・Google Vertex AI・Microsoft Foundry を含む全主要プラットフォームで利用可能だ。

```python
import anthropic

client = anthropic.Anthropic()

# xhigh 努力レベルで複雑なコードレビューを実行する例
response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=16000,
    thinking={
        "type": "enabled",
        "budget_tokens": 10000,  # xhigh に相当する思考予算
    },
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "image",
                    "source": {
                        "type": "base64",
                        "media_type": "image/png",
                        "data": architecture_diagram_base64,  # 2576px まで対応
                    },
                },
                {
                    "type": "text",
                    "text": "このアーキテクチャ図のセキュリティ上の問題点を列挙し、優先順位付きの改善案を提示してください。",
                },
            ],
        }
    ],
)
print(response.content[-1].text)
```

### CVE-2026-42945（NGINX Rift）— 緊急対応チェックリスト

```bash
# 1. バージョン確認
nginx -v
# → nginx/1.30.0 以下なら要アップデート

# 2. HTTP/2 有効状態とリライトモジュール設定の確認
nginx -T | grep -E "(http2|rewrite)"

# 3. 脆弱なリライトパターンの特定
# "unnamed capture ($1/$2) + ? を含む置換文字列" が危険なパターン
grep -rn 'rewrite.*\$[0-9]' /etc/nginx/
# 例: rewrite ^/old/(.*)$ /new/$1?; ← 危険（? の後に次のディレクティブがある場合）

# 4. 即時緩和策（アップグレード不可の場合）
# unnamed capture を named capture に書き換える
# 変更前: rewrite ^/api/(.*)$ /v2/$1? break;
# 変更後: rewrite ^/api/(?P<path>.*)$ /v2/${path}? break;

# 5. パッチ適用（Debian/Ubuntu 系）
sudo apt update && sudo apt install nginx
# RHEL/CentOS 系
sudo dnf update nginx
# Alpine（Kubernetes Init コンテナ含む）
apk upgrade nginx
```

影響範囲は Web サーバーとしての NGINX にとどまらず、**NGINX Ingress Controller**（Kubernetes）・**NGINX Gateway Fabric**・**NGINX App Protect WAF** も対象となる。Kubernetes クラスターで Ingress Controller を利用している場合は Helm チャートのイメージタグを確認し、upstream イメージが 1.30.1 以上に更新済みかを検証すること。

### Microsoft Exchange Server CVE-2026-42897 — XSS / スプーフィング零日が野放し悪用中

Microsoft は **Exchange Server Subscription Edition・2016・2019** に存在する **CVE-2026-42897**（スプーフィング + 格納型 XSS）の実環境での悪用を公式確認した。攻撃者は細工したメール本文を通じて OWA（Outlook Web Access）上でスクリプトを実行させ、セッションクッキーの窃取や管理者なりすましを行える。Exchange Online（クラウド版）は影響を受けない。オンプレミス Exchange を運用する組織は **2026 年 5 月の Patch Tuesday 累積アップデート**を即時適用し、OWA へのアクセス元 IP を信頼範囲に絞る IP ベースの制限を一時的な緩和策として検討されたい。
