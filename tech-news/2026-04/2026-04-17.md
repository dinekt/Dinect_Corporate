## 本日のニュース TOP 3

### 1. Stanford AI Index 2026 — 中国が米国のAIリードをほぼ消滅、Arena 差はわずか 39 ポイントに

Stanford HAI が公開した「2026 AI Index Report」によると、かつて米国が大きなアドバンテージを持っていた AI モデル性能差が、2026 年 3 月時点でわずか 39 Arena ポイント（2.7%）まで縮小した。2023 年 5 月時点では米国トップモデルが 1,300 ポイント以上の差をつけていたことを考えると、驚異的な追い上げといえる。米国はまだ高品質モデルの数（2025 年に 50 本 vs 中国 30 本）とハイインパクト特許で優位を保っているが、中国は論文件数・引用シェア・特許取得件数・ロボティクスで米国を凌駕している。さらに、米国への海外 AI 人材流入が鈍化しているという人材面の懸念も報告されており、地政学的な AI 競争が新たな局面を迎えていることを示している。Fortune が「nearly erased」と表現したこの逆転劇は、AI 規制・投資・安全保障政策のあり方にも影響を与えそうだ。

**開発者・ビジネスへの影響**:
- 中国発のオープンソースモデル（後述の GLM-5.1 など）が性能・ライセンス面で急速に競争力を高めており、モデル選定時に地政学リスクとライセンス条件を同時に評価する重要性が増している
- AI 政策・規制の変化スピードが上がっており、グローバルにサービスを展開する開発者はコンプライアンス要件の継続的なモニタリングが必要

### 2. Anthropic Claude Mythos — 史上最高性能モデルを非公開、Project Glasswing でゼロデイ検出に活用

Anthropic は、同社が開発した最強モデル「Claude Mythos」が SWE-bench Verified で 93.9%、GPQA Diamond で 94.6% というスコアを記録し、さらにすべての主要 OS・ブラウザにわたる数千件のゼロデイ脆弱性を自律的に発見したことを確認した。しかし同モデルは一般公開されず、「Project Glasswing」と呼ばれるプログラムのもとで 50 の審査済み組織のみがゲートアクセスを受ける形をとっている。参加組織の役割はモデルを攻撃ではなく防御目的に使い、自組織のインフラを脆弱性スキャンすることだ。AI が実際にゼロデイを大量発見できる能力を持つことが証明された一方、その能力を限定公開にとどめるという Anthropic の選択は、フロンティアモデルのリリース判断における安全性議論を加速させている。OpenAI も 4 月 14 日に「GPT-5.4-Cyber」をリリースし、Trusted Access for Cyber プログラムを数千人規模に拡大して対抗姿勢を見せている。

**開発者・セキュリティ担当者への影響**:
- AI によるゼロデイ自動検出が現実のものとなり、脆弱性対応のサイクルが今後さらに短縮される可能性がある。パッチ適用の優先度付けと自動化の仕組みを今から整備しておくことが重要
- 高能力 AI の段階的公開モデル（gated access）が業界スタンダードになりつつあり、モデルの利用可否を前提としたシステム設計は将来的なリスクになりうる

**出典**: [Prism News — Anthropic withholds Claude Mythos](https://www.prismnews.com/news/anthropic-withholds-powerful-ai-model-after-it-finds-zero) / [What LLM? — New AI Models April 2026](https://whatllm.org/blog/new-ai-models-april-2026)

### 3. Microsoft 4月 Patch Tuesday — 167 件修正、SharePoint ゼロデイ (CVE-2026-32201) が野外で積極悪用中

Microsoft は 4 月の Patch Tuesday で 167 件の脆弱性を修正し、そのうち 2 件が野外で積極悪用されているゼロデイだった。特に注目されるのは SharePoint Server の CVE-2026-32201（CVSS 6.5）で、ネットワーク経由で認証なしに XSS 系のスプーフィング攻撃が可能となる欠陥だ。CISA はこれを Known Exploited Vulnerabilities (KEV) カタログに追加し、連邦政府機関に 4 月 28 日までの修正を義務付けた。今月の Patch Tuesday はほかにも Critical 8 件（うち RCE 7 件、DoS 1 件）を含む大規模なアップデートで、SAP・Adobe・Fortinet・Cisco 各社も同時期にパッチを公開している。The Register は「It's raining bugs」と表現するほどの修正量で、エンタープライズ環境では優先度付けの作業が急務となっている。

**開発者・運用者への影響**:
- SharePoint をオンプレまたはハイブリッドで運用している組織は、4 月 28 日のCISA期限前に CVE-2026-32201 のパッチ適用を最優先で実施すること
- 今月は対象製品・ベンダーが広範にわたるため、パッチ管理ツールでのリスクスコアリングによる優先度付けが特に重要

**出典**: [BleepingComputer — Microsoft April 2026 Patch Tuesday](https://www.bleepingcomputer.com/news/microsoft/microsoft-april-2026-patch-tuesday-fixes-167-flaws-2-zero-days/) / [The Hacker News — SharePoint Zero-Day](https://thehackernews.com/2026/04/microsoft-issues-patches-for-sharepoint.html) / [Security Affairs](https://securityaffairs.com/190831/security/microsoft-patch-tuesday-for-april-2026-fixed-actively-exploited-sharepoint-zero-day.html)

## 新技術・新リリース

### Zhipu AI GLM-5.1 — MIT ライセンスで GPT-5.4 をコーディングで超える

中国の Zhipu AI がオープンソースモデル「GLM-5.1」を MIT ライセンスで公開し、コーディングベンチマークで GPT-5.4 を上回るスコアを記録した。MIT ライセンスでの商用利用が完全に自由であることが特徴で、欧米の商用クローズドモデルに代わる選択肢として注目が集まっている。Stanford AI Index が指摘した中国モデルの台頭を象徴するリリースといえる。

### OpenAI Agents SDK 更新 — コンフィギュラブルメモリ・スナップショット機能追加

OpenAI は Agents SDK を更新し、設定可能なメモリ（configurable memory）、標準化されたツールインテグレーション、ポータブルワークスペースサポート、ビルトインスナップショット機能（durable agent runs のため）を追加した。ネイティブサンドボックス実行によりファイル・ツール・コードワークフローの安全性も強化されている。

```python
# Agents SDK 更新後の永続エージェント例
from agents import Agent, Runner, MemoryStore

agent = Agent(
    name="persistent-assistant",
    memory=MemoryStore(backend="snapshot"),  # 新: スナップショットバックエンド
    tools=[...],
)

# ポータブルワークスペースで実行 → セッション間で状態が継続
result = await Runner.run(agent, "前回の続きから作業してください")
print(result.workspace_id)  # 新: ワークスペースIDで再開可能
```

### Gemma 4 — Google が Apache 2.0 で最強オープンウェイトファミリーを公開

Google はオープンウェイトモデルの最新世代「Gemma 4」を Apache 2.0 ライセンスで公開した。同社が「これまでで最も強力なオープンウェイトファミリー」と位置付けており、商用・研究・個人利用のすべてで制限なく使用できる。GLM-5.1 と合わせ、オープンソース AI の競争が高性能フロンティアモデルに迫るフェーズに入ってきている。

### Apache ActiveMQ — CVE-2026-34197 が野外で積極悪用、CISA が 4/30 期限を設定

Apache ActiveMQ Classic の CVE-2026-34197（CVSS 8.8）は、不正な入力検証に起因するコードインジェクション脆弱性で、攻撃者が影響を受けるインストール上で任意コードを実行できる。CISA は KEV カタログへの追加と同時に、連邦政府機関に対して 2026 年 4 月 30 日までのパッチ適用を義務付けた。ActiveMQ はメッセージブローカーとしてエンタープライズシステムに広く組み込まれており、影響範囲が広い点に注意が必要だ。

### NIST NVD — CVE 爆増に対応、エンリッチメント対象を条件付きに変更

NIST は、CVE 登録件数が 2020〜2025 年間で 263% 増加したことを受け、National Vulnerability Database（NVD）において一定条件を満たした CVE のみをエンリッチ（詳細情報付与）する方針を発表した。エンリッチされない CVE は基本情報のみの公開となるため、セキュリティツールや脆弱性管理プラットフォームがどの情報ソースに依存しているかの再確認が必要になってくる。
