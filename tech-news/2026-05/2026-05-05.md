### Apache HTTP Server 2.4.67 リリース — HTTP/2 ダブルフリー RCE（CVE-2026-23918）修正、リバースプロキシ構成は特に優先アップグレードを

Apache HTTP Server が **バージョン 2.4.67** をリリースし、HTTP/2 実装にあったダブルフリーのメモリ破壊脆弱性（CVE-2026-23918、重要度: High）を含む複数のセキュリティ修正を行った。この脆弱性は HTTP/2 ストリーム処理時に同一メモリ領域を二度解放してしまうロジックバグで、ヒープが破壊されることで攻撃者がコード実行パスを操作できる可能性がある。現時点での野生悪用は未確認だが、同じリリースで **mod_proxy** のリクエストスマグリングも修正されており、リバースプロキシ構成を取る環境では特にアップグレードの優先度が高い。

```bash
# Apache バージョン確認（2.4.67 未満なら即アップグレード）
$ apache2 -v
Server version: Apache/2.4.67 (Debian)

# HTTP/2 モジュールが有効か確認
$ apachectl -M | grep http2
 http2_module (shared)

# パッチ前の暫定緩和策 — HTTP/2 を無効化して http/1.1 のみ許可
# /etc/apache2/sites-available/your-site.conf
<VirtualHost *:443>
    Protocols http/1.1
</VirtualHost>

# Debian / Ubuntu 系アップグレード
$ sudo apt update && sudo apt upgrade apache2

# RHEL / Rocky / AlmaLinux 系アップグレード
$ sudo dnf update httpd
```

暫定緩和策として HTTP/2 を無効化できるが、HTTP/2 の性能上のメリット（ヘッダー圧縮・ストリーム多重化）を失うトレードオフがある。パッチ適用後は HTTP/2 を再度有効化することで影響を最小限に抑えられる。

### MOVEit CVE-2026-4670 — 運用者向け緊急対応チェックリスト

2023 年の大規模侵害（数百組織への影響）の教訓を踏まえると、MOVEit 系の新脆弱性は開示直後から攻撃者の標的となる傾向が強い。

**即時確認事項:**
- MOVEit Automation のバージョンが **2025.1.5 / 2025.0.9 / 2024.1.8 以降** でなければ即刻アップグレード
- 管理コンソールへの外部アクセスを IP ホワイトリストで制限
- サービスバックエンドのコマンドポート（デフォルト: 8089）をファイアウォールで遮断し外部に露出させない

**再発防止:**
- MOVEit のセキュリティアドバイザリ RSS を監視し、新脆弱性開示後 24 時間以内のパッチ適用を運用ポリシーに明記
- CVE-2026-5174（特権昇格）との組み合わせ悪用に備え、最小権限の原則を改めて確認する

### Linux "Copy Fail" CVE-2026-31431 — CISA が KEV に追加、FCEB 機関は 5/15 までに対応必須

Linux カーネルの権限昇格脆弱性 **CVE-2026-31431**（通称: Copy Fail）が CISA の**既知悪用脆弱性（KEV）カタログ**に追加された。ローカルユーザーが root 権限を取得できる LPE（Local Privilege Escalation）脆弱性で、クラウド環境の共有ホストでは特にリスクが大きい。連邦政府系機関（FCEB）には **5 月 15 日**までの修正が義務付けられており、一般の組織も早急なカーネルアップデートが推奨される。Ubuntu・Debian・RHEL・Fedora 等の主要ディストリビューション向けパッチはすでに配布済みで、`apt upgrade` または `dnf update kernel` で適用できる。
