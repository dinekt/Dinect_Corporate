### 1. Anthropic、Claude Fable 5 公開 — ほぼ全ベンチマーク SOTA・iOS 17 では初のサードパーティ AI として iPhone に搭載

Anthropic は **Claude Fable 5**（一般向け）と信頼アクセスユーザー向けの **Claude Mythos 5** を正式公開した。Fable 5 はソフトウェアエンジニアリング・知識業務・ビジョン・科学リサーチを含むほぼ全ての評価ベンチマークで最高水準（SOTA）を達成しており、長文コンテキスト性能と安全性向上も両立している。また Apple が **WWDC 2026**（6 月 8〜12 日）で発表した **iOS 27 マルチ AI 拡張システム**により、Claude は **iPhone で初めて選択可能なサードパーティ AI** となった。Apple の新 Foundation Models フレームワークが提供する `LanguageModel` プロトコルを各 AI プロバイダが実装する形で、Claude・Gemini・OpenAI の各エージェントをコード変更なしに切り替えられる共通推論インターフェースが iOS 27 / macOS Golden Gate アプリで利用可能になる。財務面では Anthropic が 6 月 1 日に SEC へ IPO のための **S-1 の機密提出（confidential S-1）** を完了したことも報じられており、同社の 650 億ドル Series H（過去最大の民間 AI 調達）に続く資本市場への本格参入ステップとなった。

### 2. Chrome V8 ゼロデイ CVE-2026-11645 が野良悪用 — 今年 5 件目・即時パッチ適用を、Cisco SD-WAN CVE-2026-20245 はパッチなしで継続悪用中

Google は **Chrome 149.0.7827.102/103** でゼロデイ **CVE-2026-11645**（CVSS 8.8）を修正した。V8 エンジンの **境界外読み書き（Out-of-Bounds Read/Write）** を突いた本脆弱性は、細工した HTML ページを表示させるだけでサンドボックス内での任意コード実行が可能で、セキュリティ研究者 "303f06e3" が 4 月 27 日に発見（報奨金 55,000 ドル）後、Google が野良悪用を確認して緊急パッチを配布した。2026 年に入ってから Chromium ゼロデイの悪用は **5 件目**であり、ブラウザのバックグラウンド自動更新が無効化されている環境は特に注意が必要だ。並行して **Cisco Catalyst SD-WAN Manager** の **CVE-2026-20245**（CVSS 7.8）は、**パッチが現時点で存在しないまま**積極的に悪用され続けている。認証済み netadmin 権限を持つリモート攻撃者が細工ファイルをアップロードすることで root 権限でのコマンド実行が可能になる欠陥で、これは Cisco SD-WAN 関連の **2026 年 7 件目の悪用確認済み脆弱性**だ。既存の CVE-2026-20182 / CVE-2026-20127 との連鎖による初期権限昇格からの悪用チェーンも観測されている。

### 3. トランプ政権、AI イノベーション・安全保障大統領令を署名 — 任意のフロンティアモデル審査フレームワークと AI サイバーセキュリティ共有拠点を設置

6 月 2 日、トランプ政権は **「先進 AI イノベーション・安全保障促進」大統領令** に署名した。イノベーション優先姿勢を維持しつつも、高度 AI がもたらす国家安全保障上のリスクへの対処を明文化した点が特徴だ。主要施策は 2 軸で、①財務省・NSA・CISA が連携する **AI サイバーセキュリティ共有拠点**を 30 日以内に設置し、脆弱性スキャン・検証・パッチ優先付けを官民で共同実施する、②**カバードフロンティアモデル**の指定を行い、開発者が公開前 30 日間に連邦政府へ機密裏にアクセスを提供できる任意フレームワークを設計する、の 2 点だ。大統領令は明示的に「強制的なライセンス・事前認可・許可要件は設けない」と定めており、EU AI 法の義務的規制とは対照的な自発的協力モデルを採る。2026 年 8 月 2 日に EU AI 法が全面適用されるタイミングと重なり、米欧間の AI ガバナンス路線の差異がより鮮明になった。

## 新技術・新リリース

### Apple WWDC 2026 — Foundation Models `LanguageModel` プロトコルで AI プロバイダをコード変更なしに切り替え（Swift）

WWDC 2026 で発表された **Foundation Models フレームワーク**の最大の変化は、サードパーティ AI プロバイダが実装できる公開 Swift インターフェース **`LanguageModel` プロトコル**だ。これにより iOS 27 / macOS Golden Gate アプリは、Apple Intelligence（オンデバイス）・Claude・Gemini・OpenAI のいずれかをコード変更なしに差し替えられる統一推論面を持てるようになった。Xcode 27 では **ローカル Neural Engine モデル**（リアルタイム Swift 補完）と**クラウドルーティング層**（Claude / Gemini / OpenAI エージェントによる重いタスク分析）を組み合わせたデュアルエンジン型エージェントコーディングシステムも搭載されており、iOS シミュレータを Device Hub 経由で直接操作しながらテストを自動実行できる。

```swift
// Foundation Models LanguageModel プロトコル（教育目的サンプル）
// iOS 27 / macOS Golden Gate 以降で利用可能

import FoundationModels

// 1. 任意の AI プロバイダをプロトコルに準拠させる例（サードパーティ実装）
struct ClaudeLanguageModel: LanguageModel {
    func generate(
        prompt: String,
        options: GenerationOptions
    ) async throws -> GenerationResult {
        // Claude API への実際のリクエストはここに実装
        fatalError("実装はプロバイダ SDK を参照")
    }
}

// 2. アプリ側はプロトコル型で受け取るだけ — プロバイダ変更はここだけ
class ChatViewModel: ObservableObject {
    private let model: any LanguageModel

    // Apple Intelligence、Claude、Gemini、OpenAI のどれでも差し替え可能
    init(model: any LanguageModel = SystemLanguageModel.default) {
        self.model = model
    }

    func send(message: String) async throws -> String {
        let result = try await model.generate(
            prompt: message,
            options: GenerationOptions(maxTokens: 1024)
        )
        return result.text
    }
}

// 3. 使用例: デバイス / クラウドを環境変数で切り替える
let model: any LanguageModel = ProcessInfo.processInfo
    .environment["USE_CLOUD_AI"] == "1"
    ? ClaudeLanguageModel()
    : SystemLanguageModel.default

let vm = ChatViewModel(model: model)
```

Xcode 27 と iOS 27 Beta 1 は 6 月 8 日から開発者向けベータとして配布開始されており、対応デバイスを持つ開発者はすぐに試せる状態だ。

## セキュリティ

### Chrome CVE-2026-11645 即時アップデート ＋ Cisco SD-WAN CVE-2026-20245 緩和策（パッチなし）

Chrome の V8 ゼロデイは既にパッチが配布済みだが、**バックグラウンド更新を無効化している環境**では手動での適用が必要だ。Cisco SD-WAN は現時点でパッチが存在せず、ベンダー推奨の緩和策とネットワーク分離による被害最小化が求められる。

```bash
# --- CVE-2026-11645: Chrome バージョン確認と強制更新 ---

# Chrome バージョン確認（149.0.7827.102 以上が必要）
# Linux: Chromium のバージョン確認
google-chrome --version 2>/dev/null || chromium-browser --version

# Windows PowerShell: インストール済み Chrome のバージョン確認
(Get-Item "C:\Program Files\Google\Chrome\Application\chrome.exe").VersionInfo.FileVersion

# macOS
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --version

# Linux: 強制アップデート（Debian/Ubuntu 系）
sudo apt-get update && sudo apt-get install --only-upgrade google-chrome-stable

# --- CVE-2026-20245: Cisco SD-WAN 緩和策チェックリスト（パッチなし） ---

# 1. netadmin 権限アカウントの棚卸しと最小権限への絞り込み
#    Cisco SDWAN Manager の管理コンソールまたは CLI で確認:
#    show users  /  show aaa users

# 2. ファイルアップロード機能へのアクセスを信頼済みホスト IP に限定
#    SD-WAN Manager の ACL / ファイアウォールポリシーで制限

# 3. 既知の悪用チェーン (CVE-2026-20182 / CVE-2026-20127) の修正確認
#    Cisco Security Advisory を参照しパッチ適用済みか確認:
#    https://sec.cloudapps.cisco.com/security/center/

# 4. 侵害の痕跡（IoC）確認 — root で実行された不審なコマンドのログ精査
sudo grep -E "(sudo|root)" /var/log/auth.log | tail -200

# 5. CISA KEV カタログで最新の対象バージョン範囲を確認
# https://www.cisa.gov/known-exploited-vulnerabilities-catalog
echo "[!] CVE-2026-20245: No patch available — isolate SD-WAN Manager and rotate credentials"
```

**Chrome（CVE-2026-11645）優先度: 緊急**。バージョン 149.0.7827.102 以上への即時更新を実施すること。**Cisco SD-WAN（CVE-2026-20245）優先度: 高**。パッチ公開まで netadmin 権限の最小化・ファイルアップロード API へのアクセス制限・不審なアウトバウンド通信の監視を継続すること。
