### 2. Microsoft 6月Patch Tuesdayが史上最多208 CVE — Windows Kernel RCE「CVE-2026-45657」（CVSS 9.8）にワーム感染リスク、今週中のパッチ適用が必須

Microsoftが6月10日（米国時間）に公開した**6月Patch Tuesday**では過去最多となる**208件のCVE**が修正された。うち37件がCritical（深刻度最高）に分類され、公開済みゼロデイが3件含まれる。中でも最優先対処が必要なのが**CVE-2026-45657**（**Windows Kernel Remote Code Execution Vulnerability、CVSS 9.8**）だ。本脆弱性はWindowsカーネルの**TCP/IPスタックにおけるuse-after-freeおよびヒープバッファオーバーフロー（CWE-416/CWE-122）**であり、未認証の攻撃者がネットワーク越しに特殊なパケットを送信するだけで**ユーザー操作不要・SYSTEM権限でコード実行**が可能だ。Microsoftは特定ネットワーク構成下で**ワーム（自己増殖）感染が可能**と分類しており、Eternalblue（MS17-010）の再来となる可能性が研究者から指摘されている。影響を受けるOSはWindows 11 23H2/24H2/25H2/26H1（x64・ARM64）、Windows Server 2022/2025（Server Core含む）と広範であり、パッチリリースから公的PoC公開までの猶予は「週単位ではなく日単位」との警告が複数のセキュリティ研究機関から発せられている。加えて、**CVE-2026-42904**（TCP/IP RCE、CVSS 9.8）・**CVE-2026-44815**（DHCP RCE、CVSS 9.8）・**CVE-2026-47291**（HTTP.sys RCE、CVSS 9.8）という「ネットワーク経由RCE 4連打」が6月パッチに集中しており、これらを未適用のままインターネット公開している環境は極めて危険な状態に置かれている。

### TIOBE June 2026 最終確定 & Rust 2026の現在地 — Pythonが初の19%割れ、Rustが#12に定着しシステム言語のデファクトへ

6月最終TIOBEインデックスにてPythonが**18.96%**と初めて19%ラインを下回り、C++が前月比でJavaを逆転し3位に返り咲いた（C++ 13.62% vs Java 13.41%）。**Rust**は12位に定着しており、Paul Jansen（TIOBE編集長）は「6ヶ月前の上方修正予測が現実になった」とコメントした。とはいえAI研究論文の89%が依然Pythonをプライマリ言語として使用しており、ランキング下落はAI/ML以外のシステム・インフラ・WebAssembly領域でのシフトを反映している。

Rustエコシステムの成熟として注目されるのは、**2026年を通じたLinux Kernelへの本格統合**の進行だ。Rustで書かれたドライバーがmainlineへの取り込みペースを上げており、特にNVIDIAがRustベースのGPUドライバーモジュールをKernel 6.10系に提出したことで組み込み・ドライバー開発でのRust採用が加速している。

```rust
// Rust 2024 edition (stabilized in Rust 1.85) を使った非同期処理の例
// 2026年時点でasync/awaitが組み込みドライバでも利用可能になりつつある

use std::sync::Arc;
use tokio::sync::RwLock;

#[derive(Debug)]
struct SensorData {
    temperature: f64,
    timestamp: u64,
}

async fn collect_sensor(
    store: Arc<RwLock<Vec<SensorData>>>,
    sensor_id: u32,
) -> anyhow::Result<()> {
    // 実際のドライバコードではカーネルの非同期I/O APIを呼ぶ箇所
    let data = SensorData {
        temperature: 72.5 + sensor_id as f64 * 0.1,
        timestamp: std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)?
            .as_secs(),
    };
    store.write().await.push(data);
    Ok(())
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let store: Arc<RwLock<Vec<SensorData>>> = Arc::new(RwLock::new(Vec::new()));
    let handles: Vec<_> = (0..4)
        .map(|id| {
            let s = Arc::clone(&store);
            tokio::spawn(async move { collect_sensor(s, id).await })
        })
        .collect();
    for h in handles {
        h.await??;
    }
    println!("Collected {} readings", store.read().await.len());
    Ok(())
}
```
