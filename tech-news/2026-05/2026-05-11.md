### 1. Anthropic が Project Glasswing を発表 — Claude Mythos Preview が 17 年物の FreeBSD RCE をゼロから自律発見

Anthropic は AI モデル「**Claude Mythos Preview**」と、それを活用してクリティカルソフトウェアを守るための産業横断イニシアチブ「**Project Glasswing**」を発表した。Mythos Preview は汎用 LLM としての性能も高いが、コンピュータセキュリティタスクで特筆すべき能力を示しており、完全自律で 17 年間見落とされていた FreeBSD の NFS 実装における未認証 RCE 脆弱性（CVE-2026-4747）を発見・PoC まで作成した。Anthropic によれば Mythos が発見した脆弱性の 99% 以上はいまだ未パッチであり、責任ある開示プロセスに従って現在は詳細非公開とされている。Project Glasswing には AWS・Apple・Broadcom・Cisco・CrowdStrike・Google・JPMorganChase・Linux Foundation・Microsoft・NVIDIA・Palo Alto Networks が参画し、Anthropic は $1 億のモデル利用クレジットを充当する。モデルは現時点では厳選されたセキュリティ研究者・オープンソース開発者にのみ提供されており、「防御側が攻撃側より先に行動できる時間を確保する」という哲学のもと運営される。

### 2. Linux カーネル「Dirty Frag」(CVE-2026-43284/43500) — 1 コマンドで root 昇格、PoC 公開済み

Linux カーネルの ESP（IPsec）サブシステムと RxRPC サブシステムに起因する特権昇格脆弱性チェーン「**Dirty Frag**」（CVE-2026-43284・CVE-2026-43500）が 5 月 7 日に公開された。攻撃者がローカルアクセスを持つ場合、単一コマンドで root 権限を取得できる働く PoC が既に公開されており、Ubuntu・RHEL・Fedora・openSUSE・OpenShift など主要ディストリビューションのほぼすべてが影響を受ける。2017 年（ESP）および 2023 年（RxRPC）以降のカーネルが対象範囲で、race condition ではなく決定論的な page-cache 書き込みプリミティブを悪用するため安定性・再現性が高い点が特に厄介だ。Linux Kernel Organization はパッチを 5 月 8 日に公開しており、ディストリビューション各社がそれぞれのパッケージに取り込み中。Microsoft Defender は既に野外での限定的な悪用活動を観測していると報告している。

### Rust 1.96 beta — 次世代トレイトソルバーが coherence に有効化、Unicode 17 対応

Rust 1.96.0 のベータ版が公開された（正式リリースは 2026 年 5 月 28 日予定）。最大のハイライトは**次世代トレイトソルバー（next-generation trait solver）** が coherence チェックにデフォルト有効化された点で、長年の健全性（soundness）バグ複数件が解消される。その他、`&mut`・`*mut`・`&Cell`・`*const Cell` の定数文脈での安定化、const 初期化子内での static 参照作成、raw ライフタイム・ラベル構文（`'r#ident`）のサポート、RISC-V 向けターゲットフィーチャー 29 種の追加（RVA22U64・RVA23U64 プロファイルの大部分をカバー）、Unicode 17 への更新などが含まれる。また `wasm32-wasi` ターゲットが本バージョンで完全削除され、1.78 以降で準備が進められてきた `wasm32-wasip1` への移行が完了する。

```rust
// Rust 1.96: raw ライフタイム構文（'r#ident）の例
// キーワードと衝突するライフタイム名を raw identifier で定義できる
fn parse<'r#loop>(input: &'r#loop str) -> &'r#loop str {
    input.trim()
}

// const 文脈での *mut / &mut 安定化
const CELL_IN_CONST: &std::cell::Cell<u32> = &std::cell::Cell::new(42);

fn main() {
    // 次世代トレイトソルバーが coherence チェックを改善
    // → 型エラーメッセージがより正確に
    let trimmed = parse("  hello  ");
    println!("{}", trimmed);
}
```

## セキュリティ

### Dirty Frag の緩和策 — カーネル更新前の即時対応手順

パッチ適用前の緊急緩和策として、脆弱な ESP および RxRPC カーネルモジュールをロード禁止にする方法が各ディストリビューターから案内されている。

```bash
# Dirty Frag (CVE-2026-43284/43500) 緩和策
# 脆弱なカーネルモジュールをブラックリスト登録してアンロード

printf 'install esp4 /bin/false\ninstall esp6 /bin/false\ninstall rxrpc /bin/false\n' \
  | sudo tee /etc/modprobe.d/dirtyfrag.conf

sudo rmmod esp4 esp6 rxrpc 2>/dev/null; true

# カーネルバージョンを確認（4.14 以降は対象の可能性あり）
uname -r

# Ubuntu / Debian: パッチ済みカーネル確認
apt-cache policy linux-image-$(uname -r) | grep Installed
# → 5.15.0-xxx 以降でパッチ反映済みのビルドかどうか確認

# RHEL / Fedora
rpm -q kernel --queryformat '%{VERSION}-%{RELEASE}.%{ARCH}\n' | head -3
```

**注意点:** ESP を無効化すると IPsec VPN 接続が停止します。IPsec を運用中の環境ではカーネルのアップデートを優先し、モジュール無効化は最終手段として検討してください。

**出典**: [Dirty Frag vulnerability fixes — Ubuntu Blog](https://ubuntu.com/blog/dirty-frag-linux-vulnerability-fixes-available) / [RHSB-2026-003 Dirty Frag — Red Hat](https://access.redhat.com/security/vulnerabilities/RHSB-2026-003)

### Copy Fail (CVE-2026-31431) CISA 期限 5/15 迫る

別途報告済みの Linux カーネル root 昇格脆弱性「Copy Fail」（CVE-2026-31431、CVSS 7.8）は CISA の KEV カタログ入りしており、米国連邦文民機関には 5 月 15 日までのパッチ適用が義務付けられている。2017 年以降のカーネルが対象で、クラウド環境・Kubernetes ワークロードへの影響が特に指摘されている。Dirty Frag と合わせて Linux 基盤を持つ本番環境は今週中のカーネル更新が強く推奨される。
