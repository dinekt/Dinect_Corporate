### MCP（Model Context Protocol）が9,700万インストール突破、Linux Foundationへ移管
Anthropicが主導してきたModel Context Protocol（MCP）が2026年3月に9,700万インストールを達成し、OpenAI・Google・Mistralを含む全主要AIプロバイダーが対応ツールを出荷した。さらにLinux Foundationがプロトコルのオープンガバナンスを引き受け、特定企業依存からコミュニティ主導の標準化フェーズへと移行した。MCPはAIエージェントが外部ツール・データソースと相互運用するためのRPCレイヤーであり、エージェント型AIシステムの「USB規格」とも評される。エコシステムの標準化が進むことで、エージェントと外部サービスをつなぐインテグレーション開発のコストが大幅に低下することが見込まれる。

```python
# MCP サーバー実装例 (Python SDK)
from mcp.server import MCPServer

server = MCPServer("my-data-tool")

@server.tool()
def search_records(query: str, limit: int = 10) -> list[dict]:
    """Search internal records and return matching items."""
    # DB接続・検索ロジックをここに実装
    results = db.search(query, limit=limit)
    return [r.to_dict() for r in results]

if __name__ == "__main__":
    server.run()  # stdin/stdout でAIエージェントと通信
```

### CISA、AIパイプライン基盤Langflow RCE（CVE-2026-33017）を緊急パッチ対象に指定
CISAが連邦機関に対し、AIパイプライン構築ツールLangflowのリモートコード実行脆弱性CVE-2026-33017の即時パッチ適用を命じた。認証前RCEにより攻撃者がモデル推論インフラと認証情報へアクセスできる状態になっており、AI開発ツールチェーン自体がサイバー攻撃の標的になるという新たな脅威面が確認された。LangflowはPythonベースのオープンソースLLMオーケストレーションツールとして広く使われており、自己ホスト型AI基盤を持つ組織は早急な対応が求められる。MLOpsインフラの外部露出を最小化し、Langflowサーバーをプライベートネットワーク内に閉じ込める構成への見直しも推奨されている。

### Apple、DarkSword Webエクスプロイト対策をiOS 18.7.7として追加デバイスに展開
AppleがiOS 18.7.7をさらに多くのデバイスへ拡大配布し、DarkSwordと呼ばれるWebエクスプロイトをブロックする修正を適用した。DarkSwordはWebKit経由でサンドボックス脱出を可能にする手法で、標的型攻撃での悪用が確認されている。国家支援型のスパイウェア攻撃が特定の端末モデルに集中するケースが増えており、AppleはiOSの更新範囲を段階的に拡大することで対応している。iOS端末を利用している場合は最新バージョンへの更新を推奨する。
