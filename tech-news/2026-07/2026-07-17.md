### 3. SonicWall SMA 1000 シリーズ ゼロデイ2件を連鎖悪用（CVSS 10.0）— 本日が連邦機関の修正適用期限

Rapid7 MDR チームが発見した**CVE-2026-15409**（SSRF、CVSS 10.0）と**CVE-2026-15410**（認証後コードインジェクション、CVSS 7.2）がSonicWall SMA 1000シリーズで実際に連鎖悪用されていることが確認された。攻撃者は2026年6月末から標的型ゼロデイ攻撃を継続しており、2つの脆弱性を組み合わせてSSRFで認証情報・アクティブセッション・TOTPのMFAシード値を窃取したのち、コードインジェクションで管理者コマンドを実行し、内部ネットワークへのラテラルムーブメントを展開している。米CISAはBinding Operational Directive（BOD 26-04）に基づき、**本日7月17日**を連邦機関の修正期限として設定した。修正版は`12.4.3-03453`（platform-hotfix）以降および`12.5.0-02835`（platform-hotfix）以降。SonicWallは「即時適用」を強く要請しており、パッチ適用不能な場合は機器のネットワーク切断を推奨している。

### Gemini 3.5 Pro — 2M トークンコンテキストを活かした大規模ドキュメント処理

Gemini 3.5 Pro の最大の差別化点は**200万トークンのコンテキストウィンドウ**だ。これは英語テキスト換算で約1,500万文字、標準的なコードリポジトリを丸ごと読み込む規模に相当する。長大なコードベースの横断解析・法的ドキュメント全件精査・研究論文全巻の要約といったユースケースで従来比で大きく価値が高まる。

```python
import google.generativeai as genai

# Gemini 3.5 Pro — 2M トークンコンテキストウィンドウ活用例
genai.configure(api_key="YOUR_GEMINI_API_KEY")

model = genai.GenerativeModel("gemini-3.5-pro")

# 2M トークン ≈ 約 1,500 万文字のテキストを一度に処理可能
# コードリポジトリ全体・長大な法的文書・研究論文全巻の分析に適する
def analyze_large_codebase(filepath: str) -> str:
    with open(filepath, encoding="utf-8") as f:
        source = f.read()

    response = model.generate_content([
        "以下のコードベース全体を解析し、潜在的なバグ・セキュリティ上の懸念・改善点を列挙してください。",
        source,
    ])
    return response.text

# Deep Think モード: Ultra サブスクリプション ($250/月) で利用可能
# 複雑な多段階推論タスク（数学証明・長文コード生成・戦略立案）に特化
# generation_config={"thinking_budget": -1} で自律的に思考深度を決定
result = analyze_large_codebase("src/")
print(result)
```

あわせて**Google NotebookLM**が本日**Gemini Notebook**にリネームされ、各ノートブックにネイティブコード実行環境が統合された。データ分析をノートブック内で完結できるようになり、Jupyter Notebookとの使い分けに新たな選択肢が加わった。

また**DeepSeek API移行期限が7月24日**に迫っており、`deepseek-chat`・`deepseek-reasoner`を利用中の開発者は、V4安定版に向けた移行作業を今週中に完了させる必要がある。

さらに**OpenAI**は初の物理デバイス「**Codex Micro**」（$230）を発売した。Codex AI コーディングアシスタント専用のキーパッドコントローラで、ショートカット・マクロを物理ボタンにマッピングできる。AI支援コーディングが「ソフトウェア内完結」から「ハードウェア統合」段階に進んだことを象徴するプロダクトだ。
