### 1. ロシア系脅威アクターが「数百体の AI エージェント」を使い PaperCut に侵入 — 48カ国395組織・440インスタンスを26秒で突破

ロシア語話者の脅威アクターが、OpenAI の Codex ハーネスと DeepSeek モデルを組み合わせた**数百体の自律 AI エージェント**を展開し、印刷管理ソフト **PaperCut NG/MF** の重大脆弱性 2件（CVE-2026-81578：認証バイパス / CVE-2026-82078：アンセーフリフレクション RCE）を悪用、8月31日を起点に**48カ国395組織・440インスタンス以上**を侵害したと GreyNoise が報告した。攻撃者はまず Netlas.io のスキャン API（侵害済みキー経由）でターゲットリストを生成し、Active Directory と連動した PaperCut 環境を模倣したプライベートラボで攻撃を開発・テストしてから本番へ移行した。エージェントが最高速度に達すると**26秒で11組織へのコード実行**を確立し、空のワークスペースから初回 RCE まで**4時間を切る**速度で実行された。PaperCut は Windows 上で SYSTEM 権限で動作しながら Active Directory と直接統合されており、横断的侵害の足がかりとして極めて魅力的なターゲットとなっている。今回の事案は AI エージェントが実際のサイバー攻撃に大規模投入された事例として記録に残るものであり、自動化された脆弱性悪用の速度と規模が人間主導の攻撃を大幅に凌駕し始めていることを示している。

### 3. Cognition が SWE-2 コーディングモデルを発表 — Kimi K3（2.8兆パラメータ）ベースで DeepSeek V4.1 Flash を上回るベンチマーク

AI コーディングエージェント「Devin」を開発する Cognition が新コーディング特化モデル **SWE-2** を発表した。**Kimi K3（2.8兆パラメータ規模のベースモデル）から強化学習（RL）でポストトレーニング**されており、Cognition はこれを「多兆パラメータ規模で RL がスケールした初のコーディングモデル」と位置づけている。独立ベンチマーク KingBench 3（8タスク）では **83.75% のスコアを記録し、DeepSeek V4.1 Flash（81.25%）およびベースモデルの Kimi K3（約77%）を上回る**パフォーマンスを示した。現在は Devin Pro（月額20ドル）に組み込まれており、2026年10月10日まで SWE-2 利用は無償提供される。一方 DeepSeek も **V4.1 Flash を発表し、前版の約2倍となる552億アクティブパラメータを持ちながら価格を引き下げ**るという競争的な動きを見せており、大規模コーディング AI の性能競争が急速に激化している。コスト・性能の最適化と RL スケーリングという方向性は、今後の AI モデル開発の主戦場を明確に示している。

## 新技術・新リリース

### DeepSeek V4.1 Flash — 552B パラメータ・100万トークンコンテキスト・価格引き下げで登場

DeepSeek が V4.1 Flash を公式ソーシャルチャンネルと Hugging Face で同時公開した。旧版 V4 Flash（約284B パラメータ）の約2倍となる **552B パラメータ（アクティブ13B）** を持ちながら、価格を引き下げてリリースされた。コンテキスト長は**100万トークン**に対応しており、長文書類や大規模コードベースの解析に適している。コーディングベンチマークでは SWE-2 に続く2位の水準を示しており、オープンウェイトモデルとしての競争力を維持している。

```python
# DeepSeek V4.1 Flash の利用例（OpenAI 互換 API）
from openai import OpenAI

client = OpenAI(
    api_key="<your-deepseek-api-key>",
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-v4-flash",          # V4.1 Flash モデル指定
    messages=[
        {"role": "system", "content": "You are a helpful coding assistant."},
        {"role": "user", "content": "Implement a bubble sort in Python with type hints."}
    ],
    max_tokens=1024,
    temperature=0.0
)

print(response.choices[0].message.content)
# コンテキスト長: 最大 1,000,000 トークン
# 入力価格: 従来比引き下げ（詳細は DeepSeek API Docs 参照）
```

DeepSeek V4.1 Flash は特にコスト効率を重視する開発者・企業向けに最適化されており、API 経由での利用と Hugging Face からのセルフホストの両方が可能だ。Cognition SWE-2 との直接競争が始まったことで、コーディング AI の民主化がさらに加速する見通しだ。
