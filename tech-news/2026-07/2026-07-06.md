### 1. Claude Fable 5 / Mythos 5、米商務省が輸出規制を解除 — 史上初「AIモデルへの輸出規制」から3週間で全面復帰

2026年6月12日、米国商務省は史上初めてAIモデルそのものに輸出規制を適用し、AnthropicのフラッグシップモデルClaude **Fable 5** および **Mythos 5** の外国国籍者向けアクセスをすべて停止した。発端はAmazon研究者が報告したジェイルブレイク技術であり、同技術はFable 5のサイバーセキュリティ保護を迂回できるとされた。規制は米国内在住の非市民スタッフを含む外国国籍者にも適用されるという異例の内容で、AIモデルが武器輸出管理に近い扱いを受ける前例を作った。Anthropicは規制に従いながら公式に異議を表明し、米政府・Amazon・外部パートナーと協調して新たな安全分類器を訓練。**6月30日に商務省が規制解除を通知**し、7月1日からアクセス段階的再開が始まった。Pro/Max/Team および一部Enterpriseプランユーザーには7月7日まで週間利用上限の50%枠でFable 5が提供されており、Mythos 5は6月26日に先行してアクセス再開済みだ。今回の事例は、フロンティアAIが安全保障リスクとして扱われる政策環境が現実のものとなったことを示す分水嶺となった。

### 3. SimpleHelp CVE-2026-48558（CVSS 10.0）— MSPサプライチェーン攻撃、CISA KEV対応期限超過でリスク最大化

MSP（マネージドサービスプロバイダ）向けRMMソフトウェア**SimpleHelp**に存在する**CVE-2026-48558**（CVSS 10.0）が積極悪用中であり、CISA KEV（既知悪用済み脆弱性カタログ）追加日の6月29日に設定された修正期限（**7月2日**）を既に過ぎた状態だ。脆弱性の根本原因はOpenID Connect（OIDC）認証でのトークン署名検証の完全な欠如にある。攻撃者は正規のOIDCトークンを偽造してSimpleHelp サーバーに送信するだけで管理者権限を持つ「Technician」アカウントを作成でき、そのMSPが管理する**数千のクライアントエンドポイント全体**への完全なアクセスを1段階で獲得できる。実際の攻撃チェーンでは偽造OIDCトークン→Technicianアカウント作成→管理アクセス確立→**TaskWeaver**ローダーとインフォスティーラー**Djinn Stealer**の展開が確認されている。MSPが単一の侵害ポイントから配下の全顧客環境に波及するサプライチェーン攻撃構造を持つため、影響の裾野が特に広い。Horizon3.aiが侵害指標（IoC）を公開しており、SimpleHelp 5.xおよび6.xの全バージョンが対象とされる。

### GLM-5.2（Z.ai）— MITライセンスのオープンウェイトコーディングモデルがGPT-5.5をSWE-bench Proで凌駕、コスト比1/6

中国AI企業 **Z.ai**（旧ZhipuAI）が6月13日にリリースした**GLM-5.2**は、オープンウェイトモデルとして初めてフロンティアクローズドモデルのコーディング性能に肩を並べたモデルとして注目されている。SWE-bench Proで**62.1%**を記録し、GPT-5.5（58.6%）やGLM-5.1（58.4%）を明確に上回った。FrontierSWEでは74.4%を達成し、Claude Opus 4.8（75.1%）と僅差だ。MITライセンスで完全な自己ホスティングが可能であり、ホストAPIの価格は$1.40/$4.40（入力/出力 per 1M tokens）で、GPT-5.5の約1/6に相当する。

アーキテクチャは**Sparse MoE（Mixture-of-Experts）設計**を採用しており、総パラメータ数753Bながらトークンごとの活性化パラメータは約40Bに抑えられているため、推論コストを大規模密結合モデルの水準より大幅に低く維持している。1Mトークンのコンテキストウィンドウも持ち、大規模コードベースの一括処理が可能だ。

```python
# GLM-5.2 API（Z.ai ホスト）経由のコーディングエージェント呼び出し例
import openai  # Z.ai は OpenAI 互換 API を提供

client = openai.OpenAI(
    api_key="YOUR_ZAI_API_KEY",
    base_url="https://open.bigmodel.cn/api/paas/v4/"
)

response = client.chat.completions.create(
    model="glm-5.2",
    messages=[
        {
            "role": "user",
            "content": "このPythonコードのバグを特定して修正してください:\n\n"
                       "def binary_search(arr, target):\n"
                       "    left, right = 0, len(arr)\n"  # バグ: right は len(arr)-1 が正しい
                       "    while left <= right:\n"
                       "        mid = (left + right) // 2\n"
                       "        if arr[mid] == target:\n"
                       "            return mid\n"
                       "        elif arr[mid] < target:\n"
                       "            left = mid + 1\n"
                       "        else:\n"
                       "            right = mid - 1\n"
                       "    return -1"
        }
    ],
    max_tokens=1024,
    temperature=0.1  # コーディングタスクでは低めの温度が安定
)

print(response.choices[0].message.content)
# コスト: 入力 $1.40/1Mトークン、出力 $4.40/1Mトークン (GPT-5.5 の約 1/6)
```

GLM-5.2の登場は、オープンウェイトモデルとクローズドフロンティアモデルの性能差が急速に縮小していることを示す。コスト効率と自己ホスティング可能性を組み合わせた選択肢として、プライバシー要件が厳しい環境やオンプレミス展開が必要なシナリオでの採用が増加するとみられる。ただしAPI利用時に中国サーバーにデータが送信される点は地政学的リスクとして認識する必要があり、機密性の高いコードに対しては自己ホスティング構成を前提とすべきだ。
