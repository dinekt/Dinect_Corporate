### 1. Google、Gemini 3.1 Ultra 正式リリース — 200万トークンコンテキスト・ネイティブマルチモーダル推論

Google が Gemini 3.1 Ultra を正式リリース。テキスト・画像・音声・動画を学習段階からネイティブに統合したマルチモーダル推論モデルで、コンテキストウィンドウは 200万トークンに拡大された。新搭載の「sandboxed Code Execution ツール」により、モデルがコード記述・実行・テストを会話の中でリアルタイムに行えるようになった。合わせて効率モデル Gemini 3.1 Flash-Lite も同日公開。入力 100万トークンあたり $0.25 と従来比 2.5倍の高速レスポンスを実現しており、コスト重視の API 利用に向く。

**開発者への影響**:
- コンテキスト 200万トークンの実用化で、長大なコードベース全体を一度に分析・変換するワークフローが現実的になった
- コード実行ツール内蔵により「プロンプト → 実行 → 検証」のループを外部サンドボックスなしで構築できる

### 2. 半導体産業が年間売上 $1 兆に接近 — TSMC 3 月売上発表・Samsung Q1 利益 700% 超の急成長

TSMC が 3月 2026 月次売上報告を公開し、AI 向けチップ需要の加速を裏付けた。Samsung は Q1 2026 の利益が前年同期比 700% 超に急増したと発表。主因は AI システム向け HBM（高帯域幅メモリ）の需要急拡大で、半導体産業の年間販売額は 2026 年に $9,750 億規模（前年比 +26%）に達する見通し。一方、米議会では MATCH Act の審議が進み、中国向け半導体製造装置の輸出規制がさらに強化される可能性が浮上。ASML 株は同報道を受けて下落しており、地政学リスクがサプライチェーン全体に波及している。

**開発者への影響**:
- AI 学習・推論向け GPU/HBM 需要は当面供給不足が続く見込み。クラウドインフラ調達やモデル選定の際には、ハードウェアコストの上昇圧力を考慮する必要がある
- 輸出規制強化が続けば、特定リージョンでのクラウドサービス展開や OSS への中国からの貢献にも間接的な影響が及ぶ可能性がある

### 3. Anthropic Managed Agents が本格展開 — Notion・Rakuten・Sentry・Asana が採用

Anthropic の Managed Agents がプロダクション採用を拡大。サンドボックス化・権限管理・状態管理・エラーリカバリをプラットフォーム側が吸収する設計で、内部テストではタスク成功率が通常プロンプト比で最大 10 ポイント向上した。Notion、楽天、Sentry、Asana がそれぞれ実環境へのデプロイを開始しており、「AI エージェントの信頼性をインフラレベルで保証する」サービスとしての確立が進んでいる。MCP（Model Context Protocol）も 3月時点で 9,700 万インストールを突破し、全主要 AI プロバイダーが MCP 互換ツールを提供する事実上の標準となった。

**開発者への影響**:
- エージェント基盤をゼロから実装せずに Managed Agents に乗るパスが実用化。エラーハンドリング・セキュリティ境界の自前実装コストを削減できる
- MCP が標準化されたことで、ツール統合の設計はプロバイダー固有 SDK ではなく MCP ファーストで考えるのが得策になりつつある

## 新技術・新リリース

### Rust 1.83 — async クロージャ安定化・WebAssembly 改善

Rust 1.83 が正式リリースされ、`async fn` 以来最大の待望機能とされていた async クロージャ（`async || { ... }`）が安定版に昇格した。非同期コードの記述が大幅に簡素化される。合わせて WebAssembly ターゲットでの未定義シンボル処理が改善され、実行時クラッシュにつながっていた長年の問題が解消。Rust Foundation は同時に、規制産業向けのエンタープライズ認定プログラムの提供も開始した。

```rust
// Rust 1.83 以前: 非同期処理に別途 fn が必要
async fn fetch(url: &str) -> Result<String, reqwest::Error> {
    reqwest::get(url).await?.text().await
}

// Rust 1.83 以降: async クロージャが安定化
let fetch = async |url: &str| -> Result<String, reqwest::Error> {
    reqwest::get(url).await?.text().await
};

// Iterator との組み合わせも自然に記述可能
let results: Vec<_> = urls.iter()
    .map(async |url| fetch(url).await)
    .collect();
```

### Carbon Language — Nightly ビルド継続・v0.0.0-nightly.2026.04.04

C++ 後継言語として Google が進める Carbon Language がナイトリービルド `v0.0.0-0.nightly.2026.04.04` をリリース。GitHub スター数は 33,700 超・コミット数は 5,100 超に達し、実験的プロジェクトとしての成熟度が増している。現在も実験段階だが、C++ との双方向相互運用性が核心機能として開発継続中。

## セキュリティ

### CVE-2026-35616: Fortinet FortiClient EMS — CVSS 9.8、CISA KEV 登録・積極的悪用継続

FortiClient EMS 7.4.5〜7.4.6 に影響する不適切なアクセス制御の脆弱性。未認証でのリモートコード実行（RCE）が可能で、4月4日の公開後すぐに積極的な悪用が観測された。4月6日に CISA の Known Exploited Vulnerabilities（KEV）カタログに追加。米連邦機関には4月9日を期限としたパッチ適用が義務化。Shadowserver のスキャンでは約 2,000 件の公開インスタンスが検出されており、完全パッチはまだリリースされていない（ホットフィックス提供済み）。

### CVE-2026-21643: Fortinet 第二の重大脆弱性 — CVSS 9.8、同製品を二重に直撃

同じ FortiClient EMS を対象とする CVE-2026-21643（CVSS 9.8）も 4月4日の Fortinet アドバイザリで積極的悪用が確認された。FortiClient EMS を利用している組織は CVE-2026-35616 と合わせて二重の脆弱性リスクを抱えており、緊急アップデートが求められる。

### CVE-2026-39888: Python サンドボックス脱出 — CVSS 9.9

Python サンドボックス実装に関連する脆弱性で CVSS スコアは 9.9。制限された Python 実行環境から任意コード実行が可能になる。AI エージェントや自動化ツールが Python サンドボックスを利用している場合は影響範囲の確認が急務。
