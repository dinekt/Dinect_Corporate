## 本日のニュース TOP 3

### 1. Claude Code v2.1.92 リリース — Bedrockウィザード・コスト分析・ファイル書き込み60%高速化
Anthropicが Claude Code v2.1.92をリリース。AWS Bedrockの設定ウィザードをログイン画面から直接起動可能に。コスト分析機能が詳細化され、大規模ファイル書き込みは最大60%高速化。`/powerup`コマンドでインタラクティブレッスンも追加された。重要: denyルールがバイパスされる脆弱性がv2.1.90で修正済み。またサードパーティハーネス（OpenClaw等）へのサブスクリプション利用は遮断され、API課金への移行が必要に。

**個人開発者への影響**:
- 即時`npm update -g @anthropic-ai/claude-code`でアップデートを。denyルールバイパスの脆弱性は特にCI/CD連携している場合に要注意
- Bedrockウィザードにより、エンタープライズ環境でのセットアップが大幅に簡易化

### 2. Microsoftが日本に100億ドル（約1.6兆円）のAI投資を発表
Microsoftが日本向け3本柱投資計画（2026〜2029）を発表。AIインフラ拡充（SoftBank連携）、サイバーセキュリティ連携、2030年までに100万人以上のスキルアップが柱。IT導入補助金は上限5億円、AI実装案件の補助率が最大2/3に改善。

**個人開発者への影響**:
- 国内AIインフラのコスト低下が見込まれる
- IT導入補助金の改定はAIコンサル案件の提案材料として活用できるタイミング
- さくらインターネットが連携先として注目（株価20%上昇）

### 3. Cursor 3 リリース — IDEからエージェント管理プラットフォームへ
Cursorがバージョン3をリリース。マルチリポワークスペース、内蔵ブラウザ、MCP/スキルのプラグインマーケットプレイスが主要機能。Claude Codeが AIコーディング市場の54%を占めるとの推計値も報じられ、競合各社のエージェント管理機能強化が加速。

**個人開発者への影響**:
- AIコーディングツールが「コード補完」から「エージェント管理」へとフェーズが変わった象徴的なリリース
- Claude Code vs Cursor の使い分けがより明確に。Claude Codeはターミナル中心の自律実行、Cursorは視覚的なIDE体験

## セキュリティ

### Claude Code denyルールバイパス脆弱性 — v2.1.90で修正済み
コマンドパーサーのバグにより、開発者が設定したdenyルールが無声でスキップされる脆弱性。CI/CDや本番環境操作でClaude Codeを使っている場合は即時アップデート推奨。

### April Patch Tuesday（4月14日予定）
Secure Boot証明書（2011年発行）の有効期限が6月26日に迫り、移行措置が含まれる見通し。脆弱性悪用は全サイバー侵害の40%を占め、フィッシングを超えた主要侵入経路に。
