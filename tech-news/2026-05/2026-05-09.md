### Python 3.15 Beta 1 — JIT が 8〜13% 高速化、遅延インポートとフローズン辞書を導入

Python 3.15 の Beta 1 が公開された（正式リリースは 2026 年 10 月予定）。JIT コンパイラが主要プラットフォーム全体で 8〜13% の速度向上を達成し、Windows バイナリもデフォルトでテールコーリングインタープリタに切り替わる。主な新機能は以下のとおり。

```python
# PEP 690: 明示的遅延インポート（lazy imports）
# __future__.lazy_imports を使うことでインポート時間を削減
from __future__ import lazy_imports

import heavy_module  # この時点ではロードされない

def use_it():
    heavy_module.do_something()  # 初回使用時にロード

# PEP 799: 新しい集中プロファイリング API
import profiling

with profiling.Profiler() as p:
    heavy_computation()

p.print_stats()

# フローズン辞書（読み取り専用の不変マッピング）
config = frozendict({"host": "localhost", "port": 8080})
# config["port"] = 9090  → TypeError: frozendict is immutable
```

Beta 1 リリースにより API の安定性が高まり、フレームワーク・ライブラリ側の対応テストが本格化する。

### Rust 1.95.0 安定版リリース — 次の 1.96.0 Beta は 5 月 28 日

Rust 1.95.0 が安定版としてリリースされ、1.96.0 Beta は 2026 年 5 月 28 日に予定されている。C++ から Rust への移行が金融・組み込み・クラウドインフラ領域で加速しており、CPython のビルドシステムを Rust 化する PEP（Python 3.16 ターゲット）も進行中だ。

```rust
// Rust 1.95 の改善例: async fn in traits (安定化済み機能の活用)
use std::future::Future;

trait DataFetcher {
    async fn fetch(&self, url: &str) -> Result<String, reqwest::Error>;
}

struct HttpClient;

impl DataFetcher for HttpClient {
    async fn fetch(&self, url: &str) -> Result<String, reqwest::Error> {
        reqwest::get(url).await?.text().await
    }
}
```

## セキュリティ

### Copy Fail（CVE-2026-31431）— Linux クラウド環境でのルート権限昇格、CISA KEV 追加

Microsoft セキュリティブログが公開した **CVE-2026-31431**（通称 Copy Fail）は、Linux カーネルのコピー操作に起因する権限昇格脆弱性で、クラウド環境・Kubernetes ワークロードで特に危険度が高い。CISA は KEV カタログに追加し、連邦政府機関への修正期限を 2026 年 5 月 15 日と定めた。先週の「Dirty Frag」（CVE-2026-43284/43500）と並び、Linux カーネルのローカル権限昇格脆弱性が短期間に連発している点が懸念材料だ。

```bash
# カーネルバージョン確認と緊急パッチ適用
uname -r

# Debian / Ubuntu 系
apt-get update && apt-get dist-upgrade

# RHEL / Fedora 系
dnf update kernel --security

# Kubernetes ノードのバージョン確認
kubectl get nodes -o wide

# EKS ノードグループの AMI バージョン確認
aws eks describe-nodegroup \
  --cluster-name YOUR_CLUSTER \
  --nodegroup-name YOUR_NODEGROUP \
  --query "nodegroup.releaseVersion"
```

**影響範囲の優先度:** クラウドホスト型 Kubernetes ノード > 公開 API・Web サーバー > 内部 Linux ホスト

**出典**: [CVE-2026-31431 Copy Fail — Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/05/01/cve-2026-31431-copy-fail-vulnerability-enables-linux-root-privilege-escalation/) / [CISA Adds CVE-2026-31431 to KEV — The Hacker News](https://thehackernews.com/2026/05/cisa-adds-actively-exploited-linux-root.html)
