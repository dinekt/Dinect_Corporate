### 1. PyTorch Lightning PyPI パッケージが供給チェーン攻撃で汚染 — バージョン 2.6.2/2.6.3 が資格情報窃取マルウェアを同梱、AI 開発環境で数十万件/日のダウンロードに影響

機械学習フレームワーク「PyTorch Lightning」の PyPI パッケージ `lightning` が、4 月 30 日に公開されたバージョン **2.6.2 と 2.6.3** においてサプライチェーン攻撃を受けていたことが複数のセキュリティ研究者により報告された。悪意あるコードは「Mini Shai-Hulud」と名付けられた手口を使い、パッケージのインポート時に隠し `_runtime` ディレクトリ内の難読化 JavaScript ペイロードを自動実行する。窃取対象は認証トークン・環境変数・クラウドシークレット（AWS/GCP/Azure 系）に及び、GitHub リポジトリへのポイズニング試行も確認された。`lightning` は毎日数十万件ダウンロードされる AI/ML 環境の中核パッケージであり、影響規模は大きい。PyPI 運営者は既に問題バージョンを隔離済みだが、当該バージョンをインポートした環境は侵害済みとして扱い、すべてのクラウド認証情報のローテーションが推奨される。今回の攻撃は SAP 関連 npm パッケージを狙った同キャンペーンの延長線上にあると評価されており、AI 開発ツールチェーンを標的とした供給チェーン攻撃の傾向が強まっている。

### 2. CISA が Linux カーネル LPE（CVE-2026-31431）と Windows NTLM ゼロデイ（CVE-2026-32202）を KEV に追加 — 連邦機関の修正期限は 5 月 12 日

CISA は既知悪用脆弱性（KEV）カタログに新たに **CVE-2026-31431**（Linux カーネルローカル権限昇格、CVSS 7.8）と **CVE-2026-32202**（Windows NTLM ゼロクリックハッシュリーク）を追加し、連邦民間行政府機関（FCEB）に対して **2026 年 5 月 12 日**までのパッチ適用を義務付けた。CVE-2026-31431 は 732 バイトの Python スクリプトで悪用可能な LPE で、Amazon Linux・RHEL・SUSE・Ubuntu を含む 2017 年以降にリリースされたほぼ全 Linux ディストリビューションが影響を受ける。CVE-2026-32202 は Microsoft が 2 月に不完全修正したコード実行脆弱性（CVE-2026-21510）の残存欠陥で、ロシアの APT28 がウクライナおよび EU 諸国への攻撃に悪用したことが確認されている。民間組織に法的義務はないが、CISA は同等のタイムラインでの対応を強く推奨しており、特に Linux サーバーを運用する組織はカーネルのアップデートを優先すべき状況だ。

### 3. EU AI 法が全面施行フェーズへ — 米国・中国との 3 分岐規制体制が AI ガバナンスの新たな地政学軸を形成

EU の AI 規制法（AI Act）は 2026 年に全面施行フェーズへ移行し、高リスク AI システムへの詳細な文書化・リスクアセスメント・人間監視の義務が EU 市場で展開するすべての AI プロバイダーに適用される。フィンランド・トゥルク大学の分析によると、現在の AI ガバナンスは「EU の権利指向型規制」「米国の市場主導型」「中国の国家主導型」という 3 つの体制に分岐しており、それぞれが「ブリュッセル効果」「デジタルシルクロード」「イノベーション優先」という形で国際的な影響力を行使している。米国では FDA（医療 AI）・FAA（航空 AI）・NHTSA（自動運転）など複数省庁が分野別の AI ガバナンスフレームワークを整備中。中国はオープンソース AI 戦略を軸に途上国へのデジタルインフラ輸出を拡大しており、ラテンアメリカが米中の次の技術覇権争いの舞台になりつつあるとも指摘されている。グローバルで製品を展開する開発者・企業にとって、EU のコンプライアンス要件は実質的なエントリーバリアとして機能し始めており、早期の対応体制整備が競争優位に直結する。

### Rust 2026 + WASI 0.3 — WebAssembly にネイティブ非同期サポートが到来、wasm64 で大規模ヒープ負荷が 37% 削減

Rust エコシステムにとって 2026 年は WebAssembly 関連の大きなマイルストーンが続いている。WASI（WebAssembly System Interface）0.3.0 が 2026 年にリリースされ、Component Model レベルで非同期関数呼び出しをネイティブサポートする初めての仕様となった。Rust 1.85 では `wasm64` ターゲットが安定化し、4KB 超のメディアワークロードにおける大規模ヒープアロケーションの負荷が **wasm32 比 37% 削減**されることが実測されている。また Rust の新 WebAssembly プロジェクトゴール（2026 H1）では、新規ターゲット `wasm32-wasip3`（WASI 0.3）と `wasm32-component`（ベア Component）が追加される計画が公開されており、Rust × Wasm の本番ユースケースがさらに広がる見通しだ。

```rust
// WASI 0.3 非同期コンポーネントの概念例 (wasm32-wasip3 ターゲット向け)
use wasi::io::streams::InputStream;

// Canonical ABI レベルでの async fn が利用可能に
async fn process_stream(input: InputStream) -> Result<Vec<u8>, wasi::Error> {
    let mut buf = Vec::new();
    loop {
        match input.read(4096).await? {
            bytes if bytes.is_empty() => break,
            bytes => buf.extend_from_slice(&bytes),
        }
    }
    Ok(buf)
}
```

Meta による WhatsApp メディアライブラリの Rust 書き換えや、Google Summer of Code 2026 への Rust 参加（19 プロジェクト採択）も追い風となり、Rust の実運用採用が着実に拡大している。

## セキュリティ

### PyPI サプライチェーン攻撃 — `lightning` 2.6.2/2.6.3 の対処チェックリスト

今回の PyTorch Lightning 汚染は AI/ML 開発者にとって直接的な脅威であり、以下の対処が推奨される。

**即時確認事項:**
- `pip show lightning` で現在インストール済みのバージョンを確認
- 2.6.2 または 2.6.3 が入っている場合はパッケージを即座に削除し、`2.6.1` または `2.6.4`（クリーン版）に固定
- 当該バージョンをインポートした環境はクラウド認証情報（AWS/GCP/Azure トークン、GitHub トークン等）をすべてローテーション

**再発防止:**
- `pip-audit` または `socket.dev` の CI インテグレーションでパッケージの整合性をチェック
- 本番 ML パイプラインでは依存パッケージを `requirements.txt` にハッシュ付きで固定（`pip install --require-hashes`）

### Linux CVE-2026-31431 — ほぼ全ディストリビューションに影響する LPE、カーネル更新が根本対策

CVE-2026-31431 は非特権ローカルユーザーが root 権限を取得できる LPE で、概念実証コードが公開済みのため積極的な悪用が懸念される。Amazon Linux・RHEL・Ubuntu・SUSE の全バージョン（2017 年以降のリリース）が対象となり、カーネルアップデートが唯一の根本対策だ。コンテナ環境でも ホストカーネル共有時は同様のリスクがある。
