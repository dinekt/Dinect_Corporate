### 3. Drupal CVE-2026-9082 の野放し悪用を本日確認 — PostgreSQL 環境で未認証 SQL インジェクション → RCE

Drupal は 5/22 付けのセキュリティアドバイザリ更新で **「エクスプロイト試行を検出した」** と公表し、CVE-2026-9082 のリスクスコアを引き上げた。この脆弱性は Drupal Core のデータベース抽象化 API に存在する SQL インジェクション（CVSS 9.8）で、**PostgreSQL バックエンドを使うサイトでは認証なしで**任意 SQL が実行でき、情報漏洩・権限昇格・リモートコード実行（RCE）につながる。Drupal 8 以降の全バージョンが影響を受け、修正は各サポートブランチ（11.3.10、11.2.12、11.1.10、10.6.9、10.5.10、10.4.10）に適用済みだ。MySQL/MariaDB 環境でも最新版が推奨される理由は、上流の Symfony・Twig の修正を含んでいるためだ。Drupal 7 は非影響だが、EOL 状態のため別の理由でアップグレードが必要な状況は変わらない。

### Astral ty — Python 型チェッカーの新星、uv の作者が開発し mypy/pyright 比で 100× 高速を主張

`uv`（超高速 Python パッケージマネージャー）の開発元 Astral が **`ty`** という新しい Python 型チェッカーを正式に安定版として公開した。既存の mypy・pyright の代替を目指しており、Rust 実装による大幅な高速化が最大の訴求点だ。`uv` が pip の牙城を崩しつつあるように、`ty` は型チェックのエコシステムを再定義する可能性を持つ。

```bash
# uv 経由でインストール（推奨）
uv tool install ty

# あるいは pip でも可
pip install ty

# 型チェックを実行
ty check src/

# mypy と並走させて比較（移行前の確認に）
mypy src/ && ty check src/

# pyproject.toml での設定例
# [tool.ty]
# src = ["src"]
# strict = true

# CI での高速チェック（--no-cache は初回のみ）
ty check --output-format=json src/ | jq '.errors[] | .message'
```

`uv` との統合も進んでおり、`uv run ty check` でプロジェクトの仮想環境内チェックが可能。段階的移行のため mypy と並走させて差分を確認する方法が推奨されている。

### Ubiquiti UniFi OS — 修正済みバージョンへの即時アップグレード手順

本日公開の3件 CVSS 10.0 を含む脆弱性への対処方法。

```bash
# UniFi OS のバージョン確認（SSH でデバイスに接続して実行）
ubnt-device-info summary

# 推奨アップグレードターゲット
# UniFi OS Server: 5.0.8 以上
# UCG-Industrial / UDM / UDR / UNVR / ENVR / UCG: 5.1.12 以上

# UniFi Controller (UI) からのアップグレード手順
# Settings → System → Firmware Update → Check for Updates → Update

# インターネット非接続環境向け: CLI でファームウェアを手動適用
# (事前にファームウェアをダウンロードし、SCP で転送)
scp unifi-os-5.1.12.bin ubnt@<device-ip>:/tmp/
ssh ubnt@<device-ip> "syswrapper.sh upgrade2 /tmp/unifi-os-5.1.12.bin"

# アップグレード後のバージョン確認
ubnt-device-info summary | grep "UniFi OS"

# ネットワーク境界でのアクセス制限（パッチ適用が即座に難しい場合）
# UniFi の管理ポート（TCP 443, 8443）を信頼できる管理 IP のみに制限
```

### Drupal CVE-2026-9082 — PostgreSQL 環境の緊急パッチ適用手順

```bash
# Drupal バージョンを確認
drush status | grep 'Drupal version'
# または
php -r "define('DRUPAL_ROOT', '.'); require_once 'core/includes/bootstrap.inc'; echo \Drupal::VERSION;"

# Drush 経由でアップデート（推奨）
composer require 'drupal/core-recommended:^10.6.9'  # Drupal 10 系の例
composer update drupal/core-recommended drupal/core-composer-scaffold --with-all-dependencies
drush updb -y
drush cr

# Drupal 11 系
composer require 'drupal/core-recommended:^11.3.10'
composer update drupal/core-recommended drupal/core-composer-scaffold --with-all-dependencies
drush updb -y && drush cr

# PostgreSQL 使用の確認（影響を受けるバックエンドかチェック）
drush sql:query "SELECT version();"
# "PostgreSQL" が含まれていれば最優先でアップデートが必要

# MySQL/MariaDB 環境でも上流依存ライブラリのため更新推奨
# 更新後に Symfony/Twig が修正バージョンか確認
composer show symfony/http-foundation | grep versions
```
