### 1. OpenAI Codex を標的にした npm サプライチェーン攻撃 — 週間 2.9 万 DL のパッケージに認証トークン窃取コードが混入

セキュリティ企業 Aikido が `codexui-android` パッケージ（GitHub・npm で OpenAI Codex のリモート Web UI として宣伝）に情報窃取コードが混入していると公表した。週間 2.9 万ダウンロード・累計 6 万超のモバイルインストール実績を持つ実用的なパッケージで、**GitHub リポジトリは「クリーン」に維持しつつ npm 更新でのみ悪意のあるコードを追加する手法**がとられた点が特徴的だ。奪われるのは OpenAI の認証トークンおよび**失効しない**リフレッシュトークンで、攻撃者は被害者のアカウントを無期限に詐称できる。さらに Android アプリ「OpenClaw Codex Claude AI Agent」（package: gptos.intelligence.assistant）も同一エンドポイントへ認証情報を送信することが判明し、モバイル開発環境まで標的に含まれる。AI ツールチェーンが急拡大する中、「開発者が信頼するパッケージのアップデートそのものを侵害する」手口の高度化が鮮明になった事例として業界に衝撃を与えている。

### 2. Cisco SD-WAN 第 6 のゼロデイ CVE-2026-20182（CVSS 10.0）— UAT-8616 が認証バイパスで SD-WAN ファブリック全体を掌握

Cisco Catalyst SD-WAN Controller / Manager に認証バイパスの **CVSS 最大スコア 10.0** 脆弱性が発見・修正され、2026 年に入って Cisco SD-WAN で積極的に悪用された **6 件目のゼロデイ**となった。リモート非認証攻撃者がピアリング認証機構を迂回して SD-WAN ファブリックに「認証済みピア」として接続し、vmanage-admin の SSH `authorized_keys` を書き換えることで NETCONF（TCP 830）経由で任意のファブリック再構成が可能になる。標的型攻撃を実施しているのは APT グループ **UAT-8616** で、さらに旧脆弱性 CVE-2022-20775 を連鎖的に悪用して root 権限まで昇格する手口も確認されている。CISA は Emergency Directive 26-03 として連邦機関に対し 5 月 17 日を修正期限に設定済みで、民間組織への迅速対応勧告も継続中だ。2026 年は SD-WAN インフラへの標的攻撃が前例のない頻度で続いており、コントローラの管理インターフェース露出面の最小化が急務となっている。

### Gemini 3.5 Flash GA を受け、Google が 3.5 Pro を 6 月ローンチへ — エージェント・長文脈処理で競合と差別化

5 月 20 日の Google I/O で **Gemini 3.5 Flash** が一般提供（GA）に移行し、Gemini API・AI Studio・Antigravity 2.0・Google 検索 AI モード・Gemini アプリのデフォルトモデルとして全世界展開が完了した。3.5 Flash は Gemini 3.1 Pro をエージェント・コーディングベンチマークで上回り、「フラッグシップ並みの知能をフラッシュ速度で」というコンセプトを体現している。続く **Gemini 3.5 Pro** は 6 月内のローンチが予告されており、多段階推論・超長コンテキスト処理・ネイティブ音声 I/O が搭載される見通しだ。価格面では Gemini 3.5 Flash が 3.1 Pro 比で約 3 倍のコスト増となっており、コスト意識の高い開発者には他社モデルとのコスト・性能トレードオフの精査が引き続き必要となっている。AI モデルの世代交代サイクルが 3〜4 か月に短縮されている現状では、依存関係の過度な固定化を避けた設計が重要性を増している。

```python
# Gemini 3.5 Flash — Function Calling / Agentic workflow example
import google.genai as genai
from google.genai import types

client = genai.Client()

def get_weather(location: str) -> dict:
    """Fetch current weather for a given city."""
    # 実際の実装では外部 API を呼び出す
    return {"location": location, "temp_c": 28, "condition": "Sunny"}

response = client.models.generate_content(
    model="gemini-3.5-flash",
    contents="東京の天気は今どうですか？",
    config=types.GenerateContentConfig(
        tools=[get_weather],
        automatic_function_calling=types.AutomaticFunctionCallingConfig(
            disable=False
        ),
    ),
)
print(response.text)
```

### Windows NTLMv2 ハッシュ漏洩（未パッチ）・HTTP/2 爆弾・Minecraft Weedhack MaaS — 6 月上旬の脅威トリオ

セキュリティ研究者が **Windows 検索 URI ハンドラの未修正問題**を公表した。特定の URI を含むリンクをクリックするだけで被害者の **NTLMv2 ハッシュ**が攻撃者の制御するサーバーへ送信され、ネットワーク上でのリレー攻撃（Pass-the-Hash）や NTLM クラッキングに悪用される恐れがある。Microsoft は現時点でパッチを提供しておらず、**SMB 署名の強制**と **NTLM 制限ポリシー**の適用が暫定的な軽減策として推奨されている。別件として研究者グループが **HTTP/2 圧縮爆弾 + Slowloris 連鎖攻撃（通称 HTTP/2 Bomb）**を公開。主要 Web サーバのデフォルト HTTP/2 設定がこの組み合わせ攻撃に対して脆弱であることが示され、同時接続ストリーム数の制限とリクエストレート制御が対策の柱となる。またマルウェア研究機関 McAfee Labs は **Weedhack** キャンペーン（Minecraft 向けマルウェア as a Service）が 2026 年 1 月から継続活動中であることをレポート。正規の Minecraft クライアント・Mod パッケージを偽装してエンドユーザーを感染させる手口で、npm サプライチェーン攻撃と並んでオープンエコシステムを狙う攻撃の裾野が広がっている。

```bash
# --- Windows NTLMv2 漏洩 — 暫定軽減策 ---

# 1. SMB 署名を強制（PowerShell、管理者権限）
Set-SmbServerConfiguration -RequireSecuritySignature $true -Force
Set-SmbClientConfiguration -RequireSecuritySignature $true -Force

# 2. NTLMv1 / LM を無効化（レジストリ）
# HKLM\SYSTEM\CurrentControlSet\Control\Lsa
# LmCompatibilityLevel = 5  (NTLMv2 のみ送信・LM と NTLM を拒否)
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Lsa" `
    -Name "LmCompatibilityLevel" -Value 5 -Type DWord

# --- HTTP/2 Bomb 対策（nginx 設定例）---
# /etc/nginx/nginx.conf に追加
# http2_max_concurrent_streams 32;     # デフォルト 128 から引き下げ
# client_header_timeout 10s;
# limit_req_zone $binary_remote_addr zone=api:10m rate=30r/m;
# limit_req zone=api burst=10 nodelay;

# --- npm サプライチェーンリスクの継続チェック ---
# Socket Security CLI で依存パッケージをスキャン
npx socket scan .

# npm audit も忘れずに実行
npm audit --audit-level=moderate
```

**影響範囲と優先度**: Windows NTLMv2 漏洩は未パッチのため SMB 署名・NTLM 制限を即時適用。HTTP/2 Bomb は nginx / Apache / IIS のデフォルト設定を見直す。npm 開発環境では `codexui-android` 含む AI ツール系パッケージのトークンスコープと更新来歴を精査し、OpenAI / Anthropic トークンの再発行・スコープ制限を検討されたい。
