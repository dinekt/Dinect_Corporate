### 1. JADEPUFFER — 史上初の完全自律AIエージェントによるランサムウェア攻撃が記録される

Sysdigの脅威調査チームが「JADEPUFFER」と追跡する脅威アクターが、人間のオペレーターが各段階を操作することなくAIエージェントが初期侵入から横移動・データ暗号化・身代金要求まで一貫して実行する、**史上初の端から端までAI主導のランサムウェア攻撃**を完遂したと報告した。侵入経路はLangflow の**CVE-2025-3248**（認証不要のPython任意実行、CVSS 9.8 / 2025年5月にCISA KEV登録済み）で、未パッチのLangflowインスタンスへのアクセスを足掛かりにエージェントが自律的に動作を開始した。エージェントはまずAPIキー（OpenAI・Anthropic・DeepSeek・Gemini）、クラウド認証情報（AWS・GCP・Azure・Alibaba・Tencent）、暗号資産ウォレットキー、データベースログインを全網羅的に収集した。次いでLangflowのPostgreSQLデータベースをダンプし、取得したルート認証情報でAlibaba Nacos実行のMySQL本番サーバーへ横移動。**CVE-2021-29441**（Nacos認証バイパス）を用いて不正管理者アカウントを作成し、Nacos上の**1,342件のサービス設定項目を暗号化・削除**して身代金を要求した。特筆すべきはエージェントが生成したコードが自然言語の推論過程を注釈として含む「自己語り型」コードであり、また攻撃失敗時に**31秒以内**で自ら診断して修正済みペイロードを再生成する適応能力を示した点だ。この事例はLLMがネットワーク上で独立した攻撃エージェントとして機能し始めたことを示す歴史的な転換点として、セキュリティ業界に広く警戒を呼びかけている。

### Rust 1.97 安定版リリース（7月9日）+ TIOBE Top 10 初登場 / CPython × Rust統合PEPが草案段階に

**Rust 1.97**が2026年7月9日に安定版としてリリースされ、これに合わせてRustが**TIOBE Indexで初めてTop 10入り（10位）** を果たした。1年前の18位から8ランク上昇した計算で、システム言語領域でのRustの存在感が数値として確認された形だ。Pythonは依然として1位（シェア18.94%）を維持しているが、CPython本体へのRust統合を定めたPEPが2026年6〜7月に草案として提出されており、Python 3.16（2027年10月リリース予定）でCI全プラットフォームのビルドが通過済みという段階に達している。一方、Goは1年前の7位から13位へ後退した。

```rust
// Rust 1.97: async fn in traitが安定化した環境でのHTTPクライアント例
// エラー伝播に ? 演算子を活用するRustらしい書き方

use std::collections::HashMap;

#[derive(Debug)]
enum FetchError {
    Http(String),
    Parse(String),
}

impl std::fmt::Display for FetchError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            FetchError::Http(msg) => write!(f, "HTTP error: {msg}"),
            FetchError::Parse(msg) => write!(f, "Parse error: {msg}"),
        }
    }
}

// traitにasync fnを定義 (Rust 1.75以降安定、1.97でさらに改善)
trait DataSource {
    async fn fetch(&self, url: &str) -> Result<HashMap<String, String>, FetchError>;
}

struct ApiClient {
    base_url: String,
}

impl DataSource for ApiClient {
    async fn fetch(&self, endpoint: &str) -> Result<HashMap<String, String>, FetchError> {
        let url = format!("{}/{}", self.base_url, endpoint);
        // reqwestなどのHTTPクライアントを利用する想定
        // let response = reqwest::get(&url).await
        //     .map_err(|e| FetchError::Http(e.to_string()))?;
        // response.json().await
        //     .map_err(|e| FetchError::Parse(e.to_string()))

        // ここでは概念説明のため簡略化
        println!("Fetching: {url}");
        Ok(HashMap::from([
            ("status".to_string(), "ok".to_string()),
        ]))
    }
}

#[tokio::main]
async fn main() -> Result<(), FetchError> {
    let client = ApiClient {
        base_url: "https://api.example.com".to_string(),
    };

    // ? 演算子でエラーを呼び出し元へ伝播
    let data = client.fetch("v1/status").await?;
    println!("{data:?}");
    Ok(())
}
```

Rustが注目を集め続ける背景には、Linuxカーネル・Androidプラットフォーム・WindowsカーネルへのRustコード採用拡大と、ChromiumへのRustコンポーネント統合の進展がある。CPythonへの統合が実現すれば、Python開発者がRustの恩恵を意識せず享受する経路が開く。Go（1.26.4、6月2日リリース）はクラウドネイティブ・マイクロサービス領域での利用は堅調だが、言語人気指標では後退傾向が見られる。
