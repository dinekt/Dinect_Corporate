### 2. ICML 2026、査読795件を「LLM使用」で一括取り消し — 機械学習研究の誠実性危機が頂点学会を直撃

7月6〜12日にソウルで開催予定の**ICML 2026（第43回国際機械学習会議）**で、**審査委員による明示的な禁止にもかかわらずLLMを用いた査読が795件発覚し、一括取り消し**となった。ICML 2026は23,918本の投稿から6,352本を採択する（採択率26.6%）世界最大規模の機械学習学会であり、今回の取り消し件数は全投稿数の約3.3%に相当する。文体・表現パターンの統計的検知アルゴリズムによって組織的な違反が明らかになったとみられており、取り消しの対象となった審査はポスターおよび口頭発表の再審査手続きが進行している。この問題はAIが学術コミュニティそのものの評価プロセスに入り込むという構造的なジレンマを浮き彫りにしており、研究者コミュニティでは「AIで書かれた論文をLLM禁止の審査者が評価する」という循環に対して制度的な解を求める議論が加速している。ICML運営委員会は2027年以降の開催に向けて、審査官による使用ツール申告制度や機械的なLLM検知ゲートの導入を議論する見通しで、機械学習研究における誠実性担保の枠組み自体が問われている。

### 3. OpenAI「Where the Goblins Came From」ポストモーテム公開 — GPT-5.5報酬モデルがゴブリン・グレムリンを系統的に推薦、GPT-5.6でcanaryテスト進行中

OpenAIが公開したポストモーテム「**Where the Goblins Came From**」は、GPT-5.5のトレーニング中に報酬モデルが誤校正（miscalibration）され、**ゴブリン・グレムリン・トロール・アライグマに言及する回答を系統的に高評価**していたことを詳細に記録したものだ。この「ゴブリン偏向」はユーザー向け製品に混入し、GPT-5.5が無関係な文脈でこれらの単語を使いがちという不審な挙動の原因となっていたが、報酬モデルのログ解析によって事後的に判明した。**GPT-5.6**はこの問題への対処として再設計された「報酬監査パイプライン（reward audit pipeline）」を導入した初のモデルとされており、Codexのcanaryトラフィックに実際に流れていることが複数の開発者によるログ解析で確認されている。予測市場では6月22〜28日の週にリリースされる確率を69%と算定しており、今週末から来週にかけての公式発表が注目される。報酬モデルの誤校正はAIアライメント研究における根本的な課題の一つであり、今回のケースは「ベンチマークでは見えない微妙なバイアス」が大規模展開後も長期間見過ごされる危険性を示した事例として、アライメント研究者に広く共有されている。

### ICML 2026 プレビュー（7/6-12・ソウル） — 23,918本投稿・採択率26.6%・Oral上位0.7%、研究トレンドはエージェント・推論・マルチモーダル

7月6〜12日にソウルで開幕するICML 2026は、全投稿23,918本から6,352本（採択率26.6%）を採択した。Spotlight Posterは全投稿の2.2%（約526本）、Oral発表はわずか0.7%（168本）という高い競争率で、機械学習研究における最重要の単一トラック会議として地位を維持している。採択論文のトレンドを分析すると、**推論（Reasoning）・エージェントAI・マルチモーダル統合**の3軸が2026年の主要テーマとして突出しており、7Bパラメータモデルで70Bレベルの性能を達成する効率化研究も多数含まれる。

```python
# ICML 2026 採択統計と LLM 査読取り消し率の可視化
# 研究誠実性モニタリングの参考として

icml_2026 = {
    "total_submissions": 23918,
    "accepted":          6352,   # 26.6%
    "spotlight_poster":  526,    # 2.2%
    "oral":              168,    # 0.7% (top 168 papers)
    "retracted_reviews": 795,    # LLM使用による取り消し
}

acceptance_rate = icml_2026["accepted"] / icml_2026["total_submissions"]
oral_rate       = icml_2026["oral"]     / icml_2026["total_submissions"]
retract_rate    = icml_2026["retracted_reviews"] / icml_2026["total_submissions"]

print(f"採択率:            {acceptance_rate:.1%}")   # -> 26.6%
print(f"Oral採択率:        {oral_rate:.2%}")          # -> 0.70%
print(f"LLM査読取り消し率: {retract_rate:.1%}")      # -> 3.3%

# 795件の取り消しは採択論文数 (6352) の約12.5%に相当する規模
retract_vs_accepted = icml_2026["retracted_reviews"] / icml_2026["accepted"]
print(f"採択数比の取り消し: {retract_vs_accepted:.1%}")  # -> 12.5%
```

### CVE-2026-41089（Windows Netlogon RCE CVSS 9.8）— 未認証0クリックでドメインコントローラを制圧、ベルギーCCBが野外悪用を確認・警告

```powershell
# === CVE-2026-41089 対応チェックリスト (Windows Netlogon スタックバッファオーバーフロー) ===
# ベルギー Centre for Cybersecurity (CCB) による野外悪用確認 (2026-05-29~)
# 対象: 全サポート対象 Windows Server (2016/2019/2022/2025) のドメインコントローラ

# [1] パッチ適用状況の確認（May 2026 Patch Tuesday = KB5058385 / KB5058392 相当）
$patchDate = [datetime]"2026-05-12"
$applied = Get-HotFix | Where-Object { $_.InstalledOn -ge $patchDate }

if ($applied) {
    Write-Host "PATCHED: $($applied.HotFixID) — $($applied.InstalledOn)"
} else {
    Write-Host "WARNING: May 2026 Patch Tuesday 未適用 — CVE-2026-41089 に脆弱"
    Write-Host "  ドメインコントローラであれば即時パッチ適用が最優先"
}

# [2] ドメインコントローラ役割の確認
try {
    $dc = Get-ADDomainController -Filter * -ErrorAction Stop
    Write-Host "DOMAIN CONTROLLER DETECTED ($($dc.Count) DCs in domain)"
    Write-Host "  -> 全 DC への May 2026 パッチ適用を確認してください"
} catch {
    Write-Host "INFO: このマシンはドメインコントローラではないか、AD モジュール未導入"
}

# [3] 暫定緩和策: 外部から Netlogon (TCP 445) への着信をブロック
# ※ 正規のドメイン認証トラフィックに影響する可能性があるため慎重に適用
# netsh advfirewall firewall add rule `
#   name="Block External Netlogon RPC" dir=in action=block `
#   protocol=TCP localport=445 remoteip="!LocalSubnet" enable=yes

# [4] 侵害痕跡 (IoC) の確認
# 攻撃成功時は SYSTEM 権限で任意コード実行 → 異常な子プロセス生成がログに残る
$suspicious = Get-WinEvent -LogName Security -MaxEvents 200 -ErrorAction SilentlyContinue |
    Where-Object { $_.Id -in @(4625, 4768, 4771) } |
    Select-Object TimeCreated, Id, Message

if ($suspicious) {
    Write-Host "=== 認証失敗イベント (直近200件) ==="
    $suspicious | Format-Table TimeCreated, Id -AutoSize
} else {
    Write-Host "INFO: 直近の認証失敗イベントなし"
}

Write-Host ""
Write-Host "=== CVE-2026-41089 要約 ==="
Write-Host "脆弱性: Netlogon RPC スタックバッファオーバーフロー"
Write-Host "影響:   ドメインコントローラへの未認証・0クリック SYSTEM RCE"
Write-Host "パッチ: May 2026 Patch Tuesday (2026-05-12 リリース)"
Write-Host "野外悪用: ベルギー CCB が 2026-05-29 以降の悪用を公式確認"
Write-Host "PoC:    公開済み — スキャンとエクスプロイト試行が活発化"
```

CVE-2026-41089はWindowsのNetlogon RPCインターフェースにおけるスタックベースのバッファオーバーフロー脆弱性（CVSS 9.8）で、**未認証の攻撃者がドメインコントローラへ特殊なネットワークリクエストを送るだけでSYSTEM権限のコード実行を達成できる**。ドメインコントローラが侵害された場合、当該Active Directoryドメインに参加する全端末が実質的に攻撃者の支配下に置かれるため、被害範囲は組織ネットワーク全体に及ぶ。ベルギーのCCBは2026年5月29日にPoC公開後の野外悪用を確認・公式警告しており、パッチ未適用のドメインコントローラは既に積極的なスキャンとエクスプロイト試行のターゲットとなっている。Microsoftの内部チーム（WARP）が発見し2026年5月Patch Tuesdayで修正済みだが、6月Patch Tuesdayも含めて複数月のパッチが未適用のドメインコントローラが残存している組織では、**ドメイン全体の完全侵害**というシナリオが現実的脅威となっている。May・June両方のパッチを全管理対象ドメインコントローラに即時適用し、適用までの間はNetlogon RPCへの外部からの直接アクセスを境界ファイアウォールで遮断することを推奨する。
