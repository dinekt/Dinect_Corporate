### 1. Anthropic、Claude Sonnet 5 を正式リリース — Opus 4.8 並みのエージェント性能を半値で提供

Anthropic は 6 月 30 日、**Claude Sonnet 5** を正式リリースし、7 月 1 日より Free・Pro プランのデフォルトモデルに切り替えた。最大の特徴は「最もエージェンティックな Sonnet」という位置づけであり、ブラウザや端末ツールの自律操作・長期計画立案をこれまで Opus クラスのモデルが担っていた水準で実行できる。コンテキストウィンドウはデフォルト・最大ともに **1M トークン**、最大出力は 128k トークン、思考プロセスの可視化機能「Adaptive Thinking」もサポートする。価格は 8 月 31 日まで入力 $2/M・出力 $10/M のイントロダクトリー価格で提供され、以降は $3/$15 の標準価格へ移行する。安全性面では Sonnet 系列初の**リアルタイムサイバーセキュリティガード**が導入され、禁止ないし高リスクなセキュリティ関連リクエストを拒否する機能が組み込まれた。また前世代（Sonnet 4.6）と比較して、不正利用への同調・幻覚・過度な同意（sycophancy）の発生率が有意に低下しており、エージェント文脈でのプロンプトインジェクション耐性も向上している。

### 2. CISA が SharePoint RCE（CVE-2026-45659）を KEV に追加 — 修正期限は本日 7 月 4 日

**CVE-2026-45659**（CVSS 8.8）は Microsoft SharePoint Server の**安全でないデシリアライゼーション**に起因するリモートコード実行脆弱性で、CISA が今週 Known Exploited Vulnerabilities（KEV）カタログに追加した。攻撃に必要な権限は Site Member レベル（最低権限）であり、ネットワーク経由で認証済み攻撃者が管理者権限なしにサーバー上で任意コードを実行できる。影響対象は SharePoint Server Subscription Edition・2019・Enterprise Server 2016 で、Microsoft は 5 月の月例パッチで修正したものの開示を失念し、CISA の KEV 追加によって初めて広く認知された経緯がある。連邦民間行政機関（FCEB）への修正期限は本日 7 月 4 日となっており、民間組織も同水準の緊急度で対処が求められる。SharePoint を外部公開している環境はもちろん、内部向け利用でも認証済み攻撃者（侵害済みアカウントを含む）からの横断的移動に悪用される恐れがあるため注意が必要だ。

### 3. Fable 5 エクスポート規制が解除 — 中国 GLM-5.2 が規制空白期間にベンチマーク首位を奪取

6 月 12 日に米国商務省が輸出管理改革法（ECRA）を AI モデルに初適用し、Anthropic の **Fable 5** および **Mythos 5** を全海外ユーザー向けに停止させた事件の続報として、7 月 1 日に Fable 5 のグローバルアクセスが制限付きで復旧した。Mythos 5 は引き続き米国機関向けのみの提供となっている。この約 3 週間の空白期間に、中国の Zhipu AI が 6 月 13 日に **GLM-5.2** をフルオープンウェイトで公開し、BridgeBench Reasoning でトップに立つという象徴的な出来事が起きた。GLM-5.2 は 300 トークン/秒の推論速度と Fable 5 比 10 分の 1 以下のコストを強みとし、ユーザーが自前の計算資源で実行できる。フランスのマクロン大統領は「米国企業が一夜にしてスイッチを切れるなら、欧州は米国製モデルを買わない」と警告しており、AI 覇権をめぐる地政学リスクが調達・ガバナンス戦略に直接影響する時代に入ったことを印象づける一件となった。

### Python 3.15 ベータ — 遅延インポート・frozendict・JIT 強化でランタイム性能が大幅向上

Python 3.15 は 2026 年 5 月に Beta 1 が公開され、6 月に機能フリーズを完了。正式リリースは 2026 年 10 月 1 日予定だ。本バージョンは**フリースレッド CPython の安定 ABI**（GIL 無効化モードの量産化）に加え、スタートアップ高速化を狙う**遅延インポート**（PEP 810）と**frozendict 組み込み型**（PEP 814）が目を引く。JIT コンパイラは x86-64 Linux で平均 8〜9%、Apple Silicon macOS で 12〜13% のパフォーマンス向上を示しており、AI/ML ワークロードでの恩恵が期待できる。テキストエンコードは UTF-8 デフォルト化が行われ、国際化対応コードの記述コストが下がる。

```python
# Python 3.15 — 遅延インポートの概念例（PEP 810）
# 大規模プロジェクトのスタートアップ時間を短縮するための宣言的遅延インポート

# 現行（3.14 以前）: モジュールレベルで即時実行
import heavy_library  # 起動時に全モジュールを読み込む

# Python 3.15: 遅延インポートは実際に使用された時点で初めてロード
import lazy  # 3.15 では __lazy_imports__ フラグで有効化
lazy heavy_library      # -> 初回参照時に初めてインポート

# frozendict の使用例（PEP 814）
config = frozendict({"env": "production", "debug": False})
# config["env"] = "dev"  -> TypeError: 'frozendict' object does not support item assignment

# JIT 恩恵の計測（ベンチマーク参考）
import timeit
result = timeit.timeit(
    stmt="sum(x**2 for x in range(10_000))",
    number=1000
)
print(f"合計時間: {result:.3f}s")
# 3.14 比で約 8-9% 高速化（x86-64 Linux 環境）
```

遅延インポートはモジュール間の循環依存を回避しやすくなる副次効果もあり、大規模なコードベースのリファクタリングコストを低減する可能性がある。frozendict は辞書型設定オブジェクトの誤変更を型レベルで防ぐことができ、設定管理パターンの堅牢化に寄与する。

### CVE-2026-45659（SharePoint RCE）と SimpleHelp RMM（CVSS 10.0）— CISA KEV 二連追加で今週が対応のリミット

```bash
# === CISA KEV 緊急対応チェックリスト (2026-07-04) ===

# ---- [1] CVE-2026-45659: Microsoft SharePoint RCE (CVSS 8.8) ----
# 修正期限: 2026-07-04（本日）
# 影響: SharePoint Server Subscription Edition / 2019 / Enterprise Server 2016
# 攻撃要件: 認証済み + Site Member 権限（最低権限）→ ネットワーク経由で RCE 可能
# パッチ: 2026 年 5 月 Patch Tuesday に含まれる更新プログラムを適用

# SharePoint 更新状況確認（PowerShell）
Get-SPProduct | Select-Object Name, Version, Patches |
  Where-Object { $_.Name -like "*SharePoint*" }

# 5月パッチの KB 番号を確認
# KB5062192 (Subscription Edition)
# KB5062193 (2019)
# KB5062194 (Enterprise Server 2016)

# ---- [2] SimpleHelp RMM: CVE-2026-54321 (CVSS 10.0) ----
# 修正期限: 2026-07-02（昨日期限・未対応環境は即時対処）
# 影響: MSP（マネージドサービスプロバイダ）環境のサプライチェーン
# 悪用: TaskWeaver ローダー展開によるランサムウェア予備段階の侵害が報告

# SimpleHelp のバージョン確認（管理コンソールから確認を推奨）
# 最新パッチ適用済みの場合:
curl -sk https://localhost:5800/api/version | jq '.serverVersion'

# ネットワーク経由で公開されている SimpleHelp サーバーが存在しないか確認
nmap -p 5800 --open -iL internal_hosts.txt

echo "=== 優先度サマリー ==="
echo "[CRITICAL] CVE-2026-45659: SharePoint RCE — 修正期限 2026-07-04（本日）"
echo "[CRITICAL] SimpleHelp RMM: CVSS 10.0 — 修正期限 2026-07-02（期限超過）"
```

CVE-2026-45659 の技術的な根本原因は**信頼されていないデータのデシリアライゼーション**であり、SharePoint がエンドポイントで受け取ったシリアライズ済み入力をオブジェクト型の検証なしに再構成するという設計上の欠陥に由来する。Site Member 権限のみで攻撃が成立する低い攻撃難易度が KEV 追加の決め手となった。SimpleHelp RMM の CVSS 10.0 脆弱性は MSP（マネージドサービスプロバイダ）が管理する多数のエンドポイントへの連鎖侵害（サプライチェーン攻撃）に悪用されており、管理下顧客環境への横展開に使われるケースが報告されている。
