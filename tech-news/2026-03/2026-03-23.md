## ニュース一覧

### 1. CanisterWorm -- ICP(Internet Computer)ブロックチェーンをC2に使う自己増殖npm攻撃
**カテゴリ**: セキュリティ / サプライチェーン
**影響度**: ★★★★★

3月19日のTrivy侵害（CI/CDパイプライン経由のシークレット窃取）を起点に、後続攻撃が拡大。脅威グループ「TeamPCP」が展開するCanisterWormが66種類以上のnpmパッケージ・141アーティファクトに波及した。

**攻撃の仕組み**:
- npmの公開パッケージに悪意あるコードを注入
- インストール時にnpm認証トークンを窃取
- 盗んだトークンで別パッケージに自動伝播（手動介入不要）
- C2サーバアドレスの取得に **Internet Computer(ICP)スマートコントラクト（Canister）** を使用 -- 改ざん耐性があるためテイクダウンが困難

**なぜ重大か**:
- 従来のC2はドメイン・IPをブラックリスト登録すれば遮断できたが、分散型ブロックチェーン上のCanisterは単一点ブロックが不可能
- 自己増殖機構により感染範囲が自動拡大する「ワーム型」npm攻撃は新型モデル

**対処**:
```bash
# npmトークンを即時ローテーション
npm token revoke <TOKEN_ID>
npm token create --read-only  # CIには最小権限トークンを発行

# lockfileで固定バージョンを使い、予期しない更新を防ぐ
npm ci  # npm install ではなく npm ci を使う
```

### 2. PSpice AES-256コピペバグ -- 鍵空間が2^256から2^32に縮退
**カテゴリ**: セキュリティ / 暗号
**影響度**: ★★★★☆

Cadence PSpice（電子回路シミュレータ）のモード4暗号化に深刻な実装バグ。DES用コードをAESに転用した際に鍵変数の置き換えが不完全で、32ビット（4バイト）のみが未知のまま28バイトが既知定数となる。

**技術詳細**:
- DES（8バイト鍵）のコードパスをAES（32バイト鍵）に流用したコピペバグ
- 32バイト鍵のうちXORされたユーザー材料は4バイトのみ
- 残り28バイト: 固定バージョンサフィックス + ヌル終端 + ゼロパディング（既知定数）

**教訓**: 暗号ルーティンはコピペ移植が最も危険。DES→AES移植時の定数・変数のレビューは必須。

### 3. タバコライターでroot権限取得 -- EMFI物理攻撃が低コスト化
**カテゴリ**: セキュリティ / ハードウェア
**影響度**: ★★★☆☆

圧電式BBQライターとインダクタを組み合わせた電磁フォルトインジェクション（EMFI）でSamsungノートPCのDDRメモリバスに障害を注入、ソフトウェア脆弱性なしにroot権限を取得した研究が公開された。

**要点**:
- 専用の高価なEMFI機器（数百万円）なしに、数千円の部品で実現
- ターゲット: DDRデータラインへの電磁パルス注入 → メモリビット反転 → 特権昇格

**含意**: IoTデバイス・組み込みシステム・キオスク端末等の物理アクセス可能な機器での脅威として再注目。
