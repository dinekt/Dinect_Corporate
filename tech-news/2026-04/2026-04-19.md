### 1. Google Gemini 3.1 Ultra 正式公開 — 200万トークンコンテキスト・ネイティブマルチモーダル推論

Google は Gemini 3.1 Ultra を正式公開した。最大の特徴は業界初となる200万トークンのコンテキストウィンドウで、テキスト・画像・音声・動画を文字起こしなしにネイティブで横断推論できる点だ。付属の新しいサンドボックス型 Code Execution ツールにより、コード生成から実行・検証まで一貫してモデル内で完結できるようになった。同時に軽量エンドポイントとして Gemini 3.1 Flash-Lite も展開され、旧バージョン比で 2.5倍の高速化と 45% の出力速度向上を実現、入力100万トークンあたり 0.25ドルという低価格設定で競争をさらに加速させている。オープンウェイト側では Gemma 4（Apache 2.0）ファミリーが追加展開され、Gemma-4-26b と Gemma-4-31b が AI Studio および Gemini API 経由で利用可能になっている。

**開発者・ビジネスへの影響**:
- 200万トークンコンテキストは長大なコードベース全体・長編文書・時系列の長い会議録などを一括処理できることを意味し、RAGアーキテクチャへの依存度を再考する契機になりうる
- Gemma 4（Apache 2.0）の商用利用が完全無料である点から、中小規模プロジェクトでのオープンウェイトモデル採用が加速する見込み

### 2. Rust for CPython April 2026 進捗報告 — 全プラットフォームCI成功、PEP ドラフト 6-7月へ

Python 公式ブログが「Rust for CPython Progress Update April 2026」を公開し、Rust を使った CPython の内部 API 再設計が重要なマイルストーンを達成したと報告した。CPython がサポートするすべてのプラットフォームで Rust コードの CI ビルドが通るようになったことが最大の進展であり、Guido van Rossum も設計方針を承認したとされる。PEP ドラフトは 2026年6〜7月を目標に策定が進んでおり、Python 3.16（ベータ1 は 2027年5月予定、正式リリースは 2027年10月）への組み込みが目指されている。CPython インターナルを Rust で書き直すことでメモリ安全性・パフォーマンス・保守性の向上が期待されており、Python エコシステム全体に長期的な影響を与える取り組みとして注目が集まっている。2026年4月 TIOBE レポートでは Python がトップを維持、Go が堅調、Rust は上位10位をキープしながらも急上昇トレンドは落ち着き始めている。

**開発者への影響**:
- Python 3.16 まではまだ時間があるが、CPython のコア変更が将来の C拡張モジュールのビルド方法や ABI 互換性に影響する可能性があり、C拡張を積極利用するプロジェクトはロードマップの動向を把握しておくことが重要
- Rust の採用が言語処理系レベルまで広がったことで、「Rust を学ぶ理由」に「Python コア開発への参加」が加わった

**出典**: [Python Insider — Rust for CPython Progress Update April 2026](https://blog.python.org/2026/04/rust-for-cpython-2026-04/) / [Python.org Discuss](https://discuss.python.org/t/rust-for-cpython-progress-update-april-2026/106895) / [Sean Kim Blog — Rust for CPython PEP](https://blog.imseankim.com/rust-for-cpython-pep-python-3-16-build-system-guido-approves-2026/)

### 3. CISA が Fortinet・Microsoft・Adobe の悪用済み脆弱性 6 件を KEV に追加 — FortiClient EMS が CVSS 9.1

CISA は 4月18日、Known Exploited Vulnerabilities（KEV）カタログに新たに 6 件の脆弱性を追加した。特に深刻なのは Fortinet FortiClient EMS の CVE-2026-21643（CVSS 9.1）で、未認証の SQL インジェクションにより攻撃者が任意コードをリモートで実行できる。Microsoft Defender の 3 件の脆弱性（BlueHammer・RedSun・UnDefend）が特権昇格およびサービス拒否攻撃を可能にするとして追加され、Adobe Acrobat Reader の Use-After-Free（UAF）脆弱性も含まれる。FortiClient EMS はゼロトラストアクセス管理や VPN 管理の基盤として大企業・官公庁で広く使用されているため、侵害された場合は組織全体のエンドポイントに影響が及ぶ可能性がある。連邦政府機関への期限付きパッチ適用義務と同様に、民間企業も同等の優先対応が強く推奨されている。

**開発者・運用者への影響**:
- FortiClient EMS（CVSS 9.1）はエンタープライズ VPN・ゼロトラスト環境の基盤となるため、即時パッチ確認および適用が必須
- Microsoft Defender に特権昇格経路が存在するという事実は、EDR ソリューション自体が攻撃対象になりうることを改めて示しており、セキュリティ製品の自動更新設定の見直しが必要

**出典**: [The Hacker News — CISA Adds 6 Known Exploited Flaws](https://thehackernews.com/2026/04/cisa-adds-6-known-exploited-flaws-in.html) / [CISA — KEV Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) / [SecurityWeek](https://www.securityweek.com/)

### OpenAI GPT-Rosalind — ライフサイエンス特化推論モデルのリサーチプレビュー公開

OpenAI はライフサイエンス領域に特化した推論モデル「GPT-Rosalind」のリサーチプレビューを公開した。生物学・創薬・トランスレーショナルメディシン（臨床応用研究）に最適化されており、生命科学論文データで追加学習することで標準的な GPT-5.4 よりも分子生物学・ゲノミクス・薬物動態学の問いに高精度で回答できるとされる。同時に 90 以上の新プラグイン（Atlassian Rovo・CircleCI・CodeRabbit・GitLab Issues・Microsoft Suite など）も追加公開されており、エンタープライズワークフローとの統合が加速している。

```python
from openai import OpenAI

client = OpenAI()

# GPT-Rosalind: ライフサイエンス特化推論モデル（リサーチプレビュー）
response = client.chat.completions.create(
    model="gpt-rosalind-preview",
    messages=[
        {
            "role": "system",
            "content": "You are a biomedical research assistant specializing in drug discovery.",
        },
        {
            "role": "user",
            "content": (
                "Summarize the mechanism of action and potential off-target effects "
                "of a KRAS G12C inhibitor."
            ),
        },
    ],
    reasoning_effort="high",  # ライフサイエンス向けに高精度推論を指定
)

print(response.choices[0].message.content)
```

### Fortinet FortiClient EMS — CVE-2026-21643（CVSS 9.1）が野外で積極悪用

Fortinet FortiClient EMS（エンドポイント管理サーバー）の CVE-2026-21643 は、認証不要の SQL インジェクション脆弱性で CVSS スコア 9.1 と極めて深刻だ。攻撃者は管理インターフェースを経由して任意のデータベースクエリを実行し、最終的にリモートコード実行（RCE）まで到達できることが確認されている。FortiClient EMS はゼロトラストアクセス管理や VPN 管理の基盤として大企業・官公庁で広く使用されており、Fortinet はパッチをリリース済みで CVE 公開に合わせた即時適用を強く推奨している。

### Microsoft Defender トリプル脆弱性 — BlueHammer・RedSun・UnDefend が野外悪用

脅威アクターが Microsoft Defender の 3 つの脆弱性（BlueHammer・RedSun・UnDefend）を悪用しており、特権昇格とサービス拒否攻撃が可能な状態であることが確認された。セキュリティ製品自体が攻撃対象となるこのケースは、EDR/EPP ソリューションの更新が通常業務アプリケーションと同等以上に優先される必要性を示している。Microsoft は先週の 4月 Patch Tuesday（167件修正）でこれらを修正済みだが、自動更新を無効化した環境やエアギャップ環境では手動での適用確認が必要だ。
