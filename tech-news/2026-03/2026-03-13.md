## ニュース一覧

### 1. OpenAI Codex Security -- AIによるコード脆弱性自動検出ツール
**カテゴリ**: セキュリティ / AI
**影響度**: ★★★★★

OpenAIが3月6日にCodex Securityをリサーチプレビューとして公開。AIエージェントがリポジトリ全体を分析し、脅威モデルを生成した上で脆弱性を検出・サンドボックスで検証・修正案を提示する3ステップの仕組み。過去30日間で120万コミットをスキャンし、約800件のCritical、10,561件の高深刻度の問題を発見した。ChatGPT Pro/Enterprise/Business/Eduユーザーは1ヶ月間無料で利用可能。

**個人開発者への影響**:
- セキュリティ専門家を雇えない個人・小規模チームでも、プロレベルの脆弱性検出が可能に
- 既存のSAST（Static Application Security Testing: 静的アプリケーションセキュリティテスト）ツールと比較して、コンテキストを理解した上での検出が強み
- **今すべきこと**: ChatGPT Pro以上のプランがあれば、自分のリポジトリでCodex Securityを試す。無料期間中に主要プロジェクトを一通りスキャンしておく

出典: [OpenAI公式](https://openai.com/index/codex-security-now-in-research-preview/) / [The Hacker News](https://thehackernews.com/2026/03/openai-codex-security-scanned-12.html)

### 2. Gemini CLI v0.33.0 -- Plan Modeが安定版に
**カテゴリ**: ツール / AI
**影響度**: ★★★★☆

GoogleのGemini CLIに「Plan Mode」が安定版として搭載された（3月5日発表、v0.33.0で3月11日リリース）。`/plan`と入力するだけで読み取り専用モードに切り替わり、AIがコードベースを調査・設計案を作成する。ファイル変更は一切行わないため安全。リサーチサブエージェント、アノテーション（フィードバック注釈）、MCP（Model Context Protocol）ツールとの連携にも対応。

**個人開発者への影響**:
- Claude CodeのPlanモードと同じコンセプト。AIコーディングツールの「まず計画、次に実装」パターンが業界標準化
- GitHub Issues、DBスキーマ、Google Docsなど外部ソースを参照しながら計画できる
- **今すべきこと**: Gemini CLIを未導入なら `npm install -g @anthropic-ai/gemini-cli` で試す。Claude Codeとの使い分けを検討

出典: [Google Developers Blog](https://developers.googleblog.com/plan-mode-now-available-in-gemini-cli/) / [Gemini CLI Docs](https://geminicli.com/docs/cli/plan-mode/)

### 3. Microsoft Patch Tuesday 3月 -- ゼロデイ2件を含む80件超の脆弱性修正
**カテゴリ**: セキュリティ
**影響度**: ★★★★★

3月10日のPatch Tuesdayで78〜84件の脆弱性が修正された。特に注意すべきは以下:
- **CVE-2026-21262**（ゼロデイ）: SQL Serverの権限昇格。ログイン済みユーザーがsysadmin権限を奪取可能
- **CVE-2026-26127**: .NET DoS脆弱性。パッチ前に詳細が公開済み
- **CVE-2026-26113 / CVE-2026-26110**: Office RCE（Remote Code Execution: リモートコード実行）。Criticalレベル

**個人開発者への影響**:
- SQL Serverを使っている場合は即座にパッチ適用が必要（本番環境のDB管理者権限が奪われるリスク）
- .NETアプリを公開している場合、DoS攻撃の対象になりうる
- Office文書を扱うWebサービスはRCE脆弱性に注意
- **今すべきこと**: Windows Updateを即実行。SQL Server利用者はCVE-2026-21262のパッチを最優先で適用

出典: [Cybersecurity News](https://cybersecuritynews.com/microsoft-patch-tuesday-march-2026/) / [Malwarebytes](https://www.malwarebytes.com/blog/news/2026/03/march-2026-patch-tuesday-fixes-two-zero-day-vulnerabilities)

### 4. Google、Wiz買収を320億ドルで完了 -- クラウドセキュリティが大幅強化
**カテゴリ**: クラウド / セキュリティ
**影響度**: ★★★★☆

Googleが3月11日、クラウドセキュリティ企業Wizの買収を正式完了。320億ドル（約4.8兆円）のオールキャッシュ取引はGoogle史上最大。Wizはマルチクラウド環境のセキュリティに強みを持ち、Google Cloud内で独立ブランドとして運営を継続する。

**個人開発者への影響**:
- Google Cloudユーザーは、Wizのセキュリティ機能が今後GCPに統合される恩恵を受けられる
- AWS/Azureを含むマルチクラウド環境のセキュリティ管理が一元化される可能性
- クラウドセキュリティの重要性がますます高まっている証拠。自分のインフラのセキュリティ見直しのきっかけに
- **今すべきこと**: GCPユーザーは今後のWiz統合機能の発表に注目。マルチクラウド利用者はセキュリティポリシーの統一を検討

出典: [TechCrunch](https://techcrunch.com/2026/03/11/google-completes-32b-acquisition-of-wiz/) / [Google Blog](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/wiz-acquisition/)

### 5. Claude Marketplace ローンチ -- Anthropicがエコシステムを拡大
**カテゴリ**: AI
**影響度**: ★★★★☆

AnthropicがClaude Marketplaceを正式ローンチ。企業が既存の支出コミットメントをClaude搭載アプリに充当できる仕組みで、GitLab、Harvey（法務AI）、Lovable（AIアプリビルダー）、Replit、Rogo、Snowflakeの6社がローンチパートナー。さらにClaude Partner Networkに1億ドルを投資し、The Anthropic Instituteを設立。

**個人開発者への影響**:
- Claude APIを使ったアプリをMarketplaceに出品できる可能性。新たな収益チャネルになりうる
- Lovable、Replitとの連携により、Claude搭載のノーコード/ローコードツールがさらに充実
- Anthropicのエコシステム拡大は、Claude APIの安定性・長期サポートへの信頼材料
- **今すべきこと**: Claude APIを使ったプロダクトがあれば、Marketplace出品の条件を確認。パートナープログラムの詳細をチェック

出典: [PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/anthropic-challenges-saas-giants-with-claude-marketplace/)

### 6. Qwen 3.5 Small -- 9Bパラメータで120Bモデルに匹敵するオープンソースLLM
**カテゴリ**: AI / オープンソース
**影響度**: ★★★★☆

Alibabaが3月1日にQwen 3.5 Smallシリーズ（0.8B/2B/4B/9Bの4モデル）をリリース。注目は9Bモデルで、13倍の規模を持つGPT-OSS-120Bとベンチマークで同等以上（GPQA Diamond: 81.7 vs 71.5）。Epoch AIの調査によれば、オープンウェイトモデルとプロプライエタリモデルの性能差は平均わずか3ヶ月にまで縮小している。

**個人開発者への影響**:

- コーディング、数学推論、一般チャットではオープンソースモデルがGPT-5やClaude Sonnet 4と競合するレベルに
- ファインチューニングによる特化型モデル開発のベースとして最適
- **今すべきこと**: Ollama等でQwen 3.5 9Bを試す。プライバシー重視のユースケースやオフライン用途での活用を検討
