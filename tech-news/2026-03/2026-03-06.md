## 🔐 セキュリティ

### **TriZetto データ流出事件：3.4 Million ユーザー影響**
健康保険技術企業 TriZetto が 2024 年のサイバー攻撃で 340 万人の個人・健康情報を流出させ、検知に **約 1 年間を要しました**。これは以下の教訓を提示：

1. **検知遅延の危険性**：攻撃後の早期発見体制が整っていないと、被害拡大を防ぎきれない
2. **個人開発の対策**：
   - WAF（Web Application Firewall）や IDS（異常通信検知）の最小限の運用
   - 定期的な依存ライブラリのセキュリティスキャン（`npm audit`, `pip-audit`）
   - CloudFlare One（本記事でも紹介）の DLP（データ流出防止）機能で API 経由の機密データ漏洩を検知可能

### **CloudFlare One の統合データセキュリティ**
- **RDP clipboard control**（リモートデスクトップのクリップボード制御）、**CASB（Cloud Access Security Brokerのこと=クラウド利用監視）** による Microsoft 365 Copilot 通信の スキャン機能を搭載
- DevOps 向けの**Operation-mapped logs**（操作に紐付いたログ記録）により、誰がどの機密リソースにアクセスしたかを追跡可能
- Next.js + Node.js バックエンドで本番環境に運用する際、API の認証・認可ログ収集を Cloudflare と統合することで検知遅延を回避できる

## 📚 用語集

| 用語 | 定義 |
|------|------|
| **CASB（Cloud Access Security Broker）** | クラウドアプリケーションへのアクセスを監視し、不正利用や情報漏洩を検知するセキュリティ機構 |
| **IDOR（Insecure Direct Object Reference）** | 認可チェック不足により、他ユーザーのリソースに直接アクセス可能な脆弱性 |
| **Auth Bypass** | 認証機構を迂回して、未認証のままシステムにアクセスできる脆弱性 |
| **DAU（Daily Active Users）** | 1 日単位でアプリを利用したユーザー数 |
| **Bun Lockfile** | パッケージ依存関係のバージョン情報を記録したファイル（npm の package-lock.json に相当） |
| **Monorepo（モノレポ）** | 複数のプロジェクト・パッケージを 1 つのリポジトリで管理する開発構成 |
| **DLP（Data Loss Prevention）** | 機密情報の不正流出を防止する仕組み |
| **WAF（Web Application Firewall）** | Web アプリケーション層の攻撃（SQL インジェクション等）を検出・ブロック |
| **IDS（Intrusion Detection System）** | ネットワーク上の異常通信や攻撃パターンを検知するシステム |
| **SAST（Static Application Security Testing）** | ソースコードを静的に分析して脆弱性を検出する手法 |
| **React Suspense** | 非同期データ取得完了まで UI 描画を遅延させ、fallback UI を表示する機構 |
| **CI/CD（Continuous Integration/Continuous Deployment）** | ソースコード変更時に自動でテスト・ビルド・デプロイを行うパイプライン |
| **Codex Security** | OpenAI が開発したコード脆弱性検出・修正 AI（研究プレビュー段階） |
| **Token Leak** | API キーや認証トークンが不適切に公開される脆弱性 |
| **Pentagon** | 米国国防総省を指す |
| **Autonomous Weapons** | 人間の指揮・統制なしに独立して動作する兵器システム |
