# AI専門家デイリーレポート 2026-03-30

## 本日のAIニュース TOP 3

### 1. Claude Mythos（コードネーム Capybara）がデータリークで存在が公式確認
3月26日に内部データのリークにより Anthropic の次世代モデル「Claude Mythos」の存在が明らかになった。3月27日に Anthropic が公式に存在を認め、サイバーセキュリティ株が急落。Mythos は Opus シリーズを超える新ティアのモデルで、コーディング・推論・サイバーセキュリティのベンチマークで Opus 4.6 を「大幅に上回る」と内部文書が説明。特にサイバーセキュリティ分野では「他のどのAIモデルよりも現在はるかに先行」という表現が使われており、ゼロデイ脆弱性の発見・攻撃面分析を自律実行できるとされる。現在は特定のサイバーセキュリティ防衛用途向けに選択された顧客のみに提供。

**個人開発者への影響**: Mythos の API アクセスが一般開放されれば、IDP/ドキュメント処理のパイプラインに高精度な推論を組み込める。現行モデルでの活用を先取りしておくことが差別化に直結する。

### 2. Claude Code に Computer Use・/loop・Voice Mode が相次いでリリース
3月中に Claude Code へ大型機能が連続投入された。

- **Computer Use**（3月23日、Pro/Max向け）: セットアップ不要でファイルを開いたりツールを起動・クリック・画面操作を自律実行
- **/loop コマンド**: インターバルとプロンプトを設定すると定期的に自律実行するセッションレベルの軽量 cron ジョブ
- **/voice コマンド**: プッシュトゥトーク方式の音声入力。スペースキー長押しで発話、離すと送信。9言語が追加

1M トークンコンテキストウィンドウ対応と Opus 4.6 がデフォルトモデルに昇格。最大出力トークンは Opus 4.6 で 64k、上限は 128k に拡張。

**個人開発者への影響**: /loop はビルド検証・ログ監視などの繰り返し作業の自動化に即使える。Computer Use は GUI 操作の自動化テストに応用できる。

### 3. Anthropic が 2026年Q4 IPO を検討・評価額 $380B・年間収益 $14B に到達
2月に $300億の Series G（評価額 $380B）を完了。Goldman Sachs 等と IPO の初期協議に入り、最短で 2026年10月の上場を目指しているとの報道。年間収益ランレートは約 $140億。

**個人開発者への影響**: IPO 前に Claude API の利用コストや利用規約が変動するリスクがある。マルチプロバイダー設計（Gemini / OpenAI への切り替え可能な抽象レイヤー）を組み込んでおくことを推奨。

## 新技術・新リリース

### Claude Code — 3月後半の主要更新

```bash
# /loop コマンド: 5分ごとにエラーログを確認して報告
claude
> /loop 300 "error.log に新しいエラーがあれば内容をまとめて"

# Computer Use の有効化確認（Pro/Max プラン必要）
claude config get computerUseEnabled

# Voice Mode の起動（スペースキー長押しで発話）
claude
> /voice

# 1M トークンコンテキストを使う場合
claude --model claude-sonnet-4-6 --context-window 1000000 "大規模コードベースを解析して"
```

### MCP エコシステム — Google Colab MCP サーバー公開

```bash
pip install colab-mcp-server
# ~/.claude/mcp_settings.json の "servers" に "colab" エントリを追加
```

MCP TypeScript SDK の依存プロジェクト数が 34,700 超。エコシステムが実質的なインフラになりつつある。

### Next.js 16.2.1 LTS — AI 対応強化

AI-ready create-next-app・ブラウザログフォワーディング・Adapter API 安定化・実験的 Agent DevTools を追加。

```bash
npm install next@16.2.1 react@latest react-dom@latest
```

### Docling（IBM）— Granite-Docling-258M モデル公開（Apache 2.0）

PDF・DOCX・PPTX・HTML の構造（テーブル・数式・レイアウト）を保持したまま JSON/Markdown に変換する 258M パラメータの軽量 VLM。GitHub Stars 37,000 超。

```bash
pip install docling

from docling.document_converter import DocumentConverter
converter = DocumentConverter()
result = converter.convert("input.pdf")
print(result.document.export_to_markdown())
```
