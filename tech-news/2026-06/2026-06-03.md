### 1. Microsoft Build 2026 Day 2 — MAI モデルファミリー 7 本と Majorana 2 量子プロセッサが登場

Build 2026 最終日（6 月 3 日）、Microsoft は自社開発モデルシリーズ **MAI（Microsoft AI）** を一挙に発表した。旗艦推論モデル **MAI-Thinking-1** はソフトウェアエンジニアリングベンチマークで最先端モデルに匹敵し、ブラインド人間選好評価では Claude Sonnet 4.6 と同等の性能を示す。コーディング特化の **MAI-Code-1** はすでに GitHub Copilot と VS Code に統合されて稼働中。他にも MAI-Image-2.5（画像編集）・MAI-Transcribe-1.5（43 言語音声認識）・MAI-Voice-2（15 言語以上対応音声合成）を含む計 7 本のモデルを公開した。オンデバイス向けには次世代 SLM **Aion 1.0 Instruct** と 140 億パラメータの推論・ツール呼び出しモデル **Aion 1.0 Plan** を Windows ローカル AI 基盤として提供する。さらに量子コンピューティング分野では **Majorana 2** プロセッサを発表。先代比 1,000 倍以上信頼性が高いトポロジカル量子ビットを採用し、量子ビット寿命がミリ秒から平均 20 秒（最長 1 分超）に向上した。Microsoft は 2029 年のスケーラブル量子コンピュータ実現を目標として掲げている。

### 2. GitHub Copilot がトークン課金へ移行 — $29/月から最大 $750+/月、開発者コミュニティで衝撃の声

GitHub Copilot は 6 月 1 日付けで**定額サブスクリプションからトークン消費ベースの従量課金（GitHub AI Credits）へ移行**した。各プランには月額料金相当の AI クレジット（1 クレジット＝$0.01）が付属し、上限超過分は API のトークン単価で課金される。コード補完・Next Edit Suggestions は引き続き全プラン無料だが、チャット・エージェントモード・コードレビューの AI 機能が課金対象となる。Reddit・X・GitHub ディスカッションでは「$29 → $750/月」「$50 → $3,000/月」という報告が相次ぎ、特に agentic ワークフローを多用するエンジニアへの影響が顕著だ。TechCrunch は開発者コミュニティの批判を「'What a joke'」と見出しで伝えており、代替ツール（Cursor・Windsurf 等）への乗り換え検討が加速している。

### Rust 1.96.0 リリース — Copy Range Types・新アサーションマクロ・Cargo セキュリティ修正

**Rust 1.96.0** が 5 月 28 日にリリースされた（Hacker News 等でのリアクションは本日 6/3 にピーク）。最大の変更は **RFC 3550 による Copy Range Types の実装**で、`Range<T>` などのレンジ型が `Iterator` ではなく `IntoIterator` を実装するよう変更され、`Copy` トレイトを持てるようになった。これにより for ループ後もレンジ値を再利用できるという長年の不便が解消される。加えて 2 つの新アサーションマクロが安定化され、WebAssembly リンク時の未定義シンボルを早期に拒否するよう改善された。セキュリティ面では Cargo のサードパーティレジストリ向けに **CVE-2026-5223**（crate tarball のシンボリックリンク展開、中程度）と **CVE-2026-5222**（正規化 URL での認証、低程度）の 2 件を修正。crates.io 利用者への影響はない。

```rust
// Rust 1.96.0: Copy Range Types — ループ後にレンジを再利用できる
fn sum_twice(n: u32) -> u32 {
    let range = 1..=n; // Range<u32> は Copy になったので move されない
    let first: u32  = range.into_iter().sum();
    let second: u32 = range.into_iter().sum(); // 1.95.0 以前はコンパイルエラー
    first + second
}

// 新アサーションマクロ (assert_matches! 相当が安定化)
use std::assert_matches::assert_matches;

fn classify(score: u32) -> &'static str {
    match score {
        90..=100 => "A",
        70..=89  => "B",
        _        => "C",
    }
}

#[test]
fn test_classify() {
    assert_matches!(classify(95), "A");
    assert_matches!(classify(75), "B" | "A"); // パターンマッチで OR も使える
}
```

```bash
# Cargo セキュリティ修正の確認（CVE-2026-5223 / CVE-2026-5222）
# サードパーティレジストリ使用者は即時アップグレードを推奨

```

## セキュリティ

### Microsoft Defender CVE-2026-41091（CVSS 7.8）— CISA KEV 期限本日・SYSTEM 権限昇格に悪用

CISA の KEV（既知悪用脆弱性）カタログに登録された **CVE-2026-41091**（Microsoft Defender、CVSS: **7.8 High**）の連邦機関向け対応期限が本日 6 月 3 日だ。悪用に成功した攻撃者は対象システムで **SYSTEM 権限**を取得できる。同時に登録された **CVE-2026-45498**（CVSS: 4.0、DoS）も Defender に影響する。加えて Google の Android 6 月セキュリティ情報では **124 件のパッチ**が提供され、うち **CVE-2025-48595**（Android/Linux カーネル整数オーバーフロー、CVSS: **8.4 High**）は標的型攻撃での実被害が確認済みで CISA KEV に 6 月 2 日追加済み。2026 年上半期の CVE 開示数はすでに **21,500 件超**（前年比 +16〜18%）に達しており、組織のパッチ運用コストが構造的に上昇している。

```bash
# --- Defender CVE-2026-41091 / CVE-2026-45498 対応チェック ---

# 1. Windows Update の適用状況を確認
Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 10

# 2. Defender の定義バージョン・エンジンバージョンを確認
Get-MpComputerStatus | Select-Object AMProductVersion, AMEngineVersion, AntivirusSignatureVersion

# 3. Windows Update を強制実行（PowerShell、管理者権限）
Install-Module PSWindowsUpdate -Force -Scope CurrentUser
Get-WindowsUpdate -AcceptAll -Install -AutoReboot

# --- Android CVE-2025-48595 対応 ---
# デバイスの Android セキュリティパッチレベルが 2026-06-05 以降であることを確認
# 設定 > 端末情報 > Android セキュリティパッチレベル
# adb で確認する場合:
adb shell getprop ro.build.version.security_patch
# 期待値: 2026-06-05 以降
```

**影響範囲と優先度**: CVE-2026-41091 は CISA の KEV 期限が本日であり、FCEB（連邦民間行政機関）は即時対応必須。民間組織も今週中の適用を強く推奨。Android CVE-2025-48595 は標的型攻撃での悪用が確認されており、エンタープライズ MDM による端末パッチ状況の集中管理が急務だ。
