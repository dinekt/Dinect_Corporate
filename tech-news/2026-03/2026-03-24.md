## ニュース一覧

### 1. Langflow CVE-2026-33017 -- 認証不要RCEが公開20時間で攻撃開始
**カテゴリ**: セキュリティ / AI基盤
**影響度**: ★★★★★

AIワークフロー構築ツールLangflowに認証バイパスとリモートコード実行の脆弱性（CVSS 9.3）。Sysdigの調査により、脆弱性の公開からわずか20時間で実際の攻撃が確認された。

**攻撃の仕組み**:
- 認証なしでLangflowの内部APIにアクセス可能
- AIパイプラインの実行コンテキストで任意コード実行
- CI/CDパイプラインやクラウド環境のシークレット窃取が目的

**対処**:
- Langflowを使用している場合は即時アップデート
- 公開インターネットからのアクセスを遮断
- AIツールのデプロイ時は認証・ネットワーク分離を徹底

**教訓**: AIツールの急速な普及に伴い、「とりあえずデプロイ」の姿勢が攻撃対象面を広げている。開発用ツールでも本番環境と同等のセキュリティ対策が必要。

> 出典: [The Hacker News](https://thehackernews.com/2026/03/critical-langflow-flaw-cve-2026-33017.html) / [Sysdig](https://www.sysdig.com/blog/cve-2026-33017-how-attackers-compromised-langflow-ai-pipelines-in-20-hours)

### 2. VMware Aria Operations CVE-2026-22719 -- CISA KEVカタログ登録、連邦機関の修正期限到来
**カテゴリ**: セキュリティ / インフラ
**影響度**: ★★★★☆

VMware Aria Operationsの脆弱性がCISA Known Exploited Vulnerabilities（KEV）カタログに登録。連邦機関の修正期限が本日3/24。積極的な悪用が確認されており、VMware環境を運用する組織は早急なパッチ適用が必要。

**対処**:
- VMware Aria Operationsの最新パッチを適用
- VMware環境の管理コンソールへのアクセス制限を確認

> 出典: [The Hacker News](https://thehackernews.com/2026/03/cisa-adds-actively-exploited-vmware.html)

### 3. OpenAI Codex Security -- 120万コミットから高重大度脆弱性1万件超を検出
**カテゴリ**: AI / セキュリティ
**影響度**: ★★★★☆

OpenAIが「Codex Security」のリサーチプレビューを公開。120万コミットを走査し、高重大度のセキュリティ脆弱性を10,561件検出した。従来のSAST（静的解析）ツールでは検出困難なパターンも含まれる。

**注目点**:
- コミット単位の差分解析で「新たに導入された脆弱性」を特定
- LLMのコード理解能力を活用し、文脈依存の脆弱性パターンを検出
- 偽陽性率の低減に注力（従来SASTの最大の課題）

**含意**: AI生成コードの増加に伴い、「AIが書いたコードをAIがレビューする」ワークフローが現実化。ただし、AI検出結果の人間によるトリアージは依然として必要。

> 出典: [The Hacker News](https://thehackernews.com/2026/03/openai-codex-security-scanned-12.html) / [OpenAI](https://openai.com/index/codex-security-now-in-research-preview/)

### 4. Microsoft Agent Framework RC -- Semantic KernelとAutoGenが統合、メンテナンスモード移行
**カテゴリ**: AI / 開発ツール
**影響度**: ★★★★☆

MicrosoftがAgent FrameworkのRelease Candidateを公開。これまで別々に開発されていたSemantic KernelとAutoGenが統一フレームワークに統合された。旧Semantic KernelとAutoGenはメンテナンスモードに移行。

**影響**:
- 既存のSemantic Kernel / AutoGenプロジェクトはメンテナンスモードで継続サポート
- 新規プロジェクトはAgent Frameworkへの移行を推奨
- マルチエージェントオーケストレーションが標準機能として統合

**含意**: エージェントフレームワークの統合は業界トレンド。Google（ADK）、OpenAI（Agents SDK）、Microsoft（Agent Framework）と大手3社がすべてエージェント基盤を整備した。

> 出典: [Subagentic AI](https://subagentic.ai/howtos/microsoft-agent-framework-rc-autogen-semantic-kernel/)

### 6. Java 26リリース -- HTTP/3・ポスト量子暗号対応・Applet API完全削除
**カテゴリ**: プログラミング言語
**影響度**: ★★★★☆

Java 26が正式リリース。主な変更点:

| 機能 | 詳細 |
|------|------|
| HTTP/3対応 | `java.net.http`クライアントがHTTP/3をネイティブサポート |
| ポスト量子暗号 | ML-KEM（旧CRYSTALS-Kyber）とML-DSA対応 |
| Applet API削除 | `java.applet`パッケージが完全削除 |
| パターンマッチング拡張 | `switch`式でのプリミティブ型パターンマッチング |

**含意**: ポスト量子暗号のJDK標準搭載により、「量子コンピュータ時代への備え」がJavaエコシステムで本格化。

> 出典: [InfoQ](https://www.infoq.com/news/2026/03/java26-released/)
