### 2. Microsoft が史上最大の Patch Tuesday を公開 — 974件の CVE を修正、Windows ALPC と Update Stack で野生の悪用ゼロデイ2件

9月8日にリリースされた Microsoft September 2026 Patch Tuesday は **974件の CVE** を修正する史上最大規模のアップデートとなり、7月の記録（621件）を57%上回った。深刻度別では **Critical 113件・Important 860件**が含まれる。特に注目されるのは、実際に野生で悪用が確認されている2件のゼロデイ脆弱性だ。**CVE-2026-85880**（Windows Advanced Local Procedure Call の ヒープベースバッファオーバーフロー、CVSS 7.8）は、認証済み攻撃者がローカルで権限昇格できる Elevation of Privilege（EoP）脆弱性。**CVE-2026-81963**（Windows Update Stack のリンクフォロー欠陥、CVSS 7.8）も同じく EoP で、ローカル攻撃者が SYSTEM 権限を奪取できる。両脆弱性は CISA の既知悪用脆弱性（KEV）カタログに同時追加されており、連邦文官機関（FCEB）への適用期限も設定された。加えて本リリースには「ワーム感染が可能」と評価される脆弱性も**20件**含まれており、各組織は2件のゼロデイを最優先にパッチを適用したうえで、ネットワーク経由の攻撃面についても評価が求められる。

## 新技術・新リリース

### Mistral Medium 3.5 — オープンウェイトモデルでクローズドモデルに匹敵するコーディング性能

Mistral AI の最新フラッグシップ **Mistral Medium 3.5** は、パラメータ数が数倍の大規模クローズドモデルを一部のコーディングベンチマークで上回る性能を発揮している。Mistral は Apache 2.0 ライセンスで重みを公開しており、ローカル展開・ファインチューニング・商用利用のすべてが可能だ。

```python
# Mistral Medium 3.5 をローカル推論で利用する例（llama-cpp-python 経由）
from llama_cpp import Llama

# モデルをローカルに配置済みと仮定
llm = Llama(
    model_path="./mistral-medium-3.5.gguf",
    n_ctx=32768,        # 最大コンテキスト長 32K
    n_gpu_layers=-1,    # GPU を最大限活用
)

response = llm.create_chat_completion(
    messages=[
        {
            "role": "system",
            "content": "あなたは優秀なソフトウェアエンジニアです。"
        },
        {
            "role": "user",
            "content": "Python で非同期 HTTP クライアントを実装してください。"
        }
    ],
    max_tokens=1024,
    temperature=0.2,
)

print(response["choices"][0]["message"]["content"])
```

```python
# Mistral API 経由（クラウド利用）
from mistralai import Mistral

client = Mistral(api_key="YOUR_MISTRAL_API_KEY")

chat_response = client.chat.complete(
    model="mistral-medium-3.5",
    messages=[
        {"role": "user", "content": "SQLインジェクションを防ぐ安全なクエリの書き方を教えてください"}
    ],
)
print(chat_response.choices[0].message.content)
```

オープンウェイトモデルの性能向上は、プロプライエタリモデルへの依存を避けたい組織にとって実用的な選択肢を大幅に広げており、特に主権 AI・オンプレミス要件を持つ欧州機関での採用が加速している。

### UNC3569 が Sogou IME の CVE-2026-51990 を悪用し GrayRabbit バックドアを展開 — ワンクリックでリモート制御を確立

```text

【Windows 全環境 — Microsoft Patch Tuesday September 2026】
CVE-2026-85880 (CVSS 7.8, EoP) — Windows ALPC ヒープバッファオーバーフロー
  攻撃手法: 認証済みローカル攻撃者が権限昇格（野生で悪用確認済み）

CVE-2026-81963 (CVSS 7.8, EoP) — Windows Update Stack リンクフォロー欠陥
  攻撃手法: ローカル攻撃者が SYSTEM 権限を取得（野生で悪用確認済み）

  ※ 本月は「ワーム可能」バグが20件含まれるため、優先度評価を徹底すること

【Sogou Input Method (Windows版) を利用する環境】
CVE-2026-51990 (RCE) — 攻撃グループ UNC3569 が野生で悪用中

  攻撃手法: 細工リンクのクリックのみで GrayRabbit バックドアを展開

  脅威アクター: UNC3569（中国アライン・スパイ目的）
  修正済みバージョン: 16.3.0.3498（自動更新で配布済み）
  対処: 最新バージョンへの更新を確認 / 不要なら削除を検討
```

Gen Threat Labs が今週公開したレポートによると、中国と関連するとされる **UNC3569** グループが Sogou Input Method の重大な脆弱性（CVE-2026-51990）を悪用し、被害者端末に **GRAYRABBIT バックドア**を展開していることが明らかになった。Sogou IME は数億台のデバイスで使用されている中国語入力ソフトウェアで、この脆弱性は「未検証のコマンドライン引数インジェクション」「制限なしの URL ナビゲーション」「古くサンドボックス化されていない Chromium エンジン」という3つの欠陥を連鎖させたワンクリック RCE だ。GrayRabbit は少なくとも2021年から UNC3569 の侵入事例で継続的に観測されており、逆シェルの確立・プラグインのロード・ファイル流出・システム情報収集など幅広い攻撃能力を持つ。Tencent は Gen Threat Labs の通報（4月9日）を受けてバージョン 16.3.0.3498 で修正を配布済みだが、自動更新が適用されているか各環境での確認が推奨される。加えて前日から続く Microsoft Patch Tuesday の対応と合わせ、今週は Windows エンドポイント全般における集中的なパッチ適用が求められる週となっている。
