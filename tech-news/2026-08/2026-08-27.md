### EU AI Act 透明性義務が本格施行 — チャットボット開示・合成コンテンツマーキングが法的義務に

2026 年 7 月 27 日に Official Journal に掲載された Regulation (EU) 2026/1744（Digital Omnibus on Artificial Intelligence）を受け、EU AI Act の **Article 50（透明性義務）** が 2026 年 8 月 2 日より執行フェーズに入った。具体的には、AI によって生成されたコンテンツであることの明示（合成コンテンツマーキング）、チャットボットが AI であることの開示（Chatbot Disclosure）、ディープフェイクへのラベリングが義務化された。違反した場合は全世界年間売上高の最大 1.5% の制裁金が科される。一方、米国は引き続き自主的な標準（Voluntary Standards）を基本方針とし、EU との規制アプローチの乖離が鮮明になっている。国連主導の **Global Dialogue on AI Governance** および **Independent International Scientific Panel on AI** も本格的な議論を開始しており、2026 年は AI ガバナンスが初めて「共有グローバル課題」として扱われる年と位置づけられつつある。

```python
# EU AI Act Article 50 準拠チェックリスト（チャットボット実装例）
from enum import Enum
from dataclasses import dataclass

class ContentType(Enum):
    TEXT = "text"
    IMAGE = "image"
    VIDEO = "video"
    AUDIO = "audio"

@dataclass
class AIContentDisclosure:
    content_type: ContentType
    is_ai_generated: bool
    model_provider: str | None = None

    def get_required_label(self) -> str:
        """Article 50 準拠ラベルを返す"""
        if not self.is_ai_generated:
            return ""
        labels = {
            ContentType.TEXT: "このコンテンツは AI により生成されました",
            ContentType.IMAGE: "AI 生成画像 | AI-generated image",
            ContentType.VIDEO: "AI 生成映像 | Synthetic media",
            ContentType.AUDIO: "AI 生成音声 | AI-synthesized audio",
        }
        return labels[self.content_type]

    def is_compliant(self) -> bool:
        """EU AI Act Article 50 コンプライアンス確認"""
        if self.is_ai_generated and not self.get_required_label():
            return False
        return True

# チャットボット開示の例
chatbot_response = AIContentDisclosure(
    content_type=ContentType.TEXT,
    is_ai_generated=True,
    model_provider="example-provider",
)
print(chatbot_response.get_required_label())
# → "このコンテンツは AI により生成されました"
print(chatbot_response.is_compliant())  # True
```
